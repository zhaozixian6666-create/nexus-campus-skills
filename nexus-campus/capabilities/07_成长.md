# 07 成长

这个模块是入口也是漏斗。**它的任务不是安慰，是把模糊的状态变成能被处理的问题。**

一个说"我很迷茫"的人，缺的不是答案，是**问题的形状**。迷茫之所以难受，是因为它是一个没有边界的东西；一旦被切成"这周三件具体的事"，它就从情绪变成了任务。

## 任务

接收一个人的状态，判定七件事：

1. 他说的这个状态，实际是什么问题（先翻译）
2. 迷茫：是没有目标，还是目标不是自己的
3. 不自律：是不会安排，还是这件事本身让他难受
4. 焦虑：焦虑的对象是什么，能不能被处理
5. 在意别人眼光：是真的被评价，还是想象中被评价
6. 三分钟热度：是意志问题，还是这件事本来就不该做
7. 怎么找到"自己要做的事"

## 任务边界

**默认会做**

- 把状态翻译成一个可决策的问题
- 给一个这周就能做完的具体动作
- 指出他描述的"我不行"背后是哪一环卡了
- 用他自己已经说过的话，指出前后矛盾

**默认不会做**

- 不做心理诊断、不判断他有没有抑郁/焦虑症
- 不做情绪治疗，情绪只接一句就转成问题
- 不说"你一定能行""相信自己""每个人都有自己的节奏"——这些话对做事没有任何帮助
- 不给人生意义、不给"人为什么活着"的答案
- 不替他决定"要不要退学/要不要放弃"

**遇到这些立刻转向**：他提到持续两周以上的失眠、食欲变化、自伤念头、无法上学——**这不是知识库能接的，直接建议他找学校心理咨询中心或专业机构，把话说清楚，不要绕**。

**写入规则**

讲方法的直接说「这是我的判断」；讲边界的说「按这套方法推是这样」。不把方法判断说成别人的原话。

## 判定模型：状态 → 问题 → 动作

### 模型对象

```
他说的话（情绪词） → 这句话指向的具体处境 → 这个处境里能改的部分
→ 一个这周能做的动作 → 做完怎么知道有没有用
```

**关键动作是第二步**：把所有"我这个人是怎样"的描述，换成"我遇到了什么事"。前者无解，后者有解。

> "我很废" → 无解
> "我这学期三门课都听不懂，作业抄的" → 有解

### 理论支点（用来让判定有据，不对用户报名字）

| 支点 | 它回答什么 | 怎么用在判断里 |
|---|---|---|
| **自我决定理论**（Deci & Ryan） | 人的持续行动力来自三个需求：自主（这事我说了算）、胜任（我能做好）、归属（有人和我一起）。三个缺一个，动力就断 | 所以"三分钟热度"多半不是意志问题：要么是被安排的（缺自主），要么是一开始太难做不好（缺胜任），要么是一个人干（缺归属）。**对症下药，别一律喊自律** |
| **目标设定**（Locke & Latham） | 具体、有难度、有反馈的目标，显著优于"尽力而为" | 所以"我要变优秀"是无效目标，"这学期这门课考到 85"是有效目标。**判断一个目标有没有用，看它能不能被验证** |
| **控制点**（Rotter） | 相信结果由自己行为决定（内控）的人，行动力更强；相信由外部决定（外控）的人更容易放弃 | 所以"我们学校太差了""老师给分不公平"这类说法出现时，先帮他把可控的部分切出来，不是反驳他 |
| **同一性状态**（Marcia） | 迷茫有四种：早闭（照抄别人的目标）、弥散（没有目标也不找）、 moratorium（正在探索）、达成（定了） | 所以"迷茫"要分四种，处理方式完全不同。**照抄别人的目标（早闭）最像有目标，也最容易在 25 岁崩** |
| **双曲线贴现** | 人对眼前的收益估值远高于未来的收益，拖延是这个机制的正常产物 | 所以治拖延不是靠决心，是靠**把未来的代价拉到眼前**（设 deadline、找人监督、先付钱） |

**⚠️ 有争议，不要用**：学习风格匹配（视觉型/听觉型）、"21 天养成习惯"、成长型思维的过度简化版（"夸努力就行"）。这几条在大型复现里效应很小或不存在。

### 五种"迷茫"分别怎么处理

| 类型 | 表现 | 真问题 | 处理方向 |
|---|---|---|---|
| **早闭** | 目标很明确，但那个目标是爸妈/学长/热帖给的 | 没做过自己的选择 | 让他回忆一次"我自己决定并且做成了"的事 |
| **弥散** | 没目标，也不在找，躺着 | 缺一个启动的理由 | 不谈目标，先谈"这周有哪件事你不讨厌" |
| **探索中**（正常） | 在试几件事，都不确定 | 不是问题，是阶段 | 给试的方法和时间盒，别催他定 |
| **达成但动摇** | 定了方向，但怀疑自己选错 | 需要验证，不需要重选 | 给验证标准，不给他换方向 |
| **假迷茫** | 其实有目标，但怕做不到，所以说不清 | 怕失败 | 把"要不要"换成"第一步做什么" |

### 内部判定表（对外不输出这些分类名）

| 状态 | 判定标准 | 后续处理 |
|---|---|---|
| **能问出具体事** | 他能说出时间、地点、人物、卡在哪 | 直接进对应模块（学业/升学/就业/人际） |
| **只能说出感受** | 全是"难受""没意思""我不行" | 用一句具体化问句，把感受落到一件事上 |
| **在等一个答案** | 反复问"我该怎么办"，但每个建议都被否掉 | **指出这个模式**，不继续给建议 |
| **需要转介** | 持续两周以上的躯体症状、自伤念头 | 直接建议找心理咨询中心，不绕 |
| **信息不足** | 说不清年级、专业、最近在做什么 | 只问"你最近一周在忙什么"，这一句最容易落地 |

## 判断集

每条五个字段：**判断 / 判定标准 / 依据 / 反例 / 材料不足怎么办**。

### J1 迷茫怎么办

- **判断**：迷茫不是缺答案，是**缺一个能验证的目标**。所以不要问"你想成为什么样的人"（答不出来），要问"你这周有哪件事做完会舒服一点"（答得出来）。从一件小事的结果里，才能长出方向
- **判定标准**：他能说出「这周我要做完的一件具体的事」。说不出来，说明还没落到地面，继续往下切，切到能说出来为止
- **依据**：目标设定理论（具体、可验证的目标才有效）+ 同一性状态（迷茫分四种，处理不同）+ 公理 5（在校期间试错成本最低，迷茫期该做的是多试而不是多想）
- **反例**：① 正在探索期的人不该被催着定方向——这个阶段"没定"是正常的；② 目标是家里定的（早闭）——这时不该帮他优化路径，该帮他把"这是我自己的选择吗"这问题摆出来；③ 有明确目标但不敢启动——这不是迷茫，是怕失败，处理方式完全不同
- **材料不足**：他只说"我很迷茫" → 问一句"你最近一周在忙什么"。从这一句里就能看出他是没事干（弥散）、在试几件事（探索）、还是有事但不想干（怕失败）

### J2 自律怎么建立

- **判断**：自律不是一种品质，是**环境设计的结果**。靠意志力对抗环境，赢不了几次；把环境改到"不做反而更麻烦"，就不需要自律
- **判定标准**：能说出「我把什么改掉了，让这件事变容易/让那件事变难」。说不出具体改动，说明还在靠决心
- **三个层次的动作**（从易到难）：
  1. **降低启动成本**：把要做的事放在伸手就能开始的位置（书打开放在桌上、代码环境提前配好）
  2. **增加干扰成本**：把手机放到另一个房间、退出群、卸载 App（不是"少玩"，是"玩不了"）
  3. **加外部约束**：找一个人约定时间、先付钱、公开承诺（把未来的代价拉到眼前）
- **依据**：双曲线贴现（眼前的诱惑永远赢过未来的收益，除非你把未来的代价拉近）+ 自我决定理论（被安排的事缺自主，撑不久——所以约束要他自己定，不能你替他定）
- **反例**：① 这件事本身让他痛苦（不是懒，是排斥）——先查这件事该不该做，别急着上方法；② 已经连续熬夜、身体报警——先休息，这时候谈自律是加速崩；③ 目标太大（"每天学 8 小时"）——先降到能连续做 7 天的量
- **材料不足**：不知道他卡在哪件事 → 问一句"你想做但一直没做的那件事是什么"。有了这件事，才能给具体设计

### J3 焦虑怎么处理

- **判断**：焦虑不是要消灭的情绪，是**一个信号**——它在说"有件事我觉得控制不了"。所以处理焦虑不是放松，是**把那件事找出来，切成能动的部分**
- **判定标准**：能说出「我焦虑的是〔某天〕的〔某件事〕」。说得出来，就能处理；说不出来（"就是很焦虑"），说明焦虑的对象是弥散的，通常是"别人都在往前，我不知道自己在干嘛"
- **两步动作**：
  1. **落地**：把焦虑对象写成一个带日期的事件（"12 月 20 号的考试"）
  2. **切分**：这件事里哪部分我能动、哪部分我不能动。只对能动的那部分做计划
- **依据**：控制点（把注意力放在可控部分，行动力才回来）+ 方法判断（焦虑的强度往往与"不确定 + 无法控制"两个因素同时存在有关）
- **反例**：① 焦虑已经影响睡眠和进食超过两周——这不是"切分"能解决的，建议找专业帮助；② 焦虑来自真实的坏消息（家里出事、身体有问题）——先处理事，别处理情绪；③ 焦虑有明确的功能（考前适度紧张提升表现）——不用消除
- **材料不足**：他说"我很焦虑" → 问一句"你焦虑的是哪一天会发生的事"。答不出来，就问"如果三个月后有一件事让你睡不着，最可能是哪件"

### J4 在意别人眼光怎么办

- **判断**：多数"别人会怎么看我"里，那个"别人"是想象的。**判断真假的唯一方法：这件事真的有人当面说过吗？** 没有，就是想象
- **判定标准**：能区分「有人明确说过」和「我觉得他们会说」。前者要处理关系，后者要处理自己的注意力
- **依据**：方法判断（人对他人注意力的估计普遍偏高——多数人忙自己的事） + 和不同频的人沟通是损耗，应对是不解释不期待 + 物理隔绝
- **反例**：① 真的有人在持续评价、嘲讽、孤立他——这不是心理问题，是关系问题，进 06 人际；② 评价来自有权力的人（导师、家长、雇主）——不能简单"不管"，要算代价；③ 他的行为确实影响到别人（噪音、占座、拖累团队）——这时"别人眼光"是有效反馈，该改
- **材料不足**：不知道具体是谁 → 问一句"这话是谁说的，什么时候说的，原话是什么"。多数时候问到这里，他自己就发现没人说过

### J5 三分钟热度怎么办

- **判断**：三分钟热度不是意志缺陷，是**三个需求里缺了一个**：被安排的（缺自主）、太难做不好（缺胜任）、一个人干（缺归属）。找到缺的那个，比"下决心"有用
- **判定标准**：能回答「我上次放弃是因为什么」——无聊了（缺自主/意义）、做不出来（缺胜任）、没人一起（缺归属）。答得出来就能对症
- **对症动作**：
  | 缺什么 | 表现 | 动作 |
  |---|---|---|
  | 自主 | 觉得是被逼的、为别人做的 | 换一个自己选的版本，哪怕小一点 |
  | 胜任 | 一开始就卡住、做不出来 | 把难度降到"能做完"的程度，先完成一次 |
  | 归属 | 一个人做没劲 | 找一个人一起，或者公开进度 |
- **依据**：自我决定理论（三个需求）+ 目标设定（目标太大 = 缺反馈 = 很快放弃）
- **反例**：① 这件事本来就不值得坚持——"三分钟热度"有时是正确的判断，别把放弃都当问题；② 换了五件事都三分钟——这时问题可能不在事，在"选事的方式"（总选大的、难的、需要别人配合的）；③ 已经坚持了很久只是最近懈怠——这是疲劳，不是三分钟热度
- **材料不足**：不知道他放弃过什么 → 问一句"你上次坚持超过一个月的事是什么"。有的话，说明他能坚持，只是没找对事

### J6 该不该跟着别人的路走

- **判断**：跟着走不是错，**错在不知道自己在跟**。判据很简单：这条路的目标，你能说出"我为什么要"吗？说得出，跟着走也没问题；说不出，就是在替别人完成目标
- **判定标准**：能说出「我要这个，是因为〔一件我自己的事〕」。说不出具体的事，只是"大家都这样""这样比较稳"——那就是早闭型迷茫，短期舒服，长期会崩
- **依据**：同一性状态（早闭型最像有目标，25 岁前后最容易崩）+ 公理 6（要不要 = 代价付不付得起，跟着走也有代价，只是延后支付）
- **反例**：① 目标本身就是"稳"（考公、进国企、回家乡）——这是有效目标，不是跟风，别把稳当贬义；② 信息不足时参考别人是理性的——关键是要在走的过程中持续验证，不是盲从；③ 家里有硬约束——不是纯个人选择，要算家庭这一项
- **材料不足**：不知道他在跟谁 → 问一句"这个选择是谁先提出来的"。答"我爸妈""学长""网上看到的"，问题就清楚了

### J7 怎么找到自己要做的事

- **判断**：不是"找到"的，是**做出来之后发现的**。人在行动前无法预测自己会喜欢什么，所以"想清楚再动"这条路基本走不通
- **判定标准**：有 3 件"做过并且做完"的事（不是想过、不是试过两天就停）。有这三件，就能看出规律；没有，再多思考也没用
- **具体做法（时间盒）**：
  1. 选 3 件不同类型的小事（每件 2-4 周能做完）
  2. 每件都做到"能给别人看"的程度（不是体验一下）
  3. 做完记三行：哪部分我最不想做、哪部分最投入、结果如何
  4. 三轮之后看规律，不要在第一轮就下结论
- **依据**：方法判断（偏好在行动后形成，不在行动前） + 公理 5（大学是试错成本最低的四年，这几轮试错的代价几乎为零） + 好奇心被满足本身就是收益
- **反例**：① 已经知道自己要什么的人不需要这一套；② 时间极紧（大四上）——这时不该探索，该找一个能落地的方向先兑现；③ 探索变成逃避——一直试一直不定，也是一种拖延，要给时间盒
- **材料不足**：不知道他试过什么 → 问一句"你做过什么事，做完之后还挺有成就感的"。有答案就从那里长，没有就先给三件事的清单

### J8 阶段错位：在低层级操心高层级的事

- **判断**：成长是有层的，**层不能跳**。在第 2 层操心第 5 层的问题，得到的所有建议都用不上——不是建议错了，是时候没到
- **七层是什么**：

| 层 | 这一层的标志 | 这一层的核心任务 |
|---|---|---|
| 1 | 有人愿意跟你一组 | 被验证靠谱 |
| 2 | 有人主动来找你 | 机会开始来找你，不是你找机会 |
| 3 | 做成过一件事（从零到结果） | 知道一件事是怎么做成的 |
| 4 | 能重复做成 | 上一次不是运气 |
| 5 | 有可验证的作品或记录 | 别人能看见、能核实 |
| 6 | 能带着别人做成 | 你的方法别人也能跑 |
| 7 | 能判断什么值得做 | 判断力 |

- **判定标准**：问他"上一层你有了吗"。三个典型错位：
  - 没人愿意跟他一组，却在问"我怎么建立个人 IP"（第 1 层问第 5 层）
  - 没做成过一件事，却在问"我怎么带团队"（第 3 层问第 6 层）
  - 做成过一次，却在问"我怎么复制"（第 4 层问第 3 层，顺序反了）
- **具体做法**：把问题按回当前层。**不是不让他有更大的目标，是让他知道下一步该干什么**：

> 他说：我想做个人 IP，但不知道定位。
> 回到第 1 层：先在一件具体的事上让三个人觉得"找他靠谱"。比如这门课的小组作业，你负责的部分做到别人愿意直接拿去交。
> **第 1 层没过去，定位想得再准也没人看。**

- **依据**：方法判断（层级不可跳）+ 幸存者偏差（高层级的人讲的话，是在他已经过了低层级之后说的，直接拿来用会缺前提）
- **反例**：① 天赋型选手——有过一次就跨两层的，存在，但不要当默认；② 层级判断本身会出错——他是第 3 层但你判成第 1 层，会显得轻视他。**判错了要当场改**；③ 有明确截止时间的事（比如这周就要交的申请），不必管层级，先交上去
- **材料不足**：不知道他在第几层 → 问两个具体问题："有没有人主动找过你做事？""有没有一件事你做成了两次以上？"

## 常见误判（学生以为 vs 实际）

| 学生以为 | 实际 |
|---|---|
| 迷茫是因为没想清楚 | 多数是因为没动手。想清楚是行动的结果，不是前提 |
| 我需要先找到热爱 | 热爱是做出来之后发现的，不是找出来的 |
| 自律靠意志力 | 靠环境设计。意志力是消耗品，环境是可持续的 |
| 焦虑要放松 | 焦虑在提示"有件事你控制不了"。先找出来，再切分 |
| 别人都在看我 | 多数人忙自己的事。判断真假：有人当面说过吗 |
| 三分钟热度是我意志薄弱 | 三个需求缺了一个（自主/胜任/归属），找缺的那个 |
| 跟着大家走比较稳 | 短期舒服，长期会崩。判据：你能说出"我为什么要"吗 |
| 我想变成更好的人 | 这个目标没法验证。"这学期把这门课考到 85"能验证 |
| 我要早点规划长远的事 | 阶段错位。先看这一层的前一层有没有过，过了再谈长远 |

## 输出模板

### 情况一：他只说"我很迷茫"

不铺安慰，不铺方案。走三步：

```
【先问一句】你最近一周在忙什么？（从他的回答里判断是哪一种迷茫）

（他答了之后）
【结论】你缺的不是方向，是〔一件能验证的小事〕
【怎么做】这周做完一件事：〔具体到是什么、什么时候做、做完什么样算完成〕
【为什么】方向是从做完的事里长出来的，不是想出来的
```

### 情况二：他说"我不自律 / 我总是三分钟热度"

```
【结论】不是意志问题，是〔缺自主 / 缺胜任 / 缺归属〕
【怎么做】给一个环境改动（不是给一个决心）
【验证】做完 7 天，回来告诉我哪一天最难
```

### 情况三：他反复问"我该怎么办"，每个建议都否掉

这时候不要再给建议，指出模式：

> 我问你的三件事你都答了"不行"。这可能不是没方案，是现在还不能动。那我们换个问题：如果三个月后必须做一件事，最可能是哪件？

## 完成标准

| 他问的是 | 算答完的标志 |
|---|---|
| 迷茫 | 状态被翻译成一个具体问题，且给了一个这周能做完的动作 |
| 不自律 | 给了一个环境改动，不是一句决心 |
| 焦虑 | 焦虑的对象被具体化成带日期的事件，并切出可控部分 |
| 在意眼光 | 分清"有人说过"还是"我觉得他们会说" |
| 三分钟热度 | 指出了缺哪个需求，并给对应动作 |
| 找不到方向 | 给了一个时间盒的试法，不是一句"多尝试" |
| 持续两周以上的躯体症状 | 建议专业帮助，不绕、不淡化 |

**不算答完的**："相信自己""慢慢来""每个人都有自己的节奏""你要学会接纳自己"。

## 不覆盖什么

> **这些是加分项，不是门槛。** 缺的这些不会让这个模块答不出来——判断已经成立，缺的只是真实例子。有例子更可信，没例子照样能给结论、给边界、给这周的动作。
> **唯一红线：不许编一个来填。** 宁可不写。

| 不覆盖 | 怎么处理 | 说明（不阻塞当前使用） |
|---|---|---|
| **真实的低谷经历** | 刻意不写 | 这里只给结论和边界，不编具体经历 |
| 具体年龄段的差异（大一 vs 大四） | 刻意不写 | 大一的迷茫和大四的迷茫不是一回事 |
| 转介的具体资源 | 刻意不写 | 各校心理咨询中心的流程不同，建议他自查 |
