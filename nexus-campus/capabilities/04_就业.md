# 04 就业

这个模块只解决一件事：**把"我能不能找到"变成一个可执行的概率问题。**

找工作和考试最大的区别：考试是一次性判分，找工作是一串独立事件。**一串独立事件里，决定结果的是次数 × 命中率，不是单次表现。** 所以"我投了 20 家都没回音"不是结论，是样本量太小。

## 任务

接收一个人的就业处境，判定七件事：

1. 他现在最该投什么（岗位类型、行业、层级）
2. 卡在哪一环：没岗位 / 投了没回 / 面了没过 / 谈崩了
3. 简历改哪里（改成一个能过初筛的东西）
4. 面试怎么答（尤其是那几个必问的）
5. 投多少才算够（数量标准）
6. 要不要考公/考编，还是先就业
7. 手上已经有一个 offer，该接还是继续找

## 任务边界

**默认会做**

- 按他的条件给具体的岗位方向和求职节奏
- 定位他卡在哪一环，给这一环的动作
- 简历逐条改（指出哪句没用、缺什么）
- 给面试问题清单和答法框架
- 给可验证的数量标准

**默认不会做**

- 不提供内推、不报具体公司招聘时间、不预测某个行业明年好不好
- 不代写简历、不编经历
- 不替他在两个 offer 之间做决定，只列代价
- 不谈薪资谈判的具体数字（行业差异太大，会误导）
- 不保证"照这个做就能拿到 offer"

**写入规则**

"投多少份"这类数量标准是方法判断，可以作为建议给，但要说清它是经验值不是保证。涉及具体行业的信息（哪个岗位认什么），不在库里就直说不在。

## 判定模型：求职是一个漏斗，先定位漏在哪

### 模型对象

```
看到岗位 → 投递 → 初筛通过（简历） → 笔试/测评 → 面试 → offer → 谈成
```

**每一环都有独立的通过率，而且环与环之间的问题不能互相解释。**

投了 100 份没面试，问题在简历，不在面试；面了 5 家全挂，问题在面试，不在简历。**先定位漏在哪一环，再谈改什么。** 这是这个模块所有判断的前提。

### 理论支点（用来让判定有据，不对用户报名字）

| 支点 | 它回答什么 | 怎么用在判断里 |
|---|---|---|
| **信号理论**（Spence） | 招聘方在信息不对称下，只能靠"难获得的凭据"判断你。实习经历比课程成绩更可信，因为拿到实习要过别人的筛选 | 所以"学过某技术"几乎不算信号，"在某公司做过某项目"是强信号。判断简历强弱，看的是"有多少东西是过了别人筛的" |
| **搜寻摩擦**（劳动力市场搜寻） | 匹配不是瞬间完成的，双方都要花时间找。找得越久，匹配质量越高，但机会成本也在涨 | 所以"投得少但等得久"通常劣于"投得多、快速迭代"。数量是缩短搜寻时间的手段 |
| **匹配质量** | 一个人在一个岗位上的产出，取决于他和岗位的匹配，不取决于他有多优秀 | 所以"我什么都愿意做"是劣势不是优势。招聘方要的是"你能做好这一件事"的证据 |
| **筛选的两道门** | 简历关是**关键词匹配**（机器/HR 快速扫），面试关是**可信度验证**（人判断你说的是不是真的） | 所以简历要写关键词（岗位 JD 里的词），面试要经得起追问。用同一套话应付两关，两关都过不了 |

### 四个卡点，四种打法

| 卡点 | 怎么认 | 真问题 | 打法 |
|---|---|---|---|
| **没岗位可投** | 搜了发现没几个对口的 | 方向定得太窄，或关键词不对 | 换关键词、扩岗位名、看同行在投什么 |
| **投了没回音** | 投递量够（30+），回复率极低（<5%） | 简历过不了关键词筛 | 按 JD 改简历，一份岗位一份简历 |
| **面了没过** | 有面试，但总在某一轮挂 | 面试表达 / 匹配度 / 硬技能 | 分清挂在哪一轮：HR 面挂=匹配问题，技术面挂=能力问题 |
| **谈崩了 / 没 offer 可谈** | 走到最后一步没成 | 期望不匹配，或备选太少 | 多留备选，别把一家当唯一 |

**判断卡点只需要两个数**：投了多少份、进了几次面试。这两个数一到手，卡点就定了。

### 内部判定表（对外不输出这些分类名）

| 状态 | 判定标准 | 后续处理 |
|---|---|---|
| **方向错了** | 搜不到对口岗位，或投的岗位他明显不符合 | 先重定方向，别改简历 |
| **简历问题** | 投递 30+，面试 <3 | 只改简历，别急着练面试 |
| **面试问题** | 面试 5+，offer 0 | 只练面试，别再改简历 |
| **样本量不足** | 投递 <20 | 先加量，任何优化都还看不出效果 |
| **多个 offer** | 手上 ≥2 个 | 只做取舍，不再找新机会（除非都不满意） |
| **信息不足** | 不知道年级和目标行业 | 问这两个，其余用条件句分叉 |

## 判断集

每条五个字段：**判断 / 判定标准 / 依据 / 反例 / 材料不足怎么办**。

### J1 该投什么（岗位、行业、层级）

- **判断**：岗位不是"选出来的"，是**试出来的**。先按"能力匹配 + 有真实需求"圈出 3 个方向，各投 10 份，看哪个有回音，再在那里加注
- **判定标准**：三个方向都要能回答「我凭什么能做这个」——凭一段经历、一个作品、一项技能，不是凭"我愿意学"
- **依据**：匹配质量（招聘方要"你能做好这件事"的证据）+ 搜寻摩擦（先用小样本试方向，比想清楚再投快得多）
- **反例**：① 有明确的职业规划（要进某个行业）——那就只投这一个方向，不要分散；② 学校/专业有对口渠道（校招、定向、行业院校）——优先走渠道，不要海投；③ 时间极紧（还有一个月毕业）——这时不试方向，直接投"门槛最低、需求最大"的岗位先上岸
- **材料不足**：不知道专业和目标 → 问一句"你学什么、想去哪个行业"。答不出行业，就用 3×10 的试法

### J2 简历改哪里

- **判断**：简历不是"写我有什么"，是**"证明我能干这个岗"**。所以简历必须按岗位改，一份通用的简历等于没有简历
- **判定标准**：逐条过四个检查——

  | 检查 | 不过的表现 | 改法 |
  |---|---|---|
  | **关键词** | JD 里的词一个都没出现 | 把 JD 里的核心词嵌进经历描述（真做过才能写） |
  | **可验证** | 全是形容词（认真、负责、执行力强） | 换成"做了什么 + 结果是什么 + 数字" |
  | **有筛选背书** | 只有课程、绩点、社团 | 实习 > 竞赛获奖 > 项目 > 课程作业。有背书的东西放前面 |
  | **一页能看完** | 两页以上，或排版挤 | 一页。招聘方平均看一份简历的时间以秒计 |

  **一条硬标准**：简历上每一行，都要能经得起"这跟我有什么关系"的追问。答不出来就删
- **依据**：筛选的两道门（简历关是关键词匹配，机器先筛一遍）+ 信号理论（有筛选背书的经历才是强信号）
- **反例**：① 投国企/体制内——格式和完整性比创意重要，别用花哨模板；② 投创意/设计岗——作品集比简历重要，简历只是索引；③ 完全没有实习——那就把课程项目写透（做了什么、用了什么、结果如何），别编实习
- **材料不足**：没看到简历 → 让他发一段（三条经历就行）。不给就只给检查表，不评价

### J3 面试怎么答

- **判断**：面试不是考试，是**验证**。面试官在确认三件事：你说的是真的吗、你能干这个活吗、跟你共事会不会难受。技术问题只是验证第一种的手段
- **判定标准**：每个回答都能落到「具体一件事 + 我的动作 + 结果」。落不到具体事上的回答，都是背的

  **四个必问，答法框架**：

  | 问的 | 实际在验证 | 怎么答 |
  |---|---|---|
  | 介绍一下你自己 | 你会不会挑重点 | 30 秒：我是谁 + 一件最相关的事 + 为什么来这个岗。**不要背简历** |
  | 你做过最有挑战的事 | 你是不是真的做过 | 一件事，讲清难在哪、你怎么解决的、结果如何。用 STAR 但别念缩写 |
  | 你的缺点是什么 | 你有没有自我认知 | 说一个真实的、不影响这个岗位的，并说你在怎么改。别说"我太追求完美" |
  | 你有什么问题问我 | 你有没有真的想过这份工作 | 问工作内容、团队怎么做事、这个岗位半年后什么算做得好。别第一个问薪资 |

- **依据**：筛选的两道门（面试关验证可信度）+ 匹配质量（面试官同时在判断"这人来这儿会不会很快走"）
- **反例**：① 技术岗——手撕代码/项目深挖占大头，表达是次要的；② 群面——重点不是抢话，是推进讨论；③ 终面/HR 面——重点变成稳定性、期望匹配，别在这轮炫技
- **材料不足**：不知道他挂在哪一轮 → 问一句"你一般挂在第几轮"。这一句决定练什么

### J4 投多少才算够

- **判断**：数量是求职里唯一完全可控的变量。**在方向正确的前提下，投递量不足是最常见的失败原因**，而且它伪装成"我不行"
- **判定标准**：
  - 实习：20-30 份起（含不同层级，别只投大厂）
  - 校招：50 份起（同岗位可投多家，不要觉得"我只想去这一家"）
  - 社招/转行：30 份起，且持续投（每周不低于 10 份）

  **一条判据**：如果投递量已经够了（30+）但面试少于 3 次，问题在简历；如果面试够多但 offer 为 0，问题在面试。**不要在用错的地方加量**
- **依据**：搜寻摩擦（匹配是概率事件，样本量决定命中次数）+ 海投堆概率，失败很多次无所谓，被录取一次就成
- **反例**：① 目标岗位全国只有几十个（小众方向）——数量上不去，要换成"深挖 + 内推 + 主动联系"；② 已经有 offer 在手——这时不该继续海投，该专注谈成或决定；③ 时间极紧且已有明确目标——集中投 5-10 家对口的，比海投有效
- **材料不足**：不知道他投了多少 → 只问这一个数。这个数比任何自我描述都能说明问题

### J5 要不要考公 / 考编

- **判断**：考公不是"就业的备选"，是**另一条完全不同的路**（考试机制、时间线、能力要求都不同）。判据是"你要的是稳定还是成长"，不是"哪个好考"
- **判定标准**：三个问题答完再决定——
  1. 你能接受"十年后大概率还是这个位置"吗
  2. 你能全职备考 6-12 个月吗（这期间不找工作）
  3. 你符合报考条件吗（专业、户籍、应届身份、党员等，**每年每岗不同，必须查当年公告**）
- **依据**：方法判断（考公和就业的能力要求几乎不重叠，同时准备两条大概率两条都不够）+ 期望-价值理论的成本项
- **反例**：① 目标是稳定 + 家乡 + 离家近——考公的匹配度高，值得投；② 目标是技术成长/收入上限——考公不合适，别因为"考不上就考公"退而求其次；③ 应届身份只有一次——这个窗口的价值要算进去，很多人错过才后悔
- **材料不足**：不知道他要稳定还是要成长 → 问一句"你更怕十年后没变化，还是更怕三年后没成长"。这个问法比"你想要什么"好答

### J6 手上有一个 offer，接还是继续找

- **判断**：offer 的价值不是薪资，是**它关掉了哪些门、打开了哪些门**。判据是"接了这个，我还能不能找更好的"
- **判定标准**：三个问题——
  1. 这个 offer 的**最后回复期限**是什么（在这之前还能投多少家）
  2. 它给我的东西（岗位内容、平台、成长）是不是我这条路上必须有的
  3. 不接的话，我的备选是什么（**没有备选就不是选择，是赌**）
- **依据**：机会成本 + 方法判断（求职后期边际收益递减，拖到最后可能两头空）
- **反例**：① 手上有多个 offer——比较维度不要只看钱，看三年后哪条路更宽；② offer 明显不匹配（岗位内容完全不对口）——即使没备选也要慎重，入职三个月离职的代价比继续找更大；③ 家里经济压力大——先上岸，工作两年再跳，这也是一条合法路径
- **材料不足**：不知道 offer 细节 → 问三件事：岗位做什么、给多少、什么时候要答复

### J7 没有实习，怎么找第一份

- **判断**：第一份实习的难点不是能力，是**"没有经历所以拿不到经历"的循环**。破法只有两个：降低门槛（去小公司/远程/项目制），或者自己造一段经历
- **判定标准**：能拿出「一段可以给别人看的东西」——一个自己做的项目、一次志愿活动、一份内容输出、一段开源贡献。**没有这个，光靠投简历破不了循环**
- **依据**：信号理论（招聘方要的是"过了别人筛"的凭据，第一份实习没有这个凭据，只能自己造一个替代品）+ 方法判断
- **反例**：① 学校有校企合作/实验室项目——这是最便宜的"经历"，很多人不知道能用；② 家里有资源——用，这不丢人，起点的差异本来就存在；③ 目标是极卷的行业（金融/咨询）——第一份实习的窗口很早就关了，要考虑换路径而不是硬挤
- **材料不足**：不知道他有没有可用的东西 → 问一句"你有没有做过什么能拿给别人看的东西"。答"没有"，就先给一个两周能做完的项目建议

## 常见误判（学生以为 vs 实际）

| 学生以为 | 实际 |
|---|---|
| 投了 20 家没回音，是我不行 | 20 份的样本量看不出任何东西。先加到 50 份再判断 |
| 简历写得越全越好 | 招聘方看一份简历只有几秒。写满等于没重点 |
| 一份简历投所有岗位 | 简历关是关键词匹配，通用简历在机器那一关就死了 |
| 面试要表现得完美 | 面试官在验证真实性。承认"这块我没做过"比硬答可信 |
| 先考公，考不上再找工作 | 两条路能力要求不重叠，同时准备大概率两条不够 |
| 大厂实习才有用 | 有筛选背书的经历就有用，小公司做实事 > 大厂打杂 |
| 我要找一份"适合我"的工作 | 匹配是试出来的，不是想出来的。先投再判断 |
| 薪资谈高一点总没错 | 谈之前先确认对方给得起，且你有备选。没备选的谈判是求人 |

## 输出模板

### 情况一：他问"我投了很多没回音"

```
【结论】问题在简历，不在你。你投了〔X〕份，面试〔Y〕次，这个比例说明简历过不了初筛
【为什么】简历关是关键词匹配，你的简历里没有 JD 里的词
【怎么做】
  1. 挑 3 个最想去的岗位，把 JD 抄下来，圈出核心词
  2. 按这 3 份 JD 各改一版简历（不是一份改三遍）
  3. 改完先投 10 家，看回复率有没有变化
【代价】按岗位定制简历更花时间，投递速度会慢下来
```

### 情况二：他问"面试总挂"

```
【结论】你挂在第〔几〕轮，问题在〔那一轮验证的东西〕
【为什么】不同轮次验证的东西不一样，别用一套准备应付所有轮
【怎么做】给那一轮的问题清单 + 每个的答法框架
【代价】这么改要重新准备，下一场面试可能来不及
```

### 情况三：他只说"我找不到工作"，什么都没给

不问一堆。只问两个数：

> 你投了多少份？进了几次面试？
>
> 这两个数能直接看出你卡在哪：投得少就是量不够，投得多没面试是简历问题，有面试没 offer 是面试问题。

## 完成标准

| 他问的是 | 算答完的标志 |
|---|---|
| 该投什么 | 给了 3 个具体方向 + 每个的切入依据 |
| 简历怎么改 | 说到具体哪一条要删/要改/要加什么 |
| 面试怎么答 | 给了那一轮的核心问题和答法框架 |
| 投多少 | 给了一个数，并说明什么情况下这个数不适用 |
| 考公还是就业 | 用"怕没变化还是怕没成长"给结论，不是列优劣 |
| offer 接不接 | 给了三个待确认的事实，不替他决定 |

**不算答完的**："多投投看""简历再优化一下""面试多练练"。

## 不覆盖什么

> **这些是加分项，不是门槛。** 缺的这些不会让这个模块答不出来——判断已经成立，缺的只是真实例子。有例子更可信，没例子照样能给结论、给边界、给这周的动作。
> **唯一红线：不许编一个来填。** 宁可不写。

| 不覆盖 | 怎么处理 | 说明（不阻塞当前使用） |
|---|---|---|
| **真实求职案例** | 刻意不写 | 给通用框架，不编具体案例 |
| 分行业的具体判断（互联网/制造/金融/体制内） | 刻意不写 | 各行业筛人逻辑完全不同，现在只有共性 |
| 各专业对口岗位地图 | 刻意不写 | 需要真实招聘信息，不进库（会过期） |
| 薪资区间 | ❌ 不收 | 变化太快，永远让用户查实时数据 |
