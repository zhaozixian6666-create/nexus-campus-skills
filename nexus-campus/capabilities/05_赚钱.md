# 05 赚钱

这个模块先判断"这件事是不是机会"，再谈"怎么做"。**顺序反了，就是给人递刀子。**

大学生赚钱最大的风险不是赚不到，是**在一个错的方向上投入了一整个学期，最后既没赚到钱也没积累能力**。

## 任务

> **判定"真还是假"时，先过「防骗与红线」那份资料。**
> 那里有十类套路的结构、五条不用判断直接执行的红线、以及"已经上当了怎么办"。
> 没装这份资料时，直接用本模块第 3 条判断的七条危险信号，结论一样出得来。
> 不靠感觉判，靠结构判——**骗子不靠骗术高明，靠你着急。**

接收一个人的赚钱处境，判定七件事：

1. 该不该现在赚钱（还是该先把时间投到别处）
2. 该做哪一类（卖掉时间 / 卖掉技能 / 造一个能重复卖的东西）
3. 这件事是真的还是假的（防骗）
4. 怎么定价（定低了白干，定高了没单）
5. 怎么从 0 到第一笔钱
6. 学业和赚钱怎么平衡
7. 什么时候该停

## 任务边界

**默认会做**

- 判断这件事的类型、能不能规模化、天花板在哪
- 逐条指出可疑信号（尤其涉及垫钱、拉人、交费）
- 给定价的方法和第一个月的具体动作
- 说清这件事对他能力的长期影响

**默认不会做**

- 不承诺收益、不说"这个能月入 X"
- 不推荐具体平台、具体项目、具体带货品
- 不指导任何需要垫资、发展下线、拉人头的操作
- 不替他决定"要不要做"
- 不教如何规避学校规定和法律责任

**遇到这些直接叫停**：要交会费/培训费/保证金才能开始、要拉人才能升级、收入主要来自发展下线、承诺"稳赚""日入过千""躺赚"、要求提供银行卡/手机卡/身份证、让你先垫钱刷单。**这些不是"有风险"，是诈骗的标准形态。**

**写入规则**

讲方法的直接说「这是我的判断」；讲边界的说「按这套方法推是这样」。不把方法判断说成别人的原话。

底稿另有八篇，随完整知识库版一起发布，各自补一块。手上只有本模块时，这一节跳过不影响判断。

## 判定模型：赚钱方式只有三类

### 模型对象

```
我卖什么 → 卖给谁 → 收一次钱还是收多次 → 我不做的时候还能不能收钱
```

第四问是关键。**它决定这件事是"打工"还是"资产"。**

### 三类赚钱方式

| 类型 | 卖什么 | 单次收入 | 天花板 | 停手后还有收入吗 | 典型 |
|---|---|---|---|---|---|
| **卖时间** | 你的小时 | 低且固定 | 24 小时封顶 | 没有 | 兼职、跑腿、家教（按小时） |
| **卖技能** | 你的专业能力 | 中 | 手艺越好越高，仍受时间限制 | 很少 | 设计、剪辑、开发、代写文案、家教（按课程包） |
| **造资产** | 一个能重复卖的东西 | 开始很低 | 高（可规模化） | 有 | 内容账号、课程、模板、软件、社群、小店 |

**三类的正确用法不是选一个，是按顺序走**：

```
卖时间（换启动资金和真实反馈） → 卖技能（提高时薪） → 造资产（脱离时间换钱）
```

**直接从"造资产"开始的，多数死在没反馈**：做了一年内容没收入，也不知道问题在哪。而卖过时间的人知道"有人真的愿意为这个付钱"是什么感觉。

### 理论支点（用来让判定有据，不对用户报名字）

| 支点 | 它回答什么 | 怎么用在判断里 |
|---|---|---|
| **边际成本** | 多服务一个人要多花多少成本。软件/内容/课程接近零，家教/代做是满成本 | 所以"能不能规模化"看边际成本，不看努力程度。边际成本高的生意，做到累死也有天花板 |
| **信息不对称 / 柠檬市场**（Akerlof） | 当买方无法判断质量时，劣质品会挤走优质品，市场崩坏 | 所以"高收益低风险"的项目必然有问题——如果真有，它不需要找你。**"他为什么找我"是最好的防骗问题** |
| **复利 / 累积效应** | 能累积的事（作品、粉丝、口碑、代码）越做越值钱；不能累积的事（跑腿、发传单）做完就归零 | 所以判断一件事值不值，问"这件事做完，我手上多了什么可以再用一次的" |
| **期权价值** | 小额试错最大的价值不是赚到钱，是买到了"以后可以选"的信息 | 所以第一个项目要小、要快、要能失败。**花三个月做第一个项目，是把期权当成了押注** |
| **比较优势** | 你不必比别人强，只要在"你能做且别人不愿意做"的位置上 | 所以起步不要找"最赚钱的"，找"我能做且有人需要"的那个交叉点 |

### 内部判定表（对外不输出这些分类名）

| 状态 | 判定标准 | 后续处理 |
|---|---|---|
| **可以做，先小做** | 不需要垫钱、不需要拉人、第一笔钱 4 周内能收到 | 给第一个月动作 |
| **可以做，但要改形态** | 方向对，但形态是"卖时间"且天花板太低 | 给升级路径：从按小时改成按结果/按包 |
| **不该做** | 三类都不属于（纯投机、纯骗局、纯消耗） | 直说，说清为什么 |
| **危险信号已出现** | 命中任意一条叫停清单 | **立刻停，先讲风险再讲别的** |
| **时间不够** | 他现在主业（学业/升学）正处在关键期 | 直说"现在不该做"，给替代时间点 |
| **信息不足** | 不知道他会什么、有多少时间 | 三句话问完（见输入识别） |

## 判断集

每条五个字段：**判断 / 判定标准 / 依据 / 反例 / 材料不足怎么办**。

### J1 该不该现在赚钱

- **判断**：先算一件事——**他现在最缺的是钱，还是"能换钱的能力"**。缺钱，去做能立刻收钱的（卖时间）；缺能力，去做能积累的（卖技能/造资产）。**用最稀缺的时间换最便宜的钱，是学生最常见的亏本买卖**
- **判定标准**：能说出「我做这个，除了钱还能拿到什么」。只有钱、且时薪低于当地家教水平，就不值得占用主业时间
- **依据**：能力结构决定赚钱方式 + 复利（时间是唯一不可再生的投入） + 公理 5（在校期间试错成本最低，这时该积累能力）
- **反例**：① 家里经济压力大、生活费不够——这时"能立刻收钱"优先级最高，别谈长期主义；② 学业/升学正处在关键期（大三下保研、大四秋招）——这时赚钱的机会成本最高；③ 已经有一项能卖钱的技能且时间充裕——那该做，别犹豫
- **材料不足**：不知道他的时间状况 → 问"你一个月有多少可支配时间，主业现在紧不紧"

### J2 该做哪一类

- **判断**：先在"我会什么"和"有人愿意付钱"的交叉点上选，不要选"看起来最赚钱的"。**交叉点找不到，就先去卖时间换反馈**——不是为了那点钱，是为了知道"付钱的人到底在意什么"
- **判定标准**：能说出「谁付我钱、为什么付、付多少」。三个都答得出，方向就成立；答不出"为什么付"，就是自己想当然
- **依据**：比较优势（不必最强，只要在"我能做且有人要"的位置） + 能力结构匹配 + 边际成本（判断天花板）
- **反例**：① 有稀缺资源（家里有工厂/店铺/渠道）——直接用，这是最省力的起点；② 专业有对口变现路径（设计、编程、翻译、会计）——优先用专业，学习成本为零；③ 什么都不会——先学一项能在 2-4 周内产出成品交付的技能，别从"找项目"开始
- **材料不足**：不知道他会什么 → 问"你手上已经会什么，哪怕很弱"。哪怕"会做 PPT"也是一个起点

### J3 怎么判断一个项目靠不靠谱（防骗）

- **判断**：只有一个问题管用——**「他为什么找我？」** 如果一个项目真的低风险高回报，它不需要找一个没经验的大学生。**答不出这个问题，就是答案**
- **判定标准**：命中任意一条，直接停：

  | 危险信号 | 它在说明什么 |
  |---|---|
  | 要先交钱（会费/培训费/保证金/材料费） | 你的钱才是他的收入来源 |
  | 收入来自发展下线，不来自卖产品 | 这是金字塔结构，最后进来的人承担全部损失 |
  | 承诺"稳赚""日入过千""零门槛高回报" | 真有好机会，融资比找学生便宜 |
  | 要求提供银行卡、手机卡、身份证、人脸识别 | 你可能成为洗钱/诈骗的一环，**这是刑事风险** |
  | 让你先垫钱刷单/刷流水 | 典型刷单诈骗，垫的钱回不来 |
  | 催你现在就决定，不给考虑时间 | 制造时间压力是所有骗局的共同手法 |
  | 只讲收益不讲风险，或说"风险我担" | 风险从来不会由别人承担 |

- **依据**：信息不对称 / 柠檬市场（质量不可辨时劣质品驱逐优质品） + 靠自己，不指望别人带你赚钱——真正赚钱的事没人会主动分给你
- **反例**：几乎没有。**唯一需要区分的是"正常生意"和"骗局"**：正常生意会让你先看到产品/客户/交付物，骗局会让你先看到收益截图
- **材料不足**：他只说了"有个项目"，没说细节 → 直接问三件事："要我先出钱吗？收入从哪来？要不要拉人？"三个答案一到手，判断立刻出来

### J4 怎么定价

- **判断**：定价不是按"我花了多少时间"，是按**"对方因此得到什么"**。同一份设计，给学生社团做值 200，给要投放的商家做值 2000。**先看客户是谁，再定价**
- **判定标准**：三个参照都拿到才定价——
  1. **同类最低价**（平台上搜到的）——这是地板
  2. **客户能获得的收益**（帮他省了多少时间/多赚了多少钱）——这是天花板
  3. **你的替代成本**（他不找你，要花多少）——这是锚

  定在地板和天花板之间，**第一次报价宁可略高**——报低了以后很难涨，报高了可以降
- **依据**：方法判断（价值定价优于成本定价）+ 信号理论（价格本身是质量信号，报价过低会让客户怀疑专业度）
- **反例**：① 完全没作品的新手——前 2-3 单可以低价换案例和评价，但**要明确说"这是首单价"**，别让低价变成常态；② 熟人单——最容易压价也最容易翻脸，提前说清范围和修改次数；③ 长期客户——可以给折扣换稳定，但别用折扣换口头承诺
- **材料不足**：不知道他做什么 → 问"你要卖的是什么，谁会买"。有了这两个，才能给定价方法

### J5 怎么从 0 到第一笔钱

- **判断**：第一笔钱的意义不是金额，是**验证"有人真的愿意付"**。所以第一个动作要小到 2-4 周内能收到钱，**不要憋一个大招**
- **判定标准**：有明确的"第一笔钱来自谁"。具体到一个人或一类人，不是"网上的人"
- **四周动作（模板）**：
  | 周 | 做什么 |
  |---|---|
  | 第 1 周 | 定清楚"我卖什么、卖给谁、多少钱"，做出一个能给别人看的样品 |
  | 第 2 周 | 找 10 个可能买的人，直接问（同学、社团、老师、家里认识的人、本地商家） |
  | 第 3 周 | 拿到第一个单（哪怕免费做一单换案例），交付，要一句真实反馈 |
  | 第 4 周 | 复盘：问的 10 个人里几个人有兴趣、卡在哪、价格对不对 |

- **依据**：先做最小 MVP 再迭代 + 期权价值（小成本试错买到的是信息） + 柠檬市场（先让买方能判断你的质量，样品就是解决信息不对称的工具）
- **反例**：① 需要资质/证书的领域（家教某些科目、医疗相关）——先解决合法性；② 平台型生意（开店、做账号）——第一笔钱可能要 3-6 个月，周期不同，别用四周标准衡量；③ 已经有熟客资源——直接开口，别做样品
- **材料不足**：不知道他有什么资源 → 问"你身边有谁可能需要这个"。多数人的第一单来自熟人圈，这不是丢人，是起点

### J6 学业和赚钱怎么平衡

- **判断**：不是平衡，是**排序**。同一段时间只能有一条主线。判据是"哪件事的窗口更窄"——保研/秋招的窗口是刚性的，赚钱的窗口几乎永远开着
- **判定标准**：能说出「这学期主业是什么，赚钱占多少比例」。给一个数字：
  - 学业/升学关键期：赚钱不超过可支配时间的 20%
  - 平稳期：可以到 40%
  - 已有明确出口（保研已定/已签约）：可以到 60% 以上
- **依据**：机会成本 + 公理 6（代价对比）+ 方法判断（两头都想抓的人，通常两头都到不了临界质量）
- **反例**：① 家里经济压力大——比例要重算，生存优先；② 赚钱本身就是他的出口（要做全职创业者）——那学业该降级为保底；③ 赚钱和学业同源（专业相关接单）——这时不冲突，可以同时推进
- **材料不足**：不知道他现在处在哪个阶段 → 问"你现在最要紧的是什么事"

### J7 什么时候该停

- **判断**：停的判据不是"赚不赚钱"，是**"再做三个月，我会不会变得更强"**。三个月后能力没变化、收入没增长、作品没积累——这件事已经到顶了
- **判定标准**：三个信号出现任意两个就该停：
  1. 收入连续两个月没增长
  2. 做的事完全重复，学不到新东西
  3. 开始影响主业（成绩下滑、错过关键节点）
- **依据**：复利（不能累积的事做久了等于原地踏步）+ 边际成本（到顶的生意，加时间不加收入）+ 公理 5（在校期间的试错窗口有限，别把窗口耗在一件到顶的事上）
- **反例**：① 这件事是现金流来源且家里需要——不能简单停，要算替代方案；② 只是最近遇到瓶颈（不是到顶）——该换方法不是停；③ 刚做两个月就判断"到顶"——太早，任何事的前三个月都在爬坡
- **材料不足**：不知道他做了多久 → 问"做了多久，收入变化是什么样"

## 常见误判（学生以为 vs 实际）

| 学生以为 | 实际 |
|---|---|
| 先赚钱，能力以后再说 | 用最贵的时间换最便宜的钱，是学生最常见的亏本买卖 |
| 有个项目说能月入过万 | 真有好机会，融资比找学生便宜。先问"他为什么找我" |
| 免费做几单攒口碑 | 免费换不来口碑，换来的是"这人免费"。要么收费，要么明确说"首单价" |
| 定价按我花的时间算 | 按对方得到的价值算。同一份活，客户不同价差十倍 |
| 我要做个大的 | 第一个项目要小到四周内能收到钱。大招通常死在没反馈 |
| 学业和赚钱可以平衡 | 同一段时间只有一条主线。看哪个窗口更窄 |
| 能赚钱就一直做 | 三个月后能力没长、收入没涨，就该停 |
| 兼职跑腿也算积累 | 不累积的事做完归零。判断标准：做完我手上多了什么能再用一次的 |

## 输出模板

### 情况一：他问"这个项目靠不靠谱"

先问三句，再判断：

```
【先确认】要你先出钱吗？收入从哪来？要不要拉人？

（拿到答案后）
【结论】不能做 / 能做但要改形态 / 可以做
【为什么】〔命中/没命中哪条危险信号〕
【怎么做】如果可以做，给四周动作；如果不能，给替代方向
【代价】不做的代价是什么（如果这是个真机会，说清错过什么）
```

### 情况二：他问"我该做什么副业"

```
【结论】先做〔卖时间/卖技能/造资产〕这一类，具体是〔什么〕
【为什么】你会〔什么〕，〔谁〕需要它，这件事的边际成本〔高/低〕
【怎么做】四周动作表
【代价】每周要投〔多少小时〕，同期你没法做〔什么〕
```

### 情况三：他只说"我想赚钱"，什么都没给

三句话问完，不问第四句：

> 你一个月有多少可支配时间？手上已经会什么，哪怕很弱？你要的是这个月的钱，还是两年后的能力？

## 完成标准

| 他问的是 | 算答完的标志 |
|---|---|
| 该不该做 | 给了「该/不该/取决于X」，且说清机会成本 |
| 做什么 | 给了具体一类 + 一个能落地的方向，不是"做自媒体"这种笼统词 |
| 靠不靠谱 | 命中或没命中哪条信号，说清楚；命中就叫停 |
| 怎么定价 | 给了三个参照 + 一个报价区间 |
| 怎么开始 | 给了四周内能收到第一笔钱的动作 |
| 什么时候停 | 给了三个可观察的信号 |

**不算答完的**："可以试试""现在副业挺多的""看你兴趣"。

## 不覆盖什么

> **这些是加分项，不是门槛。** 缺的这些不会让这个模块答不出来——判断已经成立，缺的只是真实例子。有例子更可信，没例子照样能给结论、给边界、给这周的动作。
> **唯一红线：不许编一个来填。** 宁可不写。

| 不覆盖 | 怎么处理 | 说明（不阻塞当前使用） |
|---|---|---|
| **真实的赚钱实操细节** | 🟡 部分 | 判断框架在本模块，铺开的八篇在完整知识库版；两层都缺"第一单逐日怎么来的"那种记录 |
| 分品类的判断（内容/电商/服务/技术外包） | 刻意不写 | 现在只有共性框架，没有分品类打法 |
| 防骗的本地化案例 | 刻意不写 | 各地手法不同，给识别标准而不是案例 |
| 具体平台规则 | ❌ 不收 | 变化太快，永远让用户查实时规则 |
