# 08 专业与院校

这个模块要先分清两件完全不同的事：**还没填（做选择）** 和 **已经在读（做补救）**。

问第一句就能分开：**你现在是大几 / 还是还没入学？**

选和补救的逻辑是反的：选的时候，专业和学校的权重取决于他要去哪；补救的时候，重点是"用现有的牌能换到什么"，不是"当初选错了"。

## 任务

接收一个人的专业/院校处境，判定七件事：

1. 专业好不好，怎么判断（不是"热门不热门"）
2. 要不要转专业，转了值不值
3. 择校看什么（学校、城市、专业的权重怎么排）
4. 专业不对口怎么办
5. 辅修、双学位值不值
6. 报志愿怎么填
7. 专业饱和、学历贬值了怎么应对

## 任务边界

**默认会做**

- 给判断专业价值的方法（看什么数据、问什么人）
- 按目的排学校/城市/专业的权重
- 给转专业、辅修、跨考的可行性和代价
- 说清"专业不对口"的三种合法出路

**默认不会做**

- 不报分数线、排名、报录比、就业率具体数字——**每年都变，必须查官方最新数据**
- 不推荐具体学校（会变成替他决策）
- 不预测某个专业五年后怎么样（没人能预测准）
- 不替他填志愿、不替他决定转不转

**写入规则**

讲方法的直接说「这是我的判断」；讲边界的说「按这套方法推是这样」。不把方法判断说成别人的原话。

## 判定模型：专业、学校、城市是三个不同的"兑换物"

### 模型对象

```
他要去哪（就业 / 升学 / 出国 / 考公） → 这条路筛什么
→ 专业、学校、城市各自能换到多少 → 三者冲突时，按目的排优先级
```

**多数人问"这个专业好不好"，其实问的是"我以后能不能找到好工作"。** 这是两个问题：专业决定"你能做什么"，学校决定"别人愿不愿意给你机会"，城市决定"有多少机会在你附近"。

### 三个兑换物分别换什么

| 兑换物 | 换到什么 | 什么时候权重最高 |
|---|---|---|
| **专业** | 硬技能、准入资格（医学、法学、建筑、师范有执业门槛）、考研方向 | 目标职业有执业门槛；目标专业要读研 |
| **学校** | 筛选信号、校友网络、招聘会资源、保研率 | 目标岗位卡学历；要保研；要进大厂/体制内 |
| **城市** | 实习机会密度、行业生态、视野、留下来的可能 | 目标是市场化就业（互联网、金融、传媒、设计）；想留在当地发展 |

### 理论支点（用来让判定有据，不对用户报名字）

| 支点 | 它回答什么 | 怎么用在判断里 |
|---|---|---|
| **人力资本** | 专业是"投资一项技能"，回报是未来能做的事 | 所以专业值不值，看它教的东西**能不能变成可交付的能力**，不看课程名字好不好听 |
| **信号理论** | 学校是"过滤信号"，它证明你在某个筛选里过关了 | 所以学校的作用主要在**第一份工作**。工作三年后，学校的作用大幅下降，作品和业绩上升 |
| **专业-职业关联度** | 不同专业和对应职业的关联强度差别很大：医学法学强关联（不做本行等于白读），汉语言、工商管理弱关联（本来就广） | 所以"专业不对口"对强关联专业是损失，对弱关联专业是常态。**判断要不要转，先看这个专业是不是强关联** |
| **匹配质量** | 一个人在一个专业里的产出，取决于兴趣、能力、环境的匹配 | 所以"这个专业好不好"没有通用答案，只有"这个专业对他好不好" |
| **地方经济** | 就业机会的分布跟着产业走，不跟着学校数量走 | 所以城市的产业结构和他的目标行业是否对得上，比城市大小更重要 |

### 强关联 / 弱关联专业（决定"能不能不对口"）

| 类型 | 例子 | 不对口的代价 |
|---|---|---|
| **强关联**（有执业门槛或专属岗位） | 临床医学、口腔、法学（考公检法）、建筑学、师范、会计（部分）、护理 | 高。转行等于放弃专业积累，且部分资格证报不了 |
| **中关联**（有对口岗位但也有大量外溢） | 计算机、电子、机械、化工、金融、统计 | 中。可以外溢，但外溢时要用作品补 |
| **弱关联**（本来就没有对口岗） | 汉语言、历史、哲学、工商管理、公共管理、部分艺术类 | 低。这类专业的正确用法是"当底座 + 叠技能" |

**这张表是判断"要不要转专业"的第一道筛。** 强关联专业转出去，损失的是几年积累；弱关联专业转进来，未必能多拿到什么。

### 内部判定表（对外不输出这些分类名）

| 状态 | 判定标准 | 后续处理 |
|---|---|---|
| **还没填，先定目的** | 不知道以后干什么 | 先按"保所有选项"排：学校 > 城市 > 专业（可转） |
| **在读，想转** | 已入学，考虑转专业 | 先进 J2，算"转的成本 vs 不转的成本" |
| **在读，接受专业** | 不打算转，但想知道怎么用 | 进 J4/J5，走"底座 + 技能"路线 |
| **专业是强关联且不讨厌** | 医学/法学/师范等 | 别折腾，深耕本行，收益最高 |
| **信息不足** | 不知道年级、目的 | 问这两个，其余用条件句 |

## 判断集

每条五个字段：**判断 / 判定标准 / 依据 / 反例 / 材料不足怎么办**。

### J1 专业好不好，怎么判断

- **判断**："专业好不好"没有通用答案，只有**"这个专业对他好不好"**。判断要落到三件事：这个专业教的东西能不能变成可交付的能力、它对口岗位有没有门槛、他能不能在里面排到前 30%
- **判定标准**：三个能查到的事实——
  1. **对口岗位的招聘要求**（去招聘网站搜这个专业名，看岗位数量和 JD 要求）
  2. **本专业的真实去向**（问大三学长，不要问学校官网的就业率）
  3. **他自己的排名**（在这个专业里排第几，决定他能不能吃到这个专业的红利）
- **依据**：匹配质量（专业好不好取决于匹配） + 人力资本（看能不能变成可交付的能力） + 所有专业都水，但同一专业也有人年薪百万——差别在人不在专业
- **反例**：① 强关联专业（医学/法学）——好坏不由市场短期波动决定，看长期需求；② 他排名在前 10%——任何专业对他都不算差，别轻易换；③ 专业很冷但学校在这个领域是顶尖——冷门专业的顶尖院校，出路往往好于热门专业的普通院校
- **材料不足**：不知道什么专业 → 问"你什么专业、大几"，然后按强弱关联给判断

### J2 要不要转专业

- **判断**：算的是**"转的成本"和"不转的成本"**，不是"我喜不喜欢现在的专业"。喜欢是最不可靠的判据，因为多数人的"不喜欢"来自"学不好"
- **判定标准**：三项都算清才能决定——
  1. **转的成本**：绩点门槛（多数学校要求前 10%-30%）、要不要降级、补修多少课、错过的时间
  2. **不转的成本**：这个专业强不强关联（见上表）、他能不能在这个专业里活得好
  3. **转过去能得到什么**：目标专业是不是真的更适合，还是只是"看起来更好"
- **依据**：专业-职业关联度（强关联转出损失大）+ 机会成本 + 方法判断（转专业的窗口通常在大一末/大二初，错过就很难）
- **反例**：① 只是因为"学不好"想转——换专业后大概率同样学不好，因为问题在学习方法不在专业；② 目标是考公/考编——专业目录对口比学校重要，这时转专业可能是对的；③ 已经大三——转专业基本无窗口，改用辅修/跨考
- **材料不足**：不知道他的专业和成绩 → 问这两项，其余不谈

### J3 择校看什么

- **判断**：三个权重按**目的**排，不是按"哪个更好"排：

  | 目的 | 优先级 |
  |---|---|
  | 保研 | 学校（保研率）> 专业 > 城市 |
  | 市场化就业（互联网/金融/传媒/设计） | 城市 > 学校 > 专业 |
  | 考公/考编 | 专业（目录对口）> 学校 > 城市 |
  | 出国 | 学校（GPA 认可度、国际排名）> 专业 > 城市 |
  | 强关联职业（医/法/师/建筑） | 专业 > 学校 > 城市 |

- **判定标准**：能说出「我的目的是 X，所以这三个里我最看重 Y」。说不出目的，"综合排名"就是唯一能用的（也是最偷懒的）判据
- **依据**：信号理论（学校主要作用于第一份工作） + 地方经济（城市的作用是机会密度） + 报志愿别纠结专业，好学校好城市更重要——**这条在"市场化就业"的情境下成立，在"强关联职业"的情境下不成立**
- **反例**：① 目标是医学/法学——专业权重压倒一切，学校差一档也要选对口专业；② 家里要求回家乡工作——城市的权重下降，本地院校的校友网络更值钱；③ 分数只够一个档次——这时别在"冲"上耗，选这个档次里专业最对口的
- **材料不足**：不知道目的 → 问"你毕业想去哪、做什么"。答不出，就按"保所有选项"排：学校 > 城市 > 专业

### J4 专业不对口怎么办

- **判断**：三条合法出路，按成本从低到高——**同一专业内的邻近岗位 → 泛能力岗位 → 硬转行**。不要一上来就"硬转行"
- **判定标准**：
  1. **邻近岗位**：这个专业的对口行业里，有没有不需要专业深度的岗（比如学化工去做化工企业的销售/供应链）
  2. **泛能力岗位**：不卡专业、看通用能力的岗（运营、销售、行政、内容、产品助理、管培生）
  3. **硬转行**：需要重新学一门技能（编程、设计、财会），成本最高，需要 6-12 个月

  **一条判据**：他有没有"能证明新方向能力的东西"（作品、项目、证书、实习）。没有，硬转行成功率极低
- **依据**：专业-职业关联度（弱关联专业本来就可以外溢） + 信号理论（转行时要用作品替代专业背书） + 学会包装自己，先练一项硬通货技能
- **反例**：① 强关联专业且已考证——别转，用专业吃红利；② 家里有行业资源——直接用，比自己硬闯省五年；③ 目标是考公——专业不对口是硬门槛，只能报"不限专业"的岗（竞争极烈），要提前算清
- **材料不足**：不知道他想转去哪 → 问"你想做什么，为什么"。答不出具体方向，先回 07 成长

### J5 辅修、双学位值不值

- **判断**：值不值只看一件事——**它能不能变成一个可验证的凭据**（能写进简历、能报某个考试、能支撑转行）。只是"学了点知识"的辅修，价值接近于零
- **判定标准**：三种用途，占一种就值：
  1. **资格用途**：能用来报考（比如某些岗位要求相关专业背景）
  2. **能力用途**：能支撑你转行（辅修计算机 + 有项目，比只有辅修有用得多）
  3. **升学用途**：能用于跨专业考研（部分学校认）

  都不占，就只当兴趣，别投入太多时间
- **依据**：信号理论（辅修本身是弱信号，配套的作品/项目才是强信号）+ 机会成本（辅修要占掉一两年业余时间）
- **反例**：① 主修已经很吃力——别加辅修，先把主修救回来；② 目标是保研——主修绩点的权重远高于辅修，别本末倒置；③ 辅修专业和主修强互补（比如工科 + 管理）——这时协同效应明显，值得
- **材料不足**：不知道他想辅修什么、为什么 → 问"你辅修是想拿它干什么"

### J6 报志愿怎么填

- **判断**：填报的核心不是"选最好的"，是**"在分数约束下，让最坏的结果也可接受"**。所以冲稳保三档必须都填满，且保底那档要是"真能接受"的
- **判定标准**：三个检查——
  1. **冲稳保三档都有**（一般 2:4:2 或 3:4:3，按本省规则调）
  2. **每一档里，专业服从调剂的后果都想过**（被调到最冷门的专业，能不能接受）
  3. **保底档的学校/专业，问自己"如果只上这个，我会不会后悔四年"**——会，就说明保底还不够低

- **依据**：方法判断（填报是一个有约束的最优化问题，不是选最爱） + 公理 6（要不要 = 代价付不付得起，最坏情况的代价要先算） + 
- **反例**：① 有明确的强关联职业目标——专业优先，宁可学校降一档；② 分数在批次线附近——这时"有学上"优先于"上好学校"；③ 家里有明确安排（接班、地方关系）——按家里的资源排，不按通用逻辑
- **材料不足**：不知道分数和省份 → 不给具体建议，只给方法和检查表

### J7 专业饱和、学历贬值了怎么办

- **判断**："饱和"说的是**平均水平**，不是个体。任何专业里，前 20% 的人都不缺机会。所以问题不是"这个专业饱和了吗"，是"我怎么排到前面"
- **判定标准**：能说出「我在这个专业里，凭什么是前 20%」。答不出来，专业饱和就是他真实的风险；答得出来，饱和跟他关系不大
- **依据**：所有专业都水，但同一专业有人年薪百万 + 公理 4（稀缺决定回报，前 1% 被追着要，中间那段投入产出比最差） + 信号理论（学历贬值是"信号通胀"，解法是换更强的信号：作品、项目、实习）
- **反例**：① 整个行业在结构性萎缩（不是饱和，是消失）——这时该换行业，不是提高排名；② 他已经在前 20% 但依然找不到工作——问题在信号传递（简历、表达、渠道），不在专业；③ 目标是体制内——饱和不影响，看的是考试
- **材料不足**：不知道他说的是哪个专业 → 问一句"你担心的是什么"（找不到工作 / 工资低 / 同学都比我强），三种担心的解法完全不同

## 常见误判（学生以为 vs 实际）

| 学生以为 | 实际 |
|---|---|
| 热门专业就好 | 热门意味着竞争激烈。判断"对他好不好"，不看热度 |
| 选错专业这辈子就完了 | 弱关联专业本来就可以外溢；强关联专业也有人在研究生阶段转 |
| 学校比专业重要（或反之） | 取决于目的。考公看专业，市场化就业看城市，保研看学校 |
| 转专业是想转就能转 | 有绩点门槛和窗口期。错过窗口只能辅修/跨考 |
| 辅修了就等于会了 | 辅修是弱信号，作品和项目才是强信号 |
| 专业饱和了没前途 | 饱和说的是平均水平。前 20% 不缺机会 |
| 报志愿要冲一冲 | 冲是必要的，但保底档才是决定你会不会后悔的那一档 |
| 我专业不对口所以没机会 | 三条出路：邻近岗位、泛能力岗位、硬转行。先走成本最低的 |

## 输出模板

### 情况一：他问"我这个专业好不好"

不评价专业，先问用途：

```
【结论】对你要去的方向，这个专业是〔强关联/弱关联〕，所以〔深耕 / 当底座叠技能〕
【为什么】它教的东西能不能变成可交付能力 + 对口岗位有没有门槛
【怎么做】
  1. 去招聘网站搜这个专业名，看岗位数量和 JD 要求（当天能做）
  2. 找一个大三学长问：你们班现在都在干什么（三天内）
  3. 算出你在本专业的排名，这决定你能不能吃到这个专业的红利
```

### 情况二：他问"要不要转专业"

```
【结论】转 / 不转 / 先别急，看一个数
【为什么】转的成本是〔绩点门槛/补修/降级〕，不转的成本是〔强关联程度〕
【怎么做】给三条：转的路径、不转的补救路径、第三条路（辅修/跨考）
【代价】两条路各自放弃什么
```

### 情况三：他只说"我选错专业了"

不接"选错"这个前提，先切：

> 先别急着说选错。你现在是大几？当初为什么选它，现在具体是哪件事让你觉得不对？
>
> 因为"选错"有三种完全不同的情况：专业本身跟你目标不符（能补救）、学不好所以不喜欢（问题在方法）、不喜欢但也没别的方向（问题在方向）。三种解法差很远。

## 完成标准

| 他问的是 | 算答完的标志 |
|---|---|
| 专业好不好 | 给了强弱关联的判断 + 三个可查的事实 |
| 要不要转 | 算了转的成本和不转的成本，给结论 |
| 择校 | 按目的给了三个权重排序，不是报排名 |
| 专业不对口 | 给了三条出路里的具体一条，并说明需要什么凭据 |
| 辅修值不值 | 用"能不能变成可验证凭据"回答 |
| 报志愿 | 给了三档检查表 + 最坏情况的问题 |

**不算答完的**："选你喜欢的""都差不多""看你自己"。

## 不覆盖什么

> **这些是加分项，不是门槛。** 缺的这些不会让这个模块答不出来——判断已经成立，缺的只是真实例子。有例子更可信，没例子照样能给结论、给边界、给这周的动作。
> **唯一红线：不许编一个来填。** 宁可不写。

| 不覆盖 | 怎么处理 | 说明（不阻塞当前使用） |
|---|---|---|
| 分专业的真实去向数据 | ❌ 不收 | 每年都变，让用户查官方就业质量报告 |
| 具体省份的填报规则 | ❌ 不收 | 各省规则差异大且每年调整 |
| 真实的专业/院校案例 | 刻意不写 | 这里只给判断框架，不给个人经历 |
