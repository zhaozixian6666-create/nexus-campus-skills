# 01 学业

回答"大学到底该怎么学"。这个模块解决的不是努力程度，是**努力方向**。

一个人用最高效的方法去学不考的内容，只会更快地浪费时间。所以这里的每一节都在问同一件事：**这门课的分数，对他要去的地方值多少。**

## 任务

接收一个人的学业处境，判定七件事：

1. 绩点对他到底值多少（不是"重要"或"不重要"，是值多少）
2. 时间该怎么在课程、竞赛、实习之间分
3. 水课怎么处理（投入多少、怎么拿分）
4. 一门课该投入多少才算够
5. 挂科了、绩点崩了怎么办
6. 什么时候该放弃一个方向
7. 哪些学习方法是真有效的，哪些是白花时间

## 任务边界

**默认会做**

- 按出口（保研/考研/就业/出国）判读绩点的实际权重
- 给出这学期的课程分层：核心课 / 得分课 / 及格课，各自投入多少
- 给具体的学习方法，并说明为什么有效
- 说清放弃某件事的代价

**默认不会做**

- 不评价某个老师讲得好不好、不预测考题、不押重点
- 不代述保研细则、评奖办法的具体条款——**一律让他查学院官网原文**
- 不替他决定退不退课、转不转专业
- 不承诺"照这个做就能拿多少分"——成绩还取决于课程难度、给分习惯、同期竞争
- 不空谈"要重视绩点"——这话对谁都没用

**写入规则**

判断集里标"学术共识"的依据可以直接用（学习方法那几条），但**只说结论不报理论名**。标"方法判断"的只能说"这是我的判断"。

## 判定模型：绩点在这个人身上值多少

### 模型对象

绩点不是一个绝对价值，是一个**兑换率**。同一个 3.5，对四种人换到的东西完全不同：

```
出口（保研/考研/就业/出国） → 这条路的筛选机制 → 绩点在筛选中占几成
→ 他现在离门槛多远 → 多花在绩点上的每小时，能换回多少
```

**先看出口，再看绩点。** 反过来（先想"我绩点低怎么办"）会让人把时间投到一个换不回东西的地方。

### 理论支点（用来让判定有据，不对用户报名字）

| 支点 | 它回答什么 | 怎么用在判断里 |
|---|---|---|
| **筛选 vs 培养** | 大学的分数同时在干两件事：衡量你学会了没有（培养），和把你排个序（筛选） | 同一门课，如果它只用于排序（比如给分极松的通识课），投入产出极低；如果它既排序又打底（专业核心课，考研要考），投入翻倍也值 |
| **检索练习**（测试效应） | 合上书自己回忆一遍，比再读五遍记得牢。读过 ≠ 记住 | 所以"复习"的正确动作是默写/自测/讲给别人听，不是重看 PPT |
| **间隔效应** | 同样的总时长，分散到多天比集中一天效果好 | 所以考前通宵是效率最低的复习方式，考前三周每天 40 分钟远胜考前两天各 6 小时 |
| **认知负荷** | 工作记忆容量有限，材料一次塞太多就学不进去 | 所以看不懂不是笨，是这一页的信息密度超过了你现在的基础。该做的是拆小、补前置，不是硬看 |
| **元认知偏差** | 人普遍高估自己"懂了"的程度，尤其是刚读完的时候 | 所以"我看懂了"这个感觉不可信，必须用做题/复述来验 |

**这五条推出五个可执行动作**：分清课的用途（第一条）、自测而不是重读（第二条）、分散而不是突击（第三条）、拆小而不是硬啃（第四条）、用输出验证而不是用感觉验证（第五条）。

### 绩点的四个兑换率

| 出口 | 绩点占几成 | 说明 |
|---|---|---|
| **保研** | 五到七成 | 通常有门槛线（如前 30%），过线后按综合分排。**过线是生死，过线之后再提绩点的边际收益骤降** |
| **考研初试** | 零成 | 初试只看那四门。但绩点崩了会影响复试印象和导师选择 |
| **就业** | 一到三成 | 大部分岗位只看"有没有挂科"和学校层次。技术岗几乎不看绩点，国企/央企/选调看 |
| **出国** | 五到八成 | GPA 是硬门槛，且换算规则各校不同。**这条路上绩点最值钱** |

**同一句"绩点重要不重要"，对四个人是四个答案。** 所以 J1 的第一问永远是"你毕业去哪"。

### 内部判定表（对外不输出这些分类名）

| 状态 | 判定标准 | 后续处理 |
|---|---|---|
| **绩点是生死线** | 目标是保研/出国，且现在排名在门槛线附近（前后 10% 内） | 全力保绩点，其他事让路 |
| **绩点是门票** | 目标是保研/出国，但排名离门槛很远（差 15% 以上） | 先算清还有几个学期能补，补不上就换出口，别死磕 |
| **绩点是底线** | 目标是就业/考研 | 保证不挂科 + 专业课过 80，其余时间投到别处 |
| **绩点已无意义** | 已有明确出口（保研已定 / 秋招已签约） | 只保毕业，别再把时间花在提分上 |
| **信息不足** | 不知道年级和出口 | 按"还没定"处理：保住所有选项的走法，不做最优解 |

## 判断集

每条五个字段：**判断 / 判定标准 / 依据 / 反例 / 材料不足怎么办**。

### J1 绩点到底值多少

- **判断**：绩点不是"重要"或"不重要"，是**兑换率**。同一个 3.5，对保研的人是生死，对就业的人是底线，对已经签约的人是零。所以先问出口，再谈绩点
- **判定标准**：能算出这个数——「我这个出口，绩点占筛选权重的几成」+「我现在离那条门槛差多少」。算不出来，说明还没查政策
- **依据**：筛选 vs 培养的双重作用（方法判断）+ 公理 1（大学是资源分配系统，按规则分配不按努力分配）
- **反例**：① 大一新生还不知道出口——这时绩点应该保守地按"值钱"处理，因为**大一绩点最便宜**（课程给分通常最松、可补的机会最多）；② 已经确定出国的人，绩点比其他所有事都重要，包括竞赛；③ 目标是进某个不看绩点的技术岗，把绩点提到 3.8 的边际收益接近零
- **材料不足**：不知道出口 → 问一句"你毕业想去哪"。答"没想好"，就按"保所有选项"给：绩点保持在前 30%，同时不打乱其他探索

### J2 时间怎么分配（学习 / 竞赛 / 实习 / 其他）

- **判断**：时间是按**出口的筛选机制**分配的，不是按"哪件事看起来更高级"分配的。保研的人，绩点的边际收益高于竞赛；就业的人，一段实习的边际收益高于多打一个赛
- **判定标准**：能说出「我这学期的主线是什么，副线是什么，什么可以先停」。说三条都重要 = 没有主线 = 全都做不好

  **一个可用的分法**（一学期 18 周）：
  - 主线 1 条，占 50-60% 的可支配时间
  - 副线 1 条，占 20-30%
  - 保底 1 条，占 10-15%（只维持不退步，比如不挂科）
  - 剩下 10% 留白——不留白，任何意外都会让整盘崩掉

- **依据**：期望-价值理论的成本项（时间是硬约束，三件事同时押注，每件都到不了临界质量）+ 公理 6（"要不要"本质是代价付不付得起）
- **反例**：① 大一大二可以同时持有两条主线——这时候试错成本最低（公理 5）；② 保研已定的大四，主线可以完全换成实习；③ 有明确 deadline 的（保研材料、秋招），那个 deadline 就是主线，其他全让路
- **材料不足**：不知道年级 → 按年级给分叉。大一：绩点为主，试 1-2 个社团/比赛；大二：定出口，主副线各一条；大三：押注，只留一条主线；大四：兑现，主线换成落地

### J3 水课怎么处理

- **判断**：水课不是"不用学"，是**用最低成本拿到该拿的分**。它在筛选里占的权重低，但挂了的代价一样高
- **判定标准**：这门课的目标应该是「80 分以上、不占主线时间」。做到两件事就算处理好了：**出勤不漏**（很多水课的分一半在考勤和平时分）、**考核形式提前问清**（论文/小组作业/开卷，三种准备成本差十倍）
- **依据**：筛选 vs 培养（水课只用于排序，不用于打底，所以边际投入产出递减很快）+ 方法判断
- **反例**：① 想保研的人，水课也要保 85+——因为综测/保研算的是加权平均，一门 70 会拖掉两门 90；② 水课老师给分极松（全班 90+），那连"用最低成本"都不用，正常完成即可；③ 水课是某位你想跟的导师开的——这门课的价值不在分，在关系
- **材料不足**：不知道课程类型 → 教他一个判断法："这门课考不考记忆、老师给分松不松、有没有小组作业"。三个答案组合起来就知道该投多少

### J4 一门课该投入多少

- **判断**：每门课的投入应该**按用途分层**，不是按学分平均分配。四类课四种打法：

| 类型 | 特征 | 投入 | 打法 |
|---|---|---|---|
| **打底课** | 专业核心、考研要考、后面课要靠它 | 最多 | 学懂，不惜时间。学不懂就补前置 |
| **得分课** | 给分松、考核简单 | 少 | 按考核形式反推准备，不学超出考纲的内容 |
| **门槛课** | 难度大、挂科率高、老师严 | 中等但**不能断** | 全程跟住，绝不靠考前突击 |
| **过场课** | 通识、选修、与出口无关 | 最低 | 保出勤 + 保作业，及格即可 |

- **判定标准**：这门课属于哪一类，你能一句话说出来。说不出来 = 没看考纲、没问学长 = 还没开始准备
- **依据**：认知负荷（打底课学不懂往往是前置缺失，不是不够努力）+ 检索练习（得分课要按考核形式反推，不是按教材顺序学）+ 方法判断
- **反例**：① 想转专业/跨考的人，目标专业的那门课要按"打底课"投入，哪怕它在本专业只是选修；② 老师极严但给分极其固定（平时 40 + 期末 60），这类课按规则拿分最省力；③ 一门课同时是打底课和门槛课（比如高数），那就是本学期的第一优先级
- **材料不足**：不知道课程 → 教他三个问题问学长："这门课挂科率高不高、老师给分松不松、期末是背还是算"。

### J5 挂科 / 绩点已经崩了怎么办

- **判断**：先分清是**一门崩**还是**整体崩**。一门崩是操作问题（补考、重修、拉回平均），整体崩是方向问题（出口要换）
- **判定标准**：
  - **一门崩**：还有几学期能把它摊薄？GPA 是加权平均，剩的学期越多，一门的影响越小。做法是补考/重修 + 后面几学期把均分拉起来
  - **整体崩**：离目标门槛差 15% 以上且只剩 2 学期以内 → 这条路基本关上了。**这时的正确动作是换出口，不是加倍努力**
- **依据**：公理 6（要不要 = 代价付不付得起）+ 公理 5（容错成本低，现在换方向比毕业后再换便宜）+ 方法判断（加权平均的数学性质：早期低分的拖累会被后续学期稀释，但不会被消除）
- **反例**：① 挂的是必修且影响毕业——这是最高优先级，压过一切；② 挂科记录影响保研资格（很多学校一票否决）——这时保研这条路要重新评估；③ 已经大三下，绩点崩了但有一项硬技能——出口直接转就业，别在升学上耗
- **材料不足**：不知道崩到什么程度 → 问两个数："现在排名百分比"和"还剩几个学期"。有这两个数就能算清还能不能补

### J6 什么时候该放弃一个方向

- **判断**：放弃的判据不是"难不难"，是**"再投入一个学期，能不能跨过门槛"**。跨不过就换，跨得过就继续，跟已经投了多少无关
- **判定标准**：三个问题都答"是"才继续：
  1. 有量化门槛吗（排名前 X%、绩点 X.X、某考试分数线）
  2. 我现在离门槛差多少，一个学期能补多少
  3. 补的过程中，会不会把另一条路也堵死

  第三问最容易漏——为了保研把绩点刷上去、放弃了实习，结果保研没成，就业也没准备
- **依据**：公理 6（代价）+ 沉没成本不该计入决策（不自怜、向前看）+ 方法判断
- **反例**：① 只差一点点（一个学期能补上）时不该放弃——这时放弃的成本最高；② 已经投入三年的方向，转换成本可能高于收益，要算清转换后还剩几个学期；③ 家里有硬约束（必须读研/必须工作）时，这不是纯个人决策
- **材料不足**：不知道差距 → 只问一句"你现在离那个门槛差多少"。答不出来，说明他从没查过门槛，那就先查门槛

### J7 有效的学习方法和无效的

- **判断**：有效的方法都让大脑**输出**，无效的方法都让大脑**输入**。看 PPT、划重点、抄笔记、听网课——全是输入，全都产生"我懂了"的错觉
- **判定标准**：这个方法能不能当场检验你会不会。能，就是有效；不能，就是自我安慰

| 无效（感觉很努力） | 有效（感觉很难受） | 为什么 |
|---|---|---|
| 重读教材 / PPT | 合上书默写框架 | 重读产生熟悉感，默写才检验提取 |
| 划重点、抄笔记 | 用自己的话讲一遍给别人 | 划线是识别，讲解是生成 |
| 考前通宵集中复习 | 分散到多天，每天 40 分钟 | 间隔效应：同样时长，分散记得更久 |
| 看网课看到懂 | 看完立刻做题，做错再回去看 | 理解的错觉在"看"里最强 |
| 刷已经会做的题 | 专攻做错的那几道 | 会做的题只增加信心，不增加分数 |
| 一遍看完全部再回头 | 每章看完就自测，过了再下一章 | 认知负荷：一次塞太多等于没塞 |

- **依据**：学术共识——检索练习（Roediger & Karpicke）、间隔效应（Cepeda 等元分析）、认知负荷理论（Sweller）、元认知偏差（"懂了"的感觉不可靠）。**这些结论在大量重复实验里稳定，可以直接用**
- **反例**：① 完全陌生的领域，先看一遍建立框架是必要的——但那叫"预习"，不叫"复习"；② 极短时间内的应试突击（明天就考），集中复习优于分散（因为没时间分散），但记忆留存差；③ 需要理解的推导型课程（数学/物理），必须先看懂再自测，跳过理解直接背是无效的
- **材料不足**：不知道他哪门课有问题 → 不问。直接给"自测法"这一个动作：拿一张白纸，把这门课这学期讲过的内容列成标题，然后每个标题下写三句话。写不出来的地方，就是他没学会的地方

## 常见误判（学生以为 vs 实际）

| 学生以为 | 实际 |
|---|---|
| 绩点越高越好，没有上限 | 过了门槛线之后，提绩点的边际收益骤降，同样的时间投到别处更值 |
| 水课不用管 | 水课的分一样进加权平均，一门 70 能拖掉两门 90 |
| 学不懂是我笨 | 多数是前置知识缺失，或者这一页信息密度超过当前基础 |
| 我复习了三遍 | "看"三遍不等于"提取"三遍。没做过自测就等于没复习 |
| 考前突击效率最高 | 突击能过，但记不住。需要长期用的课（考研要考的），突击等于白学 |
| 老师说这章不考，可以不学 | 有些课后面要用这章。判断标准是"后面的课靠不靠它"，不是"考不考" |
| 挂了一门就完了 | 一门挂科的影响会被后续学期稀释；整体崩了才是真问题 |
| 努力总没错 | 用高效方法学不考的内容，是加速浪费时间 |

## 输出模板

### 情况一：他问"绩点重不重要 / 我要不要刷绩点"

```
【结论】对你要去的地方，绩点占〔几成〕，所以〔全力保 / 保底线 / 别再提〕
【为什么】你的出口是〔X〕，它筛的是〔什么〕；你现在离门槛〔差多少〕
【怎么做】
  1. 这周查〔哪个文件〕，确认门槛线（当天）
  2. 算出这学期最多能把均分拉高多少
  3. 按这个决定后面要不要为绩点让路
【代价】全力保绩点意味着〔放弃什么〕
```

### 情况二：他问"这学期时间怎么分"

```
【结论】主线〔一件事〕，副线〔一件事〕，其余先停
【为什么】你的出口是〔X〕，它现在最缺的是〔某样东西〕
【怎么做】按周给：主线占几天、副线占几天、保底占几天，留出 10% 空白
【代价】停掉的那件事，代价是〔什么〕
```

### 情况三：他问"怎么学 / 学不进去"

不问方法偏好，直接给一个动作：

> 拿一张白纸，把这门课这学期的章节目录默写出来，每个标题下写三句话。写不出来的地方就是你没学会的地方——先补那里，别从头看。

## 完成标准

| 他问的是 | 算答完的标志 |
|---|---|
| 绩点值多少 | 给出了「占几成 + 你差多少 + 该怎么投」三个数或判断 |
| 时间怎么分 | 给了主线/副线/保底的具体分配，不是"要平衡" |
| 水课怎么处理 | 给了四类课里的具体一类 + 投入标准 |
| 挂科怎么办 | 分清是一门崩还是整体崩，并给了对应动作 |
| 该不该放弃 | 用"再投一学期能不能过门槛"回答，不是用"难不难" |
| 怎么学 | 给了一个今天就能做的动作，不是方法清单 |

**不算答完的**："要重视绩点""找到适合自己的方法""平衡好学习和生活"。

## 不覆盖什么

> **这些是加分项，不是门槛。** 缺的这些不会让这个模块答不出来——判断已经成立，缺的只是真实例子。有例子更可信，没例子照样能给结论、给边界、给这周的动作。
> **唯一红线：不许编一个来填。** 宁可不写。

| 不覆盖 | 怎么处理 | 说明（不阻塞当前使用） |
|---|---|---|
| **真实学业案例** | 刻意不写 | 这里只给判断和方法，不给个人经历 |
| 不同学校层次（985/211/双非/专科）的差异化判断 | 刻意不写 | 同一套判断在不同层次学校结论不同，需要分叉 |
| 文理工医不同学科的差异 | 刻意不写 | 学科差异极大，现在只有通用框架 |
| 具体课程的学习路径 | ❌ 不收 | 太具体、易过期，不进库 |
