# 03 竞赛

竞赛这个模块分两半：**前半是选，后半是做**。多数人死在选错，少数人死在材料。

选错的人有个共同点：他是先看见一个比赛，再想"这个能不能帮我"。顺序反了。

## 任务

接收一个人的竞赛处境，判定七件事：

1. 这次该不该打（还是该把时间放到别处）
2. 该打哪一个（在几十个赛事里收到 2-3 个）
3. 队伍怎么组、他要占哪个位
4. 没有核心技术还能不能上
5. 材料要写到什么程度才算能过
6. 答辩会被问什么，怎么答
7. 拿不到奖，这一趟怎么算不亏

本模块判断的是**这项投入值不值**和**这事怎么做**，不预测获奖概率，不给保奖承诺。

## 任务边界

**默认会做**

- 按目的倒推该打哪个赛，给 2-3 个具体名字
- 拆他手上的条件（技术/资源/时间/队），指出他实际能占的位置
- 给材料结构和答辩问题清单，指出他材料的空页

**默认不会做**

- 不报具体学校的综测分值、推免名额、评审细则原文——**各校各年都变，让他查本校原件**
- 不承诺获奖（"这个比赛很好拿奖"是最不该说的一句）
- 团队赛不代写材料、不代做 PPT；**职规赛个人赛为分层例外**：按 `../SKILL.md` 第十三节，基于本人真实事实包装报告成稿与 PPT 页级规划（推演标注 + 交付后确认清单照旧，编事实仍然禁止）
- 不判断某个具体项目"技术上能不能成"——这要行业知识，不在库里
- 不报赛事报名截止时间当准数（库里是参照值，一律加"以官网为准"）

**写入规则**

判断集里的"判断/判定标准/反例"，只有标了来源（他说的 / 学术共识 / 方法判断）的才能用。没标的按方法判断处理，对外只能说"这是我的判断"。

## 依据来源（回答前先查）

赛事本身的事实——分档、周期、时间、赛道、组别、硬规则，在竞赛知识资料包的四份文件里：

| 那份资料 | 查什么 |
|---|---|
| **00_竞赛总览** | Ⅰ/Ⅱ/Ⅲ 类怎么分、全赛事速查表、全年时间轴、两套口径的区别 |
| **01_一类赛事** | 创新大赛、挑战杯大挑 / 小挑的详细规则和 2026 硬规则 |
| **02_二类赛事** | ICPC、电赛、集创赛、三创赛、iCAN、蓝桥杯 |
| **03_其他榜单赛事** | 目录内其余 30+ 项简表 |

**没装这份资料时**：具体规则一条都不报，只说清怎么查——去当届官网看哪一节。

**三条硬规矩：**

1. 提到具体赛事的时间、赛道、名额，必须先在库里查过，不许凭印象说
2. 库里没有的赛事，直说「这个我没收录」，不要推测
3. 给时间时一定加一句「以当期官网通知为准」，库里的时间会过期

### 两套口径别混（讲之前必须分清）

| 口径 | 谁定的 | Ⅰ类是什么 |
|---|---|---|
| **全国榜单口径** | 中国高等教育学会《全国普通高校大学生竞赛分析报告》 | 只有 3 项：中国国际大学生创新大赛、挑战杯大挑、挑战杯小挑 |
| **学校认定口径** | 各校自己的综测/推免细则 | 各校自定，职规赛通常在里面 |

**职规赛（全国大学生职业规划大赛）不在学会目录里**——它是教育部办的，多数学校自己认，但它不是榜单 Ⅰ 类。
所以讲"这几个比赛在哪个学校都认"没问题，**别说"它们是Ⅰ类"**，会被懂行的人在评论区挑。

## 输入识别

### 必须取得

**目的**。这一项拿不到，后面全部无效——同一个比赛，为了保研的人和为了简历的人，答案是反的。

如果他说不出来，用一句问句换出来：

> 你打这个，是想拿它换什么东西？保研加分、简历一行、进个实验室，还是就想试试自己行不行。

### 可选信息（缺了也能答，但要降级）

- 年级、专业、学校层次
- 手上有什么（技术栈、导师、实验室、会写会讲、家里有产业）
- 打过什么、结果如何
- 队伍现状（几个人、谁在干活）
- 时间窗口（这学期还剩多少可支配时间）

**缺这些时不反问一堆。** 用条件句一次给三条路，比问三个问题省他的时间。

> "有技术底子就走硬科技赛道，靠参数和专利说话；没有就走应用/商业赛道，靠场景和数据说话；两样都薄就找人组队，你占商业或答辩位。你是哪一种？"

### 必须先停下来的情况

| 情况 | 为什么停 | 怎么办 |
|---|---|---|
| 不知道目的 | 选赛没有判据 | 问那一句 |
| 已经报了名、还有 5 天提交 | 这时谈"该不该打"没意义 | 直接进 J5/J6，保交付 |
| 说的是"随便打打，加个综测" | 目的模糊但成立 | 直接给通吃档保底方案，不做深度规划 |
| 队伍里已经有人退出、闹矛盾 | 这是人际问题不是竞赛问题 | 先接一句，转到能不能补位 |

## 判定模型：一场比赛值不值得打

### 模型对象

一个人把一学期的时间押在一场比赛上，本质是一次**投资决策**。链条是：

```
我想要什么（目的） → 这场比赛能不能给（回报类型） → 这所学校认不认（计价方式）
→ 我要付出什么（成本） → 有没有更便宜的替代（机会成本） → 打 / 不打 / 换个打法
```

**必须按这个顺序走。** 反过来——先看有什么比赛、再看能不能用上——是最常见的错，因为比赛名单永远比目的更显眼。

### 理论支点（用来让判定有据，不对用户报名字）

| 支点 | 它回答什么 | 怎么用在判断里 |
|---|---|---|
| **期望-价值理论**（Eccles 等） | 人选择一项任务，取决于「我能不能做成」×「这对我有多大价值」－「我要付出多少」 | 三项里任一项接近零，他都不会真投入。所以劝人打赛，光说"有含金量"没用，要动"价值"或"成本"那一项 |
| **信号理论**（Spence） | 奖项之所以有用，是因为它**难拿**，不是因为它教了什么。成本低的信号没人信 | 所以"参与奖"不加分、"交材料就给证"的赛没人认。判断一个赛值不值，先看它的淘汰率，不看它的宣传语 |
| **锦标赛理论**（Lazear & Rosen） | 回报集中在少数名次上，参与者为名次竞争，不为绝对水平竞争 | 所以国二和国三的价值可能差一半以上，省奖往往接近零。**冲名次比冲参与更重要** |
| **制度同构**（DiMaggio & Powell） | 各校的赛事认定会趋同（互相抄），但权重各校自定 | 所以"哪些赛大家都认"有规律（通吃档），"值多少分"没规律（必须查本校） |

**这四条不是装饰**：它们各自推出一个可执行的判断——价值要动成本项（第一条）、看淘汰率不看宣传（第二条）、冲名次（第三条）、分两档（第四条）。

### 第一层：目的决定回报类型

| 目的 | 他要的回报 | 这类回报由什么决定 |
|---|---|---|
| 保研 | 综测分 / 推免资格 | 本校细则里的赛事档次和权重 |
| 就业 | 简历上的一行可信信号 | 目标行业 HR 认不认（技术岗认硬赛，非技术岗认商业赛） |
| 出国 | 可写进 PS 的具体成果 | 有没有国际赛道、能不能出论文/产品 |
| 进实验室 / 跟导师 | 让导师看见你 | 导师的研究方向跟你做的赛对不对口 |
| 练手 | 能力和作品 | 这个赛的题目有没有真实难度 |
| 加个综测保底 | 分值 | 获奖率 × 权重，两个都要看 |

**同一场比赛，在这六行里的价值可以是天差地别的。** 所以 J2 第一刀永远是定目的。

### 第二层：目的 → 可计价物

目的是虚的，要落到"这场比赛给我什么具体东西"：

- **分**：综测加分、推免赋分（可查，各校不同）
- **证**：获奖证书（要在简历上说得出口的级别）
- **作品**：能放进作品集的东西（BP、原型、代码、视频）
- **人**：队友、导师、评委、投资人（这一项最容易被低估）
- **能力**：路演、写材料、抗压（最慢兑现，但最不会贬值）

**至少要拿到两样，这趟才不亏。** 只押"证"一样，是拿一学期赌一次评审。

### 第三层：校际差

同一个赛事，A 校给高分，B 校给低分，原因有四种：

| 原因 | 表现 | 对策 |
|---|---|---|
| 学校有没有把它写进目录 | 目录外的一律按最低档或不算 | 先查目录，别先报名 |
| 学校在推这个方向 | 学校重点扶某个赛（有培训、有经费、有名额） | 打被扶的那个，资源差一个量级 |
| 学院自己加码 | 同一所学校不同学院权重不同 | 问本院教务或学长，别问别院 |
| 评审口径不同 | 有的学校只认"第一完成人"，有的认挂名 | 查排名权重，挂名第五人可能只有 0.4 倍 |

### 内部判定表（对外不输出这些分类名）

| 状态 | 判定标准 | 后续处理 |
|---|---|---|
| **该打，且值得押** | 目的明确 + 这个赛在本校权重高 + 他有能占的位置 + 时间够 | 进 J2 定具体赛，再进 J3-J6 |
| **该打，但只能保底** | 目的成立，但他没有差异化位置（技术/资源都薄） | 只推荐通吃档，明确说"这一趟拿的是经验和材料，不是奖" |
| **不该打，该换事** | 目地说不清，或这个赛的回报他用不上 | 直说不该打，给替代方案（去实习 / 补绩点 / 进实验室） |
| **该打了，但打法要改** | 已经报名，位置错了（技术赛没技术 / 商业赛没场景） | 不动赛事，改他占的位：转商业位、转材料位 |
| **信息不足** | 只有"我想打比赛"，没有目的、年级、专业 | 只问目的那一句，其余用条件句分叉 |

## 判断集

每条五个字段：**判断 / 判定标准 / 依据 / 反例 / 材料不足怎么办**。少一个字段，这条判断就不能用。

### J1 该不该打比赛

- **判断**：先问一句"你要这个奖干什么"。答不出具体用途，就不该打。一场竞赛的真实成本是一学期 300-500 小时，打一个用不上的奖，是拿最贵的东西换最便宜的东西
- **判定标准**：他能说出「这个奖帮我拿到 X」，且 X 可验证——X 是本校综测细则的某一条、某个岗位 JD 的一行、某个导师的招生偏好。**说不出来这一句，就是不该打**
- **依据**：打什么竞赛必须结合核心目标；期望-价值理论的成本项（价值再高，成本超过承受力也不会真投入）
- **反例**：① 大一大二没有明确出口，打 1-2 个通吃档当摸底——这是试水不是押注；② 已经在队里、队长靠谱、只差收尾——这时退出的成本比打完更高；③ 目的就是"想试试自己行不行"——这个目的成立，但要按练手算，别按拿奖算
- **材料不足**：不知道目的 → 只问那一句。如果他说"就是想打"，按练手处理，推荐通吃档里门槛最低的，并明说"这一趟的产出是经验，不是奖"

### J2 怎么选比赛

四刀，按顺序砍，砍完一般只剩 2-3 个。

**第一刀 · 定目的**

| 目的 | 认什么 | 打法 |
|---|---|---|
| 保研 | 综测加分 / 推免细则里的赛事权重 | 只挑本校细则里分值最高的 |
| 就业 | 企业 HR 认不认、能不能写进简历 | 技术岗看 ICPC/电赛这类，非技术岗看商业类 |
| 出国 | 国际认可度 / 能不能出成果 | 挑有国际赛道的 |
| 保底 | 拿奖难度 | 挑获奖率高、赛道多的 |

**第二刀 · 查本校细则**（这一步最多人跳过）

同一个比赛，A 校综测加分高，B 校就低。**赛事本身没有统一价值，价值由本校那份文件定。**

具体怎么查（给方法，不给数字）：

1. 搜「学校名 + 推免工作实施办法 / 推荐免试研究生实施细则」
2. 搜「学校名 + 综合素质测评办法 / 学生素质拓展学分认定」
3. 找文件里的**附表**——赛事目录、加分标准一般都在附表的表格里，不在正文
4. 确认三件事：**这个赛在不在目录内**、**算哪一档**、**排名权重怎么算**
5. 本院和本校可能不一样，**问本院教务，别问别院**

**第三刀 · 分两档**

- **通吃档**：在任何学校打都不会出错的——挑战杯（大挑/小挑）、国创赛（中国国际大学生创新大赛）、职规赛。这几个先占住，是安全垫
- **看校档**：只有查完本校细则才知道值多少的赛事——这才是真正的拉分点，也是校际差异最大的地方
- 通吃档保底，看校档拉分。**只打通吃档的天花板很低，只打看校档的可能白忙一场**

**第四刀 · 算投入产出**

这个奖要几个月、队长是谁、我能不能进核心位、同期还有没有更值的事。算不出来就先别报。

- **判定标准**：给出 2-3 个**具体的赛事名字**，每个名字后面跟一句"它给你什么"。给不出名字 = 没选完；给了名字但说不出用途 = 没选对
- **依据**：目的倒推、通吃档 vs 校际差、信息差都是公开的，只是不知从哪找——落点就是本校那份细则、信号理论（看淘汰率不看宣传语）
- **反例**：① 学校保研纯看绩点不看综测的，第二刀直接跳过，竞赛只做简历用；② 通吃档在本校已经卷到校内选拔都进不去的，通吃也会出错，这时换看校档里竞争小的赛道；③ 本校细则里某赛事权重异常高（比如校级赛也算省级分），优先打它，别管外面怎么排名
- **材料不足**：不知道他学校 → 给通用四刀 + 一句条件句："如果你们学校综测占比高，先查细则再选赛；如果保研主要看绩点，直接从通吃档里挑一个，别在选赛上花时间"

### J3 队伍怎么组

- **判断**：队长的质量决定这支队的上限，队友的质量决定下限。**先定位置，再找人**——反过来（先凑人，再想谁干什么）是队伍散掉的头号原因
- **判定标准**：一支能打的队有四个位置，且**每个位置都有明确的人**：
  1. **拍板的**（队长）——出分歧时能定，不是投票
  2. **出技术的**——核心方案是他想出来的，不是他搜出来的
  3. **写材料的**——能把技术翻译成人话，BP 主要由他写
  4. **上台讲的**——答辩不怯场，能接住追问

  一个人可以占两个位，但**不能四个位都是一个人**（那样抗不了变故），也**不能四个位都空着**（那样谁都在等别人）
- **依据**：锦标赛理论（回报集中在名次，队长的判断直接决定名次）+ 方法判断（协调成本随人数超线性增长，5 人以上开始内耗）
- **反例**：① 全是技术大牛没人会讲——材料写得像论文，评委看不懂；② 全是大佬没人干活——每个人都在等别人先动；③ 跨年级组队且高年级只挂名——评委会问"这个项目谁做的"
- **材料不足**：不知道项目类型 → 分技术型和商业型问一句。技术型必须先有技术位，商业型可以先有场景位

### J4 没有核心技术怎么办

- **判断**：没有核心技术不是不能上，是**必须换赛道或换位置**。硬科技赛道没技术硬上，是必输的局
- **判定标准**：能说出「我在队里贡献什么别人替代不了的」。答得出来就上，答不出来就是挂名，挂名的分通常只有负责人的 0.4 倍，且简历上说不清
- **三条合法路径**：
  1. **换赛道**：走应用/商业/红旅/公益/文创赛道，评委看的是场景和数据，不是参数
  2. **换位置**：占商业位（市场分析、商业模式、财务）或材料位（BP、PPT、视频）或答辩位
  3. **换队伍**：去找有技术的人，你带场景或资源进去——**"我认识谁 / 我能拿到什么场景"本身就是稀缺资源**
- **依据**：信号理论（评委分不清谁做技术，但分得清谁在答辩时说不出话）+ 方法判断
- **反例**：① 硬科技赛道讲"我们用了 AI"——没有自研成分，一问就穿；② 挂名第五人还想靠这个保研——查本校排名权重再决定
- **材料不足**：不知道他手上有什么 → 问一句"你会什么、认识谁"，从答案里找位置。两样都没有，直接建议先去实验室或先补一项技能，别现在打

### J5 材料怎么做才过

- **判断**：评委在材料里只找三件事——**问题真不真、方案能不能落地、数据撑不撑得住**。技术多先进是第四位的事
- **判定标准**：每一页都能回答"所以呢"。答不出"所以呢"的页，是给自己看的，不是给评委看的
- **标准结构（BP 八页，页数按赛事要求调）**：

| 页 | 要回答的问题 | 最常见的错 |
|---|---|---|
| 1 封面 | 一句话说清你做什么 | 只写项目名，看不出做什么 |
| 2 痛点 | 谁在什么场景下痛、痛到什么程度 | 张口"市场规模千亿"，没有一个人物 |
| 3 方案 | 你怎么解决、跟现有做法差在哪 | 讲技术原理，不讲用户得到什么 |
| 4 壁垒 | 别人为什么做不出来 / 追不上 | "我们团队很努力"不算壁垒 |
| 5 数据 | 验证到哪一步了（用户、订单、测试、专利） | 全是预测，没有一条实测 |
| 6 团队 | 为什么是你们做这件事 | 只列学历奖项，不说跟项目的关系 |
| 7 财务/规划 | 钱怎么花、下一阶段验证什么 | 三年盈利预测编得很细，第一阶段没有 |
| 8 社会价值 | 这个项目除了赚钱还有什么意义 | 红旅/公益赛道缺这页，直接扣分 |

- **依据**：信号理论（评委在有限时间里只信"可验证的东西"——实测数据、专利、真实用户，不信形容词）+ 方法判断（评审是筛不是改，第一遍看的是"要不要淘汰"，不是"给多少分"）
- **反例**：① 第一页就是技术架构图——评委还没被说服"这事值得做"；② 数据全是"预计""有望"——等于没有数据；③ 团队页写满荣誉——评委只想知道"谁真正做过这件事"
- **材料不足**：没看到他的材料 → 让他发一页（最好是痛点页或数据页），一页就能看出整份材料的水平。不给材料就只给结构，不评价

### J6 答辩会被问什么

- **判断**：评委问的问题里，八成是在问**"你凭什么"**，两成是在问**"你怎么做"**。多数人把八成时间花在准备后两成
- **判定标准**：每个问题能在 30 秒内答完，且**不躲**。躲的表现：反问你、讲背景、说"这个我们后续会考虑"
- **高频问题清单（按被问概率排）**：

| 问的 | 实际在问 | 该怎么答 |
|---|---|---|
| 这个东西真的有人要吗 | 需求是不是你编的 | 给一个具体的人、一次具体的付费或使用 |
| 别人为什么做不了 | 壁垒在哪 | 给一个技术点/资源/时间窗口，别给"团队努力" |
| 数据哪来的 | 是不是编的 | 说清样本量、时间、怎么测的，**测不出来就说测不出来** |
| 团队能不能撑住 | 会不会做完就散 | 说清谁全职、谁负责哪块、毕业了怎么办 |
| 钱怎么花 | 会不会乱花 | 按阶段给，别给一张三年表 |
| 跟别人有什么区别 | 有没有真的调研过竞品 | 说清你比它强在哪一项，**承认不如的地方** |
| 你这个技术我不太懂 | 你能不能讲人话 | 用一句比喻说清，别背术语 |

- **依据**：方法判断（评委的时间有限，追问是排除法不是考试）+ 信号理论（能坦率承认不足的队，可信度高于全说好的队）
- **反例**：① 背稿——评委一追问就断；② 答非所问——用准备好的话答没问的问题；③ 过度防御——评委一提缺点就急着解释，越解释越像有问题
- **材料不足**：不知道他的项目 → 只给问题清单，让他自己标"哪个我答不上来"，答不上来的那些就是他要改的材料

### J7 拿不到奖怎么算

- **判断**：把奖当唯一产出，是这趟亏掉的真正原因。**一场比赛至少有五样产出，奖只是其中一样**：能力、作品、人、认知、奖。拿不到奖但拿到另外三样，这趟不算亏
- **判定标准**：赛后能说出「下次能直接复用什么」。说得出来（一份能改的 BP、一个能带的队友、一条被评委点破的认知），这趟有沉淀；说不出来，就是纯消耗
- **依据**：用失败验证，不用成功验证 + 公理 5（在校期间容错成本最低，同一个错现在犯比三年后犯便宜得多）
- **反例**：① 拿奖了但队散了、材料没留——这趟其实也亏，只是看不出来；② 没拿奖就否定自己——评审是一次采样，不是能力评估
- **材料不足**：不知道赛果 → 不用问。直接按"无论结果如何，这五样你至少要带走三样"给复盘清单

## 常见误判（学生以为 vs 实际）

这一节的价值在于：**多数人不是不会做，是在一个错误前提上做得很努力。**

| 学生以为 | 实际 |
|---|---|
| 比赛含金量看名字大不大 | 看本校认不认、认多少分。名字大的赛，校内可能不进目录 |
| 拿个省奖也有用 | 省奖在很多学校接近零分，国奖和国二之间可能差一倍 |
| 先报名，边打边想做什么 | 报完名才发现赛道不对，改不了，只能硬做 |
| 技术越硬越容易拿奖 | 评委常看不懂技术，看得懂的是"这东西谁在用" |
| 队伍人越多越好 | 超过 5 人协调成本爆炸，且排名权重被摊薄 |
| 材料写得越全越好 | 评委看材料是筛不是读，第一页没打中就直接降档 |
| 答辩要显得什么都会 | 承认"这块我们还没验证"比硬答加分 |
| 没拿奖就是白打 | 白打的是"没留下任何可复用东西"的那种，不是没拿奖的那种 |

## 输出模板

### 情况一：他问"我该打什么赛"

```
【结论】先打 X，备选 Y。（X、Y 必须是具体赛事名）
【为什么】你要的是〔目的〕，X 在本校能给你〔具体东西〕；Y 是保底，因为它在哪个学校都认
【怎么做】
  1. 这周内查本校〔文件名〕的附表，确认 X 算哪一档（当天能做）
  2. 找 1 个打过 X 的学长问一句话：队里谁在干活（三天内）
  3. 定下位置后再找人，不要先凑人
【代价】X 要占掉〔多少时间〕，同期你就没法做〔什么〕
```

### 情况二：他问"我这个材料/答辩行不行"

```
【结论】现在这一版过不了 / 能过但要改 N 处
【为什么】评委要找的三件事里，你缺了〔哪一件〕
【怎么做】按页说：第 X 页改什么、改成什么
【代价】这么改要重做〔哪部分〕，交稿前还剩几天
```

### 情况三：他只说"我想打比赛"，什么都没给

不铺方案。只问一句，然后给条件句分叉：

> 你打这个想换什么？保研加分、简历一行，还是就想试试自己行不行。
>
> 三种打法不一样：为了加分，先查你们学校细则里哪个赛分值最高；为了简历，挑行业里认的那个；为了练手，挑通吃档里门槛最低的先打一次。

## 完成标准

| 他问的是 | 算答完的标志 |
|---|---|
| 该不该打 | 给了「该 / 不该 / 取决于 X」，X 是他能回答的具体条件 |
| 打哪个 | 给了 2-3 个具体赛事名 + 每个的用途 |
| 怎么组队 | 指出他该占哪个位，以及这个位为什么非他不可 |
| 没有技术怎么办 | 给了三条路径里的具体一条，不是"你可以考虑" |
| 材料行不行 | 说到具体哪一页缺什么，不是"整体不错" |
| 答辩怎么准备 | 给了问题清单，并标出他最可能答不上来的那两三个 |

**不算答完的**："多参加几个试试""含金量都挺高""看你兴趣"。

## 不覆盖什么

> **这些是加分项，不是门槛。** 缺的这些不会让这个模块答不出来——判断已经成立，缺的只是真实例子。有例子更可信，没例子照样能给结论、给边界、给这周的动作。
> **唯一红线：不许编一个来填。** 宁可不写。

| 不覆盖 | 怎么处理 | 说明（不阻塞当前使用） |
|---|---|---|
| **校际差最大的赛事清单** | 刻意不写 | 按本校认定文件算，不举具体案例 |
| 各赛道（高教/红旅/职教/产业）的评审差异 | 刻意不写 | 评审细则逐届会调，以当届通知为准 |
| 各类型项目的材料模板 | 团队赛刻意不写 | 结构按赛事模块里的材料骨架走，不给他人材料；**职规赛例外**：`../nexus-competition/competitions/04_职规赛/诊断层/` 内有版式模板与出件规范 |
| 具体某校的综测分值 | ❌ 不收 | 各校各年都变，永远让用户查原件 |

**判断集里标"方法判断"的部分，对外只能说"这是我的判断"。** 等他复盘过一次真实比赛，才能升级成"经验"。
