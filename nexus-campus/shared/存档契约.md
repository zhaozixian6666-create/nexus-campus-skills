# 存档契约

一次对话解决过的大学问题，如果以后还要回来接着看，存一份。**存档是给"下次回来"用的，不是给"留个记录"用的。**

跟用户对话时只用大白话：说「存档」、说「下次回来」、说「这件事」。本文件里的字段名和路径是技术标识，不出现在对话里。

## 一、存在哪

默认位置：

```
{当前工作目录}/_咨询存档/
```

- 用户指定了别的位置，以他说的为准，本次对话都按那个位置
- 用户有自己的知识库（比如 Obsidian），先问一句「存哪」，别替他决定
- 默认目录不存在就创建，不提示
- **不要存进 `~/.workbuddy/skills/`**——那是 Skill 本体，混进去会被当成能力文件

## 二、目录与文件名

```text
{存档根目录}/{YYYYMM}/{YYYYMMDD-HHMMSS}-{标题}.md
```

- 按月份分文件夹，一个月可能几十份，平铺会乱
- `YYYYMMDD-HHMMSS` 用本地时间
- 标题取这次问题的原话关键词，空格和标点换成 `-`，保留中文
- 同一秒已有同名文件，加 4 位随机后缀，如 `-a7k2`
- **每次新建，不覆盖。** 同一个人同一个问题问三次，就是三份存档，能看出他变化了没有
- 找"最近一份"按文件名前面的时间排，不要按修改时间——云同步会改它

## 三、文件格式

YAML frontmatter + Markdown 正文。

```yaml
---
时间: 2026-11-01T17:20:00+08:00
标题: 绩点排名30还要不要拼保研
状态: 进行中
来人: 大二 / 某双非 / 专业排名 30%
用到: 升学
下一步: 待定
---
```

| 字段 | 填什么 |
|---|---|
| 时间 | ISO 8601 带时区，形如 `2026-11-01T17:20:00+08:00` |
| 标题 | 他原话的关键词，不要自己总结成"咨询记录一" |
| 状态 | 进行中 / 已结论 / 悬置 / 已放弃 |
| 来人 | 位置信息（年级、学校层次、专业、排名段位），能填几项填几项 |
| 用到 | 这次实际用了哪几个模块，逗号分隔 |
| 下一步 | 他已经确认的下一步；没确认就写「待定」 |

**状态怎么定**

| 值 | 什么时候 | 对他说 |
|---|---|---|
| 进行中 | 还在聊、还没定 | 进行中 |
| 已结论 | 结论出了，只剩执行 | 已结论 |
| 悬置 | 他说"先放着" | 悬置 |
| 已放弃 | 他决定不走这条路 | 已放弃 |

拿不准就用「进行中」。

时间用命令取，不要自己算：

```bash
python -c "from datetime import datetime; print(datetime.now().astimezone().isoformat(timespec='seconds'))"
```

## 四、正文六段

顺序固定，每段都要有。真没有内容的写「（无）」，不要整段消失——**整段消失的存档，下次回来读不出哪些是没聊过、哪些是聊过但没结论。**

```markdown
## 他原来问什么

（1-2 句，保留他原话的语气，不要改写成书面问题）

## 已经定下来的结论

（每条一句话。没有就写「（无）」）

## 他否掉的方向

（每条写清为什么否。没有就写「（无）」）

## 还没验证的假设

（我推的、他没确认的。没有就写「（无）」）

## 已经确认的下一步

（做什么、为什么、对应哪块。没确认就写「待定，下次回来重新判断」）

## 备注

（对以后回访有用的任何信息：他的时间节点、家里的约束、他在意什么）
```

## 五、下次回来怎么接

他再说起同一件事时：

1. 先读最近一份存档，把「他原来问什么」「已经定下来的结论」接上，**不让他重复背景**
2. 状态是「进行中」的，从「已经确认的下一步」接着往下推
3. 状态是「悬置」的，先问一句"上次放着的那件事，现在要不要接着看"，不要自作主张继续
4. 状态是「已结论」的，只在他提出新问题时才动，不主动翻旧账

**不要一次读十份存档。** 只读和当前问题相关的那一份，或者同一个人最近的一份。

## 六、什么时候不该存

- 只是问了个事实（"大创什么时候报名"）——查完就完
- 一句话答完、没有后续的
- 他明确说"随便聊聊"
- 内容里全是他不愿意留下的东西（家里的事、跟谁闹矛盾）——这种只存结论，不存细节

## 七、隐私

存档里会出现他的学校、排名、家庭情况。三条硬规矩：

1. **只存在本地**，不往任何远端传
2. 不把他的信息写进 `knowledge/` 或 `capabilities/`——那是公共判断，不是个案
3. 万一以后要拿个案当例子讲出去，必须先改成"有个人"，并且问他
