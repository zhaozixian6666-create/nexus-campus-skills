# 术语表

同一件事在这套库里只有一个说法。**写的时候用左列，不用右列。**

## 一、位置

| 用这个 | 不用 | 为什么 |
|---|---|---|
| 资源 | 人脉、关系 | 资源包含机会、名额、信息，不只是人 |
| 名额 | 指标 | 名额是学生能听懂的话 |
| 窗口期 | 时机、机会期 | 窗口会关，能说明紧迫性 |
| 学院官网 | 学校官网 | 政策和名额在学院那一层 |

## 二、动作

| 用这个 | 不用 | 为什么 |
|---|---|---|
| 投 | 递简历、海投 | 一个字就够 |
| 跑通 | 打通、走通 | 指完成一次完整闭环 |
| 押注 | 专注、All in | 强调有取舍 |
| 止损 | 及时放弃 | 强调有成本 |
| 补齐 | 提升、加强 | 指补一个具体缺口 |

## 三、状态

| 用这个 | 不用 | 为什么 |
|---|---|---|
| 卡点 | 问题、困难 | 卡点是一个具体位置，能定位 |
| 空白 | 没有经验 | 空白能填 |
| 线内 / 线外 | 有希望 / 没希望 | 指与某个门槛的距离 |

## 四、判断词（区分确定程度，不能混用）

| 词 | 含义 | 能不能加"一定" |
|---|---|---|
| 事实 | 可查证的客观信息 | 不加"一定"，要写出处 |
| 判断 | 我的结论，依据可追溯 | 不加"一定" |
| 猜测 | 依据不足的推断 | 必须标"我不确定" |
| 转述 | 别人的观点，不是我验证过的 | 必须标出，不能当自己的讲 |

**规则**：写的时候，这四类词只能出现在它该在的位置。把猜测写成判断，就是编。

## 五、待统一说法

下面这些词，逐个定死口径，避免同一个意思出现三种说法：

| 待定词 | 现在几种说法 | 定成什么 |
|---|---|---|
| 硬技能 / 硬通货 / 硬本事 | 3 | 待定 |
| 出结果 / 拿到结果 / 有产出 | 3 | 待定 |
| 被看见 / 出圈 / 有存在感 | 3 | 待定 |
| 普通人 / 大多数人 / 大部分人 | 3 | 待定 |
