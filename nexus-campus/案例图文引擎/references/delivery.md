# 安装、制作与交付

## 技能安装

将 humanities-ai-case 整个文件夹放入使用工具的 skills 目录，保留 SKILL.md、references、scripts 与 agents 的相对位置。支持 SKILL.md 的工具可以加载本技能；具体安装位置以所用工具设置为准。也可将 SKILL.md 及它要求读取的参考文件一起提供给能够操作文件的 AI 助手。

可直接发送以下需求，并替换主题与输出目录。

“使用 $humanities-ai-case，根据公开资料制作一期关于【主题】的真实 AI 案例图文。面向文科生，交付小红书分页图片、完整长图和可编辑网页，保存到【输出目录】。没有指定品牌，请使用通用结尾。”

研究需要联网搜索与页面阅读能力，排版需要文件编辑能力，检查需要图像查看能力。图像编辑与生成按当前工具能力使用。外部知识库与发布平台均为可选，需用户提供目标及授权，不依赖特定账号或连接器。

## 导出环境

导出脚本使用 Node.js 22.14 或以上，以及 Playwright 和 sharp。在本技能文件夹运行以下命令安装已测试版本的依赖和 Chromium。安装过程需要网络，并会下载浏览器。

```sh
npm install --package-lock=false
npx playwright install chromium
```

依赖不随分享包附送。已经提供这些依赖的运行环境可直接使用现有安装；不要在分享文件中填写本机绝对路径。

## 网页约定

由制作助手根据内容创建 index.html、article.css、article.js 和 assets。所有资产使用相对路径，不引用其他案例目录或工具缓存。index.html 包含以下两个独立容器。

- `#xhs-edition` 包含 `.page` 页面，每页实际大小 1080×1440 CSS px。
- `#member-article` 为完整连续文章，实际宽度 1080 CSS px，高度由内容决定。

article.js 提供 `window.setEdition('xhs')` 与 `window.setEdition('member')`，切换两个版本可见性。`.export-mode` 隐藏工具栏、编辑边框和网页资料区；不使用 transform 缩放导出容器。所有内容图片使用 img 元素，关闭延迟加载，等待解码；背景图片与字体也需要核对实际显示。来源区与编辑按钮放在两个导出容器之外。

网页提供两版切换及编辑能力；编辑后可保存源文件。源码中的原始资料区保留出处、图片归属和图像处理类别。生成提示词仅在实际使用生成工具时记录，不填造提示词或结果。

从本技能文件夹执行导出命令，输入为本期目录，输出为新的成品目录。

```sh
node scripts/export-pages.cjs "案例目录" "成品目录"
```

默认使用 Playwright 安装的 Chromium。需要使用已有浏览器时，可在最后增加该浏览器可执行文件的绝对路径。成品目录的上级目录需要已经存在；脚本创建成品目录，不覆盖已有目录。修改后导出到新的目录，核对后仅清理用户授权且已被替代的本期文件。

成品目录包含小红书分页 PNG、完整版 PNG 和 export-report.json。脚本验证图片解码、页面尺寸及内容高度，不自动判定事实、字体美感、封面颜色或钩子答案。制作助手需要完成这些检查。

## 交付与可选外部同步

读取目标目录现状，建立唯一的“期号-人物或主题”目录，不覆盖其他案例。每期保留可编辑网页、最终使用的素材、两版 PNG、两版预览图与来源；使用生成工具时保留最终 image-prompts.json。网页提供图片查看入口，默认不制作案例 ZIP，用户要求打包时按其要求处理。交付时提供实际文件路径、小红书页数、完整长图尺寸及尚未完成的检查。中间文件放入单独的工作目录，不混入最终成品。

用户明确要求更新知识库时，使用当前环境支持的对应服务工具，读取目标及现有内容，确认更新范围。更新后读回核对标题、图片与顺序。不得使用预设账号、私人 token 或固定知识库位置，不擅自覆盖其他文章。没有外部授权时仅交付本地文件。

更新前检查是否已有本期文档，存在时按授权替换，不重复创建。上传后核对图片数量、顺序与返回标识；失败时停止继续写入，读取现状后只继续未完成部分，不整批盲目重复上传。更新目录时仅修改本期链接，读回确认父子关系和链接可用。认证或权限不足时完成可用的本地部分并说明同步状态，不创建额外测试文档。
