# 09 · 任务澄清

> 用途：在想「该不该做这件事」之前，先问「我到底雇它来完成什么」。
>
> **大部分错误的选择，不是因为选错了方案，是因为根本没弄清自己要解决的问题。**

---

## 一、这个模块解决什么

大学生做的大部分事，理由都是"应该"：

> "我该考研""我该考个证""我该进个社团""我该去实习""我该参加这个比赛"

问一句"为什么"，答案通常是：

> "大家都考""不考好像没出路""简历上好看""我爸妈说"

这些理由的共同点是：**它们描述的是方案，不是要解决的问题。**

同时，"考研"这一个方案，可能对应完全不同的五个人：

| 他真正要的 | 考研能解决吗 |
|---|---|
| 想进高校做研究 | ✅ 能，且必需 |
| 本科专业就业面太窄，需要换赛道 | ⚠️ 能，但要看换什么 |
| 不知道毕业干什么，先拖三年 | ❌ 不能，三年后问题还在 |
| 家里要求，不想冲突 | ❌ 不能，解决的是家庭关系不是职业 |
| 想要一个更高的学历标签 | ⚠️ 能，但要算回报 |

**同一个方案，五种任务，五种结论。** 不问清任务，讨论"考研好不好"永远是空转。

---

## 二、核心判断

### 判断 1：先看要完成的进展，后看方案

这是这个模块的第一原理。

**不要问"该不该考研"，要问"我想通过考研，从什么状态走到什么状态"。**

```
现在我在哪：______（具体处境）
我想去哪：______（具体状态）
考研是不是唯一的桥：______
还有哪些桥：______
```

**为什么这个顺序重要**：

- 先看方案（考研）→ 你只会在"考"和"不考"之间选，而这两个可能都不是最优解
- 先看进展（从 A 到 B）→ 你会发现桥有很多，考研只是其中一座，可能还是最贵的那座

**举例**：

> 现状：本科是材料专业，想进互联网做产品
> 目标：三年后能拿到产品岗 offer
> 桥有几座：
> ① 考研（跨考，三年，成本最高）
> ② 直接找产品实习，用实习转正（一年，成本低）
> ③ 先就业再转岗（两年，风险中）
> ④ 读一个产品相关的硕士（国外，成本最高）
>
> **如果只问"该不该考研"，你永远看不到桥②。而桥②可能是最便宜的。**

### 判断 2：一件事同时在完成三层任务，只看功能层会漏掉关键

人"雇"一件事，不只为功能。

| 层 | 问什么 | 例（考研） |
|---|---|---|
| **功能层** | 它实际解决什么具体问题？ | 拿到硕士学历，满足岗位门槛 |
| **情感层** | 我想通过它获得什么感受？ | 不想面对"我什么都不会"的恐慌；有个目标就不焦虑 |
| **社会层** | 我想让别人怎么看我？ | 不想被亲戚问"你怎么不考研"；想被看成上进的人 |

**三层都在起作用，但只有功能层能公开说。**

**这就是为什么很多人的选择看起来不理性**：他其实在完成情感层或社会层的任务，但用功能层的理由解释自己。

**诊断的价值在这里**：

> 如果一个人考研的真实任务是"逃避就业焦虑"（情感层），那考上之后焦虑会消失吗？
> **不会。** 只是推迟三年。三年后还是要面对，而且年龄更大、选择更少。

**注意**：这不是说他"动机不纯"。情感层和社会层的任务完全正当——**人需要安全感和认可**。问题在于：**这个方案能不能真的完成那个任务。**

### 判断 3：说"我要"的人，往往在说"我不想"

反向问一句，能挖出真任务：

| 他说 | 反向问 | 可能挖出的 |
|---|---|---|
| 我要考研 | 如果不考，你最怕什么？ | "怕找不到工作" → 真任务是就业焦虑 |
| 我要进学生会 | 如果不进，会怎样？ | "简历上没东西写" → 真任务是简历 |
| 我要考公 | 如果不考，你担心什么？ | "不稳定" → 真任务是安全感 |
| 我要转专业 | 如果转不了，你会怎样？ | "继续学这个很痛苦" → 真任务是脱离当下的痛苦 |

**"怕什么"比"要什么"更接近真相**，因为怕的东西更具体、更真实。

**但要小心**：不要把这个当成"揭穿"他。**挖出来是为了让方案对准任务，不是为了告诉他"你的动机不纯"。**

### 判断 4：方案和任务不匹配时，换方案比硬做有效

这是最有杀伤力的一条。

**匹配检查表**：

| 你的真任务 | 这个方案能完成吗 | 如果不能，缺什么 |
|---|---|---|
| 我要一个能吃饭的技能 | 考研（学术型）→ **不能** | 需要的是实操训练，不是论文 |
| 我要离开这个城市 | 考研（本校）→ **不能** | 需要选外地的学校 |
| 我要证明我不比他们差 | 考研 → **部分能** | 但证明完了呢？下一个人还要证明 |
| 我要三年缓冲期想清楚 | 考研 → **部分能** | 但三年里不想，出来还是一样的 |

**典型的不匹配**：

> 真任务：**逃避就业焦虑**
> 方案：考研
> 问题：考研三年，逃避了三年，第四年焦虑加倍（因为年龄、因为同学已工作、因为学历也不再稀缺）
> 更匹配的方案：**先实习三个月**。因为焦虑的根源是"不知道自己能干什么"，实习能直接回答这个问题。三个月的成本远低于三年。

**关键洞察**：**能缓解焦虑的不是"有个目标"，是"知道自己能干什么"。** 前者靠任何目标都能实现（包括错误的目标），后者只能靠真实的接触。

### 判断 5：同一件事，不同人做的价值可以完全相反

这是 JTBD 最反直觉的地方：**方案的价值不在方案本身，在它和任务的匹配度**。

> **考研对 A 是最优解，对 B 是最差解，两个人条件可能完全一样。**

差别只在任务：
- A 的任务是"进研究所，需要硕士学历" → 考研是最短路径
- B 的任务是"想尽快独立挣钱" → 考研是三年纯成本

**所以"考研好不好"这个问题本身是错的。** 正确的问题是"考研对我这个任务好不好"。

**推论**：所有"XX 到底值不值"的问题，都要先问"为谁、为了什么"。这也是 `03_提问法.md` 里"目标要素"的具体应用。

### 判断 6：任务会变，所以要定期重问

大一定的任务，大三可能已经变了。

> 大一：考研，因为"不知道干什么，先读书"
> 大三：不想考了，因为实习发现自己更喜欢做事

**这不是反复无常，是任务变了。**

**规则**：每个重大方案，一年重问一次："我现在雇它完成的，还是当初那个任务吗？"

**信号**：如果你发现自己在为一个"当初的理由"坚持，而那个理由现在已经不重要了——**这就是该重新选的时候**。

## 三、操作流程

### Step 1：把方案写成一句话

```
我想做：______（考研 / 考公 / 进社团 / 转专业 / 打这个比赛）
```

### Step 2：反着问三句

| 问 | 记什么 |
|---|---|
| **如果不做，我最怕什么？** | 这是情感层任务 |
| **做完之后，我希望别人怎么看我？** | 这是社会层任务 |
| **做完之后，我能做到什么现在做不到的事？** | 这是功能层任务 |

**三句都要答，不要跳过情感和社会层**——它们往往才是真正的驱动力。

### Step 3：写出"现状 → 目标"

```
现状：______（具体，带数字或事实）
目标：______（具体，能判断到没到）
```

**"现状"必须具体**：
- ❌ "我现在很迷茫"
- ✅ "我不知道自己能做什么，没实习过，也没做过项目，成绩中等"

**"目标"必须能判断**：
- ❌ "我想清楚了"
- ✅ "我能说出三个我能做的岗位，并且有对应的经历可以证明"

### Step 4：列桥（至少三座）

**强制要求：至少三个方案，其中必须有一个是"什么都不做"或"低成本试探"。**

| 桥 | 成本 | 能完成这个任务吗 | 卡在哪 |
|---|---|---|---|
| 考研 | 3 年 + 机会成本 | 部分 | 三年后仍要就业 |
| 实习转正 | 3-6 个月 | **能** | 需要先找到实习 |
| 低成本试探（做一个小项目/接一个小单） | 2 周 | 部分 | 只能验证兴趣，不能验证能力 |

**为什么必须三个**：只列两个，你会在两个都不好的选项里纠结；列到第三个，往往会发现问题有别的解法。

### Step 5：匹配检查

对每座桥问：

> **这座桥，能把我从现在这个状态，送到那个目标状态吗？**

答"不能"或"部分能"的，写清楚缺什么。

### Step 6：选，并写下"我没选的那几座桥"

```markdown
我选：______
理由：______
我放弃的：______（写明为什么放弃）
如果这个选择失败了，我会转向：______
```

**"放弃的那几座桥"必须写。** 因为一年后你会怀疑自己，那时你需要看到当时是怎么权衡的——不然你会以为自己在瞎选。

## 四、大学场景实例

### 实例 1：「我要考研」

| 步 | 内容 |
|---|---|
| 方案 | 考研 |
| 反着问 | 不做最怕：**找不到像样的工作，被同学比下去** / 别人怎么看：**上进的、有规划的** / 能做到什么：**有硕士学历，能过一些岗位的门槛** |
| 现状 | 大三上，双非一本，市场营销专业，无实习，绩点 3.3，不知道自己能做什么 |
| 目标 | 有一份能养活自己、且不讨厌的工作 |
| 桥 | ① 考研（3 年）② 找实习转正（半年）③ 考公（1 年）④ **花 2 周做一个真实的小项目，看自己能不能做出东西** |
| 匹配 | ① **部分能**：解决学历门槛，没解决"不知道自己能做什么" ② **能**：实习直接回答"我能做什么" ③ 部分能 ④ **能**：最快验证 |
| 判断 | **真实任务有两个**：功能层（要一份工作）+ 情感层（怕被比下去）。考研只解决了功能层的一半，且对情感层无效——三年后同学已经工作三年，比较反而更痛 |
| 结论 | 先做 ④（2 周），再决定是否 ①。**不是不考研，是先搞清楚"我能做什么"再考**——否则读了三年，还是不知道自己能做什么 |

**这个例子的关键**：不是得出"别考研"，是**把"考研"从"唯一出路"变成"其中一个选项，且要先验证前提"**。

### 实例 2：「我要考这个证」

| 步 | 内容 |
|---|---|
| 方案 | 考某行业资格证 |
| 反着问 | 不做最怕：**简历太空** / 别人怎么看：**有证的人看起来专业** / 能做到什么：**？**（说不出来） |
| 关键发现 | 功能层答不出来 |
| 追问 | "这个证能让你做什么现在做不到的事？" → "好像也不能，就是简历上多一行" |
| 判断 | 真实任务是**社会层**（简历好看）+ **情感层**（不焦虑）。功能层是空的 |
| 匹配 | 证书能完成社会层吗？**部分能**（HR 会看一眼）。能完成情感层吗？**不能**（考完还是焦虑） |
| 更匹配的方案 | 如果目标是"简历不空"，**一段真实项目经历 > 一个证**。成本差不多，但项目能回答问题，证书不能 |
| 结论 | 不考。用同样的时间做一个能写进简历的项目 |

**判断口诀**：**如果功能层答不出来，这个证大概率不值得考。**

### 实例 3：「我要进学生会」

| 步 | 内容 |
|---|---|
| 反着问 | 不做最怕：**大学四年什么经历都没有** / 别人怎么看：**有组织能力的人** / 能做到什么：**能组织活动、能跟老师打交道** |
| 关键发现 | 三层都有，且功能层是真的 |
| 但追问一句 | "具体是哪个部门？做什么事？" → "外联部，拉赞助" |
| 再追问 | "拉赞助能让你学会组织活动吗？" → "……好像不能，主要是打电话" |
| 判断 | **方案内部有分层**。同一个"学生会"，不同部门的任务完成度完全不同 |
| 匹配 | 外联部能完成"跟人打交道"（部分），不能完成"组织活动" |
| 更匹配的方案 | 如果想练组织活动，**自己组队打一次比赛**（从头办一件事）比进外联部更直接 |
| 结论 | 进，但换成组织部；或者不进学生会，直接组队打比赛 |

**关键**：**方案要细分到"具体做什么"**。"进学生会"太粗，粗到无法判断它能不能完成任务。

### 实例 4：「我要变得更自律」（跨模块）

这个问题看似归执行诊断，但第一步应该走任务澄清：

| 问 | 答 |
|---|---|
| 如果不自律，最怕什么 | 怕四年过去什么都没做成 |
| 别人怎么看 | 不想被看成废人 |
| 自律之后能做到什么 | （答不出来） |

**判断**：**功能层空的**。"自律"不是一个能完成任务的方案，它是一种状态。

**转**：真任务是"我想做成一件事"。那就该问"哪件事"，而不是"怎么变自律"。**转到目标清晰化立一个具体目标。**

## 五、反例与边界

### 边界 1：不是所有决定都要挖动机

买什么牌子的笔、今天去不去自习——不需要问"我雇它完成什么"。

**判断标准**：这个决定的影响超过三个月、且要投入大量时间，才做任务澄清。

**对每件事都挖动机，会变成一种自我审问式的神经质。**

### 边界 2：挖出的动机可能是假的

人对自己动机的解释，本身就不准。你以为是"怕找不到工作"，实际可能是"怕被父母失望"——而后者你不好意思说。

**所以第三步的答案要当"假设"，不是"结论"。**

**验证方法**：假设它是真的，看行为对不对得上。

> 假设：我的真任务是就业焦虑
> 检验：如果真的焦虑，我会去查岗位、去实习。但我三个月都在查考研资料，没看过一个岗位
> 结论：假设不成立。真任务可能是"想有个明确的目标，好让自己不慌"

**行为是唯一可靠的证据。** 说的动机都可能美化。

### 边界 3：情感层和社会层的任务，不要否定

"我想要别人的认可"——这句话很多人不好意思承认，但它完全正当。

**不要做的是**：告诉别人"你这是虚荣"，或者告诉自己"我不该在意别人怎么看"。

**要做的是**：承认它在起作用，然后问——**这个方案能拿到那个认可吗？拿不到的话，有没有更便宜的方式？**

### 边界 4：不要用这个模块否定别人的选择

"你考研其实是在逃避"——这句话可能是对的，但说出来只会伤人。

**这个模块用来自查，不用来诊断别人**（和 `04_执行诊断.md` 的边界 1 同理）。

**例外**：对方明确请你帮他分析时，可以说，但要用"我看到一个可能"的措辞，不要说"你就是"。

### 边界 5：有些事不需要理由

陪朋友吃饭、看一场电影、发呆一下午——这些不需要"完成什么任务"。

**不是所有行为都要有功利目的。** 把生活全部任务化，是一种病，且会让人越来越空。

### 边界 6：任务变了不是错

见判断 6。但要注意区分：

| 情况 | 判定 |
|---|---|
| 任务变了（当初为了 A，现在为了 B） | **正常**，重新选 |
| 任务没变，但发现方案不行 | **正常**，换方案 |
| 任务没变，方案也行，只是难 | **不是任务问题**，去执行诊断 |

**第三种最容易被误判成"我要重新想想"。** 其实不是要想，是要做。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **把方案当任务** | "我的目标是考研" | 只能在方案里选，看不到别的桥 |
| **只答功能层** | 说"为了学历"，其实是怕被比较 | 方案对准了错的任务 |
| **挖动机变成自我审判** | "我做这个是不是很虚荣" | 陷入内耗，什么也不做 |
| **不写放弃的桥** | 只记选了什么 | 一年后怀疑自己，无法回溯 |
| **用行为以外的话当证据** | "我觉得我是为了……" | 自我解释通常是美化过的 |
| **对小事也挖动机** | 每件事都问"我为什么" | 变得神经质，失去行动力 |
| **拿它诊断别人** | "你考研是在逃避" | 关系破裂 |

## 七、和其他模块的关系

```
提问法（把"该不该考研"改成能答的）
   ↓
任务澄清（我雇考研完成什么）
   ↓
目标清晰化（把"想找份好工作"变成可指物的目标）
   ↓
决策档案（立案，写预期和证伪条件）
   ↓
执行诊断（为什么还没动）
```

- **任务澄清在目标清晰化之前**：先确认"这件事要做"，再把它写成目标。**顺序反了会给错的事定目标**
- **任务澄清和命题审查的区别**：命题审查审"这句话对不对"，任务澄清问"这件事为了什么"
- **任务澄清 → `../capabilities/02_升学.md`**：几乎所有升学问题，第一步都该走任务澄清
- **和 `../knowledge/认知/02_意义与选择.md` 的分工**：意义与选择处理"我该成为谁"（价值层），任务澄清处理"我该做哪件事"（方案层）。**意义与选择更根本，但更慢；任务澄清能立刻用**

## 八、自检

1. 我写的是**方案**还是**任务**？（"考研"是方案，"要一份能吃饭的工作"是任务）
2. 三层任务都答了吗？情感层和社会层有没有跳过？
3. "如果不做，我最怕什么"——这个答案，行为对得上吗？
4. 现状和目标，都具体到能判断吗？
5. 桥列了几个？（少于三个 = 视角不够）
6. 有没有一座"低成本试探"的桥？
7. 我放弃的那几座桥，写下来了吗？
