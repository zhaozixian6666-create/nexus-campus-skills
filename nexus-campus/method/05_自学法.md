# 05 · 自学法

> 用途：要自学一个陌生领域（一门课、一个技能、一个行业），不知道从哪开始、学到什么程度算会。
>
> **大学真正带得走的东西只有一样：在一个陌生领域里自己变强的能力。** 专业课会忘，这套不会。

---

## 一、这个模块解决什么

大学里的自学，绝大多数是这样失败的：

> 想学数据分析 → 找了一个 60 小时的视频课 → 看到第 12 小时放弃了 → 结论"我不适合学这个"
> 想学剪辑 → 下载了软件 → 跟着教程剪了一个 → 关掉，再也没打开 → 结论"我学过剪辑"

失败的原因不是毅力，是**从输入开始，而不是从判断开始**。

自学法做的事：给一条**从"能判断"倒推"学什么"** 的路径，让学习有终点、有反馈、有验收标准。

---

## 二、核心判断

### 判断 1：学习的终点不是"知道"，是"能判断好坏"

同一个领域，知识分三层，难度和用途完全不同：

| 层 | 内容 | 怎么获得 | 能不能靠看视频 |
|---|---|---|---|
| **L1 陈述性** | 这个领域有哪些概念、流派、工具 | 看书、看课、查资料 | ✅ 能 |
| **L2 程序性** | 具体怎么操作、步骤是什么 | 跟着做、反复练 | ⚠️ 要看+做 |
| **L3 判断性** | 什么算好、什么算差、哪里会出错 | **只能通过看范本 + 被人纠正** | ❌ 不能 |

**大多数人停在 L1，以为自己会了。** 因为 L1 有明确的完成感（看完一集课），而 L3 没有。

**判定一个人是不是真会一个领域，只问一句：**

> **给你两份作品（或两个方案），你能说出哪个更好、为什么吗？**

答得出来，是 L3；只能说"都挺好"，还在 L1。

**所以自学的目标应该是 L3，路径要从 L3 倒推。** 而不是从第一集视频顺着看。

### 判断 2：从最小可判断单元开始，不要从完整体系开始

教材和课程是按**学科逻辑**组织的（从基础到前沿，从原理到应用）。但自学者的需求是**能用**。

两者顺序不同。按教材顺序自学，你会在第 3 章遇到一个"暂时看不出有什么用"的知识点，然后失去动力。

**正确做法：先找一个"最小的完整单元"——小到能独立完成，完整到能做出来给人看。**

| 领域 | 最小可判断单元 | 不是 |
|---|---|---|
| 数据分析 | 用一份真实数据做一张能说明问题的图 | 学完 Python 基础语法 |
| 剪辑 | 剪一条 60 秒、有开头有结尾的片子 | 学完软件所有功能 |
| 学术研究 | 复现一篇论文的核心结论 | 读完十本方法论 |
| 编程 | 写一个能跑起来的小工具给自己用 | 看完一门语言课 |

**为什么有效**：最小单元会**逼出你缺的那部分知识**，而且是按需出现的。你在做图的时候发现不懂聚合，就去学聚合——这时候学的知识有落点，记得住。

**顺着教材学，知识没有落点；从单元倒推，每个知识点都是被需要的。**

### 判断 3：没有反馈的练习，是在固化错误

这一条是自学的分水岭。

练习的效果不取决于练了多少，取决于**有没有及时知道对不对**。没有反馈的重复，会把错误动作练成习惯——练得越多，越难改。

所以自学一个领域，**第一件要解决的事不是找资料，是找反馈源**。

四类反馈源，按质量排序：

| 反馈源 | 质量 | 怎么获得 |
|---|---|---|
| **有人给你改** | 最高 | 找老师、找学长、找社群、付费请教。**一次具体批改 > 十次泛泛表扬** |
| **有标准可对照** | 高 | 找 3 个公认的优秀范本，逐条对比自己的 |
| **有客观结果** | 高 | 代码能不能跑、图能不能说明问题、比赛有没有过初筛 |
| **自己回看** | 低 | 隔一周重看自己的东西。能看出问题说明进步了，看不出说明没进步 |

**如果四类一个都没有，这个领域你自学不了**——不是能力问题，是结构问题。要么先建立反馈渠道，要么换成有反馈的学法（比如报一个有批改的课）。

### 判断 4：默会知识只能通过做获得（波兰尼）

波兰尼提出：**我们知道的比我们能说出来的多。** 骑车、游泳、认脸——这些知识无法用语言完整传递。

专业知识里也有大量默会部分：

> 怎么判断一个实验数据"不太对"
> 怎么感觉一篇论文"结论撑不住"
> 怎么一眼看出这个设计"用不了"

这些**没有任何教材能写清楚**，只能通过跟着做、被纠正、反复看范本来获得。

**这条判断的实践含义**：

- 不要期待"把书看完就会了"——书上没有那部分
- 要主动创造"跟着做"的机会：进实验室、跟项目、找实习、给人打下手
- **打下手不丢人，这是获得默会知识的唯一通道**

### 判断 5：专家和新手的差别在模式识别，不在记忆力（西蒙）

西蒙研究国际象棋大师发现：大师并不比普通人记忆力更好，但**他们能一眼看出棋局的"模式"**——不是看单个棋子，是看整体结构。

这个发现对自学的意义：

> **高手的快，来自"见过很多次"，不是"想得很快"。**

所以自学要刻意积累**模式库**，而不是积累知识点：

| 积累知识点 | 积累模式 |
|---|---|
| 记住十种算法 | 看到一个问题，能判断它属于哪一类 |
| 记住五种论文结构 | 拿到一篇论文，能判断它的软肋在哪 |
| 记住八种营销方法 | 看到一个产品，能判断它靠什么活 |

**操作**：每学一个案例，多问一句——**"这个和之前哪个案例是同一类？"**

问多了，模式库就长出来了。

## 三、操作流程：三阶段

### 阶段一：建图（48 小时，不是四个月）

**目标**：知道这个领域**有什么、边界在哪、谁说了算**。不求会，只求不迷路。

| 动作 | 具体做什么 | 时间 |
|---|---|---|
| 1. 找一份"目录" | 一本公认教材的目录，或一个体系化课程的大纲。**只看目录，不看内容** | 30 分钟 |
| 2. 找出核心问题 | 这个领域反复在回答的 3-5 个问题是什么 | 1 小时 |
| 3. 找三个"圈内人" | 谁是这个领域公认的高手/权威？他们在哪说话（公众号、论坛、会议） | 1 小时 |
| 4. 找三个"范本" | 这个领域的优秀作品长什么样（论文、项目、作品集） | 1 小时 |
| 5. 画一张图 | 把上面四项画成一页纸：核心问题在中间，工具/流派/范本在周围 | 30 分钟 |

**完成的标志**：你能对一个外行用三分钟讲清"这个领域在研究什么、难在哪"。

**建图阶段禁止**：深入任何一个知识点。看到不懂的就记下来，不要停。

### 阶段二：找标准（一周）

**目标**：知道**什么算好**。这是 L3 的门槛。

| 动作 | 具体做什么 |
|---|---|
| 1. 精读三个范本 | 找 3 个公认优秀的作品，不是随便三个。判断"公认"的方法：被引用多、被老师推荐、在比赛里获奖 |
| 2. 逐条拆 | 每个范本问：它做了什么？为什么这样做？如果换一种做法会怎样？ |
| 3. 写出评价维度 | 从三个范本里提炼出 4-6 个"好在哪里"的维度（比如论文：问题是否真、方法是否匹配、证据是否够、结论是否越界） |
| 4. 给自己打分 | 用这套维度给自己现在的东西打分——**这一步会很痛，但这是自学的真正起点** |

**完成的标志**：你能说出"这个领域里，什么样的东西算好，什么样的算差"，并且能举例。

### 阶段三：做反馈（持续，这是主体）

**目标**：在真实产出中，把 L1 变成 L3。

循环：

```
选一个最小单元 → 做出来 → 找反馈 → 改 → 再做下一个
```

四个关键控制点：

| 控制点 | 要求 |
|---|---|
| **单元要小** | 一个单元 3-10 小时能做完。做不完说明切大了 |
| **必须有产出** | 产出必须是别人能看的（图、文档、代码、视频），不能只是"我学了" |
| **反馈要具体** | 不要问"怎么样"，要问"这三个地方哪个最差，为什么" |
| **每轮换一个变量** | 这一轮改结构，下一轮改表达。**同时改多个变量，学不到东西** |

**完成的标准不是"学完了"，是"能判断了"**：

> 给两份同类作品，你能说出哪个更好、为什么、差在哪里。

## 四、大学场景实例

### 实例 1：自学一门专业课（比如《计量经济学》）

| 阶段 | 做法 |
|---|---|
| **建图** | 看目录：这门课在解决什么问题（用数据判断因果关系）。核心工具：回归、内生性、工具变量。先不学，知道有这些就行 |
| **找标准** | 找 3 篇用计量方法写的优秀本科论文。看它们怎么用、怎么解释结果、怎么处理质疑 |
| **做反馈** | 最小单元：**用一份公开数据，跑一个最简单的回归，写 800 字解释结果**。找老师或助教看一次 |
| **常见错** | 从第一章开始看推导，看到第三章放弃。**推导重要，但它是为"能判断结果可不可信"服务的，不是目的** |

### 实例 2：自学剪辑

| 阶段 | 做法 |
|---|---|
| **建图** | 知道剪辑在解决什么：信息密度、节奏、情绪。工具只是手段。找 3 个你喜欢的账号，拆他们的节奏 |
| **找标准** | 精读 3 条你认为最好的片子，逐镜拆：几秒一个镜头、什么时候转场、音乐怎么进。写出你的"好片子维度" |
| **做反馈** | 最小单元：**剪一条 60 秒，发出去**。发出去是关键——播放量、完播率、评论就是客观反馈 |
| **常见错** | 学完所有功能再做作品。功能是查出来的，不是学出来的 |

### 实例 3：自学一个行业（想进互联网做产品）

| 阶段 | 做法 |
|---|---|
| **建图** | 这个行业有哪些岗位、各自做什么、招聘要求是什么。**直接看 30 份 JD**，比看行业报告快 |
| **找标准** | 找 3 份优秀的简历/作品集/面经。看他们怎么描述经历、怎么体现判断 |
| **做反馈** | 最小单元：**拆解一个你常用的 APP，写一份 1000 字的分析（它解决了谁的什么问题、现在最大的问题是什么、你会怎么改）**。发给一个从业者看 |
| **常见错** | 读大量行业报告，但没做过一次真实分析。**报告是别人的结论，分析才是你的能力** |

## 五、反例与边界

### 边界 1：有老师教的时候，不要自学

自学是**没有好老师时的替代方案**，不是更高级的方式。

学校里有一门好课、一个好老师，跟着学比自己摸索快十倍。**把自学精神用在该上课的时候，是浪费。**

判断标准：这门课有没有人讲得清楚、有没有作业和批改。有，就去上课。

### 边界 2：有些领域不能自学

涉及安全、临床、法律的领域（医学操作、心理治疗、法律诉讼），自学只能到"理解"，不能到"能做"。

**这些领域的默会知识和责任门槛太高，出错代价不可承受。** 自学法在这里只能用于"判断别人做得对不对"，不能用于"自己上手"。

### 边界 3：建图阶段容易变成信息收集癖

48 小时的建图，很容易拖成两周——不停找资料、收藏、整理，就是不开始做。

**硬性执行**：建图阶段最多 48 小时，到时间强制进入阶段二。资料永远找不完，**"资料不够"是最常见的拖延借口**（去执行诊断看看是不是 A 型或 C 型）。

### 边界 4：反馈不能只有表扬

找反馈时，人会不自觉选择"会说好话的人"。这样的反馈没有校准作用。

**要求**：每次反馈至少得到一个**具体的"这里不行"**。如果对方全程夸，换一个人问，或者直接问"如果必须挑一个毛病，你挑哪个"。

### 边界 5：不是所有学习都要有产出

读一本闲书、听一门感兴趣的课，不需要产出。

**这套方法只用于"我要掌握一项能用的能力"。** 把它用在所有学习上，会把求知变成 KPI，最后什么都不想学了。

### 边界 6："最小单元"可能选错

选了单元之后发现太难或太偏，允许换。**换的标准**：做了 5 小时还在原地，且不是因为懒——那就是单元切错了。

但**不要换超过两次**。第三次还在换，问题不在单元，在不想做。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **从视频第一集开始** | 顺着课程看完，从没做过东西 | 看完就忘，结论"我不适合" |
| **把收藏当学习** | 存了 200 个教程，一个没看 | 制造"我在努力"的幻觉 |
| **只要输入不要反馈** | 一直学，从不给人看 | 错误被固化，越练越偏 |
| **单元切太大** | "我要做一个完整的 APP" | 三周没进展，放弃 |
| **同时改多个变量** | 每次改版都大改 | 不知道哪个改动有效，学不到 |
| **只在 L1 打转** | 概念讲得头头是道，一做就废 | 面试第一轮就露 |
| **把自学当唯一方式** | 有好课不上，非要自己摸 | 浪费时间，且容易学歪 |

## 七、和其他模块的关系

- **自学法与 `../capabilities/01_学业.md` 的分工**：01 管"学校课程怎么学"（绩点、考试），自学法管"自己想学的东西怎么学"（技能、领域）。**01 有明确的评价标准（分数），自学法要自己造标准**
- **自学法依赖对标法**：找范本、找高手，实际就是对标。**先做对标法，再做自学法的阶段二**
- **自学法依赖提问法**：不知道学什么，是提问问题。用提问法把"我想学点东西"改成"我要在 X 场景下做成 Y"
- **自学法卡住时去执行诊断**：建图拖延、单元不开始，都是执行问题
- **自学法的产出可以进大学案例复盘（案例复盘）**：每个最小单元的产出和反馈，都是可复盘的案例

## 八、自检

1. 我要学的这个领域，**L3 的判断标准是什么**？说得出 4-6 个维度吗？
2. 最小可判断单元选了哪个？**3-10 小时能做完吗**？
3. 反馈源是什么？属于四类里的哪一类？**一次具体的批改，我打算找谁**？
4. 建图阶段有没有超 48 小时？
5. 我是在积累知识点，还是积累**模式**？（有没有问"这属于哪一类"）
6. 有没有踩到六条边界？（有老师不跟 / 危险领域 / 信息收集癖 / 只要表扬 / 万物 KPI / 频繁换单元）
7. **最重要**：我能不能给两份作品判断出哪个更好、为什么？

**第 7 条答不上来，就是还没学会，不管看了多少。**

## 九、来源与定位

- 使用的公开理论：波兰尼默会知识（tacit knowledge）、西蒙的国际象棋大师研究（chunking / 模式识别）、刻意练习的反馈条件
- 本模块的判断对外说「这是我的判断」；讲边界的说「按这套方法推是这样」。
