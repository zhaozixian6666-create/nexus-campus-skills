# 13 · 多视角模拟

> **一句话**：一个人卡住的时候，往往不是缺答案，是缺**另一个立场上的看法**。这个模块负责把「另一个立场」具体化成几个能说话的角色，让他们真的吵起来。
>
> **什么时候用**：他反复权衡、谁说的都对、自己下不了决心；或者他只有一个视角，看不见别人怎么想这件事。
>
> **什么时候不用**：事实问题（该查资料）、情绪问题（该先接住）、紧急问题（该先做）。

---

## 一、为什么需要这个模块

### 判断 1：想不明白，常常是「只站在一个位置上想」

一个学生纠结「要不要考研」，他能想到的所有理由，都是**他自己**能想到的。他想不到的，是另外几个位置上的人会怎么看：

- 他爸妈怎么算这笔账（他们出钱，他们看的是三年后的确定性）
- 他直系学长怎么算（他刚走完，知道哪些苦是真的）
- 招人的 HR 怎么算（他看的是简历上这一行值不值）
- 五年后的他自己怎么算（他在意的是这三年有没有长成别的样子）

**这四笔账，算法完全不同。** 他用一笔账去解四笔账的题，当然解不出来。

### 判断 2：不同视角的价值，不在「观点不同」，在「变量不同」

两个人说「考研好」「考研不好」，这不是两个视角，这是一个视角的两种结论。

真正的多视角，是**每个人在意的东西不一样**：

| 位置 | 他在意的变量 |
|---|---|
| 出钱的人 | 这笔钱的机会成本、什么时候回本 |
| 刚走过的人 | 哪些苦是必经的、哪些是可以绕的 |
| 招人的人 | 这个经历在筛选时算不算数 |
| 五年后的自己 | 这三年长出了什么能力 |

**变量不重复，才叫多视角。** 三个都在说"值不值"，等于一个人说了三遍。

### 判断 3：让他自己扮演别人，比听你分析有用

直接告诉他"你爸妈其实是担心钱"，他会说"我知道"。让他自己写一段"我妈会怎么说"，他会写出一些他自己都意外的东西。

**因为扮演的时候，他要真的进到那个位置上去调取信息**，而不是站在自己的位置上猜。这是这个模块最实际的用法——**多数时候你不是替他想，是让他换位置说一遍。**

## 二、两个版本，按问题选

### 版本 A：利益相关方圆桌（用来做决定）

**适用**：一个决定，牵扯到好几个人，每人的账不一样。考研、就业、出国、转专业、要不要接某个活、要不要跟某个人摊牌。

**怎么组人**：把这件事里**利益真的会被影响的人**列出来，最多四个。不是"关心你的人"，是"账本会被改的人"。

典型五个位置：

| 位置 | 他要回答的问题 |
|---|---|
| **出钱/出力的人** | 这笔投入，我看着值不值？我愿意出到什么时候？ |
| **会被你影响的人** | 你这个决定，让我多干了什么、少得了什么？ |
| **刚走过这条路的人** | 你说的那些苦，哪些是真的？哪些是吓自己的？ |
| **招人/筛选的人** | 你多花这三年，我这边会怎么给你定价？ |
| **五年后的你自己** | 三年后你回头看，会为哪件事后悔？ |

**注意**：不是每次都要凑满四个。**只请真正在这个决定里的位置。** 一个不牵扯任何人的决定（比如要不要每天早起），开圆桌是浪费。

### 版本 B：学科视角圆桌（用来理解）

**适用**：一个问题反反复复想不通，不是缺信息，是缺框架。比如"我为什么总是坚持不下来""为什么努力了没效果""我是不是不适合读书"。

**怎么组人**：不问"谁有名"，问**"这个问题涉及哪几个变量，每个变量有哪个成熟的框架在处理"**。

大学问题的常用框架池：

| 框架 | 它专门处理什么 | 说话方式 |
|---|---|---|
| **目的论** | 一个行为持续存在，它一定在达成某个目的 | 不问原因，问"你不做这件事，得到了什么" |
| **行为强化** | 什么被奖励，什么就会重复 | 只看"做完之后发生了什么" |
| **认知负荷** | 卡住是因为工作记忆被占满，不是不努力 | 数一数同时要处理几件事 |
| **信息不对称** | 双方知道的东西不一样，导致判断不同 | 问"谁知道什么，谁不知道什么" |
| **制度激励** | 规则怎么设计，人就怎么走 | 看规则奖励什么行为 |
| **机会成本** | 选一件事的真正代价是放弃的那件 | 问"这些时间本来能干什么" |
| **社会认同** | 人按"我属于哪个群体"来行动 | 问"这么做，你还算哪边的人" |
| **沉没成本** | 已经投入的会扭曲后续判断 | 问"如果今天从零开始，你还会选它吗" |

**四个就够，多了会散。** 每个框架必须能说出它在处理哪一个变量，说不出就换掉。

## 三、人怎么选：五条筛选（两个版本通用）

推荐角色的时候，先过这五条。**任何一条答不清，就换掉。**

| # | 标准 | 要问自己的 |
|---|---|---|
| 1 | **命题清楚** | 这个位置/框架，能说出它的一句核心判断吗？说不出，就只是个标签 |
| 2 | **经受检验** | 这个框架被长期用过、被批评过、被修正过吗？还是只是最近流行？ |
| 3 | **可独立验证** | 它的价值能靠公开研究、原著、大量案例检验吗？还是只能靠某个人说自己成功？ |
| 4 | **变量不重复** | 它处理的那个变量，别人是不是已经覆盖了？重复了就减掉 |
| 5 | **材料足够** | 我能忠实还原它的方法吗？还是只知道几个词？只知道词就别请 |

### 必须排除的几类

- **只靠表达和声量出名的**——他的观点是内容产品，不是判断工具
- **只给情绪价值和个人故事的**——听着舒服，拿不走
- **泛泛而谈的"人生导师"**——什么都能说，等于什么都没说
- **你自己编出来的人**——这条最重要。见边界 1

### 一个反直觉的点

**不要因为某个人"听起来很像"就请他。**

学生说"我这个问题很像那个博主讲过的"，正确的动作不是请那个博主，是问：**他讲的那套，处理的是哪个变量？那个变量的成熟框架是什么？** 然后请那个框架。

## 四、怎么开：独立生成是关键

### 判断 4：几个人一起想，会想到一起去

这是这个模块唯一必须严格遵守的技术要求。

如果让四个角色**依次**发言、后一个能看见前一个说了什么，结果一定趋同——后三个人会不自觉地向第一个靠，最后四个人说同一件事，只是措辞不同。**这叫共识，不叫多视角。**

**做法**：每个角色独立生成，**生成时不允许看别人的**。全部写完，再摆到一起。

手工做也完全可行：

> 拿四张纸，每张纸写一个角色的名字。
> 一次只写一张，写完盖住，再写下一张。
> 四张都写完，才能一起看。

**这个动作花不了十分钟，但它决定了这场圆桌有没有价值。**

### 每个角色的发言要求

写清四样，缺一样这个角色就是空的：

1. **他在意什么**（一句话，必须和其他人不同）
2. **他会怎么算这笔账**（具体到看哪些数）
3. **他的结论**（敢下结论，不许和稀泥）
4. **他最不接受对方哪一点**（这一条产生交锋）

**没有第 4 条，四个人会互相点头。互相点头的圆桌，等于没开。**

## 五、怎么收：判官三问

所有角色说完，你必须做一次总结。**这一步是这个模块的核心价值，跳过就等于白开。**

### 三问

| 问 | 不合格的表现 | 该怎么办 |
|---|---|---|
| **有真洞察吗？** | 四个人说的都是他本来就知道的 | 说明角色选错了，或者角色没真的进入位置。重开 |
| **有交锋吗？** | 四个人观点一致，或只是措辞不同 | 说明变量重复了。换掉重复的那个，补一个真正对立的 |
| **盲区在哪？** | 想不到还有什么没人提 | 想不出盲区，通常是因为漏了一个位置：**这件事的时间维度**（三个月后 / 三年后） |

### 总结要写四段

```markdown
**这场讨论里，真正对立的是什么**
（一句话说清分歧点。如果说不出分歧，直接写"这场没有真分歧"）

**哪一条最站得住**
（选一条，说明理由。不许"都有道理"）

**所有人都漏了什么**
（至少一条。这一条往往比前面四条都有用）

**所以你现在能做的判断是**
（给一个带条件的判断：如果是 A，选 X；如果是 B，选 Y。不给单一答案）
```

### 最后一句必须说清

**这是模拟，不是那些人的真实意见。**

利益相关方版本：**"这是按你描述的情况推演的，你妈真实怎么想，只有问了才知道。"**
学科视角版本：**"这些是用几个框架推的，不是哪个学者的原话。"**

**这两个版本都不许伪造具体的人的原话。** 见边界 1。

## 六、操作流程

### Step 1：判断该不该开

| 他的状态 | 该不该开 |
|---|---|
| 反复权衡、下不了决心、谁说的都对 | **开** |
| 只有一个视角，看不见别人怎么想 | **开** |
| 缺一个事实（分数线多少、政策怎么规定） | 不开，去查 |
| 情绪很重，还在难受 | 不开，先接住。见执行诊断边界 |
| 有明确截止时间，今天必须交 | 不开，先做 |

### Step 2：选版本

牵扯别人的 → **版本 A**；只是想不通 → **版本 B**。

### Step 3：组人（最多四个）

按第三节五条筛选，逐个过。**写下每个角色负责的变量，重复的删掉。**

### Step 4：独立生成

一次一个，写完盖住。每个角色四样齐全。

### Step 5：判官三问 + 四段总结

### Step 6：落到一个动作

圆桌开完不给动作，就是聊了一场天。动作分两种：

- **要问的**：利益相关方版本，最常见的一步是"去问你妈，别猜"
- **要试的**：学科视角版本，最常见的一步是"用这个框架解释一次上周发生的事，看对不对得上"

## 七、两个实例

### 实例 1：要不要退掉学生会

**他的说法**：大二了，学生会的事越来越多，感觉在浪费时间，但退了怕以后简历不好看，也怕得罪人。

**版本**：A（利益相关方）

**组人**：

| 位置 | 变量 | 他会说 |
|---|---|---|
| 他本人（现在） | 时间 | 每周十小时，够我把绩点从 3.2 拉到 3.7 |
| 学生会部长 | 人手 | 你走了这个活动没人接，我得重新找人带 |
| 招人的 HR | 简历信号 | 学生会主席有用，干事没用。你写"干事"，我看不出你干了什么 |
| 大三的他 | 后悔 | 退了我不会后悔；但我会后悔当时没去争部长 |

**交锋点**：部长说"你走了团队受影响"，HR 说"你留下我也不加分"。**这两条不能同时成立。**

**判官总结**：

> 这场真正对立的，是"对别人的责任"和"对自己简历的价值"——而后者其实不成立。
>
> 最站得住的是 HR 那句：**干事和主席在筛选时是两个东西。** 所以问题不是"退不退"，是"你能不能在这个位置上拿到能写的东西"。
>
> 所有人都漏了一点：**退会不等于退出这层关系。** 你可以不做干事，但仍然帮这个部长一次忙——关系不是靠职位维持的。
>
> 所以：如果能争到部长，留；争不到，退，但退之前把这个学期手上的事做完交接。**别用"怕得罪人"当理由留下，那个理由撑不过一年。**

### 实例 2：为什么我总是坚持不下来

**他的说法**：健身、背单词、写日记，每样都试过，最多坚持三周。

**版本**：B（学科视角）

**组人**（四个框架，变量各不相同）：

| 框架 | 变量 | 它会说 |
|---|---|---|
| 行为强化 | 做完之后发生了什么 | 三周里有没有一次"做完被看见"？没有，这个行为就没有奖励 |
| 认知负荷 | 同时要处理几件事 | 你是在考试周开始的。那时候你的工作记忆已经满了 |
| 目的论 | 不做这件事得到了什么 | 坚持失败让你可以说"我试过了"，这比"我没试"安全 |
| 沉没成本 | 已投入的扭曲判断 | 你换了四次方法，每次都在第一周就换——你在用"换方法"替代"做下去" |

**交锋点**：目的论说"你在借失败保护自己"，行为强化说"你只是没设计奖励"。**前者指向动机，后者指向设计。**

**判官总结**：

> 真正对立的是：这到底是**不想做**，还是**做法不对**。
>
> 最站得住的是认知负荷那条——**四次都失败在考试周附近，这不是巧合。** 先排除环境，再谈动机。
>
> 所有人都漏了：**你选的三件事，都没有"别人知道"这一环。** 一个人做的事，断了没人发现，也就没人拉你一把。
>
> 所以：下一件事只做一件，找一个会问你"今天做了吗"的人，从非考试周开始。**三周不成就换做法，但别换目标。**

## 八、反例与边界

### 边界 1：不许编造真人的话

**这是最硬的一条。**

- ❌ "你妈会说：这三年家里实在拿不出钱。"（你妈没说过）
- ✅ "按你描述的情况，你妈最在意的可能是这三年家里要出多少。**这句是我推的，真的怎么想，得去问。**"

**为什么这条不能松**：编一句"你妈说"，他会当成事实拿去和家里吵。**这个模块一旦开始编真人的话，就从帮忙变成挑事。**

### 边界 2：不许把名人当成权威来压人

请一个框架，是为了**多一个看问题的角度**，不是为了说"某某也这么认为，所以你对/你错"。

学科视角版本里，写框架名就够，不必写人名。**写人名容易变成诉诸权威。**

### 边界 3：四个角色吵完，决定还是他做

圆桌给的是「有哪几笔账」，不是「该选哪个」。**最后那句必须是带条件的判断，不能是命令。**

### 边界 4：不许用它替代该问的人

利益相关方圆桌最常见的误用：**用模拟代替真实沟通。**

模拟你妈怎么想，然后据此决定——这是拿猜测当事实。**圆桌的正确产出，常常是"你现在该去问你妈"，而不是"你妈大概会这么想"。**

### 边界 5：情绪很重的时候不开

一个人正在难受，你开四个人来讨论他，他会觉得被围观。**先接住，再讨论。** 见执行诊断的边界 5。

### 边界 6：不许每次都用

这个模块很重（要组人、要独立生成、要判官总结），**一周用一次都算多**。日常问题直接答，别为了显得周全就开圆桌。

## 九、自检

1. 这个决定/困惑，**真的需要多视角吗**？还是我为了显得周全？
2. 每个角色负责的变量，**写下来了吗**？有重复的吗？
3. 我是**独立生成**的吗？后一个有没有被前一个带跑？
4. 有没有**真交锋**？说不出分歧点，就是没开成。
5. 盲区找到了吗？（想不到，就先补时间维度）
6. 最后给的是**带条件的判断**，还是命令？
7. 有没有**编造真人的话**？
8. 有没有说清「这是模拟」？
9. 情绪状态适合开吗？
10. 落到了一个动作吗？（去问谁 / 去试什么）

---

## 十、材料不足怎么办

| 缺什么 | 怎么办 |
|---|---|
| 不知道有哪几方牵扯 | 问一句："这件事如果变了，谁会受影响？"通常能列出三个 |
| 不知道每个位置在意什么 | 先按第二节的五个位置套一遍，套不上的删掉 |
| 角色写出来都一个味 | 检查是不是都在用他的语言说话。让每个角色用**自己的词**说一句 |
| 学科视角选不出框架 | 说明问题还没拆清。先回概念拆解拆概念，拆完变量自然出来了 |
| 判官总结写不出盲区 | 补时间维度：三个月后 / 三年后，各会怎么看 |

## 十一、这个模块的定位

**它不是用来"显得专业"的。**

多数时候，一个学生要的不是四个人讨论，是**一个人认真听他说完，然后问一句"那你妈怎么看"**。

这个模块真正的用处只有一个：**当他被困在一个位置上时，帮他把别的几个位置摆出来，让他自己走一遍。**

摆完就走开。不要留在那儿替他判断。

*使用的公开方法：多角色模拟的独立生成原则（防趋同）、框架优先于人物、判官式总结的结构。内容按大学场景重写。*
