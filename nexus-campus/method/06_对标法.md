# 06 · 对标法

> 用途：想学一个人（学长、博主、同学、行业里的人），先判断**该不该学他、能学哪一层**。
>
> **照着成功者的做法做，多数会失败。不是因为做得不对，是因为你没看见他的约束条件和你不一样。**

---

## 一、这个模块解决什么

大学里最流行的学习方式是"找一个榜样，跟着做"：

> 保研的学长每天 6 点起，我也 6 点起
> 做起来的博主日更，我也日更
> 拿了国奖的同学参加了三个比赛，我也报三个

这些做法本身没错，失败的原因是：**你抄的是动作，忽略了动作背后的条件。**

对标法做的事：把一个人拆成**三层**，判断哪层能抄、哪层要改、哪层根本抄不了。

---

## 二、核心判断

### 判断 1：不要对标最成功的人，对标"高你两档、路径可见"的人

对标最顶尖的人（院士、首富、顶流博主），得到的信息几乎为零——因为他们的路径里有太多不可复制的因素：时代、家庭、运气、某个关键的人。

**正确的对标对象要满足三条：**

| 条件 | 为什么 |
|---|---|
| **比你高 1-2 档，不是 10 档** | 高两档的人的路径你还能走；高十档的路径缺了太多中间环节 |
| **路径可见** | 你知道他每一步做了什么。只能看到结果的（比如只看到他保研了），学不到东西 |
| **他和你起点接近** | 同校、同专业、同资源条件。差太远，他的方法在你这儿不成立 |

**举例**：

- 想保研 → 别对标清北的，对标**你们学校上一届保研到你能去的那个档次的学长**
- 做内容 → 别对标千万粉的，对标**半年前还是 1000 粉、现在 2 万粉的**
- 学技能 → 别对标行业顶尖，对标**比你早入门一年、做出过完整作品的人**

**这条判断的残酷之处**：越顶级的人，讲的话越对、越没用。因为所有条件都对了，方法就不重要了。

### 判断 2：成功者的做法里，有一部分是幸存者偏差

这是对标最大的陷阱。

你能看到的所有成功者，都是**筛选后的结果**。用同样方法失败的人，不会写经验贴，不会开分享会。

所以看到任何"我就是这么做的"，必须补两问：

> **用这个方法的人有多少？成功的有几个？**
> **失败的那批人，做法和他一样吗？**

**典型形态**：

| 他说的 | 缺的那部分 |
|---|---|
| "我每天学 12 小时，考上了" | 每天学 12 小时但没考上的人，有多少？ |
| "我大二就进了实验室" | 进实验室的人里，有多少没保研？ |
| "我做内容第二个月就爆了" | 同时期开始做、没爆的人，有多少？ |

**如果只看到分子，看不到分母，任何方法看起来都是有效的。**

**实操**：找对标对象时，主动去找"同样做法但失败的人"。他们的经验往往比成功者更有信息量——**成功的原因千差万别，失败的原因高度重合**。

### 判断 3：把一个人拆成三层，只有一层能直接抄

这是本模块最核心的工具。

| 层 | 内容 | 能不能抄 | 为什么 |
|---|---|---|---|
| **L1 动作** | 他具体做了什么：几点起、看了什么书、报了什么赛、用了什么工具 | ✅ **可以直接抄** | 动作是可观察的，执行成本低 |
| **L2 判断** | 他为什么这么选：为什么报这个赛不报那个、为什么放弃这个机会 | ⚠️ **要改条件才能用** | 判断依赖他的目标和约束，你和他可能不同 |
| **L3 结构** | 他手上的资源：家庭、学校、导师、人脉、时代窗口 | ❌ **抄不了** | 这是既定的，不是选择的结果 |

**大多数人只抄 L1，然后困惑为什么没效果。**

因为 L1 的动作为 L2 的判断服务，L2 的判断以 L3 的结构为前提。前提变了，动作就失效。

**举例（保研学长）**：

| 层 | 他的 | 你的 | 结论 |
|---|---|---|---|
| L1 | 大二进实验室、参加两个国赛、绩点 3.8 | 可以照做 | 抄 |
| L2 | 他选这两个赛，因为他学校认这两个、他的项目有老师带 | 你要查你们学校认什么、你有没有老师带 | **改条件** |
| L3 | 他舅舅是某高校教授，能推 | 你没有 | **不能抄，也别沮丧** |

**关键**：L3 不是用来嫉妒的，是用来**判断哪些路径对你不成立**的。知道"这条路我走不了"，比盲目努力有用。

### 判断 4：能抄的是动作，要自己长的是判断

L2 层面，你要做的不是"照他的想法想"，而是**问出他判断的依据**，然后用自己的条件重算一遍。

**问法（三个问题，按顺序）**：

1. **"你当时还有别的选项吗？"** —— 如果他只有一个选项，那不叫判断，叫别无选择
2. **"你为什么排除掉那几个？"** —— 排除理由里，哪些是普适的，哪些只对他成立
3. **"如果换成我这样的条件（学校/专业/资源），你会怎么选？"** —— 逼他把前提显式化

**这三个问题问完，你拿到的不是"他的选择"，是"他的选择函数"。** 把你自己代进去，才是你自己的判断。

### 判断 5：对标不是复制，是找差异

**照着做得一模一样，你最多和他一样好，大概率更差**——因为他的优势是积累出来的，你从零开始。

真正有效的对标，是找到"他做到了但没做满的地方"，或者"他的方法在你身上能放大的地方"。

**两种打法**：

| 打法 | 做法 | 适用 |
|---|---|---|
| **补短板式** | 他身上有的，我没有，补 | 差距在可补的部分（技能、经历） |
| **换赛道式** | 他的方法里，有一块我能做得比他更好 | 差距在结构（他的资源你没有，但你有他没有的） |

**举例**：对标一个做知识类短视频的博主。他讲得深、但更新慢；你能做到日更。那你的对标结论不是"我也要讲得深"，而是"我保持他 70% 的深度，用 3 倍的频率占位"。

**对标的终点是差异化，不是同质化。**

## 三、操作流程

### Step 1：定目标，再选人

不要先找人再想学什么。顺序反了，会变成"看到一个厉害的人，就想学他的一切"。

```
我要达成：______（具体、可验证）
这条路上，比我早走 1-3 年的人是谁：______
```

**选 2-3 个，不要选 1 个。** 一个人身上有太多个人特质，多个样本才能看出"哪些是共性"。

### Step 2：拆 L1（他做了什么）

只写**可观察的动作**，不写评价。

| 时间 | 他做了什么 | 结果 |
|---|---|---|
| 大一 | …… | …… |
| 大二 | …… | …… |

**信息从哪来**：他的分享、他的简历、问他本人、问和他同届的人。

**注意**：如果他讲的是"心态""认知""坚持"，那不是 L1，是包装。**追问"具体做了什么"**。

### Step 3：拆 L3（他有什么）

| 项 | 他有吗 | 你有吗 |
|---|---|---|
| 学校层次 / 专业 | | |
| 家庭能提供的（经济、人脉、信息） | | |
| 导师 / 实验室资源 | | |
| 时间窗口（他赶上的是哪一年） | | |
| 关键的人（谁帮过他） | | |

**这一步最容易漏，也最决定成败。** 很多人对标失败，不是不努力，是没意识到对方起跑线不同。

**做这一步的时候要诚实，但不要自我否定**：L3 的差距不是评价，是**信息**。知道它，你才知道该绕开哪条路。

### Step 4：拆 L2（他为什么这么选）

用判断 4 的三个问题，问出他的选择逻辑。

**如果问不到本人**，就自己推：

> 他这个选择，在当时的信息条件下，最大的收益是什么？最大的风险是什么？
> 如果他做了另一个选择，会怎样？

### Step 5：写出"我的版本"

格式固定：

```
他做的（L1）：______
他为什么做（L2）：______
前提是（L3）：______
我的前提：______
所以我的版本是：______（必须和 L1 不同）
```

**最后一行如果和 L1 一样，说明你没做 L2/L3 的分析，只是抄了。**

### Step 6：定验收标准

对标不是学完就算。要知道"学到没学到"：

> 三个月后，我要做到______（可验证的结果），参照的是他的______。

## 四、大学场景实例

### 实例 1：对标保研的学长

| 层 | 内容 |
|---|---|
| **L1** | 大二上联系导师进实验室；大二下组队打创新大赛拿省一；大三上发了一篇会议论文；绩点 3.85，专业第 3 |
| **L2** | 为什么选创新大赛：① 他们学校把它算 Ⅰ 类，加分最高 ② 他的导师刚好是评委库里的 ③ 他手上有一个现成的课题 |
| **L3** | 学校是 211，保研率 25%；导师是副院长，有横向项目；他大一就进了学院的学生会，认识教务老师，能提前看到细则变化 |
| **你的条件** | 双非，保研率 8%；没有熟悉的老师；不知道细则 |
| **我的版本** | ① 大二上不是"联系导师"，是**先把本院所有老师的课题方向查一遍，找 2 个方向对口的，去蹭课+提问**（因为双非的老师带本科生的意愿通常更低，需要更长的信任积累）② 比赛**先查你们学校认哪些**（这是 `../capabilities/03_竞赛.md` J2 的第一刀）③ 绩点在这条路上权重更高（保研率 8% 意味着排名容错更小），所以绩点优先于竞赛 |
| **结论** | 抄 L1 的前两项，改第三项（发论文在双非本科更靠运气）；L3 的差距（学校、导师级别）**决定了他能走的路你不能照走**，必须换路径 |

### 实例 2：对标一个做起来的博主

| 层 | 内容 |
|---|---|
| **L1** | 每周更 3 条，讲大学认知；用真人出镜；每条 60-90 秒；封面统一风格 |
| **L2** | 为什么讲大学认知：他自己是 985 在读，有身份背书；为什么真人出镜：算法偏好完播，真人开头留人 |
| **L3** | 他有 4 万起步粉（从别的平台导过来的）；他有剪辑搭档；他在读，有大量校园素材可拍 |
| **你的条件** | 0 粉起步；一个人做；也在读 |
| **我的版本** | ① 频率不能照抄（他 3 条是靠搭档剪辑），先做**每周 2 条**保证质量 ② 真人出镜可以抄，这是低成本高回报 ③ **不能抄的是"讲大学认知"这个定位**——他先占了这个位置，你要找细分（比如只讲竞赛、只讲某个专业） |
| **关键判断** | 他的 4 万起步粉是他最大的 L3 优势，你没有。所以你的前 3 个月不是在"做内容"，是在"积累第一批种子"，节奏和考核标准都应该不同 |

### 实例 3：对标同宿舍很厉害的同学

| 层 | 内容 |
|---|---|
| **L1** | 每天 7 点起，图书馆坐到 10 点，从不参加社团 |
| **L2** | 他要出国，GPA 是硬指标，所以时间全投绩点 |
| **L3** | 家里已经安排好中介和推荐信，他只需要 GPA |
| **你的条件** | 你要就业，需要实习和项目；家里没有资源 |
| **我的版本** | **不能抄他的时间安排**。他放弃社团是因为他不需要；你需要。你该抄的是"时间的整块使用"（不被打断的 3 小时），不是"总时长" |
| **警示** | 这是最常见的对标失败：**抄了对方的取舍，但你的目标不同，取舍就错了** |

## 五、反例与边界

### 边界 1：没有可对标的人时，不要硬找

有些路没有前人可以参照（很新的方向、很窄的领域）。这时候硬找对标对象，会找一个不匹配的人，然后照着他的路走偏。

**替代方案**：找**跨领域的类比对象**（做内容没前人就对标做销售的高手，都在解决"怎么让人信我"），或者直接用自学法的"找范本"路径。

### 边界 2：不要对标到失去自己

长期只做对标，会形成一种思维：所有决定都先问"他会怎么做"。

**结果**：你变成一个次优版本的他，而不是最好的你。

**信号**：如果你发现自己的所有选择都能在某个榜样身上找到出处，说明对标过头了。**加一条自检：这个决定里，有多少是我自己的判断？**

### 边界 3：L3 的差距不是不努力的借口

知道"他有资源我没有"是**信息**，用它来解释"所以我做不到"是**借口**。

**区分标准**：说完 L3 差距之后，你有没有给出一个"绕开它"的方案？

- 有 → 这是分析
- 没有 → 这是放弃的合理化

### 边界 4：不要把对标变成崇拜

崇拜会关闭判断。一旦你把某个人当成"绝对不会错"，就再也不会去问他"你当时还有别的选项吗"。

**检验方法**：你能不能说出这个对标对象的**一个错误决定**？说不出来，说明你在崇拜，不在对标。

### 边界 5：成功者的自述要打折

人在讲自己的成功时，会无意识地：
- 夸大努力的作用（因为努力是自己的）
- 缩小运气和资源的作用（因为那不值得骄傲）
- 事后合理化（把当时的随机选择讲成深思熟虑）

**所以：自述是第一手材料，但不是准确材料。** 要交叉验证——问和他同届的人、看他当时的具体记录（成绩单、时间线）。

### 边界 6：不需要对标的场景

有些事不需要榜样：规律作息、好好吃饭、按时交作业。**这些有明确标准的事，照做就行，不用研究"谁做得好"。**

对标只用于**路径不清晰、有多种打法、结果差异大**的领域。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **只抄动作** | 他 6 点起我也 6 点起 | 学了个形式，结果没变 |
| **对标太远** | 大一研究院士的成长路径 | 信息量为零，还容易自卑 |
| **只看成功者** | 只找成功案例，不看失败的 | 学到的方法可能是无效的 |
| **忽略 L3** | 完全不考虑对方的资源和起点 | 照着走，走不通，怪自己 |
| **用 L3 当借口** | "他有资源，我没有，所以算了" | 从分析滑向放弃 |
| **对标成复制** | 定位、风格、路径全部照抄 | 永远是他的次优版本 |
| **崇拜式对标** | 认为对方什么都是对的 | 关闭判断，学不到 L2 |

## 七、和其他模块的关系

- **对标法 → 自学法**：自学法的"阶段二找范本"，实际就是对标法。**先做对标法定标准，再做自学法建路径**
- **命题审查 → 对标法**：对标对象说的话，要先过命题审查的命题审查（尤其是"我每天学 12 小时"这类绝对化陈述）
- **对标法 → 提问法**：问不到本人的时候，把"他为什么这么选"改写成提问法的好问题，去问他身边的人
- **对标法 → `../capabilities/03_竞赛.md` J2**：选赛时"查本校细则"就是在补自己的 L3 信息
- **对标法和榜样与模仿（榜样与模仿）的分工**：榜样与模仿是知识层（模仿的三个层次、五重过滤、幸存者偏差），对标法是操作层（怎么拆、怎么问、怎么写出自己的版本）。**榜样与模仿讲原理，对标法给流程**

## 八、自检

1. 对标对象满足三条吗？（高 1-2 档 / 路径可见 / 起点接近）
2. 有没有找**同样做法但失败的人**？
3. L1 写的是**可观察动作**，还是他的自我评价？
4. L3 那一栏，有没有诚实填完？（学校、家庭、导师、时间窗口、关键的人）
5. L2 的三个问题问了吗？尤其是"你当时还有别的选项吗"
6. "我的版本"和 L1 **不一样**吗？（一样 = 只抄了动作）
7. 有没有踩到六条边界？（硬找 / 失去自己 / L3 当借口 / 崇拜 / 全信自述 / 该照做却研究）
8. 能不能说出这个对标对象的**一个错误决定**？说不出来，你在崇拜

## 九、来源与定位

- 使用的公开概念：幸存者偏差、选择效应、基率忽视
- 本模块的判断对外说「这是我的判断」；讲边界的说「按这套方法推是这样」。
- 与 `../knowledge/认知/10_榜样与模仿.md` 有一处交叉：「不指望贵人」和「要会抱大腿」在不同处境下各自成立。本模块不调停，只给出各自成立的条件
