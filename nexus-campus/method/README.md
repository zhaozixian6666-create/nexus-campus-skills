# method/ · 方法层

> 这一层不放领域知识，只放**跨领域的通用动作**。
>
> 它是这个库从"能回答"变成"答得专业"的关键：能力模块告诉你这个领域怎么办，方法模块告诉你**这个问题该不该这么问、这句话该不该信、这个人为什么不动**。

---

## 一、为什么单独建一层

一个问题进来，通常有三层要处理：

```
第一层：这句话对吗？（他转述的、他自己下的结论）
第二层：这个问题问得对吗？（他问的东西有没有答案）
第三层：这个领域的答案是什么？
```

**只做第三层，是搜索引擎；做了前两层，才叫专业判断。**

举例：

> 用户说："我学长说绩点不重要，能力更重要。所以我这学期打算不刷绩点了，去参加社团。"

- 只做第三层（能力模块）：讲绩点和能力各占多少权重 → **他其实不信，因为他已经有答案了**
- 做了第一层（命题审查）：审出这句话有定义偷换，且"能力"没有可观察对应 → **他才会重新想**
- 做了第二层（提问法）：把"我该不该刷绩点"改成"我们学校保研的绩点门槛是多少" → **变成一个能查的问题**

**三层都过，才是一条完整的回答。**

## 二、十四个工具

### 第一组：把问题处理干净（命题审查-提问法）

| 编号 | 名称 | 一句话 | 什么时候调 |
|---|---|---|---|
| **命题审查** | 命题审查 | 这句话能不能信 | 他转述别人、或自己下了很强的结论 |
| **概念拆解** | 概念拆解 | 这个词到底在说什么 | 他反复用一个模糊词，且这个词让他有情绪 |
| **提问法** | 提问法 | 把大问题改成能回答的小问题 | 他问的东西大得没法答 |

### 第二组：做决定与学东西（自学法、对标法、理论溯源）

| 编号 | 名称 | 一句话 | 什么时候调 |
|---|---|---|---|
| **自学法** | 自学法 | 学校不教的东西怎么学 | 他要学一个学校没有的能力 |
| **对标法** | 对标法 | 该学谁、能学他哪一层 | 他说"想学某某人""照着做" |
| **理论溯源** | 理论溯源 | 这说法有依据吗、历史比方能成立吗 | 他说"史上最难""AI 会取代""和以前一样" |

### 第三组：想清要什么（任务澄清 → 目标清晰化 → 决策档案）

| 编号 | 名称 | 一句话 | 什么时候调 |
|---|---|---|---|
| **任务澄清** | 任务澄清 | 我雇这件事完成什么 | 他说"该不该考研/考公/进社团" |
| **目标清晰化** | 目标清晰化 | 把"我想变优秀"变成能指物的句子 | 他说"我想提升自己""我想自律" |
| **决策档案** | 决策档案 | 做过什么决定、为什么、应验了没 | 他做完决定、或问"我该怎么选" |

### 第四组：日常底盘（执行诊断、知识库自建、协作与求助）

| 编号 | 名称 | 一句话 | 什么时候调 |
|---|---|---|---|
| **执行诊断** | 执行诊断 | 知道该做却做不到，是哪一种 | 排除睡眠/能力/环境/临床之后仍不动 |
| **知识库自建** | 知识库自建 | 存进去的东西怎么找回来 | 他找不到资料、有多个版本文件 |
| **协作与求助** | 协作与求助 | 怎么开口问人、怎么拒绝、怎么组队、怎么委派与验收 | 他要找人帮忙、不敢拒绝、要把活分给别人 |

### 第五组：看清全貌（多视角）

| 编号 | 名称 | 一句话 | 什么时候调 |
|---|---|---|---|
| **多视角** | 多视角 | 换个位置看，这件事是什么样 | 他反复权衡、谁说得都对、下不了决心 |

### 第六组：换立场（思想校准）

| 编号 | 名称 | 一句话 | 什么时候调 |
|---|---|---|---|
| **思想校准** | `14_思想校准.md` | 取一条本人认可的观点，把问题换成一个更答得动的问题 | 他在方向、代价、自我判断上反复打转，且不缺步骤 |

**它和前十三项不一样**：前十三项处理问题的毛病，这一项处理**看问题的立场**。观点原文在 `knowledge/思想/`，按信号定位在 `../knowledge/思想/02_问题-原子对照表.md`。规则题、事实题、转述别人的话，都不调它。

### 调用顺序（多个信号并存时）

```
概念拆解 拆词 → 提问法 改问题 → 命题审查 审命题 → 任务澄清 → 目标清晰化 立目标
   → 领域模块（capabilities/）→ 执行诊断 执行 → 决策档案 立案留档
                                      ↑
                          自学法/对标法/理论溯源 在"要学东西"时插入
                          知识库自建/协作与求助 在"存资料/找人/分活"时插入
                          多视角 在"卡在选择上、看不见别的立场"时插入
                          思想校准 在"不缺步骤、缺一个看事情的立场"时插入（一次一条，用完落回模块）
```

**理由**：词不清则问题不清，问题不清则命题无从审；任务不清则目标无意义，目标不清则领域模块答了也没用。**顺序反了会返工。**

**决策档案的特殊位置**：它是**存储器**。前面所有工具得出的结论，最后都该落进档案，否则三个月后全忘。

### 三条纪律

1. **一次只调一个**，同时上两套工具会让人感觉在被审问
2. **必须落回领域模块**，停在方法层等于只说了"你的问题问得不好"，没给解决方案
3. **不报工具名**，对外直接给结果："你这句话里，'重要'指两件不同的事"——不说"我用概念拆解分析了"

## 三、每个文件的统一结构

九节，缺一节不算写完：

| 节 | 写什么 | 为什么必须有 |
|---|---|---|
| 一、这个模块解决什么 | 边界，不是卖点 | 不写边界就会什么都往里塞 |
| 二、核心判断 | 4-6 条，每条一个机制 | 这是内容主体，每条要能独立站住 |
| 三、操作流程 | Step 1-N，带判定表 | 只有判断没有流程 = 只有观点没有方法 |
| 四、场景实例 | 至少 3 个，走完整个流程 | 没有实例的方法，学生用不出来 |
| 五、**反例与边界** | 5-6 条"什么时候不该用" | **最重要的一节，见下** |
| 六、常见误用 | 表格，表现 → 后果 | 防止工具被用歪 |
| 七、和其他模块的关系 | 调用图 + 分工说明 | 防止重复和打架 |
| 八、自检 | 7 条左右，能自己打分 | 交出去之前的最后一道闸 |
| 九、来源与定位 | 理论出处 + 归属声明 | 开源时的合规要求 |

### 为什么第五节不能省

**只讲成立、不讲边界的判断，最后一定会变成教条。** 而教条恰恰是这一层要反对的东西。

每一份的第五节都至少包含两类边界：

- **适用边界**：什么情况下这套不成立（比如命题审查在紧急决策时不该用）
- **伦理边界**：这套被误用会伤害谁（比如执行诊断的目的论被拿去指认别人"你就是在装"）

**写第六节（常见误用）时，要写出"我自己最可能犯的那一个"**，不是列一堆别人的错。

## 四、归属声明

**这一层讲的是方法，不是谁的个人经历。**

| 内容 | 对外怎么说 |
|---|---|
| 方法本身（从公开理论到可执行动作） | **"这是我的判断"** |
| 讲适用边界时 | **"按这套方法推是这样"** |

具体用到的公开理论：

| 模块 | 理论 |
|---|---|
| 命题审查 | 休谟实然/应然二分、波普尔可证伪性、幸存者偏差（沃德）、反事实因果 |
| 概念拆解 | 维特根斯坦《哲学研究》：意义即使用、家族相似、语言游戏 |
| 提问法 | 现象学式的"回到事实本身"、约束场思维 |
| 执行诊断 | 阿德勒个体心理学：目的论、课题分离 |
| 自学法 | 波兰尼默会知识、西蒙模式识别（chunking）、刻意练习的反馈条件 |
| 对标法 | 幸存者偏差、选择效应、基率忽视 |

**这些理论都是公开的，谁都能查。这个库做的是另一件事：把它们变成"遇到这句话，下一步做什么"。**

## 五、什么时候该再加一个

**不要为了凑数加。** 加一个新方法的门槛是三条全满足：

1. **它处理的问题，现有动作都覆盖不了**（不是"稍微不一样"）
2. **它在大学场景里高频**（一个月能被触发十次以上）
3. **它有明确的判定标准**（能说出"什么情况算用对了"）

有些问题不单独成篇，放在已有模块里：

| 问题 | 放哪 | 为什么 |
|---|---|---|
| 时间分配 | `../capabilities/01_学业.md` | 多目标冲突的判定已经在那里 |
| 团队协作 | `../capabilities/03_竞赛.md` | 组队是竞赛里的一个判断 |
| 信息检索 | 各模块的「查本校细则」 | 拆出来会碎 |
| 表达与写作 | `../knowledge/认知/03_表达与个人IP.md` | 更偏内容侧 |

**判断标准：如果一个问题能用现有模块的某一节回答，就不要新建文件。** 文件越多，调用越乱。

## 六、怎么改（维护规则）

| 动作 | 怎么做 |
|---|---|
| 发现某条判断不对 | 直接改那一条，但**必须在第九节记一句"某年某月改了什么、为什么"** |
| 新增一条判断 | 加在第二节，同时**检查第五节有没有对应的边界**（新判断几乎总会带来新边界） |
| 发现两份冲突 | 先判断哪份更前置（命题审查比对标法前置），在前置的那份里写明冲突，不要在两份里各说一套 |

**第二条最容易漏**：新增一条判断，就回头看看有没有对应的边界。只讲「成立」不讲「什么时候不成立」，判断会变成教条。
