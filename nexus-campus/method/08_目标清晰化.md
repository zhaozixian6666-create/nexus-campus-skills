# 08 · 目标清晰化

> 用途：把「我想变优秀」「我要提升自己」「我想变得更自律」这类话，改成能开始做、能判断做没做到的句子。
>
> **一个目标如果不能告诉你「现在做什么」和「什么时候算完」，它就不是目标，是愿望。**

---

## 一、这个模块解决什么

大学生说得最多的话，几乎都是没有验收标准的：

> 我想变得更优秀
> 我要提升自己的能力
> 我想好好学英语
> 我要多读书
> 我想变得更自信
> 我要努力一点

这些话的共同点：**说完之后，你不知道下一步做什么，也不知道什么时候算完成。**

结果是：说的时候很有动力，三天后忘了，一个月后自责，然后重新说一遍。**循环四年。**

目标清晰化做的事：把这类话拆成**能指物、能证伪、有完成态**的句子。

**它不负责让你有动力**——动力不归它管。它负责让你**知道该干什么**。

---

## 二、核心判断

### 判断 1：一个目标要能完成两件事，否则不算目标

判断一个句子是不是目标，只问两句：

1. **它能告诉我下一步做什么吗？**
2. **它能让我认出「做完了」吗？**

两句都过，这个目标可以用了。任何一句不过，它还是愿望。

| 句子 | 下一步做什么？ | 怎么算完了？ | 判定 |
|---|---|---|---|
| 我想变优秀 | 不知道 | 不知道 | 愿望 |
| 我要提升表达能力 | 不知道 | 不知道 | 愿望 |
| 这学期每周三晚在社团例会做 3 分钟即兴发言 | 周三去例会 | 做了 16 次 | ✅ 目标 |
| 12 月前把六级从 480 提到 550 | 每天背 30 个词+每周一套真题 | 出分 ≥550 | ✅ 目标 |

### 判断 2：删掉一个词，如果交付物变了，这个词就在做工作

这是最快判断"这个词重要不重要"的方法。

很多人用错判据：删掉后句子还通顺 → 这个词是废话。**这是错的。**

正确的判据是：**删掉后，要做的东西、给谁、什么范围、怎么做、怎么验收，有没有变？**

| 原句 | 删掉的词 | 删后语义变了吗 | 判定 |
|---|---|---|---|
| 交一份 CSV 格式的表 | CSV 格式 | 交付规格变了 | **在做工作** |
| 我想变得更优秀 | 更 | 几乎没变 | 不做工作 |
| 我想在**三个月内**把六级提到 550 | 三个月内 | 时间边界消失了 | **在做工作** |
| 我要**系统地**学一遍高数 | 系统地 | 说不清变了什么 | **不做工作（除非能说明）** |

**这条判断的用途**：把一句话里所有"不做工作"的词挑出来删掉，剩下的是骨架。骨架还立不住，就说明缺信息。

### 判断 3：目标成熟度看五条，不要求全过

不需要五条全中，通常过三条就够用。

| # | 特征 | 检测问句 | 不通过的典型 |
|---|---|---|---|
| 1 | **可指物** | 完成时，有东西能被指出来吗？（文件、数字、行为、事件） | "变优秀"——指不出任何东西 |
| 2 | **可证伪** | 存在能判断"没完成"的情况吗？ | "提升自己"——怎么做都算提升了 |
| 3 | **有完成态** | 它在某个条件下能结束吗？ | "坚持读书"——没有终点 |
| 4 | **语法健全** | 谁做、做什么、做到什么程度，能看懂吗？ | "优化一下"——优化什么、到哪 |
| 5 | **嵌在上下文** | 和我的时间、资源、处境兼容吗？ | 大三下说"每天学 8 小时英语"，同时要保研 |

**优先放行规则**：只要第 1 条（可指物）和第 3 条（有完成态）都过，就可以开始做了，剩下三条边做边补。

**为什么**：等到五条全过才行动，会永远不行动。目标的作用是让你现在能动，不是让你把它写完美。

### 判断 4：三个最常见的失败模式，各有各的修法

90% 的模糊目标落在三种里：

| 失败模式 | 典型句子 | 缺什么 | 修法 |
|---|---|---|---|
| **A 无指物** | 我想变优秀 / 我想成长 | 不知完成时能指出什么 | **问"谁会看到什么"**——把内在状态换成外部可见的结果 |
| **B 无完成态** | 我要坚持跑步 / 我要多读书 | 没有终点 | **加数量或时间盒**——"跑满 30 次""读完 4 本" |
| **C 不可证伪** | 我要努力 / 我要认真 | 怎么做都算做到了 | **找反例**——什么情况算我没做到 |

**修法举例**：

| 原句 | 模式 | 修后 |
|---|---|---|
| 我想变优秀 | A | 这学期绩点进专业前 15%，并且做完一个能给别人看的项目 |
| 我要多读书 | B | 12 月 31 日前读完 4 本，每本写 500 字笔记 |
| 我要努力 | C | 每天 20:00-22:00 在图书馆，手机放包里。一周记录做到几天 |

### 判断 5：目标里不能有别人的标准（除非你认了）

"我想变优秀"最大的问题不是模糊，是**标准是别人的**。

优秀的标准是谁定的？绩点？竞赛？实习？社交？——**不同人说不一样，你按谁的标准努力，就活成谁想要的样子。**

**检测方法**：把这个目标说给三个人听，问他们"你觉得我做到了吗"。如果三个人的答案不一样，说明这个目标的标准不在你手里。

**处理**（两条路，必须选一条）：

| 路 | 做法 | 适合 |
|---|---|---|
| **接管标准** | 明确写出"我按谁的标准"，并承认这是选择 | 你要的就是那个体系的回报（保研、进大厂） |
| **换标准** | 换成"我自己认可什么"，可能和主流不同 | 你发现自己在追一个不想要的东西 |

**不能选的是第三条**：用别人的标准努力，但心里不认。这是四年最常见的痛苦来源——**做得很累，且不觉得值得**。

### 判断 6：目标不能替对方定（保留主权）

给建议时，最容易犯的错是替对方决定：期限、数字、给谁看、什么算成功。

**这些必须他自己说。** 我能做的是：
- 指出这句话缺哪个要素
- 给 2-3 个候选写法（标明是候选）
- 问"这三个里哪个更接近你要的"

**不能做的**：直接给一个"你应该这样定"。

**为什么**：目标的价值来自**他认**。我定的目标再合理，他不认就不会执行——而且他不知道是目标的问题，会以为是自己不行。

## 三、操作流程

### Step 1：抄下原句，一个字不改

先看它落在哪个失败模式（A 无指物 / B 无完成态 / C 不可证伪）。

### Step 2：做语义做工检测

把句子里的修饰词逐个删，看交付物变不变。

```
原句：我想在这学期系统地提升一下自己的编程能力
删"系统地" → 交付物变了吗？没变 → 删
删"一下"   → 没变 → 删
删"这学期" → 变了（时间边界没了）→ 留
剪完：我想在这学期提升编程能力
```

**剪完还剩什么，就是这句话的全部信息量。** 通常会发现信息量接近于零——这就是为什么它没法执行。

### Step 3：过五条特征

填表，标出哪条不过：

| # | 特征 | 过？ | 不过的话缺什么 |
|---|---|---|---|
| 1 | 可指物 | | |
| 2 | 可证伪 | | |
| 3 | 有完成态 | | |
| 4 | 语法健全 | | |
| 5 | 嵌在上下文 | | |

### Step 4：按失败模式修

| 不过的条 | 修法 |
|---|---|
| 1 可指物 | 问"完成那天，别人能看到什么？"（一个文件、一个数字、一段视频、一张证书） |
| 2 可证伪 | 问"什么情况说明我没做到？"（必须有具体情形） |
| 3 有完成态 | 加数量（30 次）、加时间盒（12 月 31 日前）、加事件（比赛结束） |
| 4 语法健全 | 补齐"谁、做什么、到哪" |
| 5 嵌在上下文 | 减量，或换时间（现在做不到就先定小一点） |

### Step 5：写成目标卡

```markdown
## 目标卡

**原话**：______

**改后**：______（谁 + 做什么 + 做到什么程度 + 什么时候）

**完成时能指出的东西**：______
（必须是别人能看到的，不能是"我感觉我变强了"）

**什么情况算没做到**：______

**第一步（今天或这周）**：______
（必须小到 30 分钟内能开始）

**怎么检查**：______（每周/每月看什么）

**这个标准是谁的**：我的 / 某体系的（如保研细则）
```

**"这个标准是谁的"这一行不能空。** 它是防止你努力四年才发现方向不对的唯一保险。

### Step 6：立刻做第一步

目标卡写完，**当场做那个"第一步"**，或者定一个 24 小时内的时间。

不做，这张卡就是又一张纸。

## 四、大学场景实例

### 实例 1：「我想变得更优秀」

| 步 | 内容 |
|---|---|
| 失败模式 | **A 无指物** + 判断 5 的标准问题 |
| 语义检测 | 删"更"→ 没变。整句信息量 = 零 |
| 五条 | 可指物 ❌ / 可证伪 ❌ / 有完成态 ❌ / 语法健全 ⚠️ / 嵌上下文 ❌ |
| 追问 | "你说的优秀，是哪个场合下的？保研评审？找实习？还是你自己觉得？" |
| 修后（假设他要保研） | 这学期绩点进专业前 15%；6 月前完成一个能讲 5 分钟的项目；认识 2 个本方向的学长并问过问题 |
| 完成时能指出 | 成绩单排名、项目文档、聊天记录 |
| 算没做到 | 排名掉出 15%，或项目没做完 |
| 第一步 | **今天查本院保研细则里绩点占多少权重** |
| 标准是谁的 | 保研细则（我认，因为我要这个结果） |

**关键**：原句里的"优秀"被替换成了**三个不同维度的具体项**。不是变清楚了，是变具体了——清楚是感觉，具体是能查。

### 实例 2：「我要提升表达能力」

| 步 | 内容 |
|---|---|
| 失败模式 | **A 无指物** + **B 无完成态** |
| 追问 | "表达在哪个场合？讲课、面试、答辩、还是日常聊天？"（**场合不同，练法完全不同**） |
| 修后（假设是答辩） | 这学期在 3 次组会里各做一次 5 分钟汇报，每次录下来；每次找一个人给具体反馈（不是"挺好"，是"哪一段没听懂"） |
| 完成时能指出 | 3 段录像 + 3 份反馈 |
| 算没做到 | 只做了 1 次，或没录 |
| 第一步 | **下次组会主动报名** |
| 标准是谁的 | 我的（我想在答辩时不慌） |

**关键**：**加了场合**。没有场合的"表达能力"，是一个无法训练的抽象物。

### 实例 3：「我要好好学英语」

| 步 | 内容 |
|---|---|
| 失败模式 | **B 无完成态**（学到什么时候算好？） |
| 追问 | "学英语是为了什么？考试、看文献、还是口语？" |
| 修后（假设是六级） | 12 月考前把六级从 480 到 550：每天 30 个词（用 APP，通勤时做），每周六上午做一套真题，错题当天整理 |
| 完成时能指出 | 12 月成绩单 ≥550 |
| 算没做到 | 低于 550，或真题没做满 12 套 |
| 第一步 | **今天下载真题，做一套，看现在几分**（先知道起点） |
| 标准是谁的 | 六级分数线（外部标准，我认） |

**关键**：**先测起点**。不知道现在 480，就不知道 550 有多远，也不知道每天 30 个词够不够。

### 实例 4：「我想变得更自信」

| 步 | 内容 |
|---|---|
| 失败模式 | **A 无指物**（自信是内在状态，指不出东西） |
| 难点 | 这是最难改的一类，因为它的目标本身是"感受" |
| 转换 | 问"如果一个人很自信，你会看到他做什么？" → 通常是：主动发言、敢拒绝、被否定时不慌 |
| 修后 | 这学期在课上主动发言 10 次（不管说得对不对）；拒绝 3 次不合理的请求 |
| 完成时能指出 | 自己记的次数 |
| 算没做到 | 少于 5 次 |
| 第一步 | **下次课准备一个问题，下课问老师**（比课上发言门槛低） |
| 注意 | 这里做的是**行为**，不是感受。**感受是行为的副产品，不能直接设定为目标** |

**关键**：内在状态不可直接设定，只能通过行为间接获得。**要求自己"变自信"，等于要求自己"变高"——不是努力能解决的事。**

## 五、反例与边界

### 边界 1：不是所有目标都该清晰化

有些东西要模糊一点才活得下去：

> "我想成为一个有意思的人""我想做点有意义的事"

这类**方向性愿望**不需要验收标准，它的作用是给你一个大致朝向。把它 KPI 化，会杀死它。

**区分标准**：这个东西如果是**要达成的事**，就清晰化；如果是**想成为的人**，就留着模糊。

**判断问句**："如果三年后我做到了，我会说'完成了'，还是'我还在路上'？"——前者清晰化，后者不要。

### 边界 2：清晰化会杀掉一部分热情

有个真实的现象：把梦想写成 KPI 之后，很多人反而不想做了。

因为模糊的愿望是**无限的**（我可以成为任何样子），具体的目标是**有限的**（我只能做到这个）。从无限到有限，会有一阵失落。

**处理**：接受这个失落，它是正常的。**具体的代价换来的是可实现**——你失去的是幻想的空间，得到的是真的能改变的东西。

**如果失落持续超过两周且完全不想动**，说明这个目标本身不是你要的，回到判断 5 重新看标准。

### 边界 3：目标不能定得比资源大

"这学期绩点 4.0 + 发一篇论文 + 学会剪辑 + 考过六级 + 每周健身三次"——这不是目标，是许愿池。

**检测**：把每项要花的时间加起来，看是否超过你除上课外的可用时间。

**规则**：**一学期最多三个目标，其中一个必须是主目标。** 三个以上，等于没有。

### 边界 4：不要替别人定目标

见判断 6。给朋友建议时，最多说"你这句里缺完成态"，不要说"你应该定成每周三次"。

**为什么**：他执行失败时会归因到"我做不到"，而不是"这个目标不是我要的"。**你替他定得越具体，他越容易受伤。**

### 边界 5：目标清晰化不解决"不想做"

它能告诉你做什么，**不能给你做的理由**。

如果你把目标写得极其清楚，还是不动——那不是目标问题，是执行问题，去 `04_执行诊断.md`。

**信号**：目标卡写完了，看着它没有任何感觉。这时候缺的是意义，去 `../knowledge/认知/02_意义与选择.md`。

### 边界 6：有些目标会过期，允许放弃

大一给自己定的"要考研"，大三发现更适合就业——**放弃这个目标不是失败，是修正**。

**规则**：每个目标卡写复查时间。到时间不复查，它就变成了枷锁。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **用"坚持"当目标** | "我要坚持早起" | 没有终点，坚持到哪天？ |
| **用感受当目标** | "我要变自信""我要快乐" | 不可直接设定，努力方向错 |
| **定太多** | 一学期八个目标 | 每个都做一点，每个都没成 |
| **标准是别人的却不承认** | 按父母/同学的标准努力 | 做到了也不快乐 |
| **写得很漂亮但不动** | 目标卡写得很完整，第一步没做 | 变成新的自我安慰 |
| **清晰化到僵化** | 每天几点做什么都定死 | 一次打乱就全崩，然后放弃 |
| **替别人定** | 给朋友一套详细计划 | 他失败后更自责 |

## 七、和其他模块的关系

```
概念拆解 拆词（"优秀"是什么意思）
   ↓
目标清晰化 立目标（变成能指物的句子）
   ↓
任务澄清（我为什么要做这件事）
   ↓
决策档案 立案（记下预期和证伪条件）
   ↓
执行诊断 执行（为什么不动）
```

- **概念拆解 → 目标清晰化**：概念拆解拆"优秀"这个词的意思，目标清晰化把它落成具体项。**先拆后立，顺序不能反**
- **目标清晰化 → 任务澄清**：目标定了，但可能是错的（比如"我要考研"其实是逃避就业），用任务澄清问"我雇它来完成什么"
- **目标清晰化 → 决策档案**：目标卡要进决策档案，否则三个月后忘了
- **目标清晰化 → 执行诊断**：目标清楚但不动，去执行诊断
- **和 `../capabilities/07_成长.md` 的分工**：07 管"迷茫"这个状态怎么处理，目标清晰化管"模糊的愿望怎么变成目标"。**07 处理情绪，目标清晰化处理句子**

## 八、自检

1. 这句目标，能告诉我**下一步做什么**吗？
2. 完成那天，**别人能看到什么**？（不能是"我感觉变强了"）
3. **什么情况算我没做到**？说得出具体情形吗？
4. 它有**完成态**吗？（数字、日期、事件，三选一）
5. 语义检测：删掉修饰词，交付物变了吗？没变的删掉了吗？
6. 这个标准**是谁的**？我认吗？
7. 一学期几个目标？（超过三个 = 没有主目标）
8. 第一步是不是**30 分钟内能开始**？
9. 有没有踩到六条边界？（方向性愿望被 KPI 化 / 杀热情 / 超资源 / 替人定 / 当动力用 / 过期不弃）

## 九、来源与定位
