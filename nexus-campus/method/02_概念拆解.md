# 02 · 概念拆解

> 用途：拿到一个词（内卷、躺平、优秀、情商、格局、自律、信息差），先搞清它到底在说什么，再决定要不要为它焦虑。
>
> 很多痛苦不是来自处境，是来自**用一个自己没定义清楚的词描述处境**。

---

## 一、这个模块解决什么

大学生的高频困扰，几乎都长在一个模糊词上：

> "我们专业太**内卷**了" → 所以呢？该退还是该打？
> "我想变得**优秀**" → 优秀的标准是谁定的？
> "我**情商**低" → 具体是哪件事做错了？
> "我**自律**性太差" → 是起不来床，还是坚持不了三天？

这些词的问题不在于错，在于**它们让人以为已经理解了**。一旦说"我自律性差"，思考就停止了——因为你已经给问题命了名，命了名就好像解决了。

**概念拆解的功能，是把这种"假的理解"打掉，逼出一个能被行动回答的说法。**

---

## 二、核心判断

### 判断 1：一个词的意思，看它让人做了什么（意义即使用）

维特根斯坦的核心主张：词的意义不在字典里，在**使用中**。不要问"这个词的定义是什么"，要问"**说这个词的人，接下来会做什么**"。

检验方法：同一个词，换不同人说，看他们的行动是否一样。

「内卷」这个词：

| 谁在说 | 说完之后他会做什么 | 这个词在他嘴里意思是 |
|---|---|---|
| 抱怨的同学 | 继续跟着卷，但心里舒服一点 | "我不如别人，但这不是我的错" |
| 准备保研的人 | 更精确地算加分 | "竞争激烈，我要提高效率" |
| 已经放弃的人 | 不再投入，转向别的赛道 | "这条路投入产出比太差，我换一条" |

**三种意思，三种行动。** 所以当你听到"内卷"这个词，第一件事不是共情，是问：**你说这个词，是想让我做什么？**

- 如果答案是"什么都做不了" → 这个词在你这里是**情绪出口**，不是判断
- 如果答案是"换个方式竞争" → 它在说效率问题
- 如果答案是"换条路" → 它在说赛道问题

**同一个词，三种诊断，三种解法。混着用，就会得出"内卷无解"这种结论。**

### 判断 2：很多概念没有共同本质，只有一族相似（家族相似）

维特根斯坦的另一个工具：很多词指的东西，没有一个是所有成员共有的特征，只有交叉重叠的相似性——像一家人，眼睛像爸爸，鼻子像妈妈，但没有一个特征全家都有。

「优秀」就是典型：

- 绩点 4.0 的人优秀吗？可能是自律，也可能是只会考试
- 创业赚到钱的人优秀吗？可能是能力，也可能是运气加时机
- 支教两年的人优秀吗？可能是理想，也可能是在逃避就业

**没有共同本质。** 所以你问"到底什么才算优秀"，永远得不到答案——这个问题本身预设了一个不存在的共性。

正确的处理不是造一个定义，而是：**列出这个词在你这个场合下，具体指哪几个可观察的特征。**

比如"我想变优秀"，在你的场合（大二、想保研）可以落成：

> 绩点进前 15%、有一段实验室经历、能独立讲清一个专业问题、有两三个能借力的人

**四个可观察项，取代一个不可观察的词。** 焦虑立刻变成清单。

### 判断 3：去掉这个词，还说得清吗（大白话测试）

这是最快的拆词法，不需要任何理论。

操作：把这句话里的目标词去掉，用大白话把同一件事重说一遍。

| 原话 | 去掉后重说 | 判断 |
|---|---|---|
| "我们专业太内卷了" | "我们专业的人为了同样的名次，投入的时间越来越多" | 说得出 → 词只是包装，真问题是**投入产出比** |
| "我情商低" | "我在___场合说了___，对方的反应是___" | 说不出来 → 这个词在**掩盖一处理解空白** |
| "我要提升格局" | ？ | 完全说不出来 → 这个词**没有可观察的对应物**，是纯装饰 |
| "我自律性差" | "我计划每天 7 点起，实际连续 5 天 9 点起" | 说得出，但有细节 → 真问题是**具体行为的偏差** |

三种结果，三种处理：

- **说得出** → 用大白话版本替换，原词丢掉。真问题会自己浮出来
- **说不出来** → 你其实不知道自己遇到了什么。这时候该去**收集事实**，不是找解法
- **不同人说出不同版本** → 这个词被混用了，先分清谁在说哪个意思

**判断依据是"语义有没有丢失"，不是"句子通不通顺"。** 一句通顺但丢掉了关键信息的重述，是失败的。

### 判断 4：很多问题句式自带一个不存在的前提（错误预设）

有些问题，无论怎么答都是错的，因为**问题里藏了一个假前提**。

| 问题 | 藏着的预设 | 为什么是假的 |
|---|---|---|
| "怎么才能不内卷？" | 存在一个"不参与竞争"的选项 | 只要资源稀缺，退出竞争的方式只有"换赛道"，没有"不竞争" |
| "怎么提高情商？" | 情商是一个可以单独训练的通用能力 | 它是具体场景下的具体反应，不存在脱离场景的"情商" |
| "大学该怎么规划才不留遗憾？" | 存在一个"没有遗憾"的规划 | 任何选择都放弃其他可能，遗憾是选择的必然后果，不是规划的失败 |
| "怎么才能又轻松又成功？" | 两者可以同时最大化 | 大部分时候是取舍关系，不是并列关系 |

**拆法**：把问题改写成陈述句，看那个陈述是不是真的。

> "存在一种不参与竞争的活法" → 假。所以"怎么不内卷"无解，该问"我该换哪条赛道"。

**这一步的杀伤力在于：它把大量无解的问题，直接判定为"问错了"，而不是"我还没找到方法"。** 后者会让人反复内耗，前者能让人立刻转向。

### 判断 5：有些问题要答案，有些问题要实践（Question 与 Problem）

- **Question**：有标准答案，一段文字就能答完。例："保研需要哪些材料""这个证什么时候报名"
- **Problem**：答案的形式是**一段实践**，说不出来，只能做出来。例："我适不适合做科研""我能不能坚持做内容"

大学生最常犯的错，是**把 Problem 当 Question 问**：

> "我该不该读研？"——这不是查资料能答的，是读一段时间的科研、做一次完整的项目之后才知道的
> "我适不适合创业？"——去卖一次东西比想一百天有用

**审法**：这个问题，如果一个人给我一段完美的文字回答，我会照做吗？

- 会 → Question，去查、去问人
- 不会，我还是得自己试 → Problem，**别问了，去设计一个最小成本的试验**

**这个区分能省掉大量的"咨询式拖延"**：反复问别人"我该不该"，其实是在推迟那个必须自己做的试验。

### 判断 6：说不清楚的，就说说不清楚（克制）

维特根斯坦那句被引用最多的话：凡是能说清楚的，就说清楚；说不清楚的，应当沉默。

在大学场景里，这条的实操含义是：

- 词源、出处不确定 → 就说"我不确定它最早出自哪"，不要编一个来源
- 只能靠实践回答的 → 不要给一段看起来完整的文字答案
- 不要用一个更复杂的词，去解释一个不懂的词（"内卷的本质是存量博弈下的非理性竞争"——学生听完还是不知道该怎么办）

**"我不知道"是一个合法答案。** 在知识库这种要长期使用的东西里，编一个解释的代价，远高于承认不知道。

### 附：四种问题词的完整分类

判断 3 和判断 4 是同一条流水线上的两道工序。合起来是四种词，**每种的处理方式都不一样**：

| 类型 | 怎么判定 | 怎么处理 | 大学里的例子 |
|---|---|---|---|
| **包装词** | 用大白话重说，对象、行动、结果都没丢 | 说明它只是包装。他想继续用这个词，可以，但要知道它没带来新信息 | 「核心竞争力」→「别人为什么选你，不选另一个差不多的人」 |
| **混用词** | 同一段对话里有两种以上用法，而且两种用法会导致**不同的行动** | 列出各是哪个意思，指出混淆在哪一步造成了损失 | 「保研」——有人指"拿到推免资格"，有人指"最终被录取"。前者要刷绩点，后者还要面试、联系导师，行动完全不同 |
| **错误预设** | 问题本身预设了一个不存在的东西 | 指出预设，把问题改写成能回答的 | 「怎么规划才不留遗憾」——预设了存在一种没有遗憾的规划 |
| **伪概念** | 大白话重说时说不出来，或者说出来后没有任何可观察的差异 | 直接说它是伪概念，并说明它掩盖了哪一处理解空白 | 「格局」「认知层次」「思维维度」——三个人说出三个意思，没有一个能落到具体行为 |

**顺序很重要：先试包装词，再试混用词，最后才判伪概念。** 上来就说"这是个伪概念"，多数时候是你没听懂他指的是什么。

### 判断 7：同一个词，在两处场合里遵守两套规则（语言游戏）

这是判断 1 的另一面。判断 1 说"意义看它让人做了什么"，判断 7 说的是：**同一个词，在不同的场合里，让人做的事不一样。**

以「公平」为例，同一个学生可能在三件事上说这个词：

| 场合 | 「公平」在这里指什么 | 他实际想要的动作 |
|---|---|---|
| 评奖学金 | 规则透明、按同一个标准算 | 公开评分细则 |
| 小组作业 | 每个人出力差不多 | 让划水的人多干点 |
| 家里分钱 | 谁更需要给谁 | 多要一点生活费 |

**三处说的是同一个词，规则完全不同。** 两个人吵"这不公平"，往往是一个在说规则（程序公平），一个在说结果（结果公平），谁也说服不了谁。

**拆法**：先问"你这话是在哪个场合说的"，再问"在这个场合里，你希望对方具体做什么"。

**这是最省力的一招**：大量关于"公平""尊重""自由""值不值"的争论，拆开场合就不吵了——因为他们本来就没在说同一件事。

### 判断 8：涉及价值、价格的词，要用四把尺子量（奥地利学派校准）

凡是词里带"值不值""含金量""有没有用""前景""需求"的，都可以用下面四把尺子过一遍。**只写有发现的项，不必四条都写。**

| 尺子 | 要问的 | 大学里的常见病 |
|---|---|---|
| **主观价值** | 这个词是不是预设了一个脱离具体人的"客观价值"？ | 「这个专业有前途」「这个证含金量高」——把某个人群、某个机构的评价，说成了这个东西本身的属性 |
| **行动** | 它描述的是一个人的行动，还是**替代**了行动？ | 「赛道」「风口」「蓝海」——让人以为**选对了就有收益**，而收益只能来自做了什么 |
| **自发秩序** | 它是不是假设存在一个可以算出来的最优解？ | 「最优路径」「完美规划」「正确选择」——假设有一个标准答案摆在某处等着被发现 |
| **可观察信号** | 它能不能落到能看见的行为、结果、数据上？ | 落不下来时，就用可观察信号替换它 |

**最有用的两个校准**：

> 「这个专业有没有前途？」
> 改成：**这个专业的毕业生，去了哪些岗位，起薪多少，三年后还在不在这个行业。** 这是可查的。

> 「这个比赛含金量高不高？」
> 改成：**在你们学校的保研加分表里，它算几分；在你想去的公司的招聘要求里，它出不出现。** 这才是"含金量"的真实度量。

**一句要记住的**：与其争论一个东西"有没有价值"，不如去看**谁愿意为它付出什么**。争论价值是争论定义，看付出是看事实。

**边界**：这把尺子只管"声称有实用价值"的词。审美、情感、道德上的价值不适用——**"这首诗好不好"不能靠有没有人买单来判**。用错地方就是粗俗。

## 三、操作流程

### Step 1：把词单独拎出来，放到句子里看

不要拆孤立的词。同一个词在不同句子里意思不同。

> "这个专业太卷了" vs "他特别卷"——前者说环境，后者说人。解法完全不同。

### Step 2：问三个问题（谁在说 / 什么场合 / 反义词）

| 问题 | 目的 | 例（"优秀"） |
|---|---|---|
| **谁在说？** | 说话人决定了这个词的用途 | 辅导员说 vs 同学说 vs 家长说，标准三套 |
| **什么场合？** | 场合决定了判定标准 | 评奖学金场合 / 找实习场合 / 自我要求场合 |
| **反义词是什么？** | 反义词划出了这个词的边界 | 优秀的反义词是"平庸"还是"不合格"？前者是排序，后者是及格线 |

**第三问最有信息量。** 反义词如果是"差"，说明它在做**排序**（相对位置）；如果是"不合格"，说明它在做**判定**（是否达标）。排序和判定的应对方式完全不同：排序要争，判定只要过线。

### Step 3：做大白话测试

去掉词，重说一遍。记录三种结果中的哪一种。

### Step 4：找出可观察的行为

这是拆解的终点，也是唯一有用的产出：

> **这个词，对应到什么样的人、做了什么样的事、别人能观察到什么？**

填不出来，说明这个词在你这里没有信息量，可以直接丢掉。

### Step 5：写成一句能行动的话

格式：

```
原来我说：【原话】
它实际在说：【大白话】
我能观察到的：【具体行为/事实】
所以我该做：【一个动作】
```

**最后一行如果是"所以我要努力提升 XX"，说明拆解失败**——你把一个模糊词换成了另一个模糊词。

## 四、大学场景实例：六个词逐个拆

### 拆 1：「内卷」

| 项 | 内容 |
|---|---|
| 谁在说 | 学生说得多，且多在自己处于劣势时说 |
| 大白话 | 一群人为了同样的名次，投入越来越多的时间，但名次总数不变 |
| 真正的机制 | **总量固定的零和竞争**。注意：不是"竞争激烈"叫内卷，是"**投入增加但总产出不变**"才叫内卷。如果投入增加带来了总产出增加（比如整个行业变强），那不叫内卷，叫进步 |
| 反义词 | 增量竞争（蛋糕变大） |
| 可观察的 | 你的投入增加后，绝对能力有没有提升？还是只提升了相对排名？ |
| 该怎么用 | 分两种处境：① 你在这条赛道上**有优势** → 内卷对你有益，继续投入；② **没优势** → 内卷是纯损耗，该换赛道（换赛道不等于躺平，是换一个"投入能变成能力"的场） |
| ⚠️ 常见误用 | 把所有累都叫内卷。累但能力在长，那是训练；累且能力不长，才是内卷 |

### 拆 2：「躺平」

| 项 | 内容 |
|---|---|
| 谁在说 | 三种人：真放弃的、嘴上说说缓解焦虑的、用来自我保护的 |
| 大白话 | 停止为外部评价标准投入 |
| 隐藏的混淆 | "不参与评价"和"不做事"是两件事。有人躺平了外部评价，但自己在做喜欢的事；有人只是不做事，也说自己在躺平 |
| 反义词 | 奋斗？不准确。更准确的反义词是"**参与评价体系**" |
| 可观察的 | 他停的是"争取名次"，还是"做任何事"？ |
| 该怎么用 | 如果你在考虑躺平，先分清你想退的是**评价体系**还是**所有事**。退评价体系是选择（合法）；退所有事是抑郁信号（该求助，不是该励志） |
| ⚠️ 边界 | 长期失去行动意愿、伴随睡眠和食欲改变，这是心理健康问题，**不属于本模块范围**，应建议寻求专业帮助 |

### 拆 3：「优秀」

| 项 | 内容 |
|---|---|
| 谁在说 | 评价者说的时候，通常指"符合我的标准" |
| 大白话 | 在某个具体标准下，排在前若干名 |
| 关键发现 | **这个词必须带标准才有意义**。不带标准的"优秀"是一句空话，但它能制造真实的焦虑 |
| 反义词 | 平庸（排序义）/ 不合格（判定义）——两义常被混用 |
| 可观察的 | 谁定的标准？标准写在哪？前多少名算？ |
| 该怎么用 | 把"我要变优秀"换成"在**谁的**标准下，进**前多少**"。如果这个标准你不认同，那你要的不是优秀，是**换一个评价体系** |
| ⚠️ 常见误用 | 把多个体系的标准叠加（绩点要好、要有作品、要会社交、要身体好），得出一个谁都达不到的"优秀"，然后自责 |

### 拆 4：「情商」

| 项 | 内容 |
|---|---|
| 谁在说 | 通常是事后评价别人，很少用在自己身上（用在自己身上时，多半是在自责） |
| 大白话 | 在具体场合，说了合适的话、做了合适的反应 |
| 关键发现 | **它不是能力，是一组场景化的表现**。"情商高"的人也会在某个场合说错话；"情商低"的人在某些场合反而很得体 |
| 错误预设 | "情商是一个可以单独训练的通用能力"——假的。有效的训练单位是**具体场景**：怎么拒绝、怎么道歉、怎么提要求、怎么接住别人的情绪 |
| 可观察的 | 具体哪一次、哪句话、对方什么反应、你原本想达到什么效果 |
| 该怎么用 | 不要说"我情商低"，说"我在**拒绝别人**这个场景里，总是拖到最后才说，导致对方更被动"。**场景 + 行为 + 后果**，这个描述才能改 |
| ⚠️ 边界 | 有些人被说"情商低"，实际是因为他不愿意讨好。**不愿意和不会，是两件事**，别混着改 |

### 拆 5：「格局」

| 项 | 内容 |
|---|---|
| 谁在说 | 几乎只出现在评价别人"格局小"的时候，且评价者通常处于优势位 |
| 大白话测试 | **说不出来**。这个词没有可观察的对应物 |
| 判断 | **纯装饰词**。它不传递信息，只传递"我比你高"的位置 |
| 唯一的合理内核 | 如果非要说它指什么，可能是"**愿不愿意为长期利益放弃短期利益**"——但这个意思已经有更清楚的词了（长期主义、延迟满足） |
| 该怎么用 | 听到"你要有格局"，把它翻译成一句具体的话再判断：他是要我**放弃这次的利益**吗？放弃多少、换什么、什么时候兑现？三个都答不出来，这句话不用听 |
| ⚠️ 注意 | 这是全库唯一一个建议"直接丢掉"的词。丢掉不等于否定说话人，是拒绝接受一个无法检验的评价 |

### 拆 6：「信息差」

| 项 | 内容 |
|---|---|
| 谁在说 | 卖课的人说得多（"你不知道的信息差，我告诉你"）；真正受益的人很少说 |
| 大白话 | 有人知道某条路径/规则，有人不知道，知道的人因此占了便宜 |
| 关键拆解 | **信息差有三种，成本完全不同**：① **公开但分散**（保研细则、报名时间）——查就能查到，成本是"知道去哪查"；② **半公开**（某个实验室在招人、某位老师愿意带本科生）——要靠人，成本是"有人告诉你"；③ **不可公开**（评审的真实偏好、某个圈子的潜规则）——只能靠进入那个圈子，成本是"成为自己人" |
| 可观察的 | 这条信息，网上搜得到吗？搜不到的话，需要认识谁？ |
| 该怎么用 | 90% 的"信息差"是第一种，它不稀缺，稀缺的是**检索习惯**。所以多数时候该做的不是买课，是**学会查文件**：学校官网、教务处、学院通知、往年公示名单 |
| ⚠️ 常见误用 | 把第三种（不可公开）说成第一种（查得到），卖给你。判断标准：他给的信息，你能不能自己验证到出处？ |

## 五、反例与边界

### 边界 1：不是所有词都值得拆

日常交流里的词不需要拆（"吃饭""上课"）。**只在两种情况下拆**：① 这个词让你产生了情绪（焦虑、羞耻、愤怒）；② 这个词要用来做决定。

对每个词都做哲学分析，会变成一个说话没人听得懂的人——那不是严谨，是另一种逃避。

### 边界 2：拆解会破坏一些安慰

"内卷"这个词有个隐性功能：它让失败变得可以接受（不是我不行，是环境太卷）。

拆掉之后，你可能要面对一个更难的说法："我在这条赛道上确实没有优势。"

**这是拆解的代价，要提前知道。** 温和的处理是：拆完之后不要停在"所以是我不行"，要走到"所以我该换哪条路"——拆解的目的是换一个能行动的说法，不是换一个更狠的自责。

### 边界 3：情感表达不需要概念清晰

朋友跟你哭诉"我觉得自己特别没用"，这时候做概念拆解是残忍的。

**先接住情绪，再处理概念。** 判断标准：对方是在**求助**还是在**倾诉**。倾诉的时候，清晰是一种冒犯。

### 边界 4：拆解不能替代领域知识

能拆清"内卷"这个词，不代表知道你们专业该怎么办。拆解负责**把问题问对**，具体判断要靠 `capabilities/` 里的八个模块和 `knowledge/` 里的知识包。

### 边界 5：不要用拆解去赢

和命题审查一样的边界。把"你这个词用得不准"当武器，是最低级的用法——它让你在对话中占上风，同时让对方再也不想跟你说真话。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **拆词不拆句** | 分析"自律"这个词十分钟，不看"我自律性差"这句话的上下文 | 拆完还是不知道该怎么办 |
| **把拆解当结论** | "原来内卷是这个意思，那我懂了" | 懂了词，没做任何改变 |
| **只拆别人的词** | 挑别人说话不严谨，自己的模糊表述不碰 | 变成讨厌的人，且自己没进步 |
| **造新词代替旧词** | 把"格局"换成"长期主义"，继续模糊 | 换汤不换药 |
| **对一切词保持怀疑** | 什么词都要定义，说话越来越绕 | 沟通成本暴涨，实际判断力没提升 |

## 七、和其他模块的关系

- **概念拆解是命题审查的工具**：命题审查五道病检里的"定义偷换"，必须靠概念拆解的大白话测试才拆得开
- **概念拆解的输出是提问法的输入**：拆完发现"我不知道自己到底遇到了什么"，就该用提问法把问题钉成现象
- **和概念澄清与思维（概念澄清与思维）的分工**：概念澄清与思维是知识层的六个词的结论，概念拆解是拆任何词的方法。**概念澄清与思维可以引用概念拆解，概念拆解不依赖概念澄清与思维**
- **拆"情商"要接执行诊断**：拆完发现"我在拒绝别人时总是拖"，这是执行问题，去执行诊断
- **"信息差"拆完接 `../capabilities/03_竞赛.md` J2**：查本校细则是第一种信息差的具体动作

## 八、自检

1. 这个词**谁在说**？说完他会做什么？
2. 反义词是什么？它在做**排序**还是**判定**？
3. 大白话测试的结果是三种里的哪一种？（说得出 / 说不出来 / 不同人说不同版本）
4. 能不能列出**三个可观察的行为**？
5. 最后一句是不是"我要提升 XX"？（是 → 拆解失败）
6. 四种问题词判了哪一种？（包装词 / 混用词 / 错误预设 / 伪概念）**是不是判早了**？
7. 涉及"值不值""含金量"时，四把尺子过了吗？落到可观察信号了吗？
8. 有没有踩到五条边界？（乱拆 / 破坏安慰 / 对情绪拆解 / 替代领域知识 / 拿去赢辩论）
