# 01 · 命题审查

> 用途：拿到一句话（学长的建议、网上的爆款观点、自己的直觉），先判断它能不能信，再决定要不要照着做。
>
> 这是全库的地基。八个能力模块判断"该怎么做"，这里判断"该不该信"——顺序不能反。

---

## 一、这个模块解决什么

大学生每天接收的判断，绝大多数没经过审查：

> 「努力就有回报」「绩点不重要，能力重要」「大一必须定方向」「多参加活动锻炼能力」「不喜欢就转专业」「学历贬值了读书没用」

这些话不是全错，是**没有边界**。没边界的判断听起来永远对，用起来处处错。

命题审查只做一件事：**把一句无限定的话，切成一句有限定的话**——切成"在什么条件下成立、什么条件下不成立、我能拿它干什么"。

它不负责告诉你答案，负责告诉你**这句话值几分可信度**。

---

## 二、核心判断

### 判断 1：一句话的强度，跟说它的人有多成功，关系不大

这是最容易犯的错。看到学长保研清北，就把他整套做法当模板；看到博主赚了钱，就把他每句话当规律。

问题在于：**成功者的样本是经过筛选的**。他们成功了，所以他们的做法被看见；用同样做法失败的人，不会站出来说话。你看到的是分子，看不到分母。

所以审一句话，第一问不是"他是谁"，而是：

> **用这个做法的人里，有多少没成？我没看到的那部分在哪里？**

（这个偏差的学名是**幸存者偏差**，最早由二战时统计返航飞机弹孔的沃德提出：该加固的不是弹孔多的地方，是弹孔少的地方——因为打中那里的飞机没回来。）

### 判断 2：分清"是什么"和"该怎样"（休谟铡刀）

休谟指出：从"是什么"推不出"该怎样"。这两类命题之间有一道跨不过去的沟。

大学生最常掉进去的形态，是**用实然描述直接驳回应然要求**：

| 实然（描述） | 被偷偷推出的应然（主张） | 缺的那一步 |
|---|---|---|
| "大学不奖励努力，奖励稀缺" | "所以别努力了" | 努力和稀缺不是二选一。稀缺是**努力的方向问题**，不是努力的对错问题 |
| "学历在贬值" | "所以别读了" | 贬值是**回报率下降**，不是回报为负。下降的曲线也可以在上面 |
| "关系比能力重要" | "所以我不用练能力" | 没能力的人，关系只能用一次 |

**审法**：一句话里如果出现了"所以应该/所以别/所以没必要"，先问——这个"所以"中间，是不是偷渡了一个价值判断？那个价值判断，是谁的？

### 判断 3：判不出来的话，不是判断，是信念（可证伪性）

波普尔划的线：一个命题要算**经验判断**，必须说得清什么证据能推翻它。

- "努力会有回报"——什么情况算被推翻？说不清。这是**信念**，不是判断。
- "在保研这条路上，竞赛加分的边际收益大于绩点的边际收益"——什么情况算被推翻？绩点差 0.1 掉出前 10% 而竞赛分没补回来。这是**判断**。

审一句话，第二问：

> **什么样的观察结果，会让你放弃这句话？**

答不出来的，别当判断用。可以当动力用，但不能当依据用。

### 判断 4：因果不是"先后发生"，是"如果不这样，结果会不会不同"

大部分"经验之谈"的因果是假的，因为它们是**倒推**出来的：看到成功者做了 A，就说 A 导致成功。

真正的因果判断需要**反事实**：如果他没有做 A，结果会不一样吗？

举例：「我大二进了实验室，后来保研成功了，所以进实验室是保研的关键。」

反事实检验：
- 进实验室的人里，有多少没保研？（如果很多，实验室不是关键）
- 保研的人里，有多少没进实验室？（如果很多，实验室不是必要条件）
- 他保研的真实原因，是不是绩点本来就够，实验室只是加分项？

**三个问题问完，"关键"这个词通常就站不住了。**

### 判断 5：一个词在同一句话里换了意思，这句话必然错

这叫**定义偷换**。大学里最高发的是"能力"这个词：

> "绩点不重要，能力才重要。"

这句话里，"绩点"是一种**可验证的、跨校可比的信号**；"能力"如果指的是解决具体问题的本事，那它需要场景才能被看见。两个东西根本不在一个维度上，比不了。

它真正成立的版本是：

> "绩点只在第一道筛子里起作用（保研、考公、大厂初筛）；过了第一道筛子，后面的判断更多看具体做过什么。所以绩点要过线，但过线之后不要继续加码。"

**审法**：把这句话里的关键词，各自用一句大白话解释一遍。解释完如果发现它们不是一回事，这句话就是拼出来的。

### 判断 6：你自己的判断，也要过同一道审查

这是最难的一条，也是这个模块真正的门槛。

人对自己得出的结论，审查标准会自动放宽。听别人的话会问"有证据吗"，自己想出来的话直接当事实。

所以审查要双向：**审别人给你的建议，也审你自己刚刚下的结论**。后者更重要，因为前者你还有戒心，后者你完全没有。

## 二·五、五层消解：先判断该从哪一层下手

前面六条判断是**审查工具**。这一节是**顺序**——面对一个问题，先看哪一层，看到哪一层可以停。

**核心规则：某一层已经把问题解决了，就不必往下。某一层只是让问题变准了，带着修正后的问题继续往下。**

| 层 | 要查什么 | 大学里的典型 |
|---|---|---|
| **一、语言陷阱** | 核心词有没有定义？能不能落到可操作、可观察的标准上？ | 「我适不适合读研」——「适合」的标准是什么？说清了，问题就变成"读研三年能不能让我进到某个具体岗位" |
| **二、假设错误** | 把问题改写成「你的问题假设了 X，X 成立吗」 | 「我想保研但没有资源怎么办」——假设了资源要先于行动存在。资源多半是在做的过程中攒的 |
| **三、逻辑错误** | 相关当因果、幸存者偏差、单一理由决策 | 「我每天学到十二点，为什么绩点还是低」——学习时长和绩点是相关，不是因果。决定绩点的是"做对了多少题"，不是"坐了多久" |
| **四、事实前提** | 问题里陈述的事实，对不对 | 「我们学校保研率只有 5%」——去教务处网站查，可能写的是 15%。前提错了，后面全错 |
| **五、关键事实缺口** | 问题成立，但答案取决于一个还不知道的事实 | 「我该考研还是就业」——取决于你有没有一段真实实习过。没有这个事实，任何回答都是猜 |

**出现频率是经验判断**：前三层（语言、假设、逻辑）最常见，第四、五层较少。**但不要把这个比例说给当事人听**——那会变成一种评价。

### 第五层的处理方法（最容易被糊弄过去的一层）

缺事实的时候，**不许硬答，也不许说"这要看你自己"**。三步：

1. **先给一个带条件的判断**：如果是 A 情况，我倾向 X；如果是 B 情况，我倾向 Y。
2. **说清缺的是哪个事实**，以及它为什么会翻转结论。
3. **给出拿到这个事实的最低成本动作**——优先是"去做一件小事"，不是"再去查资料"。

示例：

> **学生**：我该考研还是直接工作？
>
> **带条件的判断**：你现在没有任何实习，那考研的风险在于——你只是把"不知道自己能干什么"推迟了三年。如果你想要的那个岗位明确要硕士，考研；如果不确定，先去投十份简历。
>
> **缺的事实**：你喜不喜欢做那个专业方向的事。
> **最低成本动作**：这个寒假去做一个月实习，或者跟着老师的项目做两周。**两周的实际体验，比三个月的纠结准。**

### 通过漏斗之后：真问题分四类，回答义务不一样

问题熬过五层还在，说明它是真问题。**但真问题不等于都该由你给答案。**

| 类型 | 你该做什么 | 大学里的例子 |
|---|---|---|
| **可推导的** | 给明确结论 + 推导过程 | 「参加这个比赛值不值」——算保研加几分、要投入多少小时、这些小时本来能干什么 |
| **价值选择** | 讲清利弊 + **说明这是你的判断** + 交给他决定 | 「稳妥一点还是拼一把」——这是他的价值排序，不是事实问题 |
| **资源约束** | 从材料里把约束提出来；缺的只问一个最关键的问题 | 「我该不该转专业」——先看他现在的学分、绩点、家庭条件 |
| **超出边界** | 说明问题成立，但需要专业人士 | 心理危机、法律纠纷、医疗问题 |

**最常犯的错，是把"价值选择型"当成"可推导型"来答。** 明明是他的取舍，你给了一个斩钉截铁的建议——他照做了，将来不满意，这笔账会记在你头上。**该交回去的，必须交回去。**

## 三、操作流程

### Step 1：把原话抄下来，一个字不改

不要凭记忆审。记忆会自动把模糊的地方补成确定，把限定词（"有时候""在有些学校"）吃掉。

### Step 2：过五道病检

| # | 病 | 检测问句 | 命中信号 |
|---|---|---|---|
| 1 | **绝对化** | 有没有"都、一定、只要、凡是、从来、永远、根本"？ | 有 → 立刻找一个反例试试 |
| 2 | **因果跳跃** | 它说的是"因为 A 所以 B"，还是只说了"A 之后出现了 B"？ | 只有时间先后 → 问反事实 |
| 3 | **定义偷换** | 关键词前后是不是同一个意思？ | 换个解释句子仍通顺 → 偷换了 |
| 4 | **经验普遍化** | 这是一个人的经历，还是一群人的分布？ | 单个案例 → 找分母 |
| 5 | **反向推断** | 是不是"因为成功者做了 X，所以 X 导致成功"？ | 是 → 找没做 X 也成功的人 |

**五道全过，才能进 Step 3。任何一道命中，先修这句话，再谈要不要信。**

### Step 3：给一个四态判断

| 状态 | 什么情况 | 怎么处理 |
|---|---|---|
| **保留** | 命题和它的证据匹配，边界也清楚 | 可以照着做，但仍要标出适用条件 |
| **收窄** | 核心洞察对，但适用范围说大了 | 把"都/一定"换成具体条件，缩小到能成立的区间 |
| **重构** | 现象是真的，给出的原因不对 | 保留现象，换一个解释，重新推结论 |
| **放弃** | 现象和原因都缺支撑 | 不用，且要记住"这条被审过"，避免下次又被它打动 |

**四态里最高频的是"收窄"。** 大部分流传的判断不是错的，是没划边界的——它们在某个人身上、某个学校、某一年是对的。

### Step 4：写出"修正后的一句话"

格式固定：

```
原话：……
病在哪：……
修正：在【条件】下成立；在【条件】下不成立。
我能拿它干什么：【具体动作】
```

**最后一行不能空。** 一句审完却不能变成动作的话，说明还没审到底。

## 四、大学场景实例：六句流行判断逐条审

### 实例 1：「努力就有回报」

| 项 | 内容 |
|---|---|
| 病 | **绝对化** + **定义偷换**（"回报"是什么回报？绩点、机会、钱、还是能力增长？） |
| 反例 | 每天刷 12 小时题、绩点 3.9，因为没参加任何竞赛，保研差 0.5 分落榜。努力了，没回报 |
| 四态 | **收窄** |
| 修正 | 在**规则明确、评价单一**的场域（考试、绩点），努力和回报接近线性；在**规则复杂、评价多维**的场域（保研、求职、创业），努力的回报取决于**方向是否对准了评价标准**。付出同样的力气，对准标准的那个回报高一个数量级 |
| 能干什么 | 做任何长期投入前，先花两小时把评价标准找出来（保研细则、招聘 JD、评审规则）。这两小时比后面两百小时值钱 |

### 实例 2：「绩点不重要，能力更重要」

| 项 | 内容 |
|---|---|
| 病 | **定义偷换**（绩点和能力不在一个维度）+ **绝对化** |
| 反例 | 保研卡前 10%，差 0.05 直接出局。这时候能力再强，门都进不去 |
| 四态 | **重构** |
| 修正 | 绩点是**通过型信号**，能力是**区分型信号**。通过型信号只在门槛处起作用，过了门槛边际收益骤降；区分型信号在门槛之后决定结果。所以：绩点要**过线**（不是越高越好），过线之后把边际精力全部投给能产出作品和案例的事 |
| 能干什么 | 查清你所在路径的绩点门槛是多少（保研看排名百分比、求职看有没有硬性 GPA 卡线）。够线就转向做作品，不够线就全力补绩点。**别在"绩点不重要"这句话上偷懒** |

### 实例 3：「大一就要确定方向」

| 项 | 内容 |
|---|---|
| 病 | **经验普遍化** + 忽略**可逆性差异** |
| 反例 | 大一决定考研，大二发现自己更喜欢做产品，转回来成本不高；但如果大一为了"确定方向"放弃了转专业窗口，那个窗口是不可逆的 |
| 四态 | **收窄** |
| 修正 | 大一大二真正该做的不是"确定方向"，是**把不可逆的决定往后推、把可逆的探索做够**。判断标准是这件事**反悔成本**多高：转专业、退学、休学这类高成本决定，尽量晚做且多做信息收集；实习、社团、比赛、旁听这类低成本探索，尽量早做且多做 |
| 能干什么 | 列一张表，左边写"做了就不能反悔的事"，右边写"做了随时能退的事"。左边的事花时间调研，右边的事尽快去试 |

### 实例 4：「多参加活动锻炼能力」

| 项 | 内容 |
|---|---|
| 病 | **因果跳跃**（参加 = 锻炼？）+ 定义空白（什么能力？） |
| 反例 | 参加十个社团，每个都是搬桌子、发传单、拍照。两年后简历上写"组织活动十余场"，面试官问"遇到过最大的冲突是什么，你怎么处理的"，答不出来 |
| 四态 | **重构** |
| 修正 | 能力不来自"参加"，来自**承担了一个有后果的责任并处理了它**。同样是社团，部长和干事的差别不在头衔，在**有没有为结果负责**。判断一个活动值不值得参加，看它给不给你"决策 + 承担后果"的位置 |
| 能干什么 | 参加前问一句：这个位置我能做决定吗？做错了会有后果吗？两个都是"不能"，就是去当人力 |

### 实例 5：「不喜欢就转专业」

| 项 | 内容 |
|---|---|
| 病 | **反向推断**（把"不喜欢"当成可靠信息）+ 忽略**信息不对称** |
| 反例 | 大一不喜欢本专业，多半是因为只接触了导论课和高中式的考试。真正的专业面貌在大三的专业课和项目里。这时候转，可能从一个不了解的专业转进另一个更不了解的专业 |
| 四态 | **收窄** |
| 修正 | "不喜欢"要拆成三种：① **不了解**（接触太少，不是不喜欢）② **不擅长**（学得吃力，误判成不喜欢）③ **价值不认同**（知道它是什么，仍不想做）。只有第三种是转专业的充分理由。前两种应该先补信息：找大三学长问课程实感、去旁听一门核心专业课、找一个该专业的从业者聊一小时 |
| 能干什么 | 转专业申请前，做三件事：旁听一门核心课、访谈两个高年级、查一次该专业近三年就业/升学去向。做完再决定，成本一周，能省两年 |

### 实例 6：「学历贬值了，读书没用」

| 项 | 内容 |
|---|---|
| 病 | **定义偷换**（贬值 ≠ 无价值）+ **混淆存量与增量** |
| 反例 | 学历贬值的意思是：同样一个本科文凭，十年前能进的岗位，现在要硕士。但这不等于"读硕士没用"，而是"所有人的门槛一起抬高了"。在门槛整体抬高的市场里，不读的相对位置更差 |
| 四态 | **重构** |
| 修正 | 学历的**绝对价值**在下降，**相对价值**取决于你在人群里的位置。真正决定回报的不是学历本身，是"学历 + 你有什么别人没有的东西"。所以问题不是"要不要读"，是"读完我要拿什么作为区分" |
| 能干什么 | 别问"读研值不值"，问"三年后我拿什么跟同届研究生区分"。答不出来，这个研读得就只是补门槛，不产生溢价 |

## 五、反例与边界：这套什么时候不该用

**这一节不能省。** 只讲成立不讲边界的判断，最后会变成教条——而教条正是这个模块要反对的东西。

### 边界 1：紧急决策时不要审

这个模块是**慢思考工具**，一次完整审查要十几分钟到几天。如果你正在被追着做决定（明天截止报名、今天必须答复），先做，事后复盘。**在需要速度的时候用需要精度的工具，是最常见的误用。**

### 边界 2：审到"什么都不可信"就过头了

审查的目的是**提高信噪比**，不是把所有信号都判为噪声。如果审完之后你什么建议都不听了，方向就反了——从"轻信"变成了"瘫痪"。

判定信号：如果连续审十条建议，十条都判"放弃"，问题多半在审查者，不在建议。**正常分布应该是：大部分"收窄"，少数"保留"，极少数"放弃"。**

### 边界 3：涉及个人价值的判断，不适用

"该不该读这个专业""要不要放弃保研去做喜欢的事"——这类问题的核心不是命题真假，是**你愿意付什么代价**。用逻辑去审价值选择，会得出一个看起来严密、但你自己不会执行的结论。

这类问题归意义与选择（意义与选择），归因方式是"代价三问"，不是命题审查。

### 边界 4：命题审查不能替代领域知识

这个模块能告诉你"这句话的推理有问题"，**不能告诉你"正确的答案是什么"**。

比如"竞赛加分比绩点划算"这句话，审查能指出它缺条件（哪个学校、哪一类赛、什么等级），但具体在你们学校划不划算，得查你们学校的细则。**审查负责打开问题，领域知识负责回答问题。** 用审查替代领域知识，会得出"什么都有问题、但什么都不知道"的空转。

### 边界 5：不要用它去赢辩论

这套工具用来判断**自己该信什么**，不是用来在群里驳倒别人。一旦用于后者，你会开始挑对方话里的毛病而不是找事实，最后赢了口舌、输了判断。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **只审别人，不审自己** | 对学长的建议逐条挑刺，对自己"我觉得我不适合读研"全盘接受 | 最后信的全是自己的偏见 |
| **审完就否定** | 每条建议都被找出毛病，然后什么都不做 | 从轻信变成瘫痪，比轻信更糟 |
| **把"收窄"做成"取消"** | "这句话有条件，所以它不对" | 丢掉了本来有用的那部分 |
| **审措辞不审结构** | 抓住"一定"这个词不放，忽略整句话的机制可能是对的 | 捡了芝麻 |
| **用审查代替行动** | 反复审一句话，就是不开始做 | 审查变成新的拖延方式 |

最后一条最隐蔽：**有些人用"我还没想清楚"来替代"我还没开始"**。审查是有时间盒的——一句话审超过二十分钟还没结论，说明缺的是领域信息，不是逻辑工具。

## 七、和其他模块的关系

```
              ┌─ 命题审查（该不该信）
外部信息 ─────┤
              └─ 概念拆解（这个词到底什么意思）
                        ↓
                  提问法（把它变成能回答的问题）
                        ↓
              八个能力模块（具体该怎么做）
                        ↓
                  执行诊断（为什么没做）
```

- **命题审查和概念拆解是配对使用的**：审一句话时，五道病检里的"定义偷换"，实际要靠概念拆解的大白话测试才拆得干净
- **命题审查的输出常常是提问法的输入**：审完发现"这句话在你们学校成不成立"无法回答，就该把它改写成提问法的好问题，去查细则
- **命题审查不替代概念澄清与思维（概念澄清）**：概念澄清与思维是知识层的判断，命题审查是操作层的方法。概念澄清与思维可以引用命题审查
- **命题审查的结果要能落到八个能力模块上**：审完一句"竞赛加分比绩点划算"，动作应该出现在 `../capabilities/03_竞赛.md` 的 J2，不是停在审查报告里

## 八、自检：交出去之前

1. 原话是不是一字不改抄下来的？（有改动就不是审查，是重构）
2. 五道病检过了几道？命中哪道？**说得出病名**
3. 四态判断是哪个？**说得出为什么不是另外三个**
4. "修正后的一句话"里，条件写具体了吗？（"有时候""看情况"不算条件）
5. 最后一行"我能拿它干什么"，是不是一个**这周能做的动作**？
6. 有没有审自己刚下的结论？（只审别人 = 没审）
7. **五层消解从哪一层下手的？** 有没有在该停的那一层停下来，而不是一路挖到底？
8. 缺事实的时候，给了**带条件的判断 + 最低成本动作**吗？还是含糊过去了？
9. 这个问题是**可推导 / 价值选择 / 资源约束 / 超边界**里的哪一类？回答义务对上了吗？
10. 边界五条有没有踩到？（紧急决策 / 审到瘫痪 / 价值判断 / 替代领域知识 / 用来赢辩论）

**任何一条答不上来，就不算审完，只算有意见。**
