# 07 · 决策档案

> 用途：把「我做过什么决定、当时为什么这么选、后来应验了没有」记下来。
>
> **不记录的人，每次决策都从零开始。** 四年下来做了三十个决定，学到的经验是零——因为记不住当时怎么想的。

---

## 一、这个模块解决什么

大学生做决定的方式，基本是这样：

> 大三上纠结要不要考研 → 问一圈人 → 某一个瞬间被某句话打动 → 决定考
> 半年后考砸了 → 回想"当时为什么考" → **想不起来了，只记得"好像是因为就业不好"**

问题不在于决策错了，在于**决策过程没有留痕**。于是：

- 无法判断是「判断错了」还是「运气不好」
- 无法从成功里提取可复用的东西（因为是蒙对的）
- 下次遇到同类问题，还是从零开始问人

**决策档案做的事：把每次决策拆成「事实 → 判断 → 结果 → 修正」四段，存档。** 三个月后回看，你会发现自己有一套判断方式，而不是一堆运气。

---

## 二、核心判断

### 判断 1：好决策不等于好结果

这是决策科学最基础也最反直觉的一条。

一个决定的质量，取决于**当时可用的信息**和**推理过程**；结果取决于**信息之外的因素**。

```
好决策 + 好运气 = 好结果   （你会误以为自己很行）
好决策 + 坏运气 = 坏结果   （你会误以为自己错了）
坏决策 + 好运气 = 好结果   （最危险：你在强化一个错误的做法）
坏决策 + 坏运气 = 坏结果   （正常）
```

**第三行是大学里最常见的陷阱。** 比如：临时抱佛脚考了 85 分 → 结论"我适合突击" → 下次继续突击 → 大四考研时崩了。

**因为没有决策档案，你无法区分这四格。** 你会把运气当能力，把坏运气当错误。

### 判断 2：记忆会自动改写，所以必须落到纸上

人回忆过去的判断时，会不自觉地把现在的结论安到过去的自己头上。

典型表现：

> "我当时就觉得考研不靠谱"——其实当时你很想考，只是没考上。

这不是撒谎，是**记忆的正常工作机制**：大脑为了让自我叙事连贯，会偷偷修改细节。

**所以复盘不能靠回忆，必须靠当时写下的东西。** 这是决策档案存在的第一个理由。

**判断标准**：如果你现在能准确说出三个月前某个决定的三条理由，说明你当时记录过；说不出来，说明你在编。

### 判断 3：四类内容必须分开存，混在一起就无法判断

这是档案的结构核心。四类内容混着放，会导致一个具体后果：**你分不清"这是事实"还是"这是我的解释"**。

| 层 | 放什么 | 关键规则 |
|---|---|---|
| **01 事实** | 发生过什么。分数、时间、别人说了什么、你实际做了什么 | **只追加，不改写。** 后来的解释另起一条 |
| **02 规律** | 从多次事实里提炼的模式（"我晚上效率比早上高"） | **要多次验证才成立**，一次不算 |
| **03 定格** | 某一时刻的整体状态（月度画像、某次决策的诊断） | **写完不改。** 变了就新建一份带日期的 |
| **04 待解** | 还没想清楚的问题、待验证的假设 | **完成即清空。** 答案回流到 01 或 02 |

**为什么要分开**：

- 事实和解释混在一起 → 你会把"我觉得老师不喜欢我"当成事实记下来，然后基于它做决定
- 规律和单次经验混在一起 → 一次考砸就得出"我不适合学数学"，然后放弃整个方向
- 待解不清空 → 悬着的问题持续占用注意力，而且你忘了自己在悬着什么

### 判断 4：一次经验不是规律，规律要三振才成立

这是 02 层最难执行的一条。

人有一个强烈的倾向：**用一次经历总结出人生规律**。

> 一次面试被拒 → "我不擅长表达"
> 一次比赛没进省赛 → "我不是打比赛的料"
> 一次主动搭话被冷落 → "我社交不行"

这三条都会变成自我实现的预言：因为信了，所以不再尝试，于是永远没有反例。

**规则**：

| 出现次数 | 能得出的结论 |
|---|---|
| 1 次 | **只能记为事实**，不能进 02 层 |
| 2 次 | 可以记为"待验证假设"，放进 04 层 |
| 3 次以上，且情境不同 | 才能进 02 层，成为"规律" |

**"情境不同"是关键**：三次都在同一个老师课上考砸，那是这个老师的问题；三次在不同科目、不同老师那里都考砸，那才是你的模式。

### 判断 5：决策要留「预期」，否则无法回填

大部分人记录决定，只记"我决定考研"。

但**没有预期，就没有回填**——半年后你无法判断这个决定对不对，因为你当时没说"我认为会发生什么"。

**必须记的三项**：

1. **我预期会发生什么**（具体、可验证）
2. **我认为的概率**（大概几成）
3. **什么情况算我判断错了**（证伪条件）

**举例**：

> ❌ 记："决定考研"
> ✅ 记："决定考研。预期：按每天 6 小时复习，12 月能到 350 分左右（我估 6 成）。如果 10 月模考还在 300 以下，说明我的估算是错的，要改策略或换目标。"

第二个月你就知道对不对了。第一年年底你能学到东西。

### 判断 6：待解清单要清空，悬着的问题成本很高

心理学上有个说法叫**未完成任务的注意力占用**：没做完的事会持续占用认知资源，即使你没在想它。

大学生的 04 层通常堆着这些东西：

> 我到底要不要读研 / 我和室友的关系是不是有问题 / 我要不要退出社团 / 我是不是选错专业了

**这些问题堆三个月，会变成背景性的焦虑**——你说不清在焦虑什么，但一直不轻松。

**处理方式**（三选一，必须选一个）：

| 动作 | 什么情况用 |
|---|---|
| **立案** | 现在能查、能问、能试 → 转成一个具体决策，加日期 |
| **定期复查** | 现在信息不足，要等某个时间点 → 写上"几月几号再看" |
| **归档不处理** | 明知道想不清，且不影响近期行动 → 明确写下"暂不处理"，然后真的不想 |

**最糟的状态是"一直悬着"**——既不做，也不放下。

## 三、操作流程

### Step 1：建档案（一次性，约 30 分钟）

不需要任何工具，一个文件夹四个文件就够。

```
我的决策档案/
├── 01_事实.md        记发生了什么
├── 02_规律.md        记验证过的模式
├── 03_定格/          月度画像、决策诊断（写完整份不放回）
├── 04_待解.md        悬着的问题
└── 我的当前状态.md    每次打开先看这个
```

**「我的当前状态.md」模板**（这是最有用的一页）：

```markdown
# 我的当前状态

## 当前阶段
大二下 / 准备保研中 / 绩点 3.6 排 12%

## 当前最强矛盾
想保研，但排名卡在边缘，而这学期有 5 门专业课

## 当前主线
这学期只做一件事：把绩点从 3.6 提到 3.75

## 最近节点
- 6/15 期末开始
- 7 月出成绩，决定要不要转考研

## 待回填结果
- 3 月决定退出社团，预期：每周多 8 小时；验证时间：6 月底
- 4 月决定每天写 500 字，预期：三个月后写得顺；验证时间：7 月

## 暂不处理
- 要不要读博（大三下再想）

## 当前判断
保研是我最优路径（七成），前提是这学期绩点能上去
```

**这一页的价值**：每次想不清的时候，看一眼就知道自己在干什么、卡在哪、下一步是什么。

### Step 2：立案（每次做决定时）

一个决定要立成案子，必须写清五件事：

```markdown
## 决策：______（日期）

### 我在选什么
选项 A：______
选项 B：______
（不超过 3 个，多了说明还没想清）

### 我掌握的事实
- （只写事实，不写解释）
- 例：本院保研率 8%；我排名 12%；细则要求前 10%

### 我的判断
- 我认为：______
- 依据：______
- 我大概几成把握：__
- 如果错了，会是哪里错：______

### 我预期会发生
- 短期（1-3 个月）：______
- 中期（半年）：______

### 什么情况算我判断错了
- ______（必须可观察）

### 我的决定
______

### 复查时间
______
```

**最后两行是灵魂。** 没有"证伪条件"和"复查时间"，这个案子就是日记，不是决策档案。

### Step 3：回填（到复查时间就做）

回填只做三件事：

| 问 | 记什么 |
|---|---|
| **实际发生了什么** | 只写事实，不写解释 |
| **和我预期差在哪** | 差在哪里、差多少 |
| **我的判断错在哪一步** | 是事实错了、推理错了、还是运气 |

**第三问最重要，也最容易糊弄。**

糊弄的写法："运气不好。"
诚实的写法："我把'保研率 8%'当成了'前 8% 有希望'，实际是'前 8% 里还有一半要看竞赛分'。**错在把必要条件和充分条件搞混了。**"

**只有第二种写法能让你下次不犯。** 第一种只会让你觉得世界对你不公平。

### Step 4：月度画像（每月一次，20 分钟）

每月最后一天，写一份 `03_定格/状态画像_YYYY-MM.md`：

```markdown
# 2026-11 状态画像

## 这个月我在做什么
（一句话）

## 最大的变化
（和上个月比，什么变了）

## 这个月验证了什么
（有没有哪条 02 层的规律被证实或推翻）

## 这个月新增的待解
（有哪些问题冒出来了）

## 下个月只做一件事
（必须只有一件）
```

**写完不改。** 下个月情况变了，就再写一份新的。**留着旧的，是为了六个月后能看出自己是怎么变的。**

## 四、大学场景实例

### 实例 1：要不要转专业

**没档案的做法**：问十个人，得到十个答案，最后凭感觉。

**有档案的做法**：

```markdown
## 决策：转专业（2026-03-10）

### 我在选什么
A：留在本专业，走保研
B：转到计算机，重新来过

### 我掌握的事实
- 本专业保研率 8%，我目前排名 15%
- 转专业要求大一绩点前 20%，我 18%
- 计算机学院转专业后要补 4 门课
- 我问过 2 个转过去的学长：1 个说值，1 个说补课压力大
- 我实际写过的代码：0 行（只是觉得有兴趣）

### 我的判断
- 我认为：我对计算机的"兴趣"还没被验证过
- 依据：我从没写完过一个程序
- 我大概几成把握：六成（剩下四成是我可能真喜欢）
- 如果错了，会是哪里错：我把"觉得酷"当成了"愿意做"

### 我预期会发生
- 如果转：大二会很累，但大三能跟上
- 如果不转：留在本专业，可能后悔

### 什么情况算我判断错了
- 我用一个暑假写完一个小项目，还觉得有意思 → 那我错了，我是真喜欢
- 我写了两周就放弃 → 判断对了，是新鲜感

### 我的决定
先不转。用这个暑假（7-8 月）写完一个能跑的小工具，8 月底再定。

### 复查时间
2026-08-31
```

**关键**：这个案子没有直接给答案，它**把"要不要转"变成了"先花两个月验证兴趣"**。这就是好决策的样子——不是选得快，是**用低成本的方式把不确定变小**。

### 实例 2：要不要接这个实习

```markdown
## 决策：暑期实习（2026-05-20）

### 我在选什么
A：去这家中厂做运营，日薪 150，三个月
B：留校跟老师做项目，没有钱

### 事实
- 中厂实习：通勤 1.5 小时单程
- 老师项目：每周 3 次组会，能参与论文
- 我的目标：保研（需要科研经历）
- 我目前：无论文、无实习、绩点 3.5

### 判断
- 我认为：保研看科研，实习对保研几乎无用
- 依据：本院细则里"科研经历"占面试 40%，实习不计分
- 几成把握：七成
- 如果错了：可能是今年细则变了

### 预期
- 选 B：三个月后有一篇在投论文，能写进材料
- 选 A：三个月后有实习经历，但对保研无帮助

### 证伪条件
如果我查了今年的细则，发现实习算进"综合素质"，那我判断错了

### 决定
选 B。**但在做之前先花一小时查今年的细则原文。**

### 复查
2026-08-30
```

**关键**：这个案子里有一条很多人不会做——**在决定之前先验证最关键的那个事实**。判断建立在"实习不计分"上，那就先去确认它。

### 实例 3：月度画像（连续三个月）

| 月份 | 画像里的一句话 | 三个月后看出来的东西 |
|---|---|---|
| 9 月 | "主线是把高数补上来" | — |
| 10 月 | "主线还是高数，但花了一半时间在社团" | 说和做不一样 |
| 11 月 | "退了一个社团，高数上来了" | **约束不是时间，是同时开的事太多** |

**这就是决策档案的真正产出**：不是你记了三页纸，是你从三页纸里看出了**自己的行为模式**——这个模式会跟着你四年、二十年。

## 五、反例与边界

### 边界 1：小事不要立档

"今天中午吃什么""这周末去不去看电影"——立档的成本高于收益。

**判断标准**：这个决定的影响超过三个月吗？会的话立档，不会的话别记。

**过度记录是一种病**：把生活全部档案化，会让人失去"随手做决定"的轻松感，最后坚持不了两周。

### 边界 2：档案不能替代决定

有一种拖延叫"我还在收集信息"。档案会让这种拖延看起来很有道理——你在"严肃地做决策"。

**硬规矩**：一个案子最多立两周，两周内必须给出决定（包括"暂不决定"这个决定）。

**信号**：如果 04_待解里躺着一个超过一个月的案子，那不是信息不够，是**不敢选**。去 `04_执行诊断.md`。

### 边界 3：回填时不要美化自己

回填最难的是诚实。人会自动把"我当时判断错了"改写成"当时信息不足"。

**检验方法**：回填时问自己一句——**如果当时多花两小时，我能不能查到那个信息？**

- 能 → 那是判断失误，不是信息不足
- 不能 → 那才是信息不足

### 边界 4：不要用档案给自己定性

02_规律层容易变成自我标签的仓库：

> "我不擅长数学""我社交不行""我抗压能力差"

一旦写进 02 层，它会开始筛选你的行为——你会避开那些能推翻它的事。

**规则**：02 层只写**可改变的模式**，不写**身份判断**。

| ❌ 身份判断 | ✅ 可改变的模式 |
|---|---|
| 我数学不好 | 我在没有具体题目时学不进去，先做题再看书效率更高 |
| 我社交不行 | 我在陌生人多的场合会沉默，但一对一能聊得深 |
| 我抗压差 | 我在多任务并行时容易崩，单一任务时很稳 |

**右边那三条都能改，左边那三条只能认命。**

### 边界 5：这不能救「已经很久没记录」的人

如果你已经大三了，前两年什么都没记——**不要试图补记**。补记的都是被现在污染的回忆。

**正确做法**：从今天开始记。三个月后你就有三个月的数据，这比编造两年的假数据有用。

### 边界 6：涉及心理健康的部分不进档案

情绪崩溃、持续的自我否定、和家人的严重冲突——这些可以记事实，但**不要试图用"规律"解释它们**。

用决策框架去分析"我为什么这么难受"，会得出一个逻辑上说得通、但情感上完全错误的结论。这类问题去 `04_执行诊断.md` 的边界 5，或者找专业帮助。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **记成日记** | 每天写"今天心情不好" | 有情绪没有信息，回看无用 |
| **只记结果不记预期** | "我决定考研" | 无法回填，学不到东西 |
| **一次经验就写进规律** | 一次考砸 → "我不适合" | 自我实现预言 |
| **待解永远悬着** | 04 层堆了十个问题 | 背景性焦虑，越积越重 |
| **回填全是"运气不好"** | 每次错都归因外部 | 四年不进步，且越来越怨 |
| **把规律写成身份** | "我就是不行" | 从可改变变成不可改变 |
| **过度记录** | 每件事都立档 | 两周就放弃，什么都没留下 |
| **用档案替代决定** | 反复补信息，就是不选 | 高级拖延 |

## 七、和其他模块的关系

- **决策档案是命题审查-对标法的存储器**：审过的命题（命题审查）、拆过的词（概念拆解）、改好的问题（提问法）、分过的型（执行诊断）——**结论都该落进档案**，否则三个月后全忘
- **决策档案 → 提问法**：04_待解里的问题，用提问法改写成能回答的
- **决策档案 → 目标清晰化**：立案之后发现"我其实不知道自己要什么"，去目标清晰化做目标清晰化
- **决策档案 → 任务澄清**：决定做某件事之前，用任务澄清问"我雇它来完成什么"
- **和 `../knowledge/认知/06_大学案例复盘.md` 的分工**：大学案例复盘是复盘方法（四步、归因四分法），决策档案是**存储结构**。**先有档案，复盘才有素材**
- **和 `../shared/存档契约.md` 的关系**：档案的路径和命名按存档契约走，不要另起一套

## 八、自检

1. 我现在能说出三个月前某个决定的三条理由吗？（说不出 = 没记）
2. 每个案子有没有写**预期**和**证伪条件**？
3. 02_规律的每一条，是**三次以上不同情境**验证过的吗？（一次不算）
4. 02 层里有没有写成"我不行"的身份判断？（有 → 改成可改变的模式）
5. 04_待解里有没有超过一个月没动的？（有 → 立案或明确放下）
6. 上次回填时，我写的是"运气不好"还是"我错在哪一步"？
7. 有没有踩到六条边界？（小事立档 / 用档案替代决定 / 美化回填 / 自我定性 / 补记历史 / 分析情绪）
