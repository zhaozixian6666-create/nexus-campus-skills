# 00 · 防骗与红线（学生副业）

> **性质：客观信息。** 骗局类型是公开的、可核查的，谁都能讲。
> **用途**：`../../capabilities/05_赚钱.md` 的判定依据。学生问"这个兼职靠不靠谱"，先过这张表，不靠感觉。
> **边界**：这里只讲**识别结构**，不点名具体机构、不做法律判断。真涉及钱和合同，让他自己核实、必要时找学校或警方。

---

## 一、一条总判据

**骗子不靠骗术高明，靠你着急。**

所以判断一个机会，不要先看"它说得多好"，先看**它利用了你哪种急**：

| 你的急 | 他会怎么下钩 | 你要警惕的那句话 |
|---|---|---|
| 急用钱 | 日结、当天到账、动动手指 | "先垫一下，马上返你" |
| 急着证明自己 | 包就业、包过、名额有限 | "今天最后三个名额" |
| 急着变好 | 免费学、先学后付 | "签个协议就行，不用你现在掏钱" |
| 急着脱单/被认可 | 交个朋友、进个圈子 | "先交个门槛费，筛掉不认真的人" |
| 怕错过 | 风口、内部消息、稳赚 | "稳赚不赔" |

**凡是精准戳中你当下最急那件事的，先降一档信任。**

---

## 二、十类高频套路（按学生真实遇到的频率排）

### 1. 刷单 / 点赞 / 关注返利

- **长这样**：前两单真返你 5 块，第三单让你垫 200。
- **结构**：先用小额真返建立信任，再用"垫资"收割。
- **一句判据**：**任何要你先掏钱的"兼职"，一律不碰。** 没有例外，不用研究例外。

### 2. 培训贷 / 先学后付

- **长这样**："免费学，包就业"，最后让你签一份分期合同。
- **结构**：把学费转成一笔贷款，课不值钱，债是真的。
- **一句判据**：**要身份证、要绑卡、要签合同的"免费"，都不是免费。**

### 3. 打字员 / 录入员 / 数据标注外包

- **长这样**：千字 30，门槛极低。
- **结构**：先收资料费、押金、会员费，收完就断联。
- **一句判据**：**门槛低到不需要任何能力，还给你高于市场的钱——这本身矛盾。**

### 4. 代理 / 拉人头

- **长这样**：交 500 代理费，卖货赚钱，拉下线再赚一笔。
- **结构**：主要收入来自拉人头而不是卖产品。
- **一句判据**：**看它的钱主要从哪来。来自下线 = 传销结构。**

### 5. 租号 / 解封 / 实名认证

- **长这样**：租你微信号一天 200，帮忙解封给 50。
- **结构**：你的账号被拿去诈骗或洗钱，责任挂在你这。
- **一句判据**：**账号、身份证、银行卡、人脸，四样东西永不出借。** 不讨论价格。

### 6. 游戏代练 / 装备回收

- **长这样**：帮你代练，或高价收你的装备。
- **结构**：要你的账号密码，或让你先交手续费。
- **一句判据**：**要登录你账号的，一律不给。**

### 7. 校园贷 / 美容贷 / 创业贷

- **长这样**：低息、随借随还、当天到账。
- **结构**：实际年化极高，逾期后是催收而不是协商。
- **一句判据**：**不碰任何带杠杆和分期的消费贷。** 缺钱只有两条路：家里、正规银行学生贷款。

### 8. 付费内推 / 保 offer

- **长这样**：交 5000 保你进大厂实习。
- **结构**：正规大厂实习不收费内推。收费的要么是假的，要么值不了这个价。
- **一句判据**：**要你先付钱才能"被推荐"的，推荐本身就不成立。**

### 9. 知识付费割韭菜

- **长这样**："我大学四年赚了 100 万，299 全教你"。
- **结构**：他的主要收入就是卖课，那他教的是"怎么卖课"。
- **一句判据**：**看他的收入来源。收入主要来自教学，就学不到教学以外的东西。**
- **⚠️ 这条要用在自己身上**：以后你自己卖课，这条同样被用来判你。

### 10. 炒币 / 合约 / 带单

- **长这样**：跟老师操作，稳赚。
- **结构**：高杠杆，爆仓是常态；带单的人赚的是手续费和你的本金。
- **一句判据**：**"稳赚不赔"四个字出现，判断结束。**

---

## 三、五条硬红线（不用判断，直接执行）

1. **先掏钱的，一律不碰。** 不研究例外——你识别不了的那 1%，成本比收益高。
2. **账号 / 身份证 / 银行卡 / 人脸，四样永不出借。**
3. **要签合同、要绑卡、要填身份证的"免费"，都是贷款。**
4. **带杠杆的金融产品，学生不碰。**
5. **不确定时，先查"XX 是骗局吗"，再问至少两个信得过的成年人。** 查完还是不确定 → 当骗局处理。

---

## 四、已经上当了怎么办（比防更重要，因为多数人不敢说）

学生最怕的不是被骗，是**被骗了不敢讲**——所以才会被"再交一笔就能解冻"二次收割。

处理顺序：

1. **立刻停止一切转账。** 任何"再交 X 就能拿回 Y"都是第二轮骗。
2. **留证据**：聊天记录、转账记录、对方账号、链接，一个都别删。
3. **先告诉一个真人**（家人、辅导员、室友）。自己扛着是二次受骗的主要原因。
4. **报警 / 打 96110**（国家反诈专线）。金额小也报，报案记录本身有用。
5. **如果是贷款合同**：找学校资助中心或法援，别自己跟对方谈。

---

## 五、这个模块不做什么

- 不点名具体机构、平台、个人
- 不做法律判断（是不是诈骗，由警方定）
- 不承诺"帮你追回"
- 不评价"你当时怎么这么傻"——被骗的人已经知道了

## 六、和 05_赚钱的接口

学生问"这个兼职/项目靠谱吗"，走这条：

```
① 先过第二节的十类，看结构像不像
② 再问一句：钱是从哪来的？（客户 / 下线 / 你的本金）
③ 命中任何一条红线 → 直接说不碰，不解释太多
④ 没命中 → 也别背书，给"怎么自己验"的三步
```

**不要说「这个应该没问题」。** 你只能说"我没看出问题，但你自己按这三步验一遍"。
