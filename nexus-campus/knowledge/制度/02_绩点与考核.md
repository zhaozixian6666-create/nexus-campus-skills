# 绩点与考核制度

> 收录日期：2026-11-02
> 依据：各校《学分制实施办法》《课程考核管理规定》《平均学分绩点计算办法》，教育部推免新规中关于成绩口径的条款，WES/学信网 GPA 换算说明
> **这一层管的是"数字"**：绩点怎么算、排名按什么口径、挂了怎么办、刷分还有没有用。

---

## 一、先弄清一件事：绩点不是一个数，是一套算法

同一个学生，同一组成绩，用不同算法算出来的 GPA 可以差 0.3 以上。这 0.3 可能决定他保研能不能过线、留学能不能进 dream school。

所以「我绩点多少」这个问题，完整问法应该是：「**按哪个算法、算哪些课、算到第几学期**」。

三个变量：

| 变量 | 影响 |
|---|---|
| **算法** | 4.0 制 / 5.0 制 / 百分制，换档点不同 |
| **范围** | 全部课程 / 只算必修 / 剔除选修和公选 |
| **学期** | 前 3 学期 / 前 5 学期 / 全部 |

## 二、常见算法对照

### 2.1 四档制（多数 4.0 体系，最常见）

| 百分制 | 绩点 |
|---|---|
| 90-100 | 4.0 |
| 85-89 | 3.7 |
| 82-84 | 3.3 |
| 78-81 | 3.0 |
| 75-77 | 2.7 |
| 72-74 | 2.3 |
| 68-71 | 2.0 |
| 64-67 | 1.5 |
| 60-63 | 1.0 |
| <60 | 0 |

### 2.2 五档制（部分学校，粗一些）

| 百分制 | 绩点 |
|---|---|
| 90-100 | 4.0 |
| 80-89 | 3.0 |
| 70-79 | 2.0 |
| 60-69 | 1.0 |
| <60 | 0 |

⚠️ **五档制对"卡在 89 分"的人极不友好**：89 和 80 都是 3.0，等于白考 9 分。如果你的学校用五档制，**89 分和 90 分的价值差一整档**，这个认知值钱。

### 2.3 五级制（考查课、体育、实习常用）

| 等级 | 常见折算 |
|---|---|
| 优秀 | 90 / 4.5（5 分制）或 4.0 |
| 良好 | 80 / 3.5 或 3.0 |
| 中等 | 70 / 2.5 或 2.0 |
| 及格 | 60 / 1.5 或 1.0 |
| 不及格 | 0 |

### 2.4 加权平均分（百分制）

```
加权平均分 = Σ(课程成绩 × 课程学分) ÷ Σ课程学分
```

**学分越高的课，对结果影响越大。** 一门 6 学分的专业核心课拿 70，抵得上一门 1 学分选修课挂掉。

### 2.5 平均学分绩点（GPA）

```
GPA = Σ(课程绩点 × 课程学分) ÷ Σ课程学分
```

**这是保研和留学最常用的口径。**

## 三、出国申请的 GPA 换算（和国内不一样）

国内 GPA 不能直接拿去申请，要走换算或认证：

| 方式 | 说明 |
|---|---|
| **WES 认证** | 美国、加拿大多数学校要求。WES 有自己的换算表，**可能把国内 85 分算成 3.0 也可能算成 3.7**，取决于课程和学校 |
| **学校自算** | 部分学校接受你提交的官方成绩单，自己换算 |
| **百分制直接提交** | 英联邦部分学校接受百分制均分（如要求 85/100） |

⚠️ **关键认知**：WES 换算**对中国学生的专业课更友好、对公共课更严格**（马哲、体育这类可能被降权或不计）。所以"总 GPA 不高但专业课很好"的人，走 WES 反而可能更有利。

**这条规则的实际用法**：大二就想出国的人，应该先查目标学校接不接受 WES、WES 怎么算你的学校，再决定把力气花在哪些课上。

## 四、考核制度：分数是怎么来的

### 4.1 一门课的成绩构成

| 组成 | 常见占比 | 说明 |
|---|---|---|
| **平时分** | 20-40% | 出勤、作业、课堂表现、小测 |
| **期中** | 0-30% | 部分课有 |
| **期末** | 40-70% | 主体 |

**这是最被浪费的一条规则。** 平时分几乎是"送分"：按时到、交作业、坐前排，能拿到 90%+ 的平时分；缺勤三次，平时分直接掉到 60%。

一门 3 学分的课，平时分 30%、期末 70%：
- 平时分 95 + 期末 75 = **81 分**
- 平时分 65 + 期末 85 = **79 分**

**期末多考 10 分，不如平时分多拿 30 分。** 而平时分是四年里成本最低的分数来源——不需要聪明，只需要到场。

### 4.2 考核方式

| 方式 | 特点 |
|---|---|
| **考试**（闭卷/开卷） | 有标准答案，可预期，往年题价值极高 |
| **考查** | 论文、报告、作品，评分主观，**给分通常比考试松** |
| **过程考核** | 多次小测累加，不能临时抱佛脚 |
| **答辩/实操** | 技能类课程 |

**选课时的实际策略**：同样一门通识课，选"考查"（交论文）比选"考试"（闭卷）更容易拿高分，且时间可控。这不是投机，是规则允许的选择。

## 五、挂科、补考、重修

### 5.1 三个概念的差别

| 环节 | 什么时候 | 成绩怎么记 |
|---|---|---|
| **补考** | 下学期开学初（通常） | 多数学校**最高记 60 分**，绩点 1.0 |
| **重修** | 跟下一届重上整门课 | 按实际成绩记（**但见 5.2**） |
| **清考** | 毕业前最后一次（部分学校已取消） | 通过即 60 |

⚠️ **补考过了也算"有过挂科记录"**。在保研资格审核里，"是否有不及格课程"看的是**首次成绩**，补考通过不代表没挂过。**这一条每年都有人栽。**

### 5.2 重修刷分，正在失效

以前的标准做法：考了 75 分不满意，重修一次考 90，取高分。**这条路正在被关掉。**

已有多校明确（如南京航空航天大学 2028 届起）：

- 推免遴选使用**首次获得的课程成绩**
- 必修课用**首修必修平均学分绩点**

**什么意思**：重修的成绩不进保研计算。刷分对保研无效。

**但注意**：这条只约束**保研**。出国（WES 会看全部成绩，也可能只认首次）、就业（看成绩单整体）、奖学金评定，规则各不相同。

**判断顺序**：先确认他用绩点干什么 → 再确认这个用途认不认重修成绩 → 再决定要不要重修。

## 六、排名：三种口径，差很多

| 口径 | 怎么算 | 谁会看 |
|---|---|---|
| **专业排名** | 同专业同年级所有人 | 保研最常用 |
| **首修必修绩点排名** | 只算首修 + 只算必修 | **越来越多校的保研口径** |
| **综合测评排名** | 绩点 + 德育 + 加分（学生工作、竞赛、志愿） | 奖学金、评优 |

⚠️ **综测排名和绩点排名经常不是一回事**。有人绩点第 5、综测第 1（因为当干部、打比赛）；有人绩点第 1、综测第 8（因为什么活动都不参加）。

**这两个排名的用途完全不同**：
- 保研资格：看绩点排名（部分学校看综合）
- 奖学金：看综测
- 留学：看 GPA（不看排名）

所以「我排名第几」这句话，必须补一句「**哪个排名**」。

## 七、绩点对四条路的兑换率

这是本文最该记住的一张表。同一个绩点，四条路的价值完全不同：

| 出口 | 绩点占几成 | 门槛形态 | 说明 |
|---|---|---|---|
| **保研** | **七到九成** | 排名制（前 X%） | 过线是生死，过线后边际收益骤降 |
| **考研初试** | **零成** | 不看 | 只看那四门。但绩点崩了影响复试印象和导师选择 |
| **就业** | **一到三成** | 看有没有挂科 + 学校层次 | 技术岗几乎不看，国企/央企/选调看 |
| **出国** | **五到八成** | 硬门槛（GPA 线） | 这条路上绩点最值钱，且几乎不可替代 |

**由这张表推出的三个动作**：

1. 想保研的人：绩点是主战场，且**前五学期**就要算完，大三上之后补不了
2. 想考研的人：绩点只要"不挂科、能毕业"就够，时间应该压在四门课上
3. 想出国的人：从大一开始每门课都要争，因为 GPA 是累加平均值，**一门低分课要用三门高分课才能拉回来**

## 八、学分制下的几个具体问题

### 8.1 学分不够毕不了业

毕业审核看三样：**总学分 / 必修课全过 / 选修课分类学分达标**（如通识课要修满某类 X 学分）。

⚠️ 最常见的坑：**总学分够了，但某一类选修没修满**（比如"艺术类通识"要求 2 学分，你修了 4 学分其他类但没修艺术类）。大四才发现，只能延毕。

**对策**：每学期末自己核一次分类学分，别等系统提示。

### 8.2 学分绩点太低会触发警示

见 `01_学籍与专业.md` 第六节。

### 8.3 免修、免听、学分认定

- **免修**：通过考试证明已掌握，直接给学分（多为计算机、英语）
- **免听**：可以不听课但必须考试（部分学校对绩点高的人开放）
- **学分认定**：交换、竞赛、MOOC、参军经历可折算学分（各校政策差异极大）

**这条对转专业和交换回来的人尤其重要**：课程替代认定没做好，会导致"明明学过但不算学分"。

## 九、一学期的时间线（决定分数的关键节点）

| 时间 | 动作 | 影响 |
|---|---|---|
| **开学第 1-2 周** | 看教学大纲（成绩构成、考核方式）；确认选课 | 决定这学期怎么分配精力 |
| **第 3-4 周** | 决定要不要退课/换课（退课窗口通常在第 2-4 周） | 退课窗口关了就只能硬扛 |
| **期中前后** | 期中考 + 平时分累计过半 | 期中崩了还有救，期末崩了没救 |
| **第 12-14 周** | 找往年题、找学长要重点 | 信息差最大的时候 |
| **考前 2-3 周** | 复习（用自测，不要只重读） | 决定最终分数 |
| **考后 1-2 周** | **查分、申请复核**（有窗口期，通常 5-10 个工作日） | 分数算错不申请就永久错了 |

## 十、必须自查的变量

| 变量 | 去哪查 |
|---|---|
| 本校用哪种 GPA 算法（几档、换档点） | 教务处 →《平均学分绩点计算办法》 |
| 保研用哪个排名口径（是否首修、是否含选修） | 推免工作实施办法 |
| 补考/重修成绩怎么记 | 《课程考核管理规定》 |
| 重修成绩是否进保研计算 | 推免细则（**新规下多校已排除**） |
| 学业警示的学分级 | 学籍管理规定 |
| 分类选修学分要求 | 培养方案（人手一份，但没人看） |
| 退课/换课窗口 | 教务处每学期通知 |
| 成绩复核窗口 | 教务处通知 |

## 十一、常见误区

| 误区 | 实际 |
|---|---|
| "绩点不重要，能力才重要" | 对考研不重要，对保研/出国是硬门槛，看你要去哪 |
| "补考过了就等于没挂" | 保研审核看首次成绩，挂过就是挂过 |
| "重修能刷分" | 多校保研已改用首修成绩，刷分无效 |
| "平时分没多少" | 平时分占 20-40%，是不需要天赋的分数 |
| "总学分够了就能毕业" | 还要看分类选修是否达标，这条最容易漏 |
| "排名第几都一样" | 绩点排名、首修排名、综测排名是三件事 |
| "89 和 90 差不多" | 五档制学校差一整档；四档制差 0.3 |
