# 中国大学制度总览

> 收录日期：2026-11-02
> 依据：教育部及各省市公开文件、各校教务处与研究生院公开实施细则、国家大学生就业服务平台政策汇编
> 时效：**制度层的东西一部分稳定（流程环节）、一部分半年就变（名额、时间、加分口径）。每个文件末尾都标了"哪些必须当场查"，用之前先看那一节。**
> 这一层是**客观规则**，不是任何人的观点，也不是谁的经历。引用时不带"我认为"，带"规定是"。

---

## 零、这一层解决什么

大学不是"上学"，是**在一套规则里兑换资源**。

同一个分数、同一段经历，放在不同规则下换到的东西差几倍。而规则是写在文件里的——教务处网页、研究生院通知、学院公众号、省考试院公告。**绝大多数学生四年没读过其中任何一份。**

这一层的任务：把规则摊开，标出**哪个窗口在什么时候关**。

它回答的问题不是"该怎么努力"，是「**我这件事，规则上还来得及吗**」。

## 一、八个节点，一条主线

大学四年的制度性机会全部挂在八个节点上。每个节点都有窗口，窗口关了不能补。

```
大一上          大一下         大二          大三          大四
  │               │             │             │             │
转专业(第一次) ──┘             │             │             │
                 专业分流 ─────┘             │             │
                 辅修/双学位报名 ────────────┘             │
                               进组/大创 ────┘             │
                               竞赛主力年 ───┘             │
                                             保研(夏令营·预推免·九推) ─┐
                                             考研(初试12月·复试3月) ──┤
                                             秋招(9-11月) ───────────┼─→ 毕业
                                             留学申请(前一年9月-当年1月)┘
                                             春招(3-5月，补录)
```

| 节点 | 决策窗口 | 错过之后 | 详细 |
|---|---|---|---|
| **学籍与专业** | 大一上末～大一下（转专业），大一下～大二上（分流） | 专业基本定死，只能靠考研/跨考绕 | [[01_学籍与专业]] |
| **绩点与考核** | 每学期期末，重修窗口通常在大三前 | 保研/留学两条路同时受限，且刷分空间正在被政策压缩 | [[02_绩点与考核]] |
| **保研** | 前五学期绩点 + 大三暑假预推免 + 大四9月系统 | 只能转考研，从零开始四门课 | [[03_保研]] |
| **考研** | 大三下决定，大四上12月考试 | 二战＝多一年，且失去应届生身份 | [[04_考研]] |
| **出国** | 大三下考语言，大四上递申请 | 只能 gap 一年 | [[05_出国]] |
| **就业** | 大三暑假实习 → 大四上秋招 | 应届生身份只值一次，春招岗位少一半 | [[06_就业]] |
| **科研与竞赛** | 大二进组，大三出成果 | 保研加分和简历都空着 | [[07_科研与竞赛]] |
| **奖助与费用** | 每学年初评定 | 一年一评，不补发 | [[08_奖助与费用]] |

## 二、四条主线，一张时间轴

同一个学期，四条路要做的动作完全不同。这张表是全库最该先看的一张。

| 学期 | 保研线 | 考研线 | 就业线 | 留学线 |
|---|---|---|---|---|
| **大一上** | 守住绩点（权重最高的一学期，因为课少、一门课占比大）；摸清本校推免细则 | — | 加一个社团/学生组织，攒可写的事 | 保持 GPA，别出现低分课 |
| **大一下** | 绩点；开始接触竞赛 | 想清楚要不要考数学 | 第一份实习（哪怕是校内勤工） | 开始背单词 |
| **大二上** | 进实验室/进项目组；竞赛组队 | 确定考不考、考什么专业 | 第一份正经实习（寒暑假） | 语言首考 |
| **大二下** | 竞赛出成绩；六级必须过 | 开始数学、英语打底 | 实习 + 明确行业方向 | 语言刷分；了解目标院校 |
| **大三上** | 绩点是主战场（前五学期算完）；科研出成果 | 专业课第一轮 | 实习升级（大厂/对口） | 确定国家/专业/预算 |
| **大三下** | **预推免材料准备**（个人陈述、推荐信、作品集）；投递 | 全力备考 | **暑期实习转正关键期** | 语言出分；文书 |
| **大三暑假** | **预推免（7-8月，已大幅前置）** | 冲刺 | 暑期实习 | 递交申请（部分国家9月开） |
| **大四上** | **9月推免系统（九推）** | **12月初试** | **秋招9-11月** | 申请季 + 面试 |
| **大四下** | 完成毕设 | 3月复试/调剂 | 春招补录 | 收 offer |

**一句话结论：真正的分水岭在大三下。** 那一个学期里，保研的在准备材料、考研的在刷题、就业的在抢暑期实习、留学的在写文书——四条路第一次必须选一条，选错就没有第二次。

## 三、三个所有人都踩过的制度性误解

### 1. 「大四再想」

规则上不成立。保研看前五学期绩点，大四上只是走系统。秋招在大四上，大四再准备简历已经错过主战场。**所有"重要但不紧急"的事，窗口都在大二大三。**

### 2. 「绩点是虚的，能力才是真的」

问题不在真假，在**兑换率**。绩点对出国是硬门槛（换不了），对保研是入场券（换不了），对就业只值一成（可以换），对考研初试是零成（完全换不了）。所以"绩点重不重要"是个伪问题，真问题是「**你要去的地方，认不认它**」。

### 3. 「政策年年变，查了也没用」

变的是数字（名额、比例、时间），不变的是**结构**（资格由哪几项构成、哪个环节卡人、文件叫什么名字）。你不需要记住数字，你需要知道**去哪个网页找哪份文件**。这一层给的是结构 + 查法。

## 四、政策变动最大的三处（2026 年）

这一层里最容易写错、也最值钱的三块，单独拎出来：

**① 保研选拔方式被重构（2026 年起）**

教育部印发推免工作管理规定后，多校取消选拔性夏令营、优营证书失效、预推免时间整体前移约两个月。**"拿优营保底"这条路基本走不通了。** 详见 [[03_保研]]。

**② 竞赛与论文加分在收紧（2028 届起）**

多校明确：同一学生多个一类竞赛奖项只取一项、只认国家级三等奖及以上、学院出可加分清单、论文只认独作或一作。**靠堆比赛数量凑加分的方法正在失效。** 详见 [[03_保研]] 第四节。

**③ 应届生身份在放宽（2025 年起）**

多省把应届生认定从"毕业当年"扩到"离校 2 年内"（部分 3 年），且不再以是否缴社保、签劳动合同为否定项。**"先工作两年再考公"不再等于自断资格。** 详见 [[06_就业]] 第五节。

## 五、怎么用这一层

**当有人问"我这个情况还来得及吗"** → 先定位他站在哪个学期（第二节的表），再翻对应节点文件的时间线，看窗口关没关。

**当有人问"XX 是什么、怎么弄"** → 翻对应文件第一节（规则结构）和第四节（必须自查的变量）。

**当有人问"某某学校/某某专业怎么样"** → **不在这层**。这层只有规则，没有院校评价。院校判断是 `../../capabilities/08_专业与院校.md` 的事。

**引用规则（重要）**：

| 说法 | 能不能说 |
|---|---|
| "规定是……" | ✅ 能，制度层就是规定 |
| "我们学校是……" | ⚠️ 只能在他确认过本校文件后说 |
| "一般来说是……" | ✅ 能，但要补"以本校当年文件为准" |
| "肯定是……" | ❌ 不能，除非有当届文件原文 |

## 六、数据边界（每个文件都适用）

1. **文件会换版**。教育部规章、省考试院公告、学校实施细则，每年都可能改。这里标年份的，只对那一年有效。
2. **校级差异极大**。同一项规定，985 和四非、东部和西部、本科和专科，口径可能完全不同。这里写的是**通行结构**，不是某一所学校的细则。
3. **不写具体名额和比例**，除非有公开原文。凡是"大概""通常"，一律要求使用者去查本校当年文件。
4. **这一层不做判断，只给规则**。判断在 `capabilities/` 和 `judgement/`。
