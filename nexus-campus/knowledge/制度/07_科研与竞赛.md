# 科研与竞赛制度

> 收录日期：2026-11-02
> 依据：国家级大学生创新创业训练计划管理办法、各校大创与科研训练管理规定、中科院文献情报中心期刊分区表说明、国家知识产权局专利审查周期公开信息、《全国普通高校大学生竞赛分析报告》竞赛目录
> **竞赛部分只讲"和科研的关系"和"制度规则"**，具体赛事规则在 `knowledge/竞赛/`（4 份）。这一层补的是**科研**，那是竞赛库没覆盖的。

---

## 一、本科生能做的"科研"有四种，含金量差很多

| 形态 | 是什么 | 周期 | 产出 | 保研加分 |
|---|---|---|---|---|
| **进实验室/课题组的子任务** | 跟老师或学长做，打下手 | 半年-2 年 | 参与经历、可能挂名 | **低**（除非有署名成果） |
| **大创（大学生创新创业训练计划）** | 自己组队立项，有经费 | 1 年 | 结题报告、可能出论文/专利 | **中** |
| **独立/主导一个课题** | 自己提问题、自己做 | 1-2 年 | 一作论文、专利 | **高** |
| **学科竞赛** | 见 `knowledge/竞赛/` | 3-12 个月 | 奖项 | **高**（Ⅰ/Ⅱ类） |

**关键判断**：保研加分只认**成果**（论文署名、专利、奖项），不认"参与过"。所以在实验室待两年但什么都没署名的，加分是零。

**这不是说进实验室没用**——它对复试、对科研能力、对推荐信都极有价值。但要清楚：**它换的是能力和推荐信，不是加分。**

## 二、进实验室：怎么进、什么时候进

### 2.1 时间

| 时间 | 状态 |
|---|---|
| **大二上** | **最佳起点**。有基础课底子，还有 2 年时间出成果 |
| 大二下 | 可以，但节奏紧 |
| 大三上 | 偏晚，多数只能做短期任务，出不了署名成果 |
| 大三下 | 基本只能"挂个名"，对保研加分无实质帮助 |

### 2.2 怎么找导师（四种途径，按成功率排）

1. **上过他的课，课后去问**（成功率最高，有天然接触点）
2. **通过学长学姐引荐**（次高，有人背书）
3. **直接发邮件**（要看邮件写得好不好，见 2.3）
4. **学院官网找研究方向，群发**（成功率最低）

### 2.3 给老师发邮件怎么写（这是最实用的一节）

老师每天收几十封学生邮件，只回三类：**说清了要做什么、证明了自己能做、成本低的**。

邮件结构（四段，不超过 300 字）：

```
1. 我是谁：姓名、专业、年级、绩点/排名（一行）
2. 我看了你什么：具体到某篇论文/某个方向（证明不是群发）
3. 我能做什么：我会什么技能（编程/实验/文献/数据分析），每周能投入多少小时
4. 我想要什么：想参与课题/想学习，愿意从基础工作做起
```

**三个不要**：不要写"我对科研有浓厚兴趣"（空话）、不要群发（老师之间会聊）、不要一上来就要一作。

### 2.4 进组后的真实规则

- **前 3 个月基本是打杂**（洗瓶子、标数据、查文献），这是正常的
- **能不能署名，取决于你有没有实质贡献**，不是待的时间长短
- **署名顺序有规则**：一作通常是主要执行者，导师常是通讯作者。**本科生拿到一作，说明真的做了主体工作**
- **挂名有风险**：2026 年推免新规后，与直系亲属或职级明显更高者合作的成果不赋分，学术不端查得越来越严

## 三、大创（大学生创新创业训练计划）

### 3.1 是什么

国家级/省级/校级三级，学生自己组队申报项目，学校给经费，一年期，结题要有成果。

| 类型 | 内容 |
|---|---|
| **创新训练项目** | 做一个研究课题（偏科研） |
| **创业训练项目** | 做商业计划、模拟运营 |
| **创业实践项目** | 真的注册公司/实际运营 |

### 3.2 关键规则

| 项 | 通行情况 |
|---|---|
| **申报时间** | 每年 3-5 月（各校不同） |
| **周期** | 1 年（可申请延期） |
| **经费** | 国家级几千到 2 万，省级/校级更少 |
| **团队** | 3-5 人，需指导教师 |
| **结题** | 报告 + 成果（论文/专利/实物/软件） |
| **不结题的后果** | 影响后续申报资格，部分学校记入诚信档案 |

### 3.3 大创值不值

| 你的目的 | 值不值 |
|---|---|
| 拿保研加分 | **值**（多数学校认，权重中等） |
| 攒第一段科研经历（为进更好的组铺垫） | **值**，成本低 |
| 拿经费做自己的项目 | **值**，这是本科生唯一能拿到的小额科研经费 |
| 想靠大创发论文 | **看情况**，多数大创结题就结束了，出论文的是少数 |
| 想靠大创赚钱 | **不值**，经费是报销制，不是给你发钱 |

⚠️ **大创最典型的失败**：立项时热情高涨，中期不推进，结题前拼凑一个报告。**结果是花了一年，什么成果都没有，加分也拿不到。**

## 四、论文：分级、署名、水刊陷阱

### 4.1 期刊分级（人文社科 vs 理工科不一样）

**理工科/医学**

| 级别 | 说明 |
|---|---|
| **SCI**（科学引文索引） | 国际主流。分区：中科院分区（1-4 区）、JCR 分区（Q1-Q4）。**一区最难** |
| **EI**（工程索引） | 工程类，比 SCI 略易 |
| **中文核心（北大核心）** | 国内认可 |
| **CSCD**（中国科学引文数据库） | 理工科国内核心 |
| **普刊** | 普通期刊，**多数学校保研不认** |

**人文社科**

| 级别 | 说明 |
|---|---|
| **CSSCI**（南大核心） | 社科最高，本科生极难 |
| **北大核心** | 次之 |
| **普刊** | 多数不认 |

**计算机特殊**：会议论文比期刊重要，看 **CCF 分级（A/B/C）**。CCF-A 会议（如 CVPR、NeurIPS）含金量高于多数 SCI 期刊。

### 4.2 本科生发论文的真实难度

| 级别 | 本科生可行性 |
|---|---|
| SCI 一区/二区 | **极难**，通常需要跟组 1-2 年 + 导师全力支持 |
| SCI 三区/四区 | 可能，需要完整参与一个课题 |
| EI / 中文核心 | 较可能，工科本科生有一定比例 |
| 普刊 | 容易，但**多数学校保研不认** |
| 会议论文 | 看会议级别，CCF-B/C 对本科生是现实目标 |

### 4.3 署名规则（新规后很重要）

- **只认独立作者或第一作者**（多校 2028 届起明确）
- 与直系亲属、或职级明显更高者合作的成果**不赋分**
- 代表作**只取水平最高的 1 篇**

**这意味着**：挂名第五作者的论文，在保研加分上是**零**。宁要一篇一作的普刊（如果学校认），不要五篇挂名的 SCI。

### 4.4 水刊陷阱（必须警告）

**特征**：
- 承诺"一周录用""包发表"
- 收高额版面费（几千到上万）
- 期刊名模仿正规期刊（如"International Journal of..."但没有影响因子）
- 不在任何正规索引里
- 邮件主动约稿

**后果**：花了钱，学校不认；更严重的，被认定学术不端，影响毕业和推免。

**核实方法**：查期刊是否在 SCI/EI/CSSCI/北大核心目录里；查中科院预警期刊名单（每年发布）。

## 五、专利

| 类型 | 审查 | 周期 | 含金量 | 保研加分 |
|---|---|---|---|---|
| **发明专利** | 实质审查 | **2-3 年**（可申请优先审查缩短） | 高 | 高 |
| **实用新型** | 形式审查 | 6-12 个月 | 中 | 中（部分学校不认） |
| **外观设计** | 形式审查 | 4-8 个月 | 低 | 低/不认 |
| **软件著作权** | 登记制 | 1-3 个月 | 低 | 低（部分学校认） |

⚠️ **专利的时间陷阱**：发明专利 2-3 年才授权，**大三才申请，保研时还没下来**，加不了分。想靠专利加分，**大二就得申请**。

## 六、竞赛与科研的关系（制度视角）

### 6.1 两者不是一回事

| | 竞赛 | 科研 |
|---|---|---|
| 评价方式 | 评委打分，**结果导向** | 同行评议，**过程+结果** |
| 周期 | 3-12 个月 | 1-3 年 |
| 产出 | 奖项 | 论文/专利 |
| 保研加分 | **高**（Ⅰ/Ⅱ类） | 高（一作论文） |
| 能力证明 | 团队协作、快速交付 | 深度、持续性 |

### 6.2 时间上会打架

大二大三，竞赛的备赛窗口（寒假、暑假）和科研的推进期完全重叠。**同时做两个的人，通常两个都做不深。**

**判断口径**：
- 想保研，且排名在边缘 → **优先竞赛**（周期短、加分确定）
- 排名稳，想读博 → **优先科研**（推荐信、复试、直博都要）
- 排名稳，想就业 → **优先实习**（见 `06_就业.md`）

### 6.3 新规下的策略变化

2028 届起竞赛加分收紧（多个一类奖只取一项、只认国奖、学院出清单）。**这直接改变了策略**：

| 老策略 | 新策略 |
|---|---|
| 多打几个赛，总有一个中 | **选一个能打到国奖的，打透** |
| 广撒网 | 深度参与一个项目，一路打到国赛 |
| 靠数量堆加分 | 靠质量 + 科研产出（一作论文） |

## 七、时间线

| 学期 | 科研线 | 竞赛线 |
|---|---|---|
| **大一上** | 上好基础课（高数、编程、专业导论） | 了解本校认哪些赛 |
| **大一下** | 找学长了解实验室；尝试联系老师 | 组队，参加校赛练手 |
| **大二上** | **进实验室**（最佳时间） | 确定 1-2 个主攻赛事 |
| **大二下** | 承担子任务；**申大创** | 冲省赛 |
| **大二暑假** | 推进课题（暑假是唯一整块时间） | 备赛黄金期 |
| **大三上** | **申专利**（如果要加分）；写论文 | 冲国赛 |
| **大三下** | 论文投稿；准备预推免材料 | 国赛结果出来 |
| **大三暑假** | 预推免（成果要在这之前有） | — |

## 八、判断一个人该做科研还是竞赛

按顺序问：

1. **你保研的目标是什么档？排名稳不稳？** —— 边缘的人优先竞赛（加分确定）
2. **你想读博吗？** —— 想读博必须做科研（直博、复试、推荐信全看这个）
3. **你现在大几？** —— 大三上之后，出署名成果基本来不及，只能做短期任务
4. **你们学校认哪些成果？**（大创？专利？一作论文？核心期刊？）—— 这条必须查学院细则
5. **你能投入多少时间？** —— 科研至少每周 10 小时，否则不如不做

**答完必须给的一句话**：以他的时间和目标，最划算的一条路是什么，以及**第一个具体动作**（发一封邮件 / 找一个队友 / 查学院加分清单）。

## 九、常见误区

| 误区 | 实际 |
|---|---|
| "进了实验室就有加分" | 只认署名成果，参与经历不加分 |
| "论文挂名也算" | 新规只认独作/一作，挂名不加分 |
| "专利很快能下来" | 发明专利 2-3 年，大三申请来不及加分 |
| "大创随便做做就行" | 不结题影响后续申报，且大部分学校认结题成果 |
| "发论文找中介买版面" | 水刊不认，严重的算学术不端 |
| "竞赛多打几个总没错" | 2028 届起多个一类奖只取一项，广度策略失效 |
| "科研和竞赛可以同时做" | 备赛窗口和课题推进期重叠，两个都做不深 |

## 十、必须自查的变量

| 变量 | 去哪查 |
|---|---|
| 学院认哪些成果加分、各加多少 | 学院《推免加分细则》+《可加分赛事清单》 |
| 大创申报时间与结题要求 | 教务处/创新创业学院通知 |
| 本校认定的期刊目录 | 科研处/研究生院（部分学校有"认定期刊目录"） |
| 专利申请流程与费用减免 | 学校知识产权办公室（多数学校对学生的申请费有减免） |
| 实验室/课题组招人信息 | 学院官网、老师主页、学长 |
