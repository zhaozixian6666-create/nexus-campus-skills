# 奖助与费用制度

> 收录日期：2026-11-02
> 依据：财政部、教育部《学生资助资金管理办法》，全国学生资助管理中心政策口径，各校奖助学金评审办法、家庭经济困难学生认定办法
> **金额标准会随政策调整**，本文标"现行"的数字只作量级参考，实际以当年通知为准。

---

## 一、这一层的入口：家庭经济困难认定

**所有资助（助学金、助学贷款、学费减免、勤工助学、绿色通道）的前置条件，是"家庭经济困难学生认定"。**

不认定，一分钱都拿不到。认定的流程：

```
提交申请（附证明材料）→ 班级民主评议 → 院系审核 → 学校认定 → 建立困难生档案
```

**认定的等级**（各校叫法不同）：特别困难 / 困难 / 一般困难，对应不同资助力度。

### 1.1 什么算"困难"（通行口径）

- 建档立卡（原建档立卡贫困户）
- 低保家庭
- 特困供养学生
- 孤残学生
- 烈士子女
- 家庭突发变故（重病、灾害、事故）
- 低收入家庭（各地标准不同）

⚠️ **两个关键点**：
1. **认定是每年重新做的**，不是一次认定管四年
2. **认定是隐私的**，但必须主动申请——学校不会主动找你

### 1.2 不愿意申请的人，损失什么

很多学生因为"不想被同学知道"放弃认定。代价是：

- 助学金（每年几千）
- 助学贷款资格
- 勤工助学岗位（部分只对困难生开放）
- 学费减免
- 部分社会奖助学金

**这不是"要不要面子"的问题，是每年几千到上万元的差距。**

## 二、奖学金（看成绩，不看家境）

### 2.1 国家级

| 名称 | 金额（现行） | 名额 | 条件 | 谁能拿 |
|---|---|---|---|---|
| **国家奖学金** | **8000 元/年** | 极少（约在校生的 0.2%） | 成绩排名前 10%（或前 30% 且有突出表现） | 本专科生，**不看家境** |
| **国家励志奖学金** | **5000 元/年** | 约在校生的 3% | 成绩排名前 30% **且** 家庭经济困难 | **必须是困难生** |

⚠️ **国家奖学金和国家励志奖学金不能同时获得。**

**这两个的区别要记清**：
- 国奖 = 纯看优秀（成绩 + 综合表现）
- 励志 = 优秀 + 贫困（**必须先做困难认定**）

很多成绩好但家境一般的学生，从来没申请过励志奖学金，因为他们不知道这需要先做困难认定。

### 2.2 校级与社会奖学金

| 类型 | 金额 | 评定依据 |
|---|---|---|
| **校级奖学金**（一等/二等/三等） | 几百到几千 | 综合测评排名 |
| **单项奖**（学习优秀、社会实践、竞赛等） | 几百 | 单项表现 |
| **社会奖学金**（企业/校友设立） | 差异极大，有的上万 | 各设奖方定，可能要求特定专业/性别/生源地 |

**社会奖学金是信息差最大的一块**：名额少、宣传少、很多学生不知道存在。**来源**：学院官网、校友会、基金会公告。

### 2.3 评定的真实规则

多数学校按**综合测评**排名：

```
综测 = 学业成绩（70-80%）+ 德育（10-20%）+ 加分（竞赛、学生工作、志愿、论文）
```

**这条规则的实操意义**：绩点第 1 但综测第 10 的人，拿不到一等；绩点第 5 但竞赛加满的人，可能拿国奖。

**加分项每年都在变**（和推免加分收紧同向），必须查本校本年的综测办法。

## 三、助学金（看家境，不看成绩）

| 名称 | 金额（现行） | 对象 |
|---|---|---|
| **国家助学金** | **平均 3300 元/年**，分 2-3 档（约 2000-4500） | 家庭经济困难学生 |
| **校级助学金** | 各校自定 | 困难生 |
| **临时困难补助** | 一次性，几百到几千 | 突发变故 |

**关键规则**：
- 助学金**不需要成绩排名**（只要不挂科太多、没有违纪）
- 助学金**和奖学金可以同时拿**（励志奖学金除外，它本身兼有两者性质）
- 助学金每年重新评定

---

## 四、助学贷款（额度最大的一块）

### 4.1 两种贷款

| 类型 | 在哪办 | 特点 |
|---|---|---|
| **生源地信用助学贷款** | **户籍所在县的学生资助管理中心**（入学前办） | **主流方式**，覆盖绝大多数人 |
| **校园地国家助学贷款** | 学校学生资助中心（入学后办） | 部分学校/地区有 |

### 4.2 额度（现行，以当年政策为准）

| 学历 | 每年最高 |
|---|---|
| 本专科 | **16000 元** |
| 研究生 | **20000 元** |

**在校期间利息由国家财政补贴，毕业后开始计息。** 还贷期限最长可达学制 + 15 年。

### 4.3 办理时间与材料（生源地贷款）

- **时间**：每年暑假（7-9 月），入学前在户籍地办
- **材料**：身份证、录取通知书/学生证、户口本、共同借款人（通常是父母）身份证
- **流程**：线上申请（国家开发银行学生在线服务系统）→ 县级资助中心现场确认 → 学校回执确认

⚠️ **每年都要办一次**（续贷），不是办一次管四年。忘记续贷 = 那一年没贷款。

## 五、勤工助学

| 类型 | 内容 | 报酬 |
|---|---|---|
| **校内岗位** | 图书馆、实验室助理、行政助理、辅导员助理 | 按小时计，各校标准不同（常见 15-30 元/小时） |
| **助研/助教** | 帮老师做项目、批作业 | 略高 |
| **校外勤工** | 学校组织的校外岗位 | 按当地最低工资 |

**规则**：多数学校规定每周工作时间上限（如不超过 8-10 小时），不影响学习。

**值不值**：校内勤工的价值不只是钱，还有**和老师建立关系**（辅导员助理、实验室助理的推荐信价值可能超过工资）。但**时薪低，别把它当收入来源**——同样时间做家教或实习，收入高得多（见 `../../capabilities/05_赚钱.md`）。

## 六、学费减免与绿色通道

### 6.1 绿色通道

**家庭经济困难新生，可以先入学、后缴费。** 报到时走"绿色通道"办理入学手续，再通过贷款、助学金、勤工助学等方式补缴。

**这条政策的意思是：没有钱也能先上学。** 每年都有学生因为不知道这条而放弃入学。

### 6.2 学费减免

| 对象 | 减免力度 |
|---|---|
| 建档立卡/低保/特困供养 | 部分学校全额减免或减半 |
| 孤残学生、烈士子女 | 多数学校有专项减免 |
| 应征入伍 | 学费补偿/代偿（本专科每年最高 16000，研究生 20000） |
| 基层就业（中西部、艰苦边远） | 学费补偿或贷款代偿（服务满 3 年） |

⚠️ **应征入伍和基层就业的学费补偿，是"毕业时才想起来就晚了"的典型**——它要求在读期间或毕业时按规定申请。

## 七、一张表：什么情况拿什么

| 你的情况 | 该申请什么 |
|---|---|
| 成绩前 10%，家境一般 | 国家奖学金 + 校级奖学金 |
| 成绩前 30%，家境困难 | **国家励志奖学金**（先做困难认定）+ 国家助学金 |
| 成绩中等，家境困难 | 国家助学金 + 助学贷款 + 勤工助学 |
| 家里一时拿不出学费 | 绿色通道 + 生源地贷款 |
| 突发变故 | 临时困难补助 |
| 想减轻家里负担但不想欠人情 | 勤工助学（但收入低） |
| 打算入伍 | 学费补偿（在校期间申请） |

## 八、时间线（每年）

| 时间 | 事项 |
|---|---|
| **7-9 月（暑假）** | 生源地助学贷款办理/续贷 |
| **9 月（开学）** | 困难生认定申请（**一年一次，最重要**）；绿色通道 |
| **9-10 月** | 国家奖学金、国家励志奖学金申请 |
| **10-11 月** | 校级奖学金评定（综测）；国家助学金评定 |
| **11-12 月** | 发放（多数学校分学期发） |
| **次年 3-4 月** | 部分社会奖学金、临时补助 |

⚠️ **最容易错过的两个**：9 月的困难认定、7-8 月的贷款续贷。**这两个错过就是一年。**

## 九、判断一个人该拿什么（给调用者用）

按顺序问：

1. **你做过家庭经济困难认定吗？** —— 没做，先做这个，它是一切资助的入口
2. **你成绩排名多少？** —— 决定能不能冲国奖/励志
3. **你学费交得上吗？** —— 交不上，走绿色通道 + 生源地贷款
4. **你每年知道有哪些奖学金可以申吗？** —— 多数人只知道国奖，不知道社会奖学金
5. **你有没有做过综测加分的事？**（竞赛、学生工作、志愿）—— 决定校级奖学金

**答完必须给的一句话**：他现在能拿但没拿的钱是多少，以及**最近的一个申请窗口在哪个月**。

## 十、常见误区

| 误区 | 实际 |
|---|---|
| "我家不困难，不用做认定" | 认定不影响任何东西，但不做就拿不到助学金和励志奖学金 |
| "国奖和励志可以一起拿" | 不能同时获得 |
| "助学金要成绩好" | 助学金看家境，不看排名（只要不挂科太多） |
| "贷款办一次管四年" | 每年要续贷 |
| "没钱就不能上大学" | 绿色通道可以先入学 |
| "社会奖学金跟我没关系" | 名额少但竞争也小，很多没人申请 |
| "勤工助学能挣钱" | 时薪低，价值在关系和经历，不在钱 |

## 十一、必须自查的变量

| 变量 | 去哪查 |
|---|---|
| 困难生认定的时间与材料 | 学校学生资助管理中心 |
| 各类奖学金金额、名额、条件 | 学生手册 + 资助中心通知 |
| 综测办法（加分项与权重） | 学院学生工作办公室 |
| 助学贷款额度与办理流程 | 户籍地县级学生资助管理中心 + 国家开发银行学生在线服务系统 |
| 学费减免政策 | 学校资助中心 |
| 社会奖学金名单 | 学院官网、校友会、基金会 |
