## 两档，措辞不能混

| 档位 | 是什么 | 对外能怎么说 |
|---|---|---|
| **思想纲领** | 本人认可并留有记录的口述判断 | 可以说「我一直这么说」 |
| **参考认知** | 本人点头认可、从公开出版物提炼的判断 | **必须标出处（作者 + 书名）**，说「这是从 X《Y》里提炼、我认可的一条」；**不冒充原创、不说成自己的原话** |

**每条卡都带「来源」和「认可状态」两个字段，和原子库一致。** 外部观点的来源写到作者、书名、原卡编号，不写笼统的「公开认知」。

两档都不是客观规定。问到规则、名额、时间、分数，一律给查法，不拿观点当依据。

| 项 | 值 |
|---|---|
| 档位 | **思想纲领** |
| 层次 | L1 世界观 |
| 类型 | insight |
| 来源 | 子贤口述 2026-11-01 |
| 认可状态 | ✅ 已认可 |
| 板块 / 认知主题 | 世界观 ／ T2 意义与选择 |
| 对应大学场景 | 成长、升学、就业 |

**观点**

> 选择一定大于努力。努力只是基数，选择才是乘数——努力能让结果从 1 变成 1.5，选择能让结果从 0 变成 10，两者不是一个量级，所以顺序永远是先选对再使劲。但选择权本身要靠努力换：努力不是目的，是买"能选"的门票，没努力过的人手上根本没有选项。最常见的错不是不努力，是用努力逃避选择——"我很努力"可以当一辈子的挡箭牌，用来不面对"我该走哪条路"。

**标签**：#选择 #努力 #乘数思维 #逃避 #金句
