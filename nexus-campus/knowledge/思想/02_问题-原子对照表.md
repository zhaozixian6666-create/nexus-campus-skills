# 问题-原子对照表 · 02

> 用途：按学生说出口的那句话定位观点。左边是信号，右边是取哪条、拿它拆什么、拆完回哪个模块。
>
> **这不是观点原文**，是调用索引。观点在 `01_思想原子卡.md`，取用动作在 `../../method/14_思想校准.md`。

---

## 怎么用这张表

1. 找到他原话最接近的一行（找不到就别硬取，走原来的能力模块）
2. **一次只取一条**，把「拿它拆什么」里的问题问出来或自己判一遍
3. 立刻落回「用完落回」的模块，给结论和这周能做的第一件事
4. 「别用成」那一栏是边界，不是补充说明

**规则题、分数题、时间题不进这张表**，直接给查法。

---

## 零、原话速查（先查这里，不要直接拿他的话去搜库里）

**为什么要有这一张**：库里的观点用的是书面词（自卑、认可欲求、被定价、课题分离），学生说出口的是口语（没劲、好痛苦、她嫌我穷）。拿他的话直接做关键词检索，经常 0 命中。所以顺序是**先查这张表定编号，再用 `--id` 取正文**，关键词检索只作兜底。

| 他原话里出现 | 落到哪一节 | 取 |
|---|---|---|
| 痛苦、撑不住、想哭、活着没意思 | 内耗那节；**同时先判安全**（见下） | `ATOM-048` |
| 没劲、提不起劲、什么都不想做 | 「知道该做，就是做不到」 | **不取观点**，走执行诊断 |
| 没钱、穷、被嫌穷、配不上、被定价 | 「刚认识就问我家里情况」那节 | `ATOM-037` |
| 不如别人、被比下去、自卑、比不上 | 「我是不是不如别人」 | `ATOM-046` |
| 她怎么看我的、别人怎么评价我 | 同上，或「被定价」那节 | `ATOM-046` / `ATOM-037` |
| 不知道要什么、没方向、随大流 | 「我不知道自己要什么」 | `ATOM-042` |
| 怕选错、不敢定、想稳妥 | 「我不敢选，怕选错」 | `ATOM-045` |
| 白努力、努力没用、忙但不踏实 | 「我很努力了，为什么没用」 | `ATOM-038` |
| 拖、明天再开始 | 「知道该做，就是做不到」 | **不取观点**，走执行诊断 |
| 要不要继续、该不该断、一直别扭 | 「跟某人相处一直别扭」 | `ATOM-036` |
| 不敢当负责人、担不起 | 「我不敢当负责人」 | `ATOM-031` |
| 等准备好、等时机、再等等 | 「我一直在等一个合适的时机」 | `ATOM-045` |
| 被套话、有人在打听我 | 「有人在打听我的事」 | `ATOM-033` |

**出现「痛苦、撑不住、活着没意思」时的安全前提**：先按 `../../capabilities/07_成长.md` 的边界确认一次（是否持续两周以上、功能是否受损、有没有伤害自己的念头）。有第三条就直接指向学校心理咨询中心，**观点一条都不取**——这时候给观点是拿道理压人。

## 一、方向与选择

### 「我很努力了，为什么没用」／一直忙但不肯定方向

- **取**：`ATOM-038`（思想纲领）
- **拿它拆什么**：这学期花时间最多的三件事，分别服务哪个出口？如果现在停下来不选，最省力的做法是不是继续用「我在努力」挡着？努力换来的选项里，哪一个是他真的想要的？
- **用完落回**：`../../capabilities/07_成长.md`，必要时接 `../../capabilities/02_升学.md`
- **别用成**：否定他过去的努力，或者一句「选择比努力重要」就收工

### 「我不知道自己要什么」／一直由家里、学长替他定

- **取**：`ATOM-042`（参考认知）
- **拿它拆什么**：最近一个决定是谁做的？后果最后是谁承担的？有没有一件小事可以这周自己定、自己担？
- **用完落回**：`../../capabilities/07_成长.md` → `../../method/09_任务澄清.md`
- **别用成**：劝他跟家里对立；成年是承担代价，不是切断关系

### 「我不敢选，怕选错」／只想要一条稳妥的路

- **取**：`ATOM-045`（参考认知）
- **拿它拆什么**：现在这条看起来最稳的路，四年后最坏会是什么样？他为「不出错」正在付什么代价？
- **用完落回**：`../../capabilities/07_成长.md` → `../../method/07_决策档案.md`
- **别用成**：鼓励冒险，或暗示稳就是错

### 「我是不是不如别人」／自卑、横向比较

- **取**：`ATOM-046`（参考认知）
- **拿它拆什么**：他说的「我不行」，是有一处欠缺，还是已经推不出任何动作？这份欠缺感最近让他多做了什么、躲开了什么？
- **用完落回**：`../../capabilities/07_成长.md` → `../../method/04_执行诊断.md`
- **别用成**：把持续低落当成动力问题；持续低落、自伤念头一律转介专业帮助

## 二、行动与判断

### 「知道该做，就是做不到」／学了一堆方法没用起来

- **取**：**本层不取观点**。思想层 18 条里没有讲「知行不一」的，硬套任一条都会跑偏 → 直接走 `../../method/04_执行诊断.md`，先查是启动卡住还是维持卡住
- **拿它拆什么**：他把「我要好好学」变成了哪一步今天能做的动作？能不能把这一步讲给同学照着做？讲不出来，说明还停在心法
- **用完落回**：`../../method/04_执行诊断.md` → `../../capabilities/07_成长.md`
- **别用成**：再加一套方法给他收藏；这里只做「有没有落地成招式」的检查

### 「我想 all in 考研／创业／退学做项目」

- **取**：`ATOM-043`（参考认知）
- **拿它拆什么**：这个判断被什么验证过？从做对到被证明做对，中间那段反复期他打算怎么过？如果判断错了，退路在哪？
- **用完落回**：`../../method/07_决策档案.md` → 对应能力模块
- **别用成**：劝人孤注一掷，或者替他拍板；这条只用来检查判断有没有被验证过

### 「学历没用／读书不值」

- **取**：`ATOM-044`（参考认知）
- **拿它拆什么**：他说的「没用」，是在说上限还是在说下限？眼下的学习机会属于哪一头？
- **用完落回**：`../../capabilities/02_升学.md` 或 `../../capabilities/04_就业.md` → `knowledge/认知/09_学历投资与回报`
- **别用成**：拿观点替具体学校的保研/就业数据作答，那类一律给查法

## 三、人际与边界

### 「要不要经营人脉」／关系里总觉得亏

- **取**：`ATOM-034`（思想纲领）
- **拿它拆什么**：这段关系里双方各自拿出的是什么？他期待的回报，对方知道吗？
- **用完落回**：`../../capabilities/06_人际.md`
- **别用成**：把每段关系都算成交易，或者据此劝人断交

### 「网上的、学长说的，我该不该信」

- **取**：`ATOM-035`（思想纲领）
- **拿它拆什么**：这条信息是谁放出来的、想让他做什么？他自己读到时的第一反应是什么？
- **用完落回**：**先走 `../../method/01_命题审查.md`**，再回对应能力模块
- **别用成**：拿「第一感受」代替审查；信息可不可信要靠证据和边界，不靠感觉定案

### 「跟某人相处一直别扭，要不要再处处」

- **取**：`ATOM-036`（思想纲领）
- **拿它拆什么**：别扭是偶发还是一直在？他打算用「再看看」推翻的，是哪一次具体感受？
- **用完落回**：`../../capabilities/06_人际.md`
- **别用成**：替他给那个人下结论、贴标签；这条只确认他自己的感受和边界

### 「刚认识就问我家里的情况／在给我定价」

- **取**：`ATOM-037`（思想纲领）
- **拿它拆什么**：哪些问题越过了边界？他打算怎么回应，而不是怎么评价对方？
- **用完落回**：`../../capabilities/06_人际.md` → `../../method/11_协作与求助.md`
- **别用成**：揣测对方动机、给人定性

### 「组队没人带头／在等别人来找我」

- **取**：`ATOM-047`（参考认知）
- **拿它拆什么**：第一步谁做、做到什么算完成、什么时候验收？这三样写下来了吗？
- **用完落回**：`../../capabilities/03_竞赛.md` → `../../method/11_协作与求助.md`
- **别用成**：要求他一个人扛全部协调成本；带头是发起，不是包办

### 「室友／同学／导师的事让我很内耗」／替别人的情绪负责

- **取**：`ATOM-048`（参考认知）
- **拿它拆什么**：这件事的后果最后落在谁身上？哪一部分是他的，哪一部分不是？
- **用完落回**：`../../capabilities/06_人际.md`
- **别用成**：拿「课题分离」当冷漠的借口；分离是划责任，不是断关系

## 四、钱与风险

### 「要不要花时间研究理财／搞钱」

- **取**：`ATOM-041`（参考认知）
- **拿它拆什么**：他手上能动的量级，和把这段时间投在职业路径上，哪个回报更大？现在最该打通的是哪一段路径？
- **用完落回**：`../../capabilities/05_赚钱.md`
- **别用成**：给具体金额门槛或投资建议，一律给查法

### 「这个高收益／复利项目靠不靠谱」

- **取**：`ATOM-049`（参考认知）
- **拿它拆什么**：收益承诺跟「本金从哪来」对得上吗？对方回避了哪个问题？
- **用完落回**：`../../capabilities/05_赚钱.md` → `../赚钱/00-防骗与红线.md`
- **别用成**：把观点里的数字当结论；遇到具体产品只给核实路径，不报数

---

### 「我不敢当负责人／担不起这个事」

- **取**：`ATOM-031`（思想纲领）
- **拿它拆什么**：他说「我不行」时，指的是哪一件具体没做过的事？担责任、要结果、要资源、敢突破，这四样里他最怕哪一样？
- **用完落回**：`../../capabilities/07_成长.md` → `../../method/11_协作与求助.md`
- **别用成**：把「领导力」说成人格标签，让他觉得天生没有；这是练出来的位置，不是选出来的天赋

### 「我一直在等一个合适的时机／等准备好」

- **取**：`ATOM-045`（参考认知）
- **拿它拆什么**：他等的那个「准备」，过去半年推进了哪一步？他要的确定性，能不能靠一次小规模试错换到？
- **用完落回**：`../../capabilities/07_成长.md` → `../../method/04_执行诊断.md`
- **别用成**：把「磨砺」讲成吃苦崇拜；磨砺指的是有反馈的实践，不是硬扛

### 「学了很多方法，一动手就用不起来」

- **取**：`ATOM-050`（参考认知）
- **拿它拆什么**：他手上那套方法，能不能落成三个具体动作？哪一个动作他明天就能做、做完能验收？
- **用完落回**：`../../capabilities/07_成长.md` → `../../method/05_自学法.md`
- **别用成**：让他再学一套方法；这一条的方向是往下落成招式，不是往上加理论

### 「我觉得自己还没准备好／没底气」

- **取**：`ATOM-032`（思想纲领）
- **拿它拆什么**：他要的那个「底气」，是缺经验还是缺勇气？过去一年里，他真正下场做过哪件事？
- **用完落回**：`../../capabilities/07_成长.md` → `../../method/04_执行诊断.md`
- **别用成**：把「磨砺」说成吃苦崇拜；有反馈的实践才算，硬扛不算

### 「有人在打听我的事／感觉被套话」

- **取**：`ATOM-033`（思想纲领）
- **拿它拆什么**：对方问了什么、问到什么颗粒度？哪一句已经越过了他愿意公开的范围？他打算怎么回，而不是怎么评价对方？
- **用完落回**：`../../capabilities/06_人际.md` → `../../method/11_协作与求助.md`
- **别用成**：把所有打听都判成敌意；亲密关系和正常合作也会了解你，先看关系类型
