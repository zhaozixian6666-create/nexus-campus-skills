# 07 · 中国大学制度

> 这一块讲什么：保研、考研、编制、学历通胀——制度怎么运作，规则在哪
> 定位：**规则层**。资源分配与个人定价讲价格怎么形成，这一块讲价格背后的规则是谁定的、怎么变的。

---

## 一、问题界定：制度不是背景板，是牌桌

多数学生把制度当背景——「反正规则就是这样」。这是最贵的认知错误。

**制度决定三件事，每一件直接决定你的努力值多少钱：**

| 制度决定 | 后果 |
|---|---|
| **总量**（名额多少） | 决定竞争烈度。名额刚性 → 必然内卷（接概念澄清与思维的拆词） |
| **分配方式**（按什么排序） | 决定你该在哪个维度投入 |
| **变更周期**（多久改一次） | 决定你的投入会不会中途作废 |

**判断：不研究制度的人，是在一张自己不知道规则的牌桌上出牌。**

---

## 二、机制：中国大学制度的三个特征

### 2.1 总量控制：名额是刚性的

这是最重要的一个特征，也是所有焦虑的源头。

| 赛道 | 总量由谁定 | 可扩产性 |
|---|---|---|
| 保研名额 | 教育部下达 → 学校分配 → 学院再分 | **不可扩产**，年度微调 |
| 考研招生计划 | 教育部 + 学校 | 小幅可调，但报名人数涨得更快 |
| 考编岗位 | 编制总量控制 | **强刚性**，退一进一 |
| 就业岗位 | 市场 | 可扩产，但看行业周期 |

**刚性名额 = 零和博弈。** 你多一个，必然有人少一个。这决定了：**在这条赛道上，「比别人强」比「自己变强」更重要。**

而市场化的赛道（技能、作品、接活）不是零和——别人变强不影响你。**这是资源分配与个人定价里「把精力挪到非名额制赛道」的制度依据。**

### 2.2 多层级筛选：每一层都是独立关卡

几乎所有上升通道都是多层的，而且**每一层的评价标准不一样**：

| 通道 | 层级 | 每层考什么 |
|---|---|---|
| 竞赛 | 院 → 校 → 省 → 国 | 院看完整度，省看创新性，国看落地和答辩 |
| 保研 | 绩点排名 → 加分认定 → 学院评审 → 目标院校夏令营/预推免 | 每层换一套标准 |
| 考研 | 初试（统考）→ 复试（面试+笔试）→ 导师双向选择 | 初试考记忆，复试考表达和匹配 |
| 考编 | 笔试 → 面试 → 体检政审 | 笔试筛人，面试定生死 |

**核心推论：多数人只在第一层用力，然后在第二层被筛掉，却以为是第一层不够努力。**

> 竞赛里最常见：校赛拿第一，省赛被刷。原因不是做得不好，是**省赛的评分维度和校赛不同**——校赛看「做完没」，省赛看「有没有增量」。

### 2.3 政策周期：规则会变，而且变得比你想的快

| 会变的东西 | 变动频率 | 后果 |
|---|---|---|
| 推免细则的加分项 | 1-2 年一调 | 你按旧规则攒的分可能不算了 |
| 竞赛目录（认定名单） | 每年动态调整 | 你在打的赛可能被除名 |
| 考研科目 / 参考书 | 不定期 | 复习方向作废 |
| 专业目录 / 招生计划 | 每年 | 想报的专业可能停招 |

**判断：任何「按去年经验准备」的策略，都必须加一道「今年确认」的动作。**

## 三、判断标准：四条路的制度逻辑对比

这是最实用的一张表。**不要问「哪条路好」，要问「这条路的规则是什么、我卡在哪一层」。**

| 通道 | 分配机制 | 决定性因素 | 最大风险 | 适合谁 |
|---|---|---|---|---|
| **保研** | 配额制，院内排序 | 绩点排名 + 加分认定 | 政策变动、学院裁量 | 大一起就跑在前面、能稳定输出的人 |
| **考研** | 统一考试 + 复试 | 初试分数 + 复试表现 | 一年一考，失败成本高 | 能长时间高强度自学、后发的人 |
| **留学** | 申请制 | GPA + 语言 + 背景 | 费用、信息不对称 | 家庭能承担、GPA 好的人 |
| **考编** | 岗位制 | 笔试排名 + 面试 | 岗位少、专业限制、周期长 | 求稳、能接受低弹性的人 |
| **就业** | 市场制 | 可证明的能力 + 实习 | 行业周期 | 有作品、能承担不确定性的人 |

### 3.1 保研的真实结构

保研不是「成绩好就行」。它通常是三块相加：

```
保研综合分 = 学业成绩（权重最高，通常 70-85%）
           + 综合加分（竞赛、科研、社会活动，通常 10-25%）
           + 学院裁量 / 面试（少数学校有）
```

**三块的角色完全不同：**

| 块 | 角色 | 策略 |
|---|---|---|
| 学业成绩 | **门槛**。不过线，加分再多也没用 | 先保排名，别掉出范围 |
| 综合加分 | **拉分项**。这一块才是区分度 | 查细则，挑赋分最高的做 |
| 学院裁量 | **风险项**。不可控 | 提前了解学院惯例，别踩雷 |

> 这正是竞赛模块里「查本校细则」那条的制度依据：同一个比赛在不同学校值 3.5 分还是 2 分，是制度定的，不是赛决定的。

### 3.2 考研的真实结构

考研的胜负手不在初试，在**复试和择校**。

| 环节 | 筛掉什么 | 常见误判 |
|---|---|---|
| 初试 | 筛掉不自律的人 | 以为分高就稳 |
| 复试 | 筛掉「只会考试」的人 | 以为复试走过场 |
| 择校 | 决定你面对多少竞争者 | 只看学校名气，不看报录比和专业课难度 |

**判断：考研的第一步不是复习，是择校。择校错误，后面全部白费。**

### 3.3 学历通胀：制度层面的解释

「学历贬值」不是感觉，是机制：

| 机制 | 说明 |
|---|---|
| **供给增加** | 高校扩招 → 同层次学历的人变多 |
| **信号通胀** | 当本科成为普遍，本科就不再是区分信号，筛选门槛被推到硕士 |
| **岗位需求没同步增长** | 学历供给涨得比高学历岗位快 |

**推论：学历的价值不是绝对下降，是「相对位置」在变。** 同样一个本科，在本科稀缺的年代是信号，在本科普及的年代只是入场券。

> 这直接是「上大学是消费不是投资」和「毕业就失业是伪命题」的制度背景。

## 四、怎么读制度：三份必查文件

不讲方法，这一块就只是知识。可操作的动作是这三个。

### 4.1 三份文件

| 文件 | 在哪找 | 查什么 |
|---|---|---|
| **推免实施细则** | 教务处官网 / 学院官网 | 加分项清单、权重、认定有效期 |
| **综合素质测评办法** | 学生处官网 | 评奖评优的算法、各项权重 |
| **本学院竞赛认定清单** | 学院教务办（常不公开，要问） | 你打算打的赛在不在名单里 |

### 4.2 读文件的三个动作

| 动作 | 具体做法 |
|---|---|
| **找附表** | 正文都是套话，**真正的规则在附件的表格里** |
| **看年份** | 用你毕业那年适用的版本，不是入学那年 |
| **找例外条款** | 「原则上」「一般情况」后面通常跟一句「除…外」，那句才是关键 |

### 4.3 三个必问的人

| 问谁 | 问什么 |
|---|---|
| 辅导员 | 今年的细则有没有改、附件在哪 |
| 上一届成功的人 | 他实际按什么准备的（口头经验常比文件新） |
| 学院教务老师 | 本学院的认定清单（这份最不公开） |

## 五、这类问题上的判断

- 🔥 **大学不鼓励努力的人，也不奖励拼命的人——这跟高考完全两码事；大学拼的是信息差和资源，奖学金/保研/转专业名额极其有限（国奖就几个、奖学金一两位、保研丁点儿），关系户和信息差会抢你的东西；不争不抢就没有未来，身边全是竞争对手，没有一个朋友**
  - 原话：大学是不鼓励努力的人的，也不奖励拼命的人，这跟高考完全是两码事……上了大学之后你就会发现，大家拼的是信息差也是资源。一定会有关系户挡在你的面前去抢你的东西，一定会有人用信息差去拿到比你更多的奖学金，甚至抢了你的保研名额，抢了你的转专业名额……竞赛组能拿国奖的就那么几个，奖学金也就那么一两位，保研资格就是那么丁点儿，你不争不抢，你就没有未来，所以全都是竞争对手，没有一个朋友。

- 🔥 **信息差并不隐秘，都是公开的，痛点只是不知道从哪找——报完志愿立刻打开学院官网查本专业所在学院的保研/转专业/奖学金政策；政策的本质是计算方法（满足什么条款就有名额），不同学院看成绩/履历/竞赛/科研各不相同；拿着政策努力才知道方向，否则满脑子"好好学习"容易白费大量时间拿不到回报**
  - 原话：这些信息差呢，并不是隐秘的，其实都是公开的，只不过你们最难受的点就是你们根本不知道从哪儿去找……你报完志愿之后，你立刻打开你们的学院官网去搜一下你这个专业所属的学院，他们的保研、转专业、奖学金的政策，因为每一个学校的不同学院，它的政策都不一样。所谓政策，核心的东西就是计算的方法，就是它到底是满足什么样的条款，我就有这个保研名额，它到底满足什么样的条件，我就有这个奖学金的。有的学院看成绩，有的学院看履历，有的学院看竞赛，有的学院看科研，真的很不一样。你只有拿着政策去努力，你才知道方向，要不然你满脑子就是一个好好学习，你会非常容易花了大量的时间去学习，然后拿不到一丁点的回报。

- **大学的学习跟高中完全相反——学的难、考的简单，老师上课讲80%的知识点只考前面那5分钟，讲不明白的水课在985也常见；拿高考思维（老师教的必须全会）拼命学所有知识点是最大浪费，尤其害了好学生；把省下来的时间卷竞赛/科研/履历/实习都能拿高分，唯独放在学习上卷不到任何东西**
  - 原话：大学的学习跟高中是完全相反的，学的难，考的简单，老师上课讲的80%的知识点，有可能他只考前面那个5分钟，后边那些都是超纲的，都是他不考的，因为他也不想你挂科。但总有一些人拿着高考那种思维，就是老师教了我就一定得会……他总想把所有的知识点全都学明白，尤其是那些学习比较好的同学，因为他们不懂得放弃。你把时间额外留出来去卷竞赛，卷科研，卷履历，卷实习，其实都能拿到非常高的分数，唯独放在学习上，你卷不到任何东西。

**只有 3 条，撑不起一个话题。** 被追问第二层就会露。

## 不覆盖什么

| 不覆盖 | 说明 | 依据到哪一步 |
|---|---|---|
| **他亲历的制度细节** | 只有「信息差是公开的」「学考相反」两条，缺具体场景 | 讲一次他去查细则、发现某个信息的过程 |
| **名额分配的真实观察** | 缺「我见过名额怎么被分掉」 | 讲一次身边人因为信息差吃亏的事 |
| **他对考研/考编的判断** | 现在零条 | 问他怎么看这三条路 |
| **政策变化的亲历** | 缺「规则改了导致计划作废」的案例 | 讲一次被政策变化坑到 |

讲「制度很重要、要去查细则」够用；讲「保研具体怎么算」，只能给通用框架 + 查法。

## 七、和其他主题的关系

```
中国大学制度（规则层）
 ├─ 资源分配与个人定价 资源分配：制度决定价格怎么定
 ├─ 学历投资与回报 学历投资：制度决定回报率
 ├─ 概念澄清与思维 概念澄清：先拆「保研」「编制」「内卷」，才看得懂制度
 └─ 大学案例复盘 大学案例：制度落到具体的人身上，就是案例
```

**这一块的特点是「冷」**——它没有情绪价值，全是规则。但没有它，其他所有主题都只能停在「我建议你努力」的层面。
