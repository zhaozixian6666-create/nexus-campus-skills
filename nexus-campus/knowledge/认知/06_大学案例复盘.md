# 06 · 大学案例复盘

> 这一块讲什么：具体的人、具体的赛、具体的结果，可复用的做法
> 定位：**证据层**。其他主题给判断，这一块给**发生过的事**。

---

## 一、这一块放什么：只放发生过的事

| 放这里 | 不放这里 |
|---|---|
| 具体的人、具体的时间、具体的结果 | 「很多人」「一般来说」这类模糊指代 |
| 有数字（多少分、多少人、多少钱、多少天） | 只有形容词（很成功、特别难） |
| 失败的和成功的都放 | 只放成功 |
| 能复用的动作 | 只讲故事 |

**一条硬规矩：说不出「具体做了什么动作」的案例，不算案例，只是谈资。**

---

## 二、复盘方法：四步

任何一件事，走完这四步才算复盘完。

| 步 | 问什么 | 常见错误 |
|---|---|---|
| **① 目标** | 当时想达成什么（要有可验证的标准） | 事后改目标（「我本来就想…」） |
| **② 结果** | 实际发生了什么（用数字，不用形容词） | 只记好的一面 |
| **③ 原因** | 为什么是这个结果（分内因/外因） | 全归因于努力或运气 |
| **④ 动作** | 下次具体改哪一步 | 写「要更努力」这种没法执行的话 |

### 2.1 第③步最难，也最值钱

归因有四种，要分开写：

| 归因 | 例子 | 能不能改 |
|---|---|---|
| **可控内因** | 我材料准备不足 | **能改，重点写这块** |
| **不可控内因** | 我性格内向 | 短期难改 |
| **可控外因** | 我选错了赛道 | 能改 |
| **不可控外因** | 评委偏好、政策变化 | 改不了，只能规避 |

**判断：复盘只对「可控」的部分有用。** 把结果全归到不可控因素（运气、评委、学校），复盘就变成了抱怨。

### 2.2 第④步的标准：写成一个动作

| 无效结论 | 有效结论 |
|---|---|
| 「下次要更重视」 | 「下次报名前先查三份细则」 |
| 「要提前准备」 | 「提前 8 周开始，每周出一次完整稿」 |
| 「团队配合不好」 | 「组队时先明确谁负责最终交付」 |

**判断：一句结论如果没法变成「下次第一个动作是什么」，它就等于没写。**

## 四、案例怎么写：模板

以后每收到一个真案例，按这个模板建档，命名「CAS-序号_一句话.md」。

```markdown
# CAS-XXX · 一句话概括

## 基本情况
- 时间：
- 身份：（年级 / 专业 / 学校层次）
- 做了什么：

## 目标
（当时想达成什么，标准是什么）

## 结果
（数字：多少分 / 第几名 / 多少钱 / 多少天）

## 过程关键点
1.
2.
3.

## 归因
- 可控内因：
- 可控外因：
- 不可控：

## 可复用动作
（下次具体改哪一步，写成动作）

## 来源与状态
- 来源：一手经历 / 转述 / 公开信息
- 认可状态：✅ / ⏳
```

## 五、这类问题上的判断

- **大创（创新创业类比赛）是所有学科都能参加的比赛，文科生/理科生/艺术生/哲学都能上，还能接触到各种牛的大佬、导师、企业家老板——这是文科生打破"冷门专业没竞赛"误区的通路；加入校科协（校级管比赛承办的组织）而不是学生会——学生会是大型牛马基地，三年练出一身熟练的办公软件和人情世故，没有价值**
  - 原话：文科生、理科生、艺术生，甚至学哲学的人在学校里面都可以参加一个非常牛的比赛，叫创新创业类比赛，或者叫大创。有很多文科生会觉得我这个专业很冷门，没有什么可以参加的大学竞赛，但实际上并不是，在这种竞赛里边，你甚至能教到各种各样牛的大佬、导师，甚至是企业家老板都有。你看一下你们学校管组织比赛的组织叫什么？就是管这些比赛承办的组织叫什么？一般我们学校叫校科协，一定是校级的，不要去总去傻傻的面试什么学生会，学生会那个就是个大型牛马基地，你3年就练成一身熟练的办公软件和人情世故，对你来说没有任何的必要。

- **大学要会"抱大腿"+展示异于常人的技能——博主大一时因PPT做得非常强，被学长学姐求着进组打比赛；竞赛虽被调侃"PPT大赛"，但聪明人知道拿的是结果/奖/人脉而不是嘲讽；真正有价值的资源只掌握在少数人手里（学长学姐一句话、一个项目可能改变你整个大学四年）；公开场合演讲不怯场、不卑不亢、高能量，才能吸引贵人和伯乐**
  - 原话：我大一的时候为什么那么多学长学姐求着我进他们的组，跟他们一块儿打，就是因为我大一的时候做的PPT做的非常棒。很多人去调侃说大学的竞赛就是PPT大赛，但是聪明的人他会知道葡萄酸，但是我就要提前喝一口甜水，我再去争。我知道大学的竞赛有些很水，但是我要拿的是结果，我要拿的是奖，我要去社交，我要去有人脉。大学里边真正有价值的资源只掌握在少数人手里，只掌握在少数的学长学姐的手里，他们随随便便一句话，一个项目给你了，都有可能改变你整个的大学四年。所以上大学之前一定要学会在公开场合演讲不怯场，不怯懦，不自卑，不内耗，不敏感，你要不卑不亢，你要有主见，你要有自信，你要自信放光芒，要高能量，这样才能吸引到那些你在大学里边的贵人去扶持你，你才能吸引到你真正的伯乐出现，你这匹千里马才可以跑起来。

- 🔥 **打什么竞赛、什么竞赛容易获奖，必须结合你的核心目标来——为了保研就挑综测加分最大的，为了别的就挑那条路上最认的。从目的倒推手段，不是先看赛事名单**
  - 原话：有一个逻辑是这样的，就是你要打什么竞赛，什么竞赛容易获奖，一定要结合你的核心目标来。比如说你是为了保研，如果你是为了保研，那我们肯定要挑能够给你带来最大的这个综测加分的竞赛来打。所以要从目的来出发。

- 🔥 **有一类赛事在任何学校打都不会出错（挑战杯、国创赛、职规赛）；但另一类赛事有校际差——同一个比赛在 A 校综测加分高、在 B 校就低。所以选赛前必须查本校的加分细则，不能只看赛事名单**
  - 原话：像一类竞赛，在任何一个学校打都不会出错，比如说职规赛啊、挑战杯啊、国创赛啊，这些都不会出错。有一些竞赛就有可能会有问题，就比如一个竞赛可能在A学校它的综测加分是高的，在B学校它的综测加分就低。

## 不覆盖什么

**竞赛的知识已经写了两层（选赛四刀 + 赛事库），但「怎么打赢」一条都没有。**

| 不覆盖 | 为什么重要 | 依据到哪一步 |
|---|---|---|
| **他自己打过的赛** | 唯一有说服力的证据 | 打过什么、拿了什么、怎么打的 |
| **组队经验** | 竞赛里最玄也最实际的部分 | 怎么找人、怎么分工、怎么处理有人不干活 |
| **材料/答辩** | 决定名次的临门一脚 | PPT 怎么改的、答辩被问了什么 |
| **没拿奖的复盘** | 比成功案例更有说服力 | 打了几次没中，为什么 |

**补充信息优先级：先补「没拿奖的那次」。** 因为成功案例别人也在讲，失败的复盘只有他自己有。
