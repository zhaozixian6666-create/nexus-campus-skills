# 03 · 表达与个人 IP

> 这一块讲什么：在大学里怎么被看见：包装、输出、表达、个人品牌
> 定位：**杠杆层**。资源分配与个人定价讲你的价值怎么定价，这一块讲**怎么让别人知道你有价值**。

---

## 一、问题界定：大学里的「被看见」到底指什么

先分清三个完全不同的东西，混着说就会变成「教人装」。

| 层次 | 是什么 | 决定什么 |
|---|---|---|
| **会做事** | 有真本事 | 你能不能完成任务 |
| **会表达** | 能把做的事说清楚 | 别人知不知道你做了什么 |
| **会被记住** | 有一个别人记得住的标签 | 有机会时会不会想到你 |

**三者是乘法关系，不是加法：**

```
你能拿到的机会 = 真实能力 × 可见度
```

**能力为 0，可见度再高也没用（这是「装」的失败）。**
**可见度为 0，能力再高也没用（这是「老实人吃亏」的真相）。**

> 这就是「学会包装自己」和「展示异于常人的技能」真正在讲的东西——不是教人虚张声势，是**把乘法里的第二个因子补上**。

## 二、机制：为什么「被看见」这么重要

### 2.1 注意力是唯一不能扩产的资源

| 资源 | 能不能扩产 | 结论 |
|---|---|---|
| 名额 | 不能（刚性） | 零和，见中国大学制度 |
| 机会 | 能（有人创造） | 正和 |
| **别人的注意力** | **不能** | 零和，且极度稀缺 |

一个老师一年能真正记住的学生，可能不超过 10 个。一个 HR 看一份简历的平均时间，以秒计。

**判断：在所有稀缺资源里，注意力是唯一「你没有替代方案」的。** 你不去争，就永远拿不到。

### 2.2 能力不可直接观测，只能靠信号

这是资源分配与个人定价信号理论的延伸，也是这一块的理论核心。

| 你想让他知道 | 他能直接看到吗 | 他实际依据什么判断 |
|---|---|---|
| 我很努力 | 不能 | 你的成果 |
| 我很聪明 | 不能 | 你解决的问题 |
| 我靠谱 | 不能 | 你交付过的东西 |
| 我有想法 | 不能 | 你说出来/写出来的东西 |

**所以「表达」不是包装，是把自己的能力转换成别人能接收的信号。** 不做这一步转化，能力就等于不存在（对别人而言）。

### 2.3 标签效应：人只能记住一个词

认知心理学上有个稳定性很强的现象：**人对一个人的记忆，通常压缩成一个标签。**

| 别人记住你的方式 | 结果 |
|---|---|
| 「那个 PPT 做得特别好的」 | 有相关的事会想到你 |
| 「我们班那个谁」 | 想不起来 |
| 「成绩挺好的」 | 只有在聊成绩时被想起 |

**判断：没有标签的人，等于在别人的记忆里不存在。**
而标签只能有一个——**想让人记住三个优点，结果一个都记不住。**

## 三、判断标准：三步建立可见度

### 3.1 第一步：选定一个可被记住的标签

| 标准 | 说明 |
|---|---|
| **具体** | 「会做 PPT」比「能力强」有效 100 倍 |
| **可验证** | 别人能通过一件具体的事确认 |
| **有需求** | 这个技能得有人要（冷门绝活不算） |
| **你有优势** | 在你所处的圈子里能排进前列 |

**选标签的方法：把「你擅长」和「身边人经常需要」两个圈画出来，取交集。**

前面那个判断讲的就是这个：PPT 做得好 → 被学长学姐主动找 → 获得进入更高圈子的机会。**这个链条的起点不是「我很优秀」，是「我有一个具体的、别人需要的技能」。**

### 3.2 第二步：制造可被看见的证据

| 做法 | 有效性 | 为什么 |
|---|---|---|
| 在群里主动帮忙做一次 | 高 | 立刻可验证 |
| 做一个作品发出来 | 高 | 可反复被看到 |
| 在课堂/活动上发言 | 中 | 一次性，但印象深刻 |
| 只说「我会」 | **零** | 没有证据 |

**判断：说一百次「我会」，不如做一次让别人看见。** 证据 > 宣称，这是所有信号机制的铁律。

### 3.3 第三步：让证据可复用

| 层次 | 做法 | 效果 |
|---|---|---|
| 一次性 | 帮某个人做一件事 | 一个人记得你 |
| 可复用 | 做成模板/作品集 | 每次有人需要都能给 |
| **可传播** | 发出去、被人转发 | 不认识你的人也知道 |

**这一步是「个人 IP」和「会来事」的分界线：**
- 会来事：靠一次次现场表现，累且不可积累
- 个人 IP：有一个持续存在的证据载体，**睡觉时也在替你说话**

## 四、反例与边界：包装到哪一步就成了装

这一节是这一块最重要的部分。**「包装」和「骗」之间只有一条线，而且很多人踩过去了。**

| 包装（可以） | 装（不可以） |
|---|---|
| 把做过的事说清楚 | 把没做过的事说成做过 |
| 突出强项，弱化弱项 | 编造强项 |
| 用更好的方式呈现真实内容 | 内容本身是假的 |
| 表现得比实际自信一点 | 承诺自己做不到的事 |

**一条可操作的判断标准：**

> **包装是在「已有的东西」上做表达优化；装是在「没有的东西」上做无中生有。**
> 前者被揭穿只是尴尬，后者被揭穿是信誉归零，且不可逆。

**为什么这条线不能踩？** 因为大学是个小圈子，信息传播极快。**一次造假会在你还没毕业时就被所有人知道**，而这个圈子正好是你未来几年要用的资源网。

## 五、这类问题上的判断

- **短视频必须流程化（选题/剪辑/包装/发布标准化）才有稳定产出和复利；一条视频能不能火靠概率，但持续发布才有火的机会**
  - 原话：拍短视频，你必须要有流水线的流程。如果你没有办法标准化你的工作流——比如找选题、做剪辑、做包装、做发布——你就不可能有稳定的产出。每一期视频的制作会消耗你大量的时间和精力，你所有东西都是从零开始推进，你就无法在这里面获得复利的价值。你的经验没有办法沉淀成流程，那它就毫无价值。一条视频能不能火，能不能击中观众们的喜好，要看概率、看运气。但是如果你不能像陈泽说的那样，持续地去发声、持续地去展示自己，你连火的机会都没有。

- **抖音里的人不是人，是人的一种状态——迎合数据其实是迎合人的状态，那才是真正的迎合人；把观众当数据才是把观众当人，因为尊重每一个严肃的人也有娱乐的一面，这才是内容沟通的场景**
  - 原话：自媒体到底应该把观众当人呢，还是把观众当数据呢？抖音里的人，他其实不是人，他是人的一种状态。你们所说的迎合数据，其实是迎合人的这种状态，而在我看来，那个才是真正的迎合人。我觉得把观众当数据才是把观众当人。因为我尊重每一个严肃的人，他也有娱乐的一面，而这个才是我和你进行沟通的这个场景啊。这玩意儿才是抖音嘛

- **短视频前5秒是生死线——"大家好我是谁谁谁，今天分享啥"是必死开头，因为前5秒全是废话抓不住注意力；观众刷视频的真实状态是"下班后挤40分钟放松"，你不尊重这个状态，他下一条就去看女主播跳舞；知识博主配反常识开头不是不真诚，是匹配场景——你看不下去《通往奴役之路》才来刷抖音，不配钩子你也看不下去**
  - 原话：我在马斯克那个X那个平台上有8万粉丝，然后我就观察这个平台上的这帮不太会拍视频，只会写文字的人是怎么拍视频的。我发现他们所有人发的第一条视频的第一句话全部清一色都是大家好，我是谁谁谁。今天我要分享个啥啥啥，咱们说这种叫短视频必死开头，对吧？因为你前五秒说的全都是废话，你抓不住我的注意力，我就直接给你划走了。但你说这帮X上面这帮人，他们不把观众当人吗？他们太把观众当人了。我把那些没有流量的这些视频，一个一个都从头看到尾了。他们掏心掏肺跟你分享一些他们真实的观点和见解。但问题是在于你尊重了我作为一个人类的存在，你没有尊重我刷抖音时候的那个状态的存在，我刷抖音的真实状态就是我加了一天。班儿，我下了班儿，我好不容易40分钟来刷视频了。如果你不能用前5秒钟告诉我你到底要讲个啥，我也没有兴趣一点点去挖掘，对吧？那我的确下一条视频我就看女主播跳舞了。那难道我作为消费者没有这个消费内容的权利吗？啊，这时候

- **大学要学会包装自己——学一项硬通货技能（PPT、AI设计、大模型训练、AI编程等，别学传统编程），文科生理科生都能学，别给自己贴标签；文科生根本不用跟理科生竞争，只需要跟"觉得自己是文科生就什么也不是"的人竞争，心态上已经赢过90%的文科生**
  - 原话：大家上了大学之后，一定要学会包装自己，学一项技能，比如说PPT啊这种硬通货技能，或者学AI设计啊，这种大模型训练啊，自己可以训练一个大模型，这个很简单，然后也不要学编程了，你学学AI编程……这些技能是文科生也能学的，理科生也可以学，不要给自己贴标签，觉得自己是文科生啊。文科生你不用跟理科生去竞争，我跟你讲，你只要跟那些觉得自己是文科生什么也不是的、从心态上就已经输了的人竞争就可以了，你就已经超越了90%的文科生了。

- **做自媒体流量要好，必须学会5s黄金法则——5s完播率直接决定视频的额外曝光量和账号的基础流量；前5秒留不住人，算法就不给你推**
  - 原话：想要做自媒体，流量要好，必须要学位5s黄金法则，他是直接和视频额外曝光有关的，5s完播率就决定了你这个视频账号的基础流量有多少

## 不覆盖什么

**这一块讲的偏「短视频方法论」——前 5 秒、黄金法则、流程化。这是**做账号**的知识，要往**大学生怎么被看见**上翻译一层。**

| 不覆盖 | 说明 | 依据到哪一步 |
|---|---|---|
| **他自己大学怎么被看见的** | 只有 PPT 那一条，缺完整过程 | 讲一次「因为某个技能被重要的人注意到」的经历 |
| **学生的场景** | 现在全是平台流量逻辑，缺班级、社团、实验室里的场景 | 问他：学生没有账号，怎么让老师记住 |
| **失败的案例** | 缺「装过头翻车」的反例 | 问他见过谁因为包装翻车 |
| **标签怎么选** | 缺具体方法 | 问他如果给一个普通大二学生建议，让他练什么 |

**现在 5 条，讲「怎么做短视频」够用，讲「大学生怎么被看见」要补。**

## 七、和其他主题的关系

```
表达与个人IP 表达与个人 IP（杠杆层）
 ├─ 资源分配与个人定价 资源分配：能力要能被观测，才能被定价
 ├─ 榜样与模仿：先模仿，再形成自己的标签
 ├─ 大学案例复盘 大学案例：每一次露脸都是一次案例
 └─ 意义与选择：想成为谁，决定你选什么标签
```

**这一块是放大器，不是发动机。** 它能把你的能力放大 10 倍，也能把 0 放大成 0。

> ⚠️ **给建议时的顺序不能反**：先问「你有什么」，再谈「怎么让人看见」。**先谈包装的人，最后都会变成只会包装的人。**
