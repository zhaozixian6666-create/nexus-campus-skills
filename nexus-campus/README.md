## 这是什么

你问它一个大学里的问题，它不给鸡汤、不给「要努力」「要平衡」，它给你三样东西：

**一个判断、一条依据、这周能做的第一件事。**

它覆盖八类问题：学业、升学（保研考研留学）、竞赛、就业、赚钱、人际、成长、专业与院校。
再加一类：**"值不值"型的问题**（读大学值不值、内卷有什么意义、AI 会不会让我白学）——这类不给操作，给判断。

**它不是问答机器人，是决策系统。** 差别在于：问答机器人负责让你听懂，它负责让你知道下一步该干什么。

## 装好之后你能做什么

不用记命令，正常提问就行。八种真实用法：

**① 判断一件事该不该做**

```
我大三，双非，专业排名 20%，想保研但不知道还有没有戏
```
它先看窗口关没关（制度层），再看值不值得押（认知层），最后给你这周该干的第一件事。

**② 把一句问不出来的话，变成能回答的问题**

```
我该考研还是就业
```
它会先说这句问错了——考研是三年后的事，就业是半年后的事，两个时间尺度不能直接比。

**③ 拆一个让你焦虑但说不清结果的词**

```
现在什么都在内卷，卷绩点还有意义吗
```
它先拆"内卷"：你说的是竞争激烈、努力没回报、还是不知道在争什么？**这三个是完全不同的问题，药方也完全不同。**

**④ 写一份要交出去的东西**

```
帮我改这段个人陈述，这是在申请奖学金用的
```
先确认这份材料要完成什么，再排结构，再改句子，最后过一遍风险。

**⑤ 知道自己该做，但就是动不了**

```
我知道该学，但每天打开电脑就开始刷视频
```
先排掉睡眠、能力、环境、临床四个前提，再判断是哪一种卡住（六种形态），给今天能做的一步。

**⑥ 查一条规则到底怎么规定的**

```
我们学校保研资格到底要什么条件
```
**它不给数字，给查法**——该看哪三份文件、搜什么词、哪句话是关键。

**⑦ 复盘一次失败**

```
挑战杯省赛被刷了，队友说是因为 PPT 做得不好
```
不让你停在"PPT 不好"这种结论上，拆到决策点：哪一步判断错了、下次改哪个动作。

**⑧ 迷茫，但说不清迷在哪**

```
我觉得我大学白过了
```
不急着安慰，先把这句话拆成三种可能（没作品／没方向／没被看见），问一个问题定位，再往下走。

## 快速开始

**第 1 步：装**

把 `nexus-campus` 整个文件夹放进 skills 目录。不需要依赖、不需要跑脚本、不需要联网。

```bash
# macOS / Linux
~/.workbuddy/skills/nexus-campus/

# Windows
C:\Users\<你>\.workbuddy\skills\nexus-campus\
```

**第 2 步：直接提问**

不用输入任何命令。把卡住的事发过去就行，信息不全也没关系。

**第 3 步：在同一个对话里接着说**

拿到结论后直接补事实、说"不对"、或者追问"凭什么"。不用重新组织语言，也不用重开对话。

## 它和别的 AI 有什么不一样

三件事，别的 Skill 很少同时做到。

### 1. 它先审问题，再答问题

大部分 AI 你问什么它答什么。这个不是。

你问「我该考研还是就业」，它会先说：**这个问题问错了**——你在拿两个完全不同的时间尺度做比较，考研是三年后的事，就业是半年后的事。

> 问题放错位置，答案再正确也没用。

### 2. 它有判断，而且分得清是哪一类

库里的每个判断分四类，**分开标注，不许混**：

| 类型 | 怎么认 | 有多硬 | 对外能怎么说 |
|---|---|---|---|
| 原话记录 | 说过的话，能对上时间 | 说过就是说过 | "我一直这么说" |
| 团队方法判断／学术共识 | 依据里写学科 | 通用，不对人 | "这是我的判断" |
| 客观规则 | 标年份 + 查证入口 | 硬，但校校不同 | "规定是"，并补"以本校当年文件为准" |
| 换处境的边界判断 | 判断层，每条带边界 | 只能当参考视角 | "按这套方法推是这样" |

**它不会把「我觉得」说成「事实」，也不会把别人的话算成自己的。**

### 3. 它写着「这块我不会」

**这是最不一样的地方。**

每一份模块文件的末尾都有一张边界表：

```
| 不覆盖 | 怎么处理 | 说明（不阻塞当前使用） |
| 真实学业案例 | 刻意不写 | 说法停在「这是我的判断」，不会编成「我那年也这样」 |
| 不同学校层次的差异 | 刻意不写 | 985/211/双非结论不同，判断要分叉 |
```

**但没有一项是「不能答」——它们只影响说得多厚，不影响说得对不对。**

绝大部分 AI 产品会隐藏弱点。这个反过来——**它把边界摊开给你看**。因为一个在你不懂的领域用「可能」「一般来说」糊弄你的 AI，比一个说「这个我不知道，你去查 XX」的 AI，危险得多。

## 它怎么安排

六个层，一条主链，一个侧镜。

```
方法（想清）→ 能力（判断）→ 制度／认知（依据）→ 表达（说出来）
                                    ↑
                              判断（换个处境）
```

**顺序反了，就会变成「话术很好但没内容」。**

| 层 | 管什么 | 什么时候进 |
|---|---|---|
| **方法** | 这个问题该不该这么问、这句话该不该信、这个人为什么不动 | 问题本身有毛病，或卡在执行 |
| **能力** | 八类大学生活具体怎么办 | 问题成立、材料够，要落到行动 |
| **制度** | 规则上还来不来得及、条件够不够 | 他问"还能不能""要什么条件" |
| **认知** | 该不该、值不值、为什么 | 他问"凭什么""这值不值" |
| **表达** | 怎么把它说出来、写出来、讲出来 | 他要交东西、要站着讲 |
| **判断** | 换个处境，这个道理还成不成立 | 主链给的角度太旧或太满 |

**判断层不在主链上，是侧面的对照镜。** 主链能答的，不必翻它。

### 关于体量：它不需要一次读完

2.4 万行看着吓人，但**没有人需要读完它**。它的工作方式是**查字典，不是读小说**：

- 你问一个问题 → 它只读 `SKILL.md`（523 行）+ **一个**模块文件
- 只有那个模块判定不够时，才去翻对应的制度或认知层
- 表达层、方法层多数时候根本不打开

所以一次真实调用的量大概是 **1,000–1,500 行**，不是 2.4 万行。

> 上面的数字由 `scripts/gen_catalog.py` 从实际文件算出，并写进 `00_全目录.md`。两者不一致时**以 `00_全目录.md` 为准**。

**每一份文件在 `00_全目录.md` 里都有一句话说明它是干什么的。**

## 它不会做什么

这几条是硬的，不是谦虚：

| 你问 | 它怎么回应 |
|---|---|
| **规则怎么规定**（转专业窗口、保研资格构成、选调条件、档案去哪） | **给规则结构 + 去哪查**。这些是全国通行的框架，写清了才有用 |
| **具体某校的名额、分数线、今年加多少分** | **不给数字，给查法**。这些年年变、校际差十倍，给错会害人 |
| 临床心理问题（持续低落、自伤念头） | 明确建议找专业帮助，不替代医生 |
| 日常心理困扰（焦虑、感情、家庭、内耗） | 按心理学框架疏导：先解心结，再给行动路径 |
| 替你决定人生 | 给判断、给代价、给下一步，**决定权在你** |
| 编一个案例让判断显得可信 | **一次都不会**。宁可说"这块我没有" |

## `0.2` 是什么意思

**这个版本号是认真的，不是谦虚。**

没到 1.0，因为结构还在长——判断在加、边界在收紧、材料在补。0.x 阶段只有一条约定：**升级前先看 `CHANGELOG.md`**，次版本可能动结构。

有一条原则从第一版起没变过：

> **不需要真实案例来支撑每一个判断。只有结论也能解决问题。唯一不许的是假案例。**
> **宁可薄，不可假。**

所以它不会为了显得丰满而编一个「我有个学员」。**它宁可说这块不给，也不编一个听起来合理的故事。**

**所以它的正确用法是：拿它当第二个脑子，不是当标准答案。**

它给你一个你没想过的角度、一个能验证的动作，然后你去试。试完回来说「这条不对」，它才会变好。

## 几个常见问题

**装完不触发，答得像没读过？**

`SKILL.md` 要在 skill 目录的根层，和 `capabilities/`、`method/` 这些文件夹平级，不能再套一层文件夹。放错层级是最常见的原因。

**能用在我用的 AI 上吗？**

能。整套是纯 markdown，不联网、不连数据库、不装依赖。任何能读文件的模型或 Agent 都可以——告诉它「先读 SKILL.md 再回答」就行。

**它会不会替我编数据？**

规则上不许，而且写死在文档里：分数线、名额、加分细则一律给查法不给数字；没有真实案例时宁可留空，不编故事。这条你可以拿去检验它。

**`案例图文引擎/` 是什么？要装吗？**

把内容排成图文再导出的工具，需要 Node.js 和 Playwright。不做图可以完全不管它，删掉也不影响其他部分。

**以后更新了怎么升级？**

覆盖整个目录即可。如果你改过里面的文件，先把自己那份备份出来——覆盖会全部替换。

## 它答不了的，可以来问我

这套东西解决的是「有判断框架、只是没想清」的问题。有三类它帮不上：

| 你的情况 | 为什么它帮不上 |
|---|---|
| 说不太清自己卡在哪，需要有人对着问几句 | 它不会追问到那个程度，得有人接话 |
| 简历、材料、PPT 已经写完了，要有人逐页挑毛病 | 它给结构，不给逐页的红笔 |
| 要的不是一个判断，是有人盯着你推进几个月 | 它没有记忆，也不会在你不找它的时候找你 |

这三类我在群里和一对一接。

- **免费**：答疑群，日常问题直接问
- **付费**：单次深聊、材料逐页诊断、长期陪跑，形式和价格以群内公告为准

入口和边界都写在 [服务与答疑.md](服务与答疑.md)。
