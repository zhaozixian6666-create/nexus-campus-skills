# 使用说明

> 这份写给第一次用它的人。读完大概 5 分钟。
> 只想快点开始的话，看第一节就够了。

---

## 一、第一次怎么用

**第 1 步：直接说你现在卡住的事。**

不用先想"我该用哪个模块"，也不用准备材料。一句话就行：

```
我大三，双非，专业排名 20%，想保研但不知道还有没有戏
```

**第 2 步：它会先判断，再回答。**

如果问题本身有毛病（比如"是不是只有 985 才有出路"），它会先说清哪里有问题，把问题改写成能回答的，再答。
如果缺关键信息（年级、目的、手里已有什么），它会只问那一项，不铺一堆问题。

**第 3 步：在同一个对话里接着说。**

拿到结论后直接补事实、说"不对"、或者追问"凭什么"。不用重新组织语言，也不用重开对话。

---

## 二、它能接住什么

八类问题，每类给一个真实问法：

| 类别 | 真实问法 |
|---|---|
| **学业** | "高数挂了一次，重修还来得及吗" "选课怎么选才不吃亏" |
| **升学** | "排名 20% 保研还有戏吗" "考研还是工作，我拿不定主意" |
| **竞赛** | "大创和挑战杯该打哪个" "组里就我一个人干活怎么办" |
| **就业** | "没有实习经历，秋招是不是没救了" "简历上这段经历该怎么写" |
| **赚钱** | "学长拉我做一个项目，要不要投钱" "这个兼职一小时 30 值不值" |
| **人际** | "室友天天打游戏到两点" "导师一直不给我反馈" |
| **成长** | "不知道自己想干什么" "知道该努力但就是动不了" |
| **专业与院校** | "我这个专业到底有没有前景" "要不要转专业" |

**另外还有一类，问的不是"怎么做"，是"值不值"：**

"读大学到底值不值" "内卷有什么意义" "AI 会不会让我学的东西白学" "怎么才能被人看见"

这类不归上面八类管，走的是"认知层"——给的是判断和依据，不是操作步骤。

---

## 三、三层知识怎么分工（最容易混的地方）

库里同时有三类东西，回答的问题完全不同。**分不清这个，就会觉得"怎么一会儿讲规定一会儿讲道理"。**

| 层 | 回答什么 | 举例 | 说错了会怎样 |
|---|---|---|---|
| **制度层** | 规则上还来不来得及、条件够不够 | "推免名额怎么算""转专业什么时候截止" | **害人**——按错的规则准备一年 |
| **认知层** | 该不该、值不值、为什么 | "读研到底是投资还是消费""为什么要卷绩点" | 说服力下降 |
| **判断层** | 换个处境，这个道理还成不成立 | "你努力了没用，可能是定价错了，不是不够努力" | 视角偏，但不会害人 |

**它们经常一起用，顺序不能反：**

先用制度层看"窗口关没关"，再用认知层看"值不值得进这个窗口"。

反过来的结果是：你花十分钟听它讲"这条路值不值"，最后发现报名上周就截止了。

**还有一层是"方法"，不属于任何领域：**

审命题、拆概念、改问题、诊执行、自学、对标、决策档案、目标清晰化、任务澄清、知识库、协作、溯源、多视角。

这些是"通用工具"，任何领域卡住时都可能用到。它不会每次都上，只在信号出现时调一个。

## 四、七个常见场景怎么串

单问一句，它答一句。但真实的问题往往要串几个动作。下面七个是最常遇到的。

### 1. 完全不知道自己要干嘛

```
他说"我很迷茫"
  → 先收窄：迷茫有三种，不知道方向 / 不知道方法 / 知道但做不到
  → 如果是方向：进成长模块，用「意义与选择」拆"你想要什么"
  → 拆出来一个具体目标 → 用「目标清晰化」把它变成能指物的句子
  → 再看这个目标卡不卡规则（进制度层核对窗口）
```

**卡点**：多数人停在"我很迷茫"就不往下走了。真正的动作是把它变成一个能回答的问题。

### 2. 要不要考研／保研／工作

```
他说"我该不该考研"
  → 先用「提问法」改写：不是"该不该考研"，是"我要的那条路卡不卡学历"
  → 用「任务澄清」问：我雇考研完成什么（躲就业？换城市？进体制？）
  → 是正经需求 → 进制度层看四条路的窗口和门槛
  → 再进认知层看"读研这事值不值"（学历投资与回报）
  → 定下来 → 用「决策档案」立案，写下预期和"什么情况下我承认判断错了"
```

**卡点**：直接问"考研难不难"的人，通常还没想清为什么要考。

### 3. 要打一个比赛

```
他说"大创值不值得打"
  → 先问目的：为了保研加分、为了简历、为了学东西、还是为了钱
  → 目的不同，结论完全不同（同一件事对不同目的的人价值不同）
  → 进竞赛模块看赛制，进制度层看本校加分规则
  → 定了要打 → 用「对标法」找值得学的往届作品
  → 组队、材料、答辩 → 用「结构与开场」和「讲进去」
```

**卡点**：先问"哪个比赛容易获奖"的人，通常会被赛事名单带着走，最后打了对保研没用处的赛。

### 4. 要交一份东西，或者要站着讲

```
他要写论文／报告／申报书／简历
  → 「任务澄清」：这份材料要完成什么（过审？打动人？证明能力？）
  → 「目标清晰化」：一句话主张是什么
  → 「结构与开场」：排骨架、定顺序
  → 「写清楚」：写句子，落地抽象词，去 AI 味
  → 要口头讲 → 「讲进去」：听众只带走一样，具体打败抽象
  → 「风险与边界」：过一遍发布风险
```

**卡点**：直接开始写第一句的人，通常写到一半发现结构不对，全部重来。

### 5. 想赚钱，但分不清机会和坑

```
他说"学长拉我做个项目，投五千块"
  → 先不判断项目，先判断"这笔钱亏了会不会影响生活"（代价）
  → 进赚钱模块：查防骗与红线，看它属于哪一类模式
  → 用「命题审查」看对方给的理由站不站得住
  → 判断要试 → 定一个"最多亏多少、多久验证"的界限
```

**卡点**：先问"这个项目靠不靠谱"的人，通常已经在心里决定要做了，只是想要一个同意。

### 6. 知道该做，但就是动不了

```
他说"我知道该学但学不进去"
  → 先排掉四个前提：睡眠够吗 / 能力够吗 / 环境行吗 / 有没有临床问题
  → 都排掉了 → 「执行诊断」：六种形态里是哪一种
      完美主义？用思考替代行动？方向跳跃？知识上瘾？归咎外部？回避正解？
  → 认形态，再猜动机（顺序反了会误判）
  → 给今天能做的一步
```

**卡点**：一上来就归因"我懒""我不自律"的人，通常诊断错了，所以怎么努力都没用。

### 7. 想查一条具体规定

```
他问"我们学校保研要什么条件"
  → 不报数字，报到哪查（三份文件：教务处 / 学院 / 当年推免办法）
  → 给制度层对应节点，讲通用框架（四个硬门槛）
  → 明确说"以本校当年文件为准"
```

**为什么不能直接给数字**：同一个"前 30%"，985 和四非、东部和西部口径完全不同。给错一个数，可能让人白准备一年。

## 五、它不会做什么

这几条是硬的，不是谦虚：

- **不报具体学校的政策原文、分数线、报名截止时间、报录比**——这些每年变，给了就是害人，只给查法
- **不做临床心理治疗**——持续低落、自伤念头这类明确转介专业帮助
- **但日常心理困扰会认真接**——焦虑、感情、家庭、内耗、知行不一，按心理学框架先解心结，再给行动路径。行动力差很多时候根子在心里，只给路径是治标
- **不替你决定人生**——考研还是工作、转不转专业，它给两条路的代价，不替你选
- **不编数字、不编案例、不编"我有个学员"**——宁可说"这块我没有"，也不编一个听起来合理的故事
- **不因为"看起来专业"而堆术语**——理论只在内部用来判定，不摆到台面上

## 六、用久了会发生什么

**它会记住你在这个对话里说过的事实。** 换个话题时不用重复年级、专业、排名。

**它会越来越省你的时间。** 第一次用可能要来回两三句，第五次你直接说"又遇到上次那种情况"，它就知道该往哪走。

**它不会因为你问得多就变得更好。** 它不会学习你的偏好，也不会记住跨对话的事——每次新对话都是重新开始。

> 所以重要的结论自己存一份。库里有「决策档案」这个动作，专门用来做这件事。

## 七、现在缺什么（这份清单是公开的）

**说清缺什么，比假装完整更有用。**

| 缺的 | 影响 | 现状 |
|---|---|---|
| 真实学生案例 | 说法只能停在"我的判断"，讲不成"我那年也这样" | 不影响用 |
| AI 时代那块的具体打法 | 只给框架，不给操作细节 | 框架能用，细节不写 |
| 竞赛的实战细节（组队、答辩现场） | 选赛够用，打赛时参考少 | 制度层有规则，实战不写 |
| 具体学校的内部规则 | 只能给通用框架 + 查法 | **这块永远不会补**——各校不同，给了就是错 |

**这些是加分项，不是门槛。** 没有它们，库里现有的判断仍然能给出可用结论——因为一个判断能不能解决问题，取决于它准不准、边界清不清楚，不取决于它有没有配一个故事。

## 八、想改它、想续它

库里所有内容都是纯 markdown，没有数据库、没有编译，任何编辑器都能打开。

| 你想做的 | 怎么做 |
|---|---|
| 加你自己的判断 | 写进对应主题的第五节，标来源和日期 |
| 加一条学校规则 | 写进 `knowledge/制度/` 对应文件，标年份、标查证入口 |
| 换掉不认同的判断 | 直接改，但**把「什么时候不成立」那句一起改**——只留判断不留边界，就成话术了 |
| 加一个新领域 | 在 `capabilities/` 下新建，frontmatter 写清 `配套知识` 指向哪几份 |

**一条规矩**：加东西的时候，先问一句——**这条判断的边界在哪？**

- 团队自己的方法判断 → 标"团队判断"
- 官方规定 → 标年份 + 查证入口
- 讲换处境还成不成立的 → 标"边界判断"，每条都带适用条件
- 说不清边界的 → **不要写**
