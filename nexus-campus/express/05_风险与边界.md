# 05 · 风险与边界

> 用途：发帖前、发言前、用 AI 写作业前——判断这件事最坏的后果是什么，我承不承担得起。
>
> **大学里很多代价，不是来自能力不足，是来自一次没想清后果的表达。**

---

## 一、这个模块解决什么

四种高频踩坑场景：

> ① 在群里吐槽老师，被截图传出去
> ② 竞选演讲时承诺了一件做不到的事，当选后被追着要
> ③ 用 AI 写了一篇课程论文，被查重或 AIGC 检测查出来
> ④ 参加比赛时用了网上的图，被指抄袭

**这四件事的共同点**：做的时候觉得"没什么"，出问题的代价却很大（处分、失去信任、比赛资格取消）。

**这个模块做的事：给一套发之前的检查清单，让"没什么"变成"我算过"。**

**它不负责让你变得谨慎到不敢说话。** 它负责让你**在能承受的风险上放开，在承受不起的风险上收手**。

---

## 二、核心判断

### 判断 1：风险 = 概率 × 后果，先看后果能不能承受

大多数人只估概率（"应该不会有人截图吧"），不算后果。

**正确的算法**：

```
风险 = 这件事被发现的概率 × 被发现后的后果
```

**关键**：**概率低但后果不可承受的，一律不做。**

| 场景 | 概率 | 后果 | 判断 |
|---|---|---|---|
| 群里吐槽老师 | 低 | 中（关系受损、可能影响评优） | 可做，但换措辞 |
| 论文抄一段 | 低 | **不可承受**（处分、记录、影响保研考研） | **不做** |
| 比赛用网图不标来源 | 中 | 高（取消资格） | 不做 |
| 朋友圈发一句对实习公司的不满 | 低 | 中高（可能影响未来背调） | 慎做 |

**规则**：**先问"最坏会怎样"，再看"多大概率"。** 顺序反了会做错决定。

### 判断 2：书面留痕的风险，比口头高一个量级

同一句话，说出来和写下来，风险完全不同。

| 形式 | 可传播性 | 可追溯性 | 风险 |
|---|---|---|---|
| 当面说 | 低（只有在场的人知道） | 低 | 低 |
| 语音 | 中（可录音） | 中 | 中 |
| **文字（微信/群/帖子）** | **高（一键转发、截图）** | **高（永久保存）** | **高** |
| 公开平台发帖 | 极高（可被搜索、被搬运） | 极高 | **最高** |

**规则**：**情绪化的话用嘴说，不用手打。**

**因为文字有两个特性**：能被截图（脱离语境）、能被搜索（三年后还在）。

**具体做法**：

- 有情绪时，**打电话或当面说**，不要发文字
- 一定要发文字时，**先存草稿，第二天再看**
- 群里讨论敏感话题时，**默认"这段话会被截图"**

### 判断 3：AI 的用法有明确的边界，不是灰色地带

**三条线，很清楚**：

| 用法 | 判定 | 说明 |
|---|---|---|
| **辅助**：查资料、理思路、改语法、生成大纲、解释概念 | ✅ 可以 | 相当于用搜索引擎 + 词典 + 一个耐心的助教 |
| **代写**：让 AI 写完整段落/整篇，直接交 | ❌ **不行** | 这不是"用工具"，这是"不是我写的" |
| **洗稿**：AI 生成后改几个词、调一下语序 | ❌ **不行，且更糟** | 因为你还多了一层"试图掩盖" |

**为什么"洗稿"更糟**：代写是"我偷懒"，洗稿是"我偷懒并且试图骗过检查"。后者一旦被发现，性质不同。

**判断标准（很好用）**：

> **这段内容，如果老师当面问我"这句为什么这么写"，我能解释我的思考过程吗？**

- 能（是我先想了，AI 帮我表达） → 可以
- 不能（我根本不知道这段在说什么） → 不行

**注意**：不同学校、不同课程的规定不一样。**有些课明确禁止任何 AI 使用**。**先看课程要求，再按上面的标准。**

### 判断 4：学术诚信不是规则问题，是能力问题

很多人把"不能抄"理解成"老师不让"。

**更根本的理由是**：**代写和抄袭，让你失去了唯一能获得能力的环节。**

写作这件事的价值，80% 在"想清楚"的过程里，20% 在成文。**让别人（或 AI）替你想，你只拿到了那 20%。**

**具体后果**：

| 短期 | 长期 |
|---|---|
| 交上去了，没人发现 | 这门课的核心能力没建立 |
| 分数还不错 | 答辩/面试被问就露 |
| 省了三小时 | 下次遇到同类问题还是不会 |

**这条判断的实际用途**：当你犹豫"要不要用 AI 写完这一篇"时，问自己一句：**我是想交差，还是想学会？**

两个答案都合法，但**选了交差，就要承担"没学会"的后果**——而这个后果通常在两年后才出现（考研复试、面试、毕业设计）。

### 判断 5：发言前问三个问题

**这三个问题是这个模块最实用的工具。**

| # | 问 | 如果答案是"会/是/承受不了" |
|---|---|---|
| 1 | **这段话，如果被截图发到我不想让它去的地方，我还站得住吗？** | 改措辞，或者不说 |
| 2 | **三年后我再看这段话，会不会后悔？** | 存草稿，明天再看 |
| 3 | **最坏的后果，我承担得起吗？** | 不做 |

**注意第 1 问的措辞**：不是"会不会被截图"，是"**如果**被截图"。因为前者你在赌概率，后者你在算后果。

### 判断 6：沉默也有代价，不要把"安全"做成"不表达"

这个模块很容易被用成"什么都别说"。

**但沉默的代价是真实的**：

- 该争取的机会没争取（不敢问老师、不敢竞选、不敢提意见）
- 该指出的问题没说（团队方向错了，你憋着）
- 该建立的形象没建立（四年没人知道你擅长什么）

**区分标准**：

| 该说 | 不该说 |
|---|---|
| 对事：这个方案的漏洞在哪 | 对人：这个人不行 |
| 有证据：我查到数据是 X | 凭感觉：我觉得他就是在装 |
| 有场合：在会上提、私下提 | 无场合：在群里公开嘲讽 |
| 有方案：我建议改成 Y | 只抱怨：这破事没法弄 |

**规则**：**说"事"不说"人"，带"证据"不带"情绪"，找"场合"不找"观众"。**

## 三、操作流程

### 发之前：四步检查

#### Step 1：定传播范围

```
这段话可能被谁看到？
- 只在场的几个人
- 整个群（几十人）
- 会被转发（不可控）
- 公开可搜索（永久）
```

**默认假设范围比你预期的大一级。**

#### Step 2：算最坏后果

```
最坏会怎样？
（关系破裂 / 评优取消 / 处分 / 比赛资格取消 / 影响升学就业）
这个后果我承担得起吗？
```

**"承担不起"的一票否决，不管概率多低。**

#### Step 3：改写（如果决定要发）

**三种改写法**：

| 问题 | 改法 |
|---|---|
| 有情绪 | 去掉情绪词，只留事实 |
| 指向人 | 改成指向事 |
| 有绝对化 | 加限定（"这次""在这个情况下"） |

**例**：

> ❌ "这门课的作业安排得莫名其妙，老师根本不管学生死活。"
> ✅ "这门课三次作业的截止日只隔两天，和另外两门课撞了，我担心质量会下降。想问问能不能延后一周。"

**后者同样表达了不满，但它是"可以解决的问题"，不是"攻击"。**

#### Step 4：存草稿，隔一夜

**情绪化内容强制隔夜。** 第二天再看，80% 你会改，20% 你会不发。

### 用 AI 之前：三问

```
1. 这门课/这个老师，对 AI 的规则是什么？（先查，不要猜）
2. 我要 AI 做的是"辅助"还是"代写"？（按判断 3 的三条线）
3. 这段内容，老师当面问我，我能解释吗？
```

**第一问最容易被跳过。** 有些课明确禁止，用了就是违规，不管你用得多么"合理"。

### 引用别人内容时：三查

| 查什么 | 怎么做 |
|---|---|
| **出处** | 图片、数据、观点，来源在哪？（网址、书名、页码） |
| **授权** | 是公开可用、需授权、还是禁止使用？（比赛规则、课程要求） |
| **标注** | 引用格式对吗？（不同场合要求不同） |

**规则**：**拿不准就用自己拍的、自己做的、明确标注可商用的。**

## 四、大学场景实例

### 实例 1：群里吐槽老师

**原始想法**：
> "这老师讲课就是念 PPT，一节课啥也没讲，浪费我时间。"

**四步检查**：

| 步 | 结果 |
|---|---|
| 传播范围 | 班级群 80 人，**可能被转发给老师**（有人要讨好老师） |
| 最坏后果 | 老师知道 → 影响平时分、影响以后要推荐信 |
| 承担得起吗 | **承担不起**（推荐信是我要的） |
| 改写 | 不说，或者改成**建设性的提问** |

**改写版**（对班委说，或课后私下问老师）：
> "老师，这几节课的内容和教材重合度比较高，我在课上看完了教材。能不能多讲一些例题或者您的研究案例？"

**差别**：后者是**可解决的问题**，前者是**情绪宣泄**。

### 实例 2：用 AI 写课程论文

**场景**：明天截止，还有 3000 字没写。

**三问**：

| 问 | 答 |
|---|---|
| 这门课规定？ |  syllabus 里写"允许使用 AI 辅助，但需在文末说明用途" |
| 辅助还是代写？ | 如果让 AI 写完整段落 → **代写** |
| 能解释吗？ | 不能 → 不行 |

**正确做法**：

```
1. 自己先列提纲（这是核心思考，不能省）
2. 每段自己写 2-3 句核心观点
3. 用 AI 帮忙：把口语化的句子改通顺、检查逻辑漏洞、找反例
4. 文末按要求说明：本文使用 AI 进行语言润色和逻辑检查，观点与结构由作者完成
```

**为什么这个做法是对的**：**思考过程是你的，表达借助了工具。** 这两件事可以分开。

### 实例 3：比赛用了网上的图

**场景**：做 BP（商业计划书），从网上找了一张行业数据图放进去了。

**三查**：

| 查 | 结果 |
|---|---|
| 出处 | 某公众号文章，没标原始来源 |
| 授权 | 不明 |
| 标注 | 没有 |

**风险**：评审发现 → 认定为"数据来源不明"或"抄袭"，直接扣分甚至取消资格。

**正确做法**：

```
1. 找到原始数据源（统计局、行业协会、券商报告），自己重画
2. 找不到原始源的，在图上标"数据来源：XX（转引自 XX），未经原始核实"
3. 实在找不到的，不用这张图，用自己调研的数据代替
```

**第 2 条很重要**：**标注"未经核实"不会扣分，假装它是权威数据才会。**

### 实例 4：竞选承诺

**场景**：竞选学生会部长，想说"我会让每个部门都有活动经费"。

**三个问题**：

| 问 | 答 |
|---|---|
| 被截图？ | 会，竞选海报可能被留档 |
| 三年后看？ | 会觉得当时很天真 |
| 承担得起？ | **承担不起**——做不到会被追着要，反而失信 |

**改写**（承诺可控的事）：

> "我不能承诺给每个部门加经费，因为预算不在我手里。
> 我能承诺两件事：
> ① 每月 1 号把本月预算明细发到群里，谁都能看到钱花在哪
> ② 每个部门申请经费，我保证 3 天内给答复，不能批的说明原因
> 这两件事我现在就能做，做不到你们可以换掉我。"

**规则**：**承诺"我能控制的事"，不承诺"结果"。**

## 四·五、要发出去的东西：两条线分开看

前面六条判断讲的是「这件事该不该做」。这一节讲一个更具体的场景：**一段话、一张图、一条视频，已经写好了，要发出去。会不会出事？**

大学生发东西的场景比想象中多：朋友圈吐槽、社团推文、竞选发言、班级群通知、自己的账号、给老师发的邮件、参赛材料。

### 判断 7：风险有两条线，混在一起就判不准

**这是这一节的核心。绝大部分人把两条线混成一条，于是要么过度紧张，要么完全没看见。**

| | 第一条线：**机器/规则会识别什么** | 第二条线：**内容本身有没有问题** |
|---|---|---|
| 谁在判 | 平台的自动审核、学校的排查、辅导员的搜索 | 当事人、看的人、将来可能追责的人 |
| 判什么 | 关键词、外链、二维码、可识别信息、连续数字、截图 | 有没有侵权、有没有编造、有没有泄露隐私、有没有做出承诺 |
| 误判多不多 | **非常多**。正常的讨论也可能被召回 | 少。这一条基本按事实判 |
| 怎么处理 | 换个说法、去掉标识、加一句说明 | 改内容，或者干脆不发 |

**混在一起的后果**：

- 只看第一条线 → 把「正常的观点表达」也删了，人变得不敢说话
- 只看第二条线 → 发出去被平台拦了、被学校找了，还觉得自己没错

**正确顺序：先看第二条线（有没有真问题），再看第一条线（会不会被误伤）。**

### 判断 8：第一条线上，最该查的是「可识别信息」，不是敏感词

学生以为风险在"敏感词"。**实际上大学生发东西最容易出事的地方，是把自己和具体的人暴露出来。**

发的每一条内容，先过这张表：

| 会暴露什么 | 具体形态 | 后果 |
|---|---|---|
| **你是谁** | 学号、班级群截图、校园卡、宿舍门牌、课表截图（有课程和教室） | 学校一搜就能定位到你 |
| **说的是谁** | 老师全名 + 学院 + 课程、同学全名、辅导员的原话 | 从"吐槽一件事"变成"针对一个人"，性质完全不同 |
| **在哪** | 宿舍号、实验室号、定位、背景里能认出的建筑 | 同上 |
| **内部信息** | 未公开的评奖名单、群里的通知截图、还没发布的成绩 | 这一条最容易踩，因为转发的人觉得"这不是秘密" |

**一条极实用的规则：**

> **截图之前，先问一句：这张图里有没有一个东西，能让别人找到具体的人？**
> 有，就裁掉。

**注意**：这条不是说不能吐槽。**是说吐槽一件事，和指名道姓地说一个人，是两件事。**

### 判断 9：第一条线上，「词面命中」不等于「内容违规」

这一条能救回大量被自己吓死的人。

平台的机器是按词召回的。**一个词被召回，只说明它进了检查队列，不说明它有问题。**

| 情况 | 机器可能怎么处理 | 内容实际有没有问题 |
|---|---|---|
| 讨论某个品牌、某款产品 | 可能进名单召回 | 正常讨论，没问题 |
| 提到某个专业术语、药名、疾病名 | 可能被标 | 科普，没问题 |
| 用了"封""挂""翻"这类词 | 可能被误读 | 看完整语义 |
| 一条正常的经验分享里带了一个外部链接 | **很可能直接被限流** | 内容没问题，是形式问题 |

**所以对第一条线的正确态度是**：知道它存在，做技术性规避（换说法、去链接、去二维码），**但不要因为机器可能误判，就把自己想说的话删掉。**

**这两件事的差别很大**：改形式 ≠ 改内容。

### 判断 10：第二条线上，五件事必须查，一件都不能省

这是真正会让事情变严重的五件事：

| # | 查什么 | 大学里的具体样子 |
|---|---|---|
| 1 | **有没有编造** | 引用了一个数据但没出处；"我听说"当事实说；把别人的经历写成自己的 |
| 2 | **有没有侵权** | 用了网上的图/音乐/字体；搬了别人的稿子；参赛作品里有别人的部分 |
| 3 | **有没有泄露别人的隐私** | 截图里有同学的聊天记录、成绩、身份证号、病历 |
| 4 | **有没有做出承诺** | 竞选时承诺"我一定给每人争取到 XX"；社团招新承诺"包分配实习" |
| 5 | **有没有冒充身份** | 用学校/学院/社团的名义发，但没被授权；把自己说成"官方" |

**五条里最容易被忽略的是第 4 条。** 因为承诺在说出口的时候是善意的，事后兑现不了才变成问题。

**第 5 条在学生做账号时尤其要注意**：以"XX 大学学长"的身份讲学校内部的事，等于给自己挂了一个身份，而这个身份会带来额外的责任。

### 判断 11：最小必要干预——只改必须改的，别顺手把锋利的部分磨掉

**这条是整节最重要的操作原则。**

查到问题之后，最常见的过度反应是：**把整段重写一遍，把有棱角的话都磨平。**

**结果**：风险没了，内容也没了。

**正确的做法是「最小必要干预」**——能用改一个词解决的，不改一句；能用删一句解决的，不改一段。

| 问题 | 最小改法 | 过度改法（不要这样） |
|---|---|---|
| 截图里有同学的名字 | 打码 | 整条不发 |
| 有一句没出处 | 加"我记得是"或删掉那个数字 | 把整段论证删掉 |
| 提到了具体老师 | 改成"某门课的老师" | 把吐槽改成正面表扬 |
| 外链可能被限流 | 把链接改成"评论区"或"主页" | 删掉整个分享 |
| 承诺太满 | 加一个条件（"在学院允许的范围内"） | 删掉所有承诺 |

### 判断 12：这些不算风险，不要自己吓自己

**必须写清楚，否则这一节会变成一张"什么都别发"的清单：**

- **强观点、偏激判断**——不是风险。观点刺人，和观点违规，是两件事
- **情绪表达**——生气、失望、兴奋，不是风险
- **夸张和修辞**——"卷死了""累成狗"，不是风险
- **口语和不规范表达**——不是风险
- **个人偏好**——"我不喜欢这个专业"，不是风险
- **批评具体现象**——不是风险。**批评一件事和攻击一个人，分界线是有没有指向可识别的个人，以及有没有编造事实**

**「更稳妥一点」「可能让人不太舒服」「这样说会不会不太好」——这三句话不能单独作为修改的理由。**

### 发之前：一张四步检查表

```markdown
**第一步：这段话/这张图里，有没有能让别人找到具体的人的东西？**
→ 有：裁掉、打码、换成"某位老师/某个同学"

**第二步：五件事查过吗？**
→ 编造 / 侵权 / 隐私 / 承诺 / 冒充身份

**第三步：形式上的雷区有没有？**
→ 外链、二维码、连续长数字、完整联系方式

**第四步：如果删掉那些"为了安全"改的地方，我想说的那句话还在吗？**
→ 不在了：说明改过头了，回去
```

**第四步是这套检查的良心。** 它的作用是防止你为了安全，把自己变成一个不说话的人。

## 五、反例与边界

### 边界 1：不要用这套把自己变成哑巴

见判断 6。**过度谨慎的代价是四年没人知道你。**

**信号**：如果你发现自己在群里从不说话、有意见从不提、有机会从不敢争——那不是"谨慎"，是**怕被看见**。

**这时候该去 `../method/04_执行诊断.md`**，看是不是 A 型（怕失败）。

### 边界 2：不是所有风险都要规避

有些风险值得冒：

| 值得冒的风险 | 为什么 |
|---|---|
| 提出一个可能被否的方案 | 被否的成本很低，不提的成本是没有机会 |
| 问一个可能显得笨的问题 | 显得笨一次，学会一个东西 |
| 竞选一个可能选不上的位置 | 选不上的成本 < 不参选的成本 |
| 指出团队方向错了 | 说出来可能尴尬，不说可能全盘皆输 |

**判断标准**：**这个风险的最坏后果，是可逆的吗？** 可逆 → 冒；不可逆 → 不冒。

### 边界 3：学术诚信没有"灰色地带"，但有"规定不同"

不同课程、不同学校对 AI 的规定不一样，**但"代写"和"抄袭"在所有地方都违规**。

**不要把"规定没说"当成"可以做"。** 拿不准就问老师——问一句的成本是零，出事的成本很高。

### 边界 4：不要替别人判断风险

"你别发这个，会被截图"——你自己不发的判断，不能强加给别人。

**每个人承受风险的能力不同**：有人不怕得罪人（因为他不需要那个人的推荐），有人必须小心。

**做法**：可以说"我担心这个会被截图"，但不要替他决定。

### 边界 5：这套不处理已经出事的补救

如果已经发了、已经被截图了、已经被查出来了——**这套工具帮不上**。

**那时候该做的**：立刻停止扩散、主动说明、承担后果。**不要试图掩盖**（掩盖的性质比原事件更严重）。

### 边界 6：涉及法律的问题，这一章不够

诽谤、侵权、泄密、涉黄涉政——**这些超出本模块范围**。

**规则**：涉及法律风险的，先咨询学校相关部门或专业人士，**不要靠自己判断**。

## 六、常见误用

| 误用 | 表现 | 后果 |
|---|---|---|
| **只算概率不算后果** | "应该没人截图吧" | 一次意外毁掉长期积累 |
| **情绪化发文** | 半夜在群里发泄 | 第二天后悔，已收不回 |
| **AI 代写当辅助** | "我只是让它帮我写一下" | 学术不端，且没学会 |
| **洗稿求安心** | AI 写完改几个词 | 性质更重 |
| **用网图不标源** | BP 里放别人的图 | 比赛扣分或取消资格 |
| **承诺结果不承诺动作** | "我保证让大家都有机会" | 做不到就失信 |
| **过度谨慎** | 什么都不说、不争 | 四年没存在感 |
| **替别人判风险** | "你别发" | 越界 |

## 七、和其他模块的关系

- **风险与边界是写清楚-文档与报告的守门人**：写得好、讲得好，但内容有风险，一切归零
- **风险与边界 → 命题审查**：发之前先审"我要说的这个判断站得住吗"（不实的信息 + 传播 = 更大风险）
- **风险与边界 → 协作与求助**：拒绝别人的不合理请求（包括帮你写作业、帮你背书），句式用协作与求助
- **风险与边界 → `../capabilities/06_人际.md`**：宿舍矛盾、师生冲突的具体处理在那，**风险判断**用风险与边界
- **风险与边界 → 文档与报告**：报告里的引用规范，文档与报告有具体要求，风险与边界管"风险视角"

## 八、自检

1. 这段内容**可能被谁看到**？（默认比预期大一级）
2. **最坏后果**是什么？我承担得起吗？（承担不起 → 一票否决）
3. 有情绪词吗？指向人吗？有绝对化吗？
4. 存草稿了吗？隔夜了吗？
5. 用 AI 之前，查过这门课的**规定**吗？
6. 这段内容，老师当面问，**我能解释我的思考过程**吗？
7. 引用别人的东西，**出处、授权、标注**三查了吗？
8. 承诺的是"动作"还是"结果"？
9. 有没有踩到六条边界？（变哑巴 / 什么风险都不冒 / 拿"没说"当"可以" / 替别人判断 / 处理善后 / 涉法问题）
