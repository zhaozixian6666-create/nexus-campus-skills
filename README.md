# NexusAI 子贤 · 大学版 Skill

> **一套 Skill，两个包。** 一个管大学里遇到的所有事怎么办，一个管比赛怎么打。
> 不是两套工具，是同一个判断体系的两条入口。

---

## 这是什么

大学生问 AI 最多的问题，答案不在百度里，也不在学长嘴里——它取决于**你学校怎么规定、你时间还剩多少、你手上有什么**。

这套 Skill 做的就是这件事：**先把问题问清楚，再给判断、依据和这周能做的第一件事。**

它不查资料给你看，它替你判断该怎么办。

---

## 两个包，一套

| 包 | 管什么 | 文件 |
|---|---|---:|
| **`nexus-campus`** | 大学里的八类问题：学业 · 升学 · 竞赛入口 · 就业 · 赚钱 · 人际 · 成长 · 专业与院校 | 100 |
| **`nexus-competition`** | 五类比赛怎么打：创新大赛 · 大挑 · 小挑 · 职规赛 · 三创赛 | 270 |

**为什么不拆成两个仓库**：两包之间有 20 处互相引用。大学版判断"这个比赛该不该打"之后要把人交给竞赛包，竞赛包判断"你这个项目哪里不行"时要回到大学版的表达与判断层。拆开装，引用全断，功能降级。

**装就两个一起装。**

## 里面有什么

### `nexus-campus` · 八类问题中枢

```
分诊 → 方法 → 判断 → 知识 → 能力 → 表达
```

| 层 | 文件 | 干什么 |
|---|---:|---|
| `method/` | 15 | 怎么把一个问题问对：命题审查、决策档案、思想校准、知识库自建 |
| `judgement/` | 11 | **260 条**判断，按学生原话给编号。像「我这么努力为什么没用」这种话，直接能查到对应条目 |
| `knowledge/` | 38 | 制度（竞赛认定、推免、综测的实际查法）、认知（拖延、人际、概念澄清）、原子库（50 条观点 + 216 条书摘，带检索脚本）、思想层（18 张观点卡） |
| `capabilities/` | 8 | 八类问题的具体判断：学业、升学、竞赛、就业、赚钱、人际、成长、专业与院校 |
| `express/` | 7 | 怎么说清楚：结构、语言、图的视觉规范、风险与边界 |
| `案例图文引擎/` | 8 | 把案例做成可读的图文（白底、留白、低饱和重点色，不做企业模板风） |

**知识层是可以查的，不是给你读的**。原子库带 `nexus-campus/knowledge/原子库/scripts/query.py`，能按主题、层次、场景、关键词、编号、书名检索，每次取用都留痕（命中几条、没命中）。

### `nexus-competition` · 五类比赛

| 模块 | 文件 | 说明 |
|---|---:|---|
| `01_创新大赛/` | 8 | 中国国际大学生创新大赛。含 30 页通用 / 35 页硬科技两套页序、逐页改法映射表、参考标准评分表 |
| `02_大挑/` | 5 | 挑战杯 · 课外学术科技作品竞赛 |
| `03_小挑/` | 5 | 挑战杯 · 创业计划竞赛 |
| `04_职规赛/` | 101 | 职业规划大赛。**唯一会交出成稿的模块**：生涯发展报告 + PPT 页级规划 + HTML→Word 出件 |
| `05_三创赛/` | 14 | 电子商务三创赛。含官方 PDF 原件（竞赛规则〔2026〕76 号、报名通知〔2026〕71 号）与逐项核对报告 |
| `语料/` | 126 | **90 张项目卡片**（国金 / 省级冠军 / 优质项目）+ 13 个 PPT 维度 + 4 个 BP 维度 + 跨项目共性规律 + 模拟评审题库 |

**语料是"对照物"，不是模板**。它的用法是：拿同类拿奖项目比颗粒度——人家写到了 270 吨/天、180 元/吨、锰含量 30%，你只写"处理工业废料，市场广阔"，差在哪一眼就看出来。

**规矩是比对不照抄**。取完要回来重新判断，对外不报项目名。

## 怎么开始用

装好之后，正常说话就行。它靠 `description` 里的触发词自动命中：

| 你会说 | 走到哪 |
|---|---|
| 「我大三，专业排名 20%，想保研还有没有戏」 | 大学版 · 升学 |
| 「焦虑，不知道自己在争什么」 | 大学版 · 成长 |
| 「想打比赛，不知道报哪个」 | 竞赛版 · 先分诊到具体赛事 |
| 「帮我看看这份 BP，第一页怎么改」 | 竞赛版 · 项目诊断 + 逐页改法 |
| 「帮我做职规赛材料」 | 竞赛版 04 · 六步直达（采集 → 报告成稿 → HTML→Word → PPT 规划） |
| 「三创赛怎么评分」 | 竞赛版 05 · 引官方 76 号文原件 |

安装方法见 [`安装说明.md`](./安装说明.md)。

## 它会主动告诉你"不会什么"

这是这套东西里最不常见的一点：**每个模块都写了自己的边界**，而不是只列能力。

全库总闸三条：

1. **不给政策分数线和分值**——只给查法（哪个文件、哪个附表、问哪个部门）。分数线每年每校都变，写死就是错的。
2. **不做临床心理**。持续低落、自伤念头，明确转介；日常内耗、感情、知行不一，按心理学框架解心结，再给行动路径。
3. **不替他决定人生**。给判断、给代价、给这周能做的第一件事，但选哪个由他自己定。

竞赛侧的额外红线：

| 类型 | 交付边界 |
|---|---|
| 团队赛（创新大赛 / 大挑 / 小挑 / 三创赛） | 只给结构、逐页诊断、问题清单。**不代写 BP / 论文 / 计划书** |
| 职规赛个人赛 | **唯一例外**，可出成稿。但参赛材料须真实原创，推演必须标 `〔推演〕`、缺失标 `〔待填：XX〕`，交付后附确认清单，不逐条确认不给「可提交」结论 |
| 所有赛事 | 不预测获奖概率、不报本校赋分、不把获奖与推免直接挂钩（第四届通知明文要求破除唯奖项） |
