# 竞赛线 · 大学生竞赛决策与备赛 Skill

> 版本 `0.6.5` · 2026-11 · 作者：NexusAI子贤
>
> 这是**大学版套件的第二套**。第一套是 `nexus-campus`（大学四年怎么判断、怎么办），两套平级、各自独立触发，装在一起才是一整个大学版。

**一句话**：你说要打哪个竞赛，端口先分诊，对应赛事模块给你一个判断、一条依据、这周能做的第一件事。

---

## 它解决什么问题

同学问竞赛，九成不是他嘴上问的那个问题。

> 他说：「我想打互联网+，怎么报名」
> 真问题可能是：「我不知道这个奖能换什么」
> 也可能是：「我手里没技术，硬上必输，但没人跟我说过」

所以它不顺着问题答：**先问清是哪个竞赛 → 分到对应赛事模块 → 先把目的定下来 → 再看规定允不允许 → 再看结构上值不值 → 最后才给动作。**

### 具体能答的

| 他问 | 它给 |
|---|---|
| 该打哪个赛、值不值 | 2-3 个**具体赛事名** + 每个的用途 + 查本校细则的动作 |
| 互联网+／创新大赛 | 赛道和组别、报名前必须锁死的三件事 |
| 大挑还是小挑、今年办哪个 | 年份结论 + 三项各交什么 |
| 职规赛／职业规划大赛 | 成长赛道还是就业赛道、资格自查、查本校认定的动作 |
| 队怎么组、没技术怎么办 | 四个位置／三条合法路径，指出他能占哪个位 |
| 这个赛这周该做什么 | 对应模块的行动指南（如 `competitions/01_创新大赛/行动指南.md`）里按阶段排好的动作与完成标准 |
| BP／PPT／计划书行不行 | 按页说第几页缺什么，不是「整体不错」 |
| 我和拿奖的差在哪 | 同类项目的对照卡：这一项别人写到什么颗粒度（`语料/`） |
| 答辩会被问什么 | 高频问题清单，标出他最可能答不上来的那几个 |
| 没拿奖是不是白打 | 五样产出里他至少该带走三样 |

### 三个不一样

1. **先分诊，再按赛事调用，不按功能调用。** 同学说的是「我要打互联网+」，不是「帮我诊断一下」。端口第一列是他嘴里的赛事名；进了模块才按行动指南／建议／知识库／材料骨架取料。
2. **先审问题，再答问题。** 一句「学长说绩点没用」「同学说这个赛好拿奖」，先审这句话站不站得住，再谈怎么办。
3. **每种话标明是哪一种。** 客观规定说「规定是」并补「以当届官网为准」；方法和判断说「这是我的判断」；讲边界的，说「按这套方法推是这样」。三者不混。

---

## 它不做什么

- 不承诺获奖、不预测获奖概率
- 团队赛不代写 BP／PPT／创业计划书；职规赛个人赛按「设计说明书 → 确认闸 → 成稿」两档执行，见 competitions/04_职规赛/SKILL.md
- 不报具体学校的综测分值、推免名额、评审细则原文（各校各年都变，给查法不给数字）
- 不把赛事时间当永久事实（凡提日期，一律加「以当届官网通知为准」）
- **不编案例。** 结论优先，没有真实案例照样给判断，只是把适用边界写得更死

每个赛事模块内部固定四块，可单独下载、单独触发：

```
0X_赛事/
├── SKILL.md        独立触发、四块怎么调、输出契约、必答项、红线
├── 行动指南.md      按阶段的动作与完成标准
├── 建议.md          判断集、必取材料、什么情况走这个模块
├── 知识库.md        客观规定与查法
└── 材料骨架.md      结构、逐块诊断、引导问句
```

**当前覆盖四个赛事模块**：榜单 Ⅰ 类三项（榜单口径下最高档、权重最大）+ 教育部主办的全国大学生职业规划大赛（不在榜单 Ⅰ 类里，单列一份）。Ⅱ 类赛事按份给出通用判断，见 `SKILL.md` 第八节——**不覆盖不阻塞使用**，端口会直说这份没建，走 `shared/03_选赛四刀.md` 一样能给结论。

**四项不是四种同类比赛**：前三项交的是项目、按团队参赛、回报是名次换加分；职规赛交的是本人职业路径、按个人参赛、回报是实习机会或岗位录用意向。它能不能换加分由本校细则定，所以那一份多给了一步「查本校认定」的动作。

## 输出长什么样

一律四段，顺序不换：

```
【结论】一句话，敢下判断，不用「因人而异」糊过去
【为什么】规定是什么 / 结构上为什么，两样分开说
【怎么做】这周内能动手的动作，带落点，不写「尽早开始」
【代价】他放弃的是什么；没给的材料写成条件句，不替他编
```

**台后的路由、判断集编号、归属分类，一律不出现在台前。** 用户看到的是干净的对话，不是技术流程。

## 安装

把本目录整个放进 AI 工具的 skills 目录（WorkBuddy / Claude Code 这类默认是 `~/.workbuddy/skills/`），直接问竞赛相关问题即可触发。

它和 `nexus-campus` 是平级的两套，**互不嵌套**：两个目录并排放，不要把一个放进另一个里面。

也可以只装某一个赛事模块包（例如只打创新大赛就装 `nexus-competition-innovation`），它自带 `SKILL.md`，不装端口也能独立触发。

常见触发词：互联网+、创新大赛、挑战杯、大挑、小挑、职规赛、职业规划大赛、生涯发展报告、成长赛道、就业赛道、赛道、组别、组队、BP、商业计划书、模拟答辩、评委提问、综测赋分、竞赛保研加分。
