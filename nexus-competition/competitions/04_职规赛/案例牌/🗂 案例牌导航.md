# 🗂 案例牌导航

> 19 份获奖展示材料，一份拆成一张标准卡。**用来对照，不用来抄。**

---

## 一、这一层装什么

每张牌按同一套维度拆开：基本信息 → 核心要素拆解（目标怎么立 / 岗位怎么研 / 证据怎么摆 / 框架怎么收）→ 展示拆解（分段结构表、关键页、数字表达、证据配比）→ 可迁移洞察 → 反向思考 → 标签。

格式与竞赛线的项目卡片一致，方便两代人用同一套读法。

**三层递进**：

```
单份获奖材料 → 案例牌（原子化）
                  ↓ 19 张横向比
              获奖案例方法论（共性判断线）
                  ↓ 拿来判断自己的材料
              赛事模块出结论 → 内容引擎做真材料
```

| 层 | 目录 | 给什么 |
|---|---|---|
| 对照物 | `案例牌/`（本目录） | 某一类岗位实际把重心放在哪、证据写到什么颗粒度 |
| 判断线 | 本模块同级的获奖案例方法论目录（4 份） | 获奖线在哪、每页该放什么、怎么算不合格 |
| 执行 | 本模块同级的内容引擎目录（四个子件） | 收本人事实、建证据链、写正文与逐页文案 |

## 二、怎么取

| 他问的是 | 取什么 |
|---|---|
| 「我这岗位该往哪使劲」 | 同赛道的牌，先看「证据怎么摆」和「整体结构」的页数占比 |
| 「我这种经历能不能撑起一份材料」 | 找目标职业最接近的 2–3 张，比「证据配比」一行 |
| 「PPT 排得对不对」 | 比「整体结构」表的板块顺序与重心位置 |
| 「我这页写得太虚」 | 看同位置牌的「数字表达」与「关键页」 |
| 「有没有一眼能记住的做法」 | 看「可迁移洞察」，但先确认自己有对应事实 |
| 「这份材料哪里还能改」 | 看「反向思考」，是同一类材料的常见短板 |

**找牌**：按下面索引的赛道和职业定位，不要从头翻到尾。

## 五、口径说明

1. **只收结构，不收身份**：牌里不写选手、学校、企业名称，只记可观察的框架、做法与公开数字。给结论时讲做法，不讲「某某就是这么干的」。
2. **赛道按材料归档口径归类**：CASE-03、CASE-12 的封面标注与归档文件名不一致，牌内基本信息已注明；**一律以本校当年文件与当届章程为准**。
3. **页数按原件记**：CASE-09 原件 40 页中含平台推广页与封面墙，作品本体 25 页，牌内已分别标出。
4. **奖项层级只作分类标签**：来自材料标注，不代表当届评审口径，也不构成任何获奖预测依据。
5. **数字是原文口径的提炼**：用于说明「什么颗粒度算写到位」，不是可迁移的事实，不能挪进自己的材料。

---

## 六、三条规矩

1. **比对，不照抄。** 取一张牌是为了知道「这一项该写到多细」，不是把别人的经历搬过来。
2. **取完必须回来判断。** 牌只提供对照物，结论仍然在赛事模块里出，别变成「别人这样我也这样」。
3. **不编案例。** 牌里没有的事实，不要在学生材料里补出来；学生本人的事实由内容引擎收，缺的标「待补」。

---

## 七、和赛事模块的关系

案例牌是**本赛事模块自带的对照物**，不需要装完整竞赛线也能取到；竞赛线通用语料层里按维度拆的项目卡片，是另一套资料，不在这里。

取牌之前先定赛道，取完回到四块（`../知识库.md` / `../建议.md` / `../行动指南.md` / `../材料骨架.md`）出结论；要真做材料再转内容引擎。
