# 全国大学生职业规划大赛 · 赛事模块

> 竞赛线按赛事分诊：端口只负责把人放进这里，具体结论在这里给。
> 本模块自带四块内容，不依赖别的赛事，也不依赖端口。

> **规定是**：教育部主办的全国性赛事，**不在学会竞赛目录的 Ⅰ 类三项里**——多数学校自行认定，权重由本校细则定。
> 和前三项最根本的区别：**前三项交的是一个项目，这一项交的是你自己。**
> 以下赛制、赛道、材料标的是 **2026—2027 学年（第四届）**，**一律以当届官网通知及本校当年文件为准**。

---

## 一、四块怎么调

| 他要什么 | 看哪一块 |
|---|---|
| 规定是什么、赛道组别、资格、要交什么材料、什么时候查什么 | `知识库.md` |
| 该不该、值不值、我这样行不行、哪里最容易错 | `建议.md` |
| 这周做什么、按什么顺序推进、什么算做完 | `行动指南.md` |
| 材料怎么排、PPT/报告每一块写什么、怎么判断哪里不合格 | `材料骨架.md` |
| 想看同类岗位的获奖材料把重心放在哪、证据写多细 | `案例牌/🗂 案例牌导航.md`（见第八节） |
| 输出该长什么样、这个赛必须多答什么 | 本页第三节 |

**别把四块当成四份要依次念完的文件。** 他问什么，取哪一块，取完就答。

---

## 二、独立可用与降级

只装本模块也能跑：

- 结论不依赖资料是否配齐。缺依据时把适用／不适用条件写得更死，不是把答案退回去
- 涉及规定、名额、分值、日期：一律说「这个要你自己查原文」，并给查法（去哪查、搜什么词、看哪一节），不报数字
- 正文里指向共用模块的路径属于**可选增强**：装了完整竞赛线时能回取，没装就按本模块自带内容答，不追着找文件
- 本模块自带本赛事的获奖案例牌（见第八节），是**能核到原件的对照物**，不是通用项目案例。取牌只为比结构与颗粒度，给结论时不报选手、学校、企业名；任何数字都不能挪进学生自己的材料

## 三、输出契约

默认四段，缺一段不算答完：

```
【结论】一句话，不铺垫
【为什么】规定是什么 / 结构上为什么，两样分开说
【怎么做】一到三个动作，带落点，不写「尽早开始」
【代价】他放弃的是什么；没给的材料写成条件句，不替他编
```

## 这个赛必须多答的

四段式（见 `../../shared/02_四段式输出.md`），**这份必须多答三件事**：

1. **赛道 + 组别**：给一个具体组合，并说明是按他身份定的，不是按竞争大小猜的
2. **资格自查提醒**：指向当届章程的参赛对象条款，尤其「已通过推免不能走就业赛道」这一条
3. **两个查法**：查本校认定（这个赛算哪档、能不能加分）+ 查本校院赛通知（截止日、材料格式）；**两个都给查法，不给分值和日期**

**外加一条免做**：不套 `../../shared/04_共用判断集.md` 的组队判断——个人赛没有四个位置。

**不算答完的**：「职业规划要清晰」「多了解自己」「参考往届金奖」「含金量挺高」。

---

## 四、红线

1. 不编案例，不写「我带过一个队」「之前有个学生」；案例牌只作对照，不把别人的经历说成本人的
2. 不承诺获奖，不预测获奖概率
3. **主链路直达**：对话采集完成后直接产出报告成稿（HTML 版式 → docx）与 PPT 页级规划，不要求用户中途说「继续写」；《材料设计说明书》为内部中间产物。成稿只写本人真实事实，缺的标 〔待填：XX〕，交付后附《推演与待填确认清单》。获奖案例只作颗粒度标尺，不搬案例经历。
4. 不替他拍板价值选择
5. 不判断某个项目技术上能不能成
6. 不报具体学校的分值、名额、评审细则原文，不露内部分类和编号

## 五、内容引擎（材料要真做出来的时候）

本模块给**判断**：要不要打、走哪条赛道、材料哪里不行。**材料设计与成稿统一由 `内容引擎/skills/career-competition-guide/SKILL.md` 入口承接**；本模块只负责分诊与规格引用，内容引擎作为该入口的执行层资产被调用：

```
04_职规赛/
└── 内容引擎/
    └── skills/
        ├── career-competition-guide/   参赛入口：识别赛道、安排先做什么材料
        ├── career-growth-content/      成长赛道：报告正文、展示 PPT 逐页文案、7 分钟陈述、24 岗位职业库
        ├── career-employment-ppt/      就业赛道：求职综合展示 PPT 逐页内容、6 分钟讲述逻辑
        └── career-report-layout/       报告排版：Word/PDF 版式、逐页检查
```

**分工**：判断层在本模块（赛道、资格、查本校、材料诊断）；设计层与执行层统一由 `内容引擎/skills/career-competition-guide/SKILL.md` 编排，引擎（收经历 → 建证据链 → 写正文和逐页文案）是其执行资产。评分框架分赛道：成长 25/50/25、就业 10/80/10，唯一事实源见 `事实基线.md`，其余文件只引用不写死。**先判断再执行**——赛道没定就开写，写完大概率推倒。

**引擎自己的规矩**：只把学生本人提供的事实写成其经历，缺事实标「[待补：具体事实或证据]」；示范稿必须醒目标注虚构、不能仅改姓名提交；团队成果与个人贡献分开；引证要标来源和日期。

**降级**：只装本模块、没有内容引擎时，按 `材料骨架.md` 给结构和逐页诊断，不产出正文。

**来源**：引擎是竞赛线的开源执行组件（v0.4.0，适用第四届规则，随当届通知更新），自带非商业许可与来源标识；四个子件在标准开源仓库里也可独立安装。

## 七、获奖案例方法论（分赛道做 PPT 时先读）

19 份获奖案例（就业 14 + 成长 5，含国金/国银/国铜/国奖）逐页提炼的共性方法，存于本目录 `获奖案例方法论/`：

| 文件 | 给谁用 | 什么时候读 |
|---|---|---|
| `获奖案例方法论/00-共性提炼总表.md` | 全部 | 判断一份材料水平之前，先知道获奖线在哪 |
| `获奖案例方法论/01-PPT框架指引-成长赛道.md` | 成长赛道选手 | 排 PPT 框架时逐页对照 |
| `获奖案例方法论/02-PPT框架指引-就业赛道.md` | 就业赛道选手 | 排 PPT 框架时逐页对照；含简历生成工具（OnePage 简历生成器，onepage-resume-builder.app.workbuddy.host） |
| `获奖案例方法论/03-手把手制作教程.md` | 辅导者/深做选手 | 从零到成品六步走 |

分工：本节方法论给**判断与框架**（获奖线在哪、每页放什么、怎么算不合格）；逐字内容要真做出来时转内容引擎，只写本人真实事实。方法论提炼只取结构规律，不点名任何选手与学校。

## 八、案例牌（分赛道找同类对照物时先读）

`案例牌/` 下 19 张标准卡：就业 14 + 成长 5，按同一套维度拆开（基本信息 / 核心要素拆解 / 展示拆解 / 可迁移洞察 / 反向思考）。入口是 `案例牌/🗂 案例牌导航.md`。

**什么时候取**：他说「我这岗位该往哪使劲」「我这页写得太虚」「我这 PPT 排得对不对」——找同赛道、目标职业最接近的 2–3 张，比重心位置、证据配比和数字颗粒度，不要从头翻。

**三条规矩**：① 比对，不照抄；② 取完回到本模块四块出结论；③ 不编案例，牌里没有的事实不补，给结论只说做法，不报选手、学校、企业名。

**分工**：案例牌给对照物，方法论给判断线，内容引擎做真材料。三者不互相替代：只看牌不给判断等于没答，没定赛道就翻牌容易跑偏。

**降级**：只装本模块四件套、没有案例牌时，直说不假装有，按 `材料骨架.md` 给结构和逐页诊断，结论照给，边界写死。


## 十二、统一入口契约（v0.4.3 改造 · P0）

职规赛的**判断与规格**在本模块；**材料采集、落位、成稿与出件**的执行资产也在本模块（`诊断层/`）。大学版 `nexus-campus/SKILL.md` 第十三节持有**运行时六步规则**，执行时按该节流程、取本模块资产。

| 用户说什么 | 走哪 |
|---|---|
| 哪个赛、该不该打、走哪条赛道 | 本模块（判断层） |
| 帮我做职规赛材料 / 帮我设计材料 | 本模块 → 按 `诊断层/` 资产 + 大学版第十三节六步 → **直接出报告成稿 + PPT 页级规划** |
| 先看结构 / 只要设计说明书 | `诊断层/assets/材料设计说明书.md`（可选档） |
| 已有初稿能不能交 / 哪里要改 | `诊断层/atoms/通用原子/G-005-材料审核清单.md` 七道闸 |

三条不可协商：① 成稿只写学生本人真实事实，推演标 `〔推演〕`、缺失标 `〔待填：XX〕`；② 交付后确认清单逐条通过前不给「可提交」结论、不代转 PDF；③ 获奖案例只作颗粒度标尺，不搬案例经历、荣誉、访谈、数字与转折。

唯一事实源：`事实基线.md`（权威数据在 `诊断层/references/赛事事实卡.md`）。本模块及引擎内所有分值、字数、页数、体积数字均以其为准，不再各自写死。

3. 推演只限 G-007 四条允许，六条禁止任一条越线 → 整份稿作废

**降级**：只装本模块、诊断层缺失时，按 `材料骨架.md` 给结构与逐页诊断，不产出正文与出件，并直说不假装有。
