## 一、评审标准原文（唯一合法口径）

### 成长赛道（满分100分）

> ⚠️ **读表注意**：下表共 7 句说明，但只对应 **3 个指标**。同一指标下的多句**共享**该分值，**不是逐句计分**（7 句各算一次会得出 200 分的错误结果）。

| 指标 | 分值 | 说明（原文，编号为本库检索用） |
|---|---|---|
| **职业目标** | **25** | ① 职业目标能够将个人理想与国家需要、经济社会发展相结合，体现正确的择业就业观念 |
| | | ② 结合学科专业，多渠道了解相关行业发展趋势和就业市场需求，综合分析个人价值追求、能力优势、兴趣偏好等，确定职业发展方向或目标 |
| **学习实践行动** | **50** | ③ 基于职业发展方向或目标的能力特征和要求，科学分析差距，制定合理可行的学习、实践计划 |
| | | ④ 结合学校育人特色和所学专业，充分挖掘、利用学校、社会等各种资源开展学习实践 |
| | | ⑤ 在学习实践行动中克服困难、灵活应变、积极进取，取得阶段性成果 |
| **优化改进** | **25** | ⑥ 及时对学习实践行动成效进行自我评估和反思，总结分析收获、不足和原因 |
| | | ⑦ 在成长过程中对职业目标和学习实践行动路径进行动态优化，通过积极行动应对变化和挑战 |
| **合计** | **100** | |

**官方未规定句内分值分配**。25 分的①与②各占多少、50 分的③④⑤怎么切，**均无官方口径**。因此诊断时**禁止把句级评级折算成分数**（如"②做得好所以拿 15/25"），只能按第三节末的合成规则给出指标级定性。

| 指标 | 分值 | 说明（原文，编号为本库检索用） |
|---|---|---|
| **职业目标** | **10** | ① 能够结合就业市场需求和个人所学专业、能力及兴趣等特点，合理设定职业目标 |
| | | ② 深入调研并准确把握目标职业的任职要求、工作内容、业务流程和发展路径等 |
| **岗位胜任力** | **80** | ③ 具备目标岗位所需综合素质，**如**逻辑思维、沟通表达、团队协作、数字素养**等**，具有职业使命感和敬业奉献的职业精神 |
| | | ④ 具备目标岗位所需专业知识和技能，有相关实习实践经历，具备解决实际问题的专业能力 |
| **发展潜力** | **10** | ⑤ 具备持续学习能力、创新精神和应对不确定性挑战的能力，能适应未来职业发展要求和就业市场的变化 |
| **合计** | **100** | |

### 第四届相对第三届的三处关键变化（已核对原文，非推断）

> 核对依据：第三届标准见 `_原始资料/全国大学生职业规划大赛评审标准汇编（第一至三届官方原文）.md` 第 110—131 行；第四届见同文件第 164—186 行及附件1/2 原件。

1. 成长赛道由 **30＋50＋20** 改为 **25＋50＋25**，"优化改进"指标整体权重 +5。
   - 注意：**涨的是指标，不是句子**。G6、G7 两句共享这 25 分，不存在"各涨 5 分"。
2. **"科学分析差距，制定合理可行的成长计划"整句从"职业目标"移入"学习实践行动"。**
   - 第三届该句确实写在"职业目标"指标内（原文："基于职业目标对综合素质和专业能力等方面要求，科学分析个人现实情况与职业目标间的差距，制定合理可行的成长计划"）。
   - 含义：目标本身的分量在降，**能否把目标翻译成可执行行动链**的含金量在升。对"目标漂亮但行动脱钩"的选手要更严厉。
3. 就业赛道综合素质表述由第三届的"思维认知、沟通协作能力和执行力"改为"逻辑思维、沟通表达、团队协作、数字素养"；"敬业奉献的职业精神"扩展为"**职业使命感和敬业奉献**的职业精神"；"基本流程"改为"**业务流程**"。
   - 数字素养是本届最大的增量空位（见 E3-数字素养）。

## 二、定位逻辑（先看这里，再逐句评级）

两个赛道的胜负手完全不同，诊断开场必须先锚对该打哪一场仗：

| | 成长赛道 | 就业赛道 |
|---|---|---|
| 本质 | 讲一个"我怎么长过来"的过程故事 | 做一次"我就是干这个的"的能力举证 |
| 论点类型 | **过程性主张**：我正在成为谁 | **结果性主张**：我明天就能干 |
| 胜负手 | 学习实践行动 **50 分** | 岗位胜任力 **80 分** |
| 评委核心提问 | 你凭什么说你在往那个方向长？证据呢？ | 你明天能上手吗？举个你解决过的真问题。 |
| 最致命的病 | 经历与目标脱钩（经历很满，但换个目标也成立） | 实习名头响但讲不出业务链条 |
| 提分最快的点 | 盘活存量——把已有经历重新锚到目标上 | 补一段对口实习 + 提炼一个完整业务案例 |

判断口诀：**成长赛道看"目标有没有筛过我的行动"，就业赛道看"行动有没有落到那个岗位的业务流上"。**

## 三、逐句四档锚点

评级定义：**强**=有硬证据且同类占优能扛追问｜**稳**=站得住但不出挑｜**弱**=有痕迹但撑不起满分要求｜**空**=找不到对应素材。

> **编号规则**：G = 成长赛道，E = 就业赛道。G1/G2 对应"职业目标"指标下的①②两句，以此类推。**编号是检索用的句子编号，不是独立的计分项。**

### 【成长赛道】G1 = 指标「职业目标」句①（国家需要与择业观念）

- **强** — 目标职业落在具体真实的国家需求缺口上，能说出该缺口的**具体事实**（缺口数据、某起事件、某项政策的具体条款〔须自行调研，不得由模型补〕），且自己的行动确实指向这个缺口而非旁敲侧击。
- **稳** — 能对应到某条明确的国家战略方向，表述具体无口号，缺对该领域真实缺口的认知深度。
- **弱** — 口号式关联（"响应国家号召""投身基层"），或目标与国家需要之间是**常识级关联**（如"当医生是救死扶伤"）。
- **空** — 只讲个人兴趣，完全无外部视角。
- **误区** — 把"热门=国家需要"当得分项。行业热不等于岗位缺人，评委会直接戳。
- ⚠️ **举例的性质说明** — 本库提及的国产算力、核电运维、基层水利、特殊教育、非遗传承、边疆医疗等，是**往届获奖案例中出现过的方向**，用于说明"什么叫落到真实缺口"。**不等于这些方向自带高分**，更不是推荐选题清单。

### 【成长赛道】G2 = 指标「职业目标」句②（多渠道调研与自我分析）

关键词是**"多渠道"**——单一渠道不算。

- **强** — 至少 3 类**独立**信息源且有可验证的调研动作：政策/行业报告、从业者访谈（有职务或人数）、目标岗位 JD 拆解（列过若干个）、企业走访、校友访谈；并有"外部要求 × 我的优势"的逐条对照。
- **稳** — 做过 1—2 类调研（通常只有网络检索 + 看 JD），有对照但不系统。
- **弱** — 只有"我很感兴趣" + 泛泛的行业前景描述。
- **空** — 说不清目标从哪来（"家人建议""本专业对口"）。
- **误区** — 把学校组织的大赛宣讲、认知讲座当成行业调研。那算渠道吗？算，但只是一类，且含金量最低。
- **追问点** — 你说这个行业缺人，数据从哪来？你跟几个在职的人聊过？哪句话改变了你原来的判断？
- **追问点（补）** — 目标公司的全称是什么？它的招聘要求第 3 条写的是什么？（答不出 = 调研没做实）

**JD 拆解模板（直接给学生的操作模板，形态来自已入库成品的通用结构）**
岗位调研至少产出**这三块**，缺一即降档：

1. **岗位职责**：列 3—5 条具体职责（技术研发 / 项目管理 / 对外交流 / 知识产权…）
2. **岗位要求**：拆成四栏填 —— **学科要求**（对口专业）/ **项目经验**（要求哪类项目经历）/ **专业技能**（能独立做什么）/ **通用素质**（协作、沟通、解决问题、创新意识、敬业奉献…）
3. **目标企业必须具名到具体公司全称**，并配薪资段。写"行业头部企业""相关领域领先公司"= 未做调研，后续所有实习证据无处可锚。

### 【成长赛道】G3 = 指标「学习实践行动」句③（差距分析与计划）

> 这一项是第四届改动的最大受益者，诊断权重给足。

- **强** — 存在完整闭环：`目标岗位的能力要求清单 → 我的现状 → 差距项（逐条） → 针对性动作 → 阶段性验收`。差距诊断方式可信（对照真实 JD、导师评估、实习反馈、竞赛复盘），计划有时间节点与验收标准。
- **稳** — 有差距意识且做过针对性动作，但因果链松散。典型：「我沟通能力不足，所以参加了演讲比赛」——没有证明演讲比赛补的正是目标岗位要的那种沟通。
- **弱** — 有行动计划但与目标脱钩：学生会、志愿活动、通用证书堆一堆，套在任何一个目标上都成立。
- **空** — 没有计划，经历是随机长出来的。
- **误区** — 把"考取 XX 证书"列为计划。证书不是计划，除非你能说清目标岗位 JD 里点名要它。
- **追问点** — 你列的这个证书，目标岗位的招聘要求里提到了吗？在第几条？

### 【成长赛道】G4 = 指标「学习实践行动」句④（资源挖掘）

关键词是**"挖掘、利用"**。这是普通选手与冲金选手的分水岭——资源不在多寡，在于**你是否用到了别人没用的资源**。

- **强** — 用到至少一类非常规可得的资源：国家级/省部级重点实验室、校企联合培养项目、行业导师、地方特色产业资源、稀缺实践岗位（对口核电站、远洋、科考站、特殊机构），且对该资源的使用过程有具体描述。
- **稳** — 用到学校常规资源（专业实验室、导师课题、学院竞赛队）+ 一段社会实践或志愿服务。
- **弱** — 只有课程学习与班级活动。
- **空** — 无从体现。
- **常见可挖而没挖的矿** — 学校所在城市的产业集群、校友企业、行业学会的学生会员资格、国家/省级大学生创新创业训练计划、对口政府的实习见习项目、本专业教师承接的横向课题。
- **追问点** — 你们学校的这个平台，同专业有多少人用过？你是怎么申请进去的？

### 【成长赛道】G5 = 指标「学习实践行动」句⑤（克服困难与阶段性成果）

这是 50 分里最容易拉开的格子，也是成长赛道唯一带叙事张力的一句。

- **强** — 有一段能撑起叙事的转折事件（失败 / 瓶颈 / 被动局面，场景具体），应对明确，**成果可定量**（进入 XX、位列 XX、产出 XX、被 XX 采用/采纳）。
- **稳** — 有成果但过程平淡，或困难描述抽象（"克服困难坚持了下来"）。
- **弱** — 成果只能列课程分数、社团任职、四六级。
- **空** — 无任何成果陈述。
- **误区** — 把"熬夜做 PPT"当困难，把"通过四六级"当成果。这类在省赛以上直接失分。
- **追问点** — 你说遇到瓶颈，具体卡在第几步？你是根据什么判断该换方法的？

### 【成长赛道】G6 = 指标「优化改进」句⑥（自我评估与反思）

> 本句与 G7 共享 25 分。该指标本届由 20 涨至 25，是**指标整体**涨分，不是本句单独涨分。

- **强** — 有周期性自评机制（每学期/每阶段的复盘文档或记录），承认**具体的错误判断**（不是"我还不够好"这种），归因到自身而非甩给环境。
- **稳** — 有复盘，归因合理，颗粒度偏粗。
- **弱** — 只有"认识到自身不足"这种无信息量的反思。
- **空** — 通篇陈述成绩，零反思。
- **最低质量反思（识别出来就要打回来）** — 把所有不足归因于"时间不够"。这等于说自己没有问题，只是忙。
- **可复用的自评机制形态（直接教给学生，不必让他自己发明）** — 建立**三级节奏**：
  `年度规划（定方向与验收标准）→ 月度复盘（对照计划查偏差）→ 周度执行优化（调动作，不调目标）`
  配套要求：**"需要提升项"必须落到具体能力名**（如"前沿理论、交流合作、应用能力"），不得写"综合素质还需提升"这类无信息量的表述。
  判"强"看的是**这套机制是否真的在跑**（有没有记录、有没有因复盘改过动作），不是看它有没有被写进 PPT。
- **追问点** — 过去两年里你做过的**最错误的一个判断**是什么？当时为什么那么判断？
- **追问点（补）** — 你上次复盘是在什么时候？那次复盘之后，**你实际改了哪一个动作**？（答"没改什么"= 机制是摆设）

### 【成长赛道】G7 = 指标「优化改进」句⑦（动态优化与应对变化）

> 本句与 G6 共享 25 分。这一句要看到**"变"**，评委最怕一路线性叙事。

- **强** — 有至少一次可验证的目标或路径转向（原本定 A 后来转 B），能说清触发转变的**具体事件或认知**，且转变后行动随之发生改变。
- **稳** — 有微调，但讲不清触发原因。
- **弱** — 叙事完全线性，无任何调整痕迹。
- **空** — 无。
- **红线** — 不得为了凑"调整"而建议学生编造转向故事。评委追问"那段转折期你具体怎么判断的"，编的一问就穿。若履历中确实无转向，标为"素材缺失"，建议其在真实发生过的微调处做深度挖掘，而不是虚构。
  > 边界一句记住即可：**成长的价值，不在于经历看起来有多曲折，而在于每一次行动是否让自己真正有所改变。**
- **重要澄清（防误判）** — **动态调整 ≠ 频繁更换职业目标**。目标始终稳定的学生，只要能拿出"持续评估 → 完善行动路径 → 修正能力短板"的证据，同样够得上本项。不得因为"你的目标从大一到现在没变过"就直接判低分——要看的是**行动有没有因评估结果而变**，不是目标名字有没有变。

**★ 第二条实现路径：备选职业方案**
> ⚠️ **性质标注**：以下解法**提炼自已入库的两份成品材料，属本库推断，不是官方口径**。官方句⑦的后半是"通过积极行动应对变化和挑战"，未对实现方式作任何规定。

对履历中**没有真实转向**的学生——这是大多数——硬编一次转折必然在追问中穿帮（见上条红线）。
不需要撒谎的解法是：**主目标 + 2 个备选职业 + 每个的选择原因**。

| 档 | 表现 |
|---|---|
| **强** | 备选职业与主目标**共享能力底座**，讲清触发切换的具体条件（政策变化/技术路线变化/市场变化），且**为备选方向做过一点真实准备**（不是空想） |
| **稳** | 列出了 2 个备选职业并给出合理选择原因，但未说明触发条件 |
| **弱** | 备选职业与主目标无关（"考公""考研"式兜底），或写成"万一不行就去干XX"——**这暴露的是没想清楚，不是有预案，反而减分** |
| **空** | 完全没有备选，且履历中也无转向 |

> 结构位置：该模块放在生涯发展报告第三章，见 `../atoms/通用原子/G-006-生涯发展报告结构模板.md`。
> **诊断纪律**：学生说"我没换过方向"时，不要判死，先问"那你有没有想过如果这个方向走不通，你会去哪？"——这一问往往能直接把 G7 从"空"推到"稳"。

### ★ 成长赛道：句级 → 指标级的合成规则（必读，跳过会得出错误结论）

官方按**指标**赋分，本库按**句**评级。合成时必须遵守：

1. **不折算成分数。** 官方未规定句内分配，任何"②强所以 15/25"的说法都是编的，禁止出现。
2. **取短板，不取平均。** 同一指标下的多句，指标级结论取其中的**最低档**再上浮半档（不上浮则过于严苛）。
   - 例：G1 强、G2 稳 → 指标「职业目标」= **稳**（不上浮到"稳+"只有存在两项同为稳且证据互相支撑时才考虑，且需写明理由）。
   - 例：G3 强、G4 弱、G5 强 → 指标「学习实践行动」= **弱偏稳**（不能因为两句强就判稳）。
3. **出现"空"即指标降级。** 指标下任一句为"空"，该指标最高只能评"弱"，且必须写明"该句零素材"。
4. **报告里两栏都要出。** 逐句评级表 + 指标级结论，缺句级表则看不出短板在哪，缺指标级则无法定位。

### 【就业赛道】E1 = 指标「职业目标」句①（设定合理性）

> 本句与 E2 共享 10 分。

- **强** — 目标具体到**岗位名 + 细分方向 + 目标企业类型/层级**，且与"专业 / 经历 / 个人特质"三者交叉自洽（换掉任一条，这个目标就不成立了）。
- **稳** — 岗位清晰，但企业类型与方向偏泛。
- **弱** — 目标宽泛（"做互联网运营""进金融行业"）。
- **空** — 无明确目标。

### 【就业赛道】E2 = 指标「职业目标」句②（调研深度）

> 本句与 E1 共享 10 分。

- **强** — 能复述目标岗位的具体**业务流程**（第一步到第五步各做什么）+ **发展路径阶梯**（助理/初级—中级—高级各自的能力门槛与年限）+ **任职要求逐条**，且信息来自真实 JD 或从业者访谈。
- **稳** — 知道任职要求与大致工作内容，流程与发展路径说不清。
- **弱** — 只有对岗位名的想象。
- **空** — 无。
- **追问点** — 这个岗位从早上到下午的工作流是什么样的？（答不出来的基本属于纸面求职）

### 【就业赛道】E3 = 指标「岗位胜任力」句③（综合素质）

> ⚠️ 官方原文为"**如**逻辑思维、沟通表达、团队协作、数字素养**等**"——**"如"和"等"都表明这是举例，不是封闭清单**。诊断时若学生举证了清单外但确实是目标岗位需要的素质（如抗压、审美判断、跨文化沟通），同样成立，不得因"不在四项里"而判空。
> 本句与 E4 共享 80 分。

**逐项独立评级，取短板影响整体判断**（四项 + 职业精神，共五个观察点）：

- **逻辑思维**
  - 强＝有需要拆解结构的真实产出：数学建模、行研报告、系统架构设计、复杂项目方案
  - 稳＝课程论文 / 答辩
  - 弱＝只有"逻辑清晰"的自评
- **沟通表达**
  - 强＝有面向**真实外部对象**的沟通成果：招商谈判、客户交付、科普宣讲、跨部门协调、媒体出镜
  - 稳＝校内演讲 / 答辩获奖
  - 弱＝只有"善于沟通"的自评
- **团队协作**
  - 强＝带过团队，且有分工安排与**冲突处理**的真实事例
  - 稳＝参与过团队项目，无管理与冲突经历
  - 弱＝只有"有团队合作精神"
- **数字素养（本届新增，诊断时重点查）**
  - 强＝用数据或 AI 工具**真的产出了东西**：搭过数据看板、用模型解决过业务问题、做过流程自动化、参与过数字化改造项目
  - 稳＝会用数据分析工具 / 通过计算机二级 / 用 AI 提效并有具体场景
  - 弱＝只有"熟练掌握 Office"
  - 空＝完全没提
  - 说明：这是本届最容易白捡的格子。多数选手意识不到，一旦意识到很容易从"空"推到"稳"。
  - **伪数字素养（必须识别并打回）**：在 PPT 里堆 AI 工具名称、"会用 DeepSeek / 会用 AI 作图"——**一律不高于「稳」，且不得据此给"强"**。
    判据：**工具必须连接到一个具体业务问题并产出可验证结果**。链路缺失即为伪：工具 → □业务问题 → □依据调整了什么动作 → □产生了什么效果。
    示例对照：营销类学生说"我能用 AI 生成营销文案"＝伪；说清"我在实习中用数据分析工具识别消费者需求 → 据此调整投放策略 → 效果如何"＝真。
    这条对所有专业通用：**关键不在于工具多先进，而在于工具有没有帮你创造实际价值。**
- **职业使命感与敬业奉献**（官方表述为"具有职业使命感和敬业奉献的职业精神"，是与上述素质并列的后半句，**不是第五项"素质"**）
  - 强＝有需要长期投入且**无显性回报**的坚持：支教、长期志愿服务、艰苦岗位实习、冷门方向长期深耕
  - 稳＝有持续性的服务经历
  - 弱＝口号式"热爱这份职业"

### 【就业赛道】E4 = 指标「岗位胜任力」句④（专业知识与实习实践）

> 本句与 E3 共享 80 分，是就业赛道单句含金量最高的一句。

- **强** — 有与目标岗位**同岗位或强相关**的实习经历，且能讲清其中解决的**一个真实业务问题**的完整链条：问题 → 分析 → 动作 → 结果 → 复盘。
- **稳** — 有相关实习但做边角工作，讲不清业务链条（"主要是整理资料、协助……"）。
- **弱** — 实习经历与目标岗位无关，仅为填满简历；或只有校内实训、无任何真实职场验证。
- **空** — 零实习零实践。
- **含金量排序（纠正常识错误）** — 对口的小公司**核心岗** > 大厂打杂岗。本赛道实习生最忌"我在某某大厂实习过"却说不出自己做过什么判断。
- **追问点** — 那段实习里，你**独立负责过的最小一件事**是什么？结果用什么衡量？

### 【就业赛道】E5 = 指标「发展潜力」句⑤（唯一句，独占10分）

- **强** — 有跨领域自学路径 + 在不确定环境下的实际应对（转型、跨界、创业、应对变故）+ 对该行业未来 3—5 年变化的**独立判断**（不是引用别人的结论）。
- **稳** — 有学习计划，表现出好奇心。
- **弱** — 只有"我会坚持终身学习"。
- **空** — 无。

## 四、整体冲奖定位（由指标级结论合成）

> 判定的输入是**指标级结论**（成长 3 个、就业 3 个），不是句级评级。

| 定位 | 判定条件 |
|---|---|
| **冲国金** | 胜负手指标（成长=学习实践行动，就业=岗位胜任力）≥稳且其下子句至少 2 句强；**无任何"空"句**；至少有一段别人复制不了的经历 |
| **稳省金** | 胜负手指标 ≥稳，允许 1 句弱；无"空"句 |
| **冲省金** | 胜负手指标下至少 1 句强，其余可弱；补齐"空"句后有可能达上一档 |
| **省奖区** | 无"空"句但普遍偏稳/弱，靠完成度拿奖 |
| **需重构赛道或目标** | 出现结构性硬伤：目标与专业/经历完全脱钩、学籍或组别不成立、胜负手指标下多句全"空"且剩余时间不足（距校赛 < 3 个月） |

**给出"需重构"时，必须同时给出重构方向（换目标 / 换赛道 / 延后一届），不得只给结论。**

⚠️ **本节的定位是定性判断，不是分数预测。** 任何"你大概能拿 85 分"的表述都违反本 skill 的禁硬打分铁律。

## 五、使用纪律

1. 评级前必须先在 `履历采集表.md` 里找到对应字段；字段为空 → 评 `空` 并标 `〔待核实〕`，不得脑补。
2. 每项评级后必须写"依据："并引用学生的具体事实，不得只有形容词。
3. 涉及目标岗位的任职要求、行业数据、薪资范围，一律不得由模型补全，标 `〔须自行调研〕` 并给出调研路径。
4. 读 `../cases/索引.md` 校准同类案例评级后再定档。案例数 <5 时，输出须带"未经案例校准"标注。
5. **不得把句级评级折算成分数**；官方未规定句内分配，折算即编造。
6. 引用官方标准时，写"第四届大赛通知附件1/附件2"，**不得使用未核实的文号**。
