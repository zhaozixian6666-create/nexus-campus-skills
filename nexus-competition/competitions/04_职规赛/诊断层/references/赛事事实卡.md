# 赛事事实卡（第四届，2026—2027）

> 来源：**教学函〔2026〕2号《教育部关于举办第四届全国大学生职业规划大赛的通知》，2026年10月8日印发**（教育部政府门户网站全文核实于 2026-10-14）+ 附件1（成长赛道）、附件2（就业赛道）、附件3（校赛省赛工作规范）。四份原文均存于 `references/_原始资料/`。
> ✅ **文号已核实**——可正式引用，出处：教育部政府门户网站 `https://hudong.moe.gov.cn/srcsite/A15/s7063/202610/t20261010_1453481.html`。
> **所有事实性判断以本卡片为准，禁止用往届规则套本届。**

## 一、基本盘

- 主办：教育部、重庆市人民政府
- 全国总决赛承办：重庆市教育委员会、重庆大学、重庆师范大学
- 主题：**筑梦青春志在四方，规划启航职引未来**
- 周期：2026年10月 — 2027年4月
- 大赛目标（原文）：努力将大赛打造成**强化生涯教育的大课堂、促进人才供需对接的大平台、服务毕业生就业的大市场**
- **报名截止：由各地各高校根据省赛安排决定，不得晚于 2027年1月31日**（大赛平台 zgs.chsi.com.cn，登录页可下载操作手册）
- **省赛须于 2027年3月15日前完成**
- 全国总决赛：2027年4月，重庆，约 800 人（成长赛道约450 / 就业赛道约350）
- 赛制：校赛 → 省赛 → 全国总决赛
- 组织机构：组织委员会（秘书处设教育部学生服务与素质发展中心）、**专家委员会**、**纪律与监督委员会**
- 同期活动：校企供需对接、**校赛育人成果展**、以创促就活动，并鼓励面向中学生开展职业启蒙
- 奖项：金/银/铜奖 + 优秀指导教师奖 + 地方优秀组织奖 + **校赛育人奖**
- 本届**不设课程教学赛道国赛奖项**，新增"校赛育人奖"
- **往届国赛金奖、银奖选手不得再报名原赛道**（限原赛道，不是全部禁赛）
- **参赛材料须保证真实、原创**，各地各高校须审查**选手资格、指导教师实质参与情况、参赛材料内容和意识形态**；材料失实将被取消参赛资格及所获奖项，并承担法律责任
- **防诈骗条款（原文）**：大赛组委会根据需要组织赛事说明会或相关工作培训，**不委托任何第三方机构或个人**开展上述活动

### 校赛阶段平台功能（往年常被忽略）
报名/校赛期间，大赛平台开放 **成长赛道生涯闯关功能**、**就业赛道职业适配度测评功能**，选手可按需使用。

## 一之二、国赛席位规则（已核实，决定竞争面）

| 规则 | 原文依据 | 可靠度 |
|---|---|---|
| 成长赛道、就业赛道**各组别每所高校入围选手不超过 1 人** | 通知"五、大赛赛制（二）"明文 | ✅ **官方原文，已核实** |
| 选手**晋级总决赛后，指导教师、目标职业、目标行业等信息不得修改** | 通知"六、赛程安排（三）"明文 | ✅ **官方原文，已核实** |
| 名额分配依据：综合考虑各地**高等教育规模、校赛省赛组织成效**等因素 | 通知"五（二）"明文 | ✅ **官方原文，已核实** |
| 推荐至国赛的选手须覆盖面：**专科生、本科生、硕士研究生、博士研究生须保持合适比例** | 通知"五（一）"明文 | ✅ **官方原文，已核实** |

**这三条对辅导的含义（宣讲时必须讲）：**

1. **竞争的第一道闸门在校内，不在省内。** 每校每组别只有 1 个国赛名额 ⇒ 选手要赢的第一批人是**本校同赛道同组别的同学**。谈竞争面必须先说校内，再看本省。（红线 15）
2. **换目标有时间窗。** 晋级国赛后目标职业与指导教师不可改 ⇒ **所有"要不要换目标职业"的决策，必须在省赛之前做完**。这是一条真正会改变选手行为的规则，不能漏讲。
3. **学历结构会影响名额。** 各省推荐时需保持专/本/硕/博合适比例，部分省份据此分赛道名额。

## 二、赛道与组别判定（Step 0 唯一依据）

### 成长赛道
参赛对象：**普通高等学校全日制本、专科非毕业年级在校学生**

| 组别 | 面向 |
|---|---|
| 高教组 | 普通本科**非毕业年级**学生 |
| 职教组 | 职教本科、高职（专科）**非毕业年级**学生 |

### 就业赛道
参赛对象：**普通高等学校全日制本、专科高年级计划求职学生，以及全体研究生**

| 组别 | 面向 |
|---|---|
| 高教本科生组 | 普通本科三、四年级（部分专业五年级）学生，**不含已通过推免获得录取资格的学生**；全体第二学士学位学生 |
| 高教研究生组 | 全体研究生；本硕（博）连读学生、直博生中**已获得本科学历者** |
| 职教组 | 职教本科三、四年级学生；高职（专科）二、三年级学生 |

### 判定要点
- 关键分界线是**是否为毕业年级**，不是年级数字本身。五年制专业的四年级可能仍属非毕业年级，须确认学制。
- **已推免录取者不能报就业赛道高教本科生组**——这是硬排除项，Step 0 必须查。
- 研究生**不能**报成长赛道。
- 每名选手只能选**一个**赛道报名。

## 三、比赛环节与时限

| 赛道 | 环节 | 时长 |
|---|---|---|
| 成长 | 主题陈述 / 评委提问 / 天降实习offer | 7分钟 / 5分钟 / 2分钟 |
| 就业 | 主题陈述 / 综合面试 / 天降offer | 6分钟 / 6分钟 / 2分钟 |

各环节据实际情况可适当调整。
> ⚠️ **天降 offer 在第四届不计入 100 分**（第一届曾占 10 分）。它的价值是"最硬的第三方当场背书"，**不得告诉学生"多拿 offer 能提分"**。详见 `议论文模型.md` 第四节。

## 四、参赛材料与合规红线

### 成长赛道
| 材料 | 格式 | 限制 |
|---|---|---|
| 生涯发展报告 | PDF | **不超过10MB**，文字不超过2000字，图表不超过5张 |
| 生涯发展展示 | PPT | 不超过50MB |

生涯发展报告必含内容：**① 设定职业目标的过程 ② 实现职业目标的具体行动和成效 ③ 职业目标及行动的动态调整**

### 就业赛道
| 材料 | 格式 | 限制 |
|---|---|---|
| 求职简历 | PDF | 无明确体积限制（但须合理） |
| 求职综合展示 | PPT | 不超过50MB |
| 辅助证明材料（实践、实习、获奖等） | PDF，**整合为单个文件** | **不超过10MB** |

> 第四届收紧点：辅助证明材料**上限由 50MB 降为 10MB**，且必须整合成单个 PDF；生涯发展报告新增 10MB 上限。

### 盖章流程（附件3，常被忽略但会影响能否参赛）
- 推荐至**省赛**的选手名单和参赛材料，**须经选手所在高校盖章确认**
- 推荐至**全国总决赛**的选手名单须经**省级**高校毕业生就业工作部门盖章确认，参赛材料须经选手所在高校盖章确认

## 五、校赛省赛工作规范（附件3全文要点，第四届新增，已入库）

结构：优化办赛机制 / 规范赛事组织 / 加强赛事监督

| 条目 | 要点 |
|---|---|
| 责任主体 | 省级高校毕业生就业工作部门是省赛主办单位，并对省内各高校校赛进行**指导和监督**；各高校是校赛主办单位 |
| 承办制度 | 省份应对申办高校评估后择优确定；有条件的省份组织高校**轮流承办**，**原则上同一高校不得连续承办三届** |
| 办赛导向 | 发动专业课教师、就业指导教师参与校赛指导，**校赛指导计入教育教学工作量** |
| **破除"唯奖项"** | 禁止简单将获奖与学生综合评价、**推荐免试研究生、免试专升本、教师职称评聘**直接挂钩；**不鼓励重金奖励**获奖选手和指导教师 |
| 方案制定 | 严格执行比赛规则、及时公布成绩与获奖名单；**不得以"内部集训""定向培优"代替比赛，不得摊派参赛指标** |
| 专家管理 | 落实回避要求、签承诺书、明确保密责任；**徇私舞弊/借机牟利/私自泄露专家身份和评审细节 → 依规永久取消专家资格** |
| 企业参与 | 鼓励设置**企业心选团**；**不得委托第三方商业机构承办赛事**；**严禁教育培训类企业参与评审、企业心选团** |
| 赛事监督 | 各地各高校成立纪律与监督机构；公布监督举报方式，受理并处理**申诉和异议**；赛后归档监督记录 |

> ⚠️ **破除"唯奖项"这条必须对学生讲清楚**：获奖与学生综合评价、推免、免试专升本**不得直接挂钩**。
> 指望"拿个奖就能保研"的学生，前提判断本身就是错的。同时它也是筛除功利参赛动机的一面筛子。

## 六、真实校赛流程参照（非官方统一规定，各校各省自定）

> 通知明确：各地各高校**自主确定**参赛名额、分组设置、比赛环节、评审方式和奖项设置。以下为公开检索到的真实校赛安排，仅作流程参照，**不代表选手所在校**。

| 环节 | 河南工程学院 | 广西师范大学 |
|---|---|---|
| 报名 | 2026.10—12，平台上报，操作手册在登录页下载 | 2026.10—11，平台 + "到梦空间"APP 双报名 |
| 院级/班级选拔 | 2026.10—11，按学院在校生规模分配推优名额 | 班赛 → 院赛，2026.9—10 |
| 校级决赛 | 2026.12，决赛前**集中辅导**，优化报告/简历/PPT | 2026.12 前校赛总决赛 |
| 指导教师 | **每位选手校赛阶段指导教师不超过 2 名**，要求"**实质参与**" | 指导老师是资格审查第一责任人 |
| 校内激励 | 列入校学科竞赛目录 A 类；校赛第一指导教师获育人工作量；国赛金奖第一指导教师可入选省专家库 | 参赛可获创新创业学分 |

**由此可得的辅导要点**：
- 校赛普遍设置**指导教师"实质参与"**要求，与通知里新增的审查项对应——挂名指导老师这条路本届被堵死
- 多校在校赛决赛前有**集中辅导**环节，这是补材料的最后一个窗口
- 校赛时间线普遍比通知的截止时间**更早**（多数 11—12 月就完成），**不能用 1 月 31 日倒推自己的进度**

## 八、⚠️ 流传版本纠错（网上公开解读的常见错误）

网络流传的备赛文章常把评分表写成 **成长 30+50+20**——那是**第三届及更早**的口径。
**第四届附件原文为 25+50+25**（差距分析、制定计划整句由"职业目标"移入"学习实践行动"）。
任何以 30+50+20 讲解第四届的攻略，评分框架就已经过期。**一切以附件1/附件2 原文为准。**
