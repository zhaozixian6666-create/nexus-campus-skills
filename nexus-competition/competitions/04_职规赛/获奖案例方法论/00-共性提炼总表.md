# 获奖案例共性提炼总表

> 依据：19 份独立获奖案例 PPT（就业赛道 14 份 + 成长赛道 5 份，含国金/国银/国铜/国奖各档）逐页提炼。
> 提炼只取**结构规律**，不点名任何选手与学校。原始提炼稿存外部参考区，本文件只收结论。
> 凡引当届规定，一律以当届通知为准。

---

## 一、先记一组事实（决定你怎么用这份表）

| 事实 | 含义 |
|---|---|
| 就业赛道获奖 PPT 普遍 13-40 页，成长赛道 11-29 页 | 页数不是标准，结构完整度才是 |
| 证据/行动类页面占比 40%-60%，是全篇最大头 | 谁的份量大，谁的功夫就该花在哪 |
| 获奖案例几乎**不用** MBTI/霍兰德测评页 | 测评只是起点，评委想看的是行动证据 |
| 每份获奖案例都有一套**自创的记忆点框架** | 三力模型、三气四力、冰山模型、四梦、植物隐喻……没有一份靠罗列经历 |
| 风险预案与动态调整已成新标配 | 没有调整记录的规划会被怀疑是写出来的 |

## 二、两赛道共同遵守的八条铁律

1. **标准反推法**：先从真实招聘公告、JD 原文、职业大典建立岗位标准清单，再逐条对表作答。全篇不偏航。
2. **证据金字塔**：稀缺结果在上（位次、唯一性），过程数据在中（时长、次数、件数），证书课程垫底。
3. **数字化三件套**：竞争位次（排名 1/108）＞累积总量（700+ 小时、30+ 奖项）＞过程投入（1041 次入馆记录）。能换算成数字的经历全部换算。
4. **一页只证一项能力**：能力与证据逐页对位，最后用一张人岗匹配总表（必备条件 vs 已具备）收口。
5. **第三方背书密集**：offer、企业评价、科室评语、证书、媒体报道、领导批示——自述必须配背书成对出现。
6. **主题句三次复现**：封面、中段、结尾同一句话贯穿，一句话目标全程不漂移。
7. **动机双线**：情感线（家史、师承、具体物件开场）+ 理性线（政策、宏观数据、生涯人物访谈）。
8. **结尾升华有方向**：个人目标挂接国家战略与行业使命，收尾不谈个人得失；先承认行业挑战再给个人应对姿态。

## 三、就业赛道特有规律（14 份归纳）

| 规律 | 内容 |
|---|---|
| 黄金结构 | 封面 → 职业目标确立 → **胜任力/人岗匹配（45%-59%，绝对重心）** → 发展规划 → 价值升华收尾 |
| 目标句式 | 窄切口：细分领域 + 场景 + 特色技术模式，不写宽泛职业名 |
| 实习叙述 | 按能力关键词进阶排列，每段配第三方背书 + 工作量量化 |
| 闭环标志 | 以意向 offer / 就业成果收尾，说明规划已被市场验证 |
| 技术表达 | 工科技术价值百分比化（性能提升 30%、周期缩短 40%） |
| 证书处理 | 中段精讲 3-5 项 + 尾段证书墙数字汇总 |
| 调研三件套 | 权威定义/招聘原文 + 宏观数据 + 能力清单拆解 |

## 四、成长赛道特有规律（5 份归纳）

| 规律 | 内容 |
|---|---|
| 五段式骨架 | 目标缘起（15-19%）→ 职业认知（21-28%）→ **成长行动（35-41%，最大头）** → 未来规划（14-20%）→ 动态调整（6%+） |
| 行动为重 | 与就业赛道的「人岗匹配」对应，成长赛道以「已发生的行动」当重心 |
| 里程碑化解长周期 | 长周期职业拆成 3/5/10 年阶梯，忌空洞远景 |
| 学科配比可调 | 人文类可无竞赛测评（重叙事与田野实证）；工科类竞赛科研双引擎、数据密度更高 |
| 视觉即人设 | 视觉风格与职业人设一致（工科数据图表 / 文博水墨 / 思政红金），风格服务判断 |

## 五、从共性反推的七个坑

| 坑 | 获奖案例的做法 |
|---|---|
| 写成简历扩写 | 每段经历回答「它证明了哪项能力」 |
| 形容词堆砌 | 全部换成可验证的数字与事实 |
| 测评页凑数 | 测评只作引子，行动证据才是主体 |
| 目标宽泛 | 窄切口到细分领域 + 场景 |
| 规划全是空话 | 精确到年限 + 可验证产出（标准/专利/论文/证书/岗位） |
| 没有调整记录 | 主动写目标变更史与备选方案，暴露短板显真实 |
| 数据稀薄 | 输入型努力也量化（入馆次数、自学软件数）——这是最低成本的补法 |

## 六、怎么用这张表

- **选手**：直接看分赛道框架指引（`01` 成长 / `02` 就业），按模板逐页对照。
- **辅导者**：用本表第五节七个坑做诊断问句；用第二、三、四节做评审预演。
- **要做真材料**：转内容引擎（见本模块 SKILL.md 第五节），只写本人真实事实。
