# 挑战杯小挑 · 材料骨架

> 这一块放**结构**：创业计划书怎么排、答辩 PPT 怎么排、每一块要让评委相信什么、什么样的算不合格。
> 这一块给的是判断，不说成评审文件写的；凡引规定，一律注明「以当届通知为准」。
> **不带具体项目名、学校、页码引用、分值。**

---

## 一、先定一个判断：小挑的计划书不是「商业计划书的缩小版」

国创赛的 BP 是对投资人说话（强调增长与回报），小挑的计划书是对**评审**说话（强调可行性、社会效益、团队完成能力）。

**同一份内容，两处落点不同**：

| | 国创赛 BP | 小挑计划书 |
|---|---|---|
| 评委关心 | 这件事能做多大 | 这件事你们能不能真做成 |
| 财务部分的重点 | 增长曲线 | 成本结构与盈亏平衡 |
| 社会价值 | 加分项 | **本身就是评分维度** |
| 团队 | 背书 | 分工与执行能力 |

**引导问句**：你这份计划书，是给投资人看的还是给评审看的？先把这句话答了，再动笔。

## 二、创业计划书：骨架

```
执行摘要（1-2 页）        ← 评委唯一一定看完的部分
项目背景与需求（3-5）      ← 需求真实吗
产品与服务（3-5）          ← 你提供什么
市场分析（4-6）            ← 市场多大，你怎么进
竞争分析（3-4）            ← 为什么是你
商业模式（3-4）            ← 谁付钱，怎么持续
营销与运营（3-4）          ← 怎么卖出去
团队与管理（2-3）          ← 谁来做
财务计划（4-6）            ← 钱从哪来、花在哪、什么时候平衡
风险与对策（2-3）          ← 有什么后手
社会效益（2-3）            ← 小挑必看，不是附加
```

| 板块 | 不合格的样子 | 诊断问句 |
|---|---|---|
| 执行摘要 | 写成目录的复述 | 只读这一页，评委能不能判断这事值不值得往下看 |
| 需求 | 「市场前景广阔」 | 你的第一个客户是谁？他为什么现在就要买 |
| 竞争 | 只列对手名字，不比维度 | 你的对手如果明天降价，你怎么办 |
| 商业模式 | 收入来源说不清，或者只写「卖产品」 | 第一笔钱谁付，付多少，为什么付 |
| 财务 | 全是预测，没有成本明细 | 你的固定成本和可变成本各是什么 |
| 社会效益 | 空喊口号，没有受益人数 | 受益的是谁，多少人，谁在统计 |

## 三、答辩 PPT：骨架

```
1  封面 + 一句话定位
2  问题：谁、多痛、现在怎么凑合
3  方案：我们提供什么
4  证据：已发生的（合同/用户/试点）优先于预测
5  市场：规模 + 切入路径
6  竞争：维度对比表
7  模式：收入结构
8  团队：分工，不是头衔
9  社会效益：数字 + 受益方
10 规划：这一年要做什么
```

**一个判断**：小挑答辩最容易被问倒的不是技术，是**「你们真做过吗」**。第 4 页一定要放已经发生的事，哪怕很小。

**引导问句**：
- 你们现在有真实用户吗？付费的还是免费用？
- 如果只有这一页能证明你们做成了，你放哪一页？

## 四、八个赛道的差体

> ⚠️ **先看这一行**：第十四届（2024）是「五个组别」，**第十五届（2026）已改为 8 个赛道**。下表按第十五届写。下一届可能再调，**以当届通知的赛道列表为准**。

小挑按赛道分，**赛道不只是分类，决定你强调什么**。以下「强调什么」是按各赛道官方鼓励方向给的边界判断，不是评审细则原文。

| 赛道（第十五届） | 强调什么 | 最容易走偏的地方 |
|---|---|---|
| 先进制造 | 工艺／装备的技术门槛、下游客户验证、替代进口的空间 | 只讲技术先进，不讲谁买、买了替掉谁 |
| 新一代信息技术 | 性能指标、场景落地、数据合规 | 讲成技术方案书，没有真实用户 |
| 生物医药与健康科技 | 证据链（实验／临床／伦理）、审批路径、医院或企业合作 | 只有实验室数据，没有产业化路径 |
| 新能源新材料 | 性能参数对比、成本曲线、中试与产能 | 参数漂亮但成本算不下来 |
| 现代农业与食品科技 | 增产／降本实测、农户或企业采用、可复制性 | 只讲情怀和调研，讲不出收益 |
| 新消费与文化创意 | 文化母题、用户增长、IP 与线下场景 | 只讲文化，讲不出怎么赚钱 |
| 现代服务与社会治理 | 真实痛点、服务流程、机构或政府采购 | 讲成政府工作汇报 |
| 国际交流合作 | 跨境场景、合规与本地化、国际合作方 | 只挂「一带一路」的名，没有真实跨境业务 |

**引导问句**：你选这个赛道，是因为项目真属于这一块，还是因为这里竞争小？如果是后者，材料会歪。

**第二问更关键**：你这个赛道的名字，是从当届官网抄的，还是从学长／老攻略听来的？后者八成是上一届的分组。

## 五、通用自检

1. 执行摘要能独立成立（不靠后面几页补）
2. 所有「预计」「有望」后面都有推算过程
3. 至少有一件**已经发生**的事被证明（合同、用户、试点、实测）
4. 社会效益有具体受益方和数量
5. 团队分工能对上四个位置：拍板、产品/技术、材料、答辩

---

## 不覆盖什么

这份给结构、给判断、给查法；下面几类**刻意不写**——写死就是错的：

| 不覆盖 | 为什么不写 |
|---|---|
| 评审细则原文与分值权重 | 逐届逐校都会调，写死即错。一律查当届通知与本院当年文件 |
| 具体项目、团队、获奖材料的真实案例 | 案例能指认到具体的人，不引用。只给判断，把适用与不适用条件写得更死 |
| 具体某校的认定与赋分、名额 | 各校各年不同，永远让学生查本校原件 |
| 「哪种写法得分更高」这类偏好结论 | 没有能核到原件的依据就不下结论 |
