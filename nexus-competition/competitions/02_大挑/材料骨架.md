# 挑战杯大挑 · 材料骨架

> 这一块放**结构**：论文怎么组织、发明制作类怎么组织、每一块要让评委相信什么、什么样的算不合格。
> 这一块给的是判断，不说成评审文件写的；凡引规定，一律注明「以当届通知为准」。
> **不带具体项目名、学校、页码引用、分值。**

---

## 一、先分清三类别，结构完全不同

大挑交的不是一样东西，**报错类别等于答错题**。

| 类别 | 交什么 | 评审看什么 | 谁适合 |
|---|---|---|---|
| 自然科学类学术论文 | 一篇学术论文 | 选题价值、方法严谨、结论可靠 | 有实验／数据／计算支撑的本科生 |
| 哲学社会科学类社会调查报告 | 一份调研报告 | 问题真实、方法规范、结论有解释力 | 做过实地调研、问卷、访谈的团队 |
| 科技发明制作 A 类 | 实物／样机 + 研究报告 | 创新性、完成度、可演示 | 有硬件、有作品 |
| 科技发明制作 B 类 | 作品 + 研究报告（投入较小） | 实用性、巧思 | 小成本作品 |

**引导问句**：你手上已经有的东西是——一篇能写完的论文、一份能写出结论的调研、还是一个能做出来的东西？先按「手上有什么」定类别，不按「哪个容易获奖」定。

## 二、论文类：骨架与合格线

```
题目（一个具体问题，不是一个大领域）
摘要（200-300 字：问题→方法→结果→意义，四句）
关键词
引言（这问题为什么重要 / 别人做到哪 / 我要解决哪一小块）
方法与材料（可复现：怎么做的、用了什么、样本多少）
结果（图 + 表 + 数据，不写感受）
讨论（结果说明什么、局限在哪、下一步）
结论
参考文献
```

| 板块 | 不合格的样子 | 诊断问句 |
|---|---|---|
| 题目 | 「关于 XX 的研究」——大到写不完 | 你这篇具体回答了哪一个问题？一个句子能不能问出来 |
| 引言 | 只讲意义，不讲别人做到哪 | 你这个方向上，最近三年别人做了什么？你和他们的差别在哪 |
| 方法 | 写不出别人能不能照做 | 换一个人按你写的步骤，能重复出来吗 |
| 结果 | 只有结论，没有原始数据 | 你的图是自己测的，还是引的 |
| 讨论 | 把结论重复一遍 | 你这个结果在什么条件下不成立 |

## 三、发明制作类：骨架与合格线

```
作品申报书（这是什么、解决什么、创新点在哪）
研究报告（背景→方案→实现→测试→对比→应用）
实物／样机（能演示，能复现）
佐证（测试数据、使用记录、专利／软著、鉴定）
```

| 板块 | 不合格的样子 | 诊断问句 |
|---|---|---|
| 创新点 | 「首次」「国内领先」这类形容词 | 你的创新点用一句话说，同行听了会承认是新的吗 |
| 实现 | 只有效果图，没有实物 | 现在能不能当场演示？不能的话，卡在哪一步 |
| 测试 | 自己说好，没有第三方 | 有没有第三方的数据，或者可复现的测试方法 |
| 对比 | 跟没做过的方案比 | 你比的那个东西，是真有人做的吗 |

---

## 四、社会调查报告类：骨架与合格线

```
选题（一个具体的社会问题，有地域或群体边界）
调研设计（对象、样本量、方法：问卷/访谈/观察）
数据与发现（分成 3-4 条发现，每条有证据）
原因分析（为什么会这样）
对策建议（可执行，指向具体主体）
```

| 板块 | 不合格的样子 | 诊断问句 |
|---|---|---|
| 选题 | 「当代大学生就业问题研究」——大到无法调研 | 你实际访问了多少人？在哪 |
| 样本 | 只发问卷，且全是同校同学 | 你的样本能代表你说的那群人吗 |
| 发现 | 罗列数据，没有观点 | 这三条发现里，哪一条是别人没说过、而你数据支持的 |
| 建议 | 「应加强重视」「应完善机制」 | 这条建议，具体谁明天可以做？ |

---

## 五、通用自检（三类都适用）

1. 一句话能说清你做了什么、结论是什么
2. 每一处「显著」「大幅」都换成了数字
3. 所有引用有出处，没有一处「据了解」
4. 评委追问「这是你做的吗」，能当场指出哪一部分是自己完成的
5. 材料里没有一处夸大（大挑对真实性的追问比创赛更硬）

## 不覆盖什么

这份给结构、给判断、给查法；下面几类**刻意不写**——写死就是错的：

| 不覆盖 | 为什么不写 |
|---|---|
| 评审细则原文与分值权重 | 逐届逐校都会调，写死即错。一律查当届通知与本院当年文件 |
| 具体项目、团队、获奖材料的真实案例 | 案例能指认到具体的人，不引用。只给判断，把适用与不适用条件写得更死 |
| 具体某校的认定与赋分、名额 | 各校各年不同，永远让学生查本校原件 |
| 「哪种写法得分更高」这类偏好结论 | 没有能核到原件的依据就不下结论 |
