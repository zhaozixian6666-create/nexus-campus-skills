## 轨道 A · 材料对标覆盖度（给项目材料做判断时用）

原文：`材料骨架.md:163-180`。**它不是评分表，是投出去之前的自查清单**——所以这里输出的是「覆盖 X/12」，不是分数。

| # | 共性项（原文） | 状态：有 / 不足 / 缺 | 证据在第几页 | 补齐动作 | 优先级 |
|---|---|---|---|---|---|
| 1 | 国家战略背景（政策文件、规划、卡脖子问题） | | | | |
| 2 | 市场规模与增速（带出处） | | | | |
| 3 | 三个痛点（技术／成本／效果，各对应一项方案） | | | | |
| 4 | 核心技术（专利、算法、材料、工艺，至少一样硬的） | | | | |
| 5 | 竞品对比（表格化、量化） | | | | |
| 6 | 第三方验证（检测报告、鉴定、应用证明） | | | | **硬伤位** |
| 7 | 真实客户或合同（不是「已有多家意向客户」） | | | | **硬伤位** |
| 8 | 商业模式（收入结构，不止一种更好） | | | | |
| 9 | 团队背书（能力与项目匹配） | | | | |
| 10 | 教育维度（学生成长、专创融合） | | | | |
| 11 | 社会价值（就业、环保、安全、国产替代等，带数字） | | | | |
| 12 | 战略规划（时间轴 + 可检验的里程碑） | | | | |

判读规则（照原文，不自行加码）：

- **少于八项，材料基本不成立**（`材料骨架.md:165`）。
- **第 6、7 项缺，通常是硬伤，不是靠改文案能救的**（`:180`）——诊断报告必须直说，不许写「建议进一步完善」。
- 缺的那几项就是这周要补的动作，写进 `项目诊断流程.md` 第 5 步的「补齐优先级」三档。
- 补位时可回取 `../../语料/规律提炼/30国金项目跨项目规律总结.md` 的 12 个共性要素，看同类项目这一项写到什么颗粒度；**比对不照抄，不搬别人卡片里的数据**。

**输出**：`覆盖 X/12` + 硬伤清单 + 逐项补齐动作。**不输出百分制分数。**

## 轨道 B · 模拟答辩表现（用户要「模拟打分」时用）

原文：`../../语料/60_模拟评审/模拟答辩SOP.md`。这是**答辩回答质量**的评分，不是项目本身的评审分。

### 输入（SOP「模拟前准备」）

- 项目 PPT / PDF（可选）
- 七项基本信息：赛道/组别、一句话定位、核心产品或服务、目标用户、商业模式、团队构成、目前阶段
- 最担心的一个维度

### 四轮流程（SOP 第二节）

| 轮次 | 时长 | 做什么 |
|---|---|---|
| 一 · 项目路演 | 5 分钟 | 封面定位 30s → 痛点 1min → 方案 1min → 商业模式 1min → 团队成果 1min → 总结 30s |
| 二 · 评委提问 | 15–20 分钟 | 按「技术专利 → 商业模式 → 市场竞品 → 财务数据 → 团队运营 → 产品落地 → 社会价值 → 风险合规」顺序，每维 2–3 题 |
| 三 · 追问压力测试 | 10 分钟 | 追问数据来源、核心假设不成立怎么办、客户是否真实、与竞品具体好在哪 |
| 四 · 评分与反馈 | 10 分钟 | 总分 + 各维度得分 + 最好/最差 + 需补材料 + 下轮训练重点 |

出题来源：`../../语料/60_模拟评审/专家问题库.md`（8 维度，标称 749 条国赛专家现场提问）；切换 AI 评委身份与 8 大提问意图见 `../../语料/60_模拟评审/模拟评审总览.md`；提交前自查用 `../../语料/60_模拟评审/评委提问清单.md`。

### 评分标准（SOP 第三节原文，权重不改）

| 维度 | 权重 | 评分要点 |
|---|---|---|
| 真实性 | 20% | 数据真实、案例具体、有据可查 |
| 逻辑性 | 20% | 回答条理清晰、前后一致 |
| 专业性 | 20% | 懂行业、懂技术、懂市场 |
| 应变性 | 20% | 面对追问不慌、能自圆其说 |
| 表达力 | 10% | 语言简洁、重点突出、时间控制 |
| 态度 | 10% | 自信、真诚、不狡辩 |

### 输出格式

```
【参考分】总分 __/100（按模拟答辩 SOP 六维，训练用参考分）
各维度：真实性 __/20 · 逻辑性 __/20 · 专业性 __/20 · 应变性 __/20 · 表达力 __/10 · 态度 __/10
每维附：扣分依据（引他哪一题的哪句回答）+ 改进要点
回答最好的一处 / 最差的一处
需要补充的材料（对应轨道 A 的缺项）
下一轮训练重点（可接 SOP 第六节五天训练计划）
```

**每一句都要带**：`※ 本分按包内参考标准给出，非当届官方评审分，不预测获奖。`

---

## 三条不得

1. **不得把参考分说成官方得分**，不得由参考分推「能拿什么奖」「进不进省赛国赛」。
2. **不得用生成数据补齐缺失证据**：轨道 A 缺第 6、7 项就是缺，不替他编检测报告、合同、客户评价。
3. **不得报具体学校的综测分值、推免名额、评审细则原文**（`../../shared/01_归属与边界.md:51`「给查法，不给数字」）；`材料骨架.md:211` 写明分值权重逐届逐校会调，写死即错，一律查当届通知与本院当年文件。
