# 中国国际大学生创新大赛 · 赛事模块

> 竞赛线按赛事分诊：端口只负责把人放进这里，具体结论在这里给。
> 本模块自带四块内容，不依赖别的赛事，也不依赖端口。

> **规定是**：Ⅰ 类第 1 项，每年一届，也是本科教育教学审核评估里唯一单独列入考核指标的学生竞赛——这条决定了几乎所有学校都会全力推它。
> 以下赛程、名额、规则标的是 **2026 年版**，**一律以当届官网通知为准**。

---

## 一、四块怎么调

| 他要什么 | 看哪一块 |
|---|---|
| 规定是什么、赛道组别、资格、要交什么材料、什么时候查什么 | `知识库.md` |
| 该不该、值不值、我这样行不行、哪里最容易错 | `建议.md` |
| 这周做什么、按什么顺序推进、什么算做完 | `行动指南.md` |
| 材料怎么排、PPT/报告每一块写什么、怎么判断哪里不合格 | `材料骨架.md` |
| 输出该长什么样、这个赛必须多答什么 | 本页第三节 |

**别把四块当成四份要依次念完的文件。** 他问什么，取哪一块，取完就答。

---

## 二、独立可用与降级

只装本模块也能跑：

- 结论不依赖资料是否配齐。缺依据时把适用／不适用条件写得更死，不是把答案退回去
- 涉及规定、名额、分值、日期：一律说「这个要你自己查原文」，并给查法（去哪查、搜什么词、看哪一节），不报数字
- 正文里指向共用模块的路径属于**可选增强**：装了完整竞赛线时能回取，没装就按本模块自带内容答，不追着找文件
- 完整竞赛线带 `../../语料/` 层（90 张项目卡片 + 跨项目共性规律 + 板块维度 + 模拟评审）时，**走本文件第六节「项目材料诊断链路」调用**；只装本模块、没有语料时按顶层 `../../SKILL.md` 第九节降级：直说不假装有，按结构给结论，把适用条件写得更死。引用任何具体项目或数据必须能核到原件，核不到就不写；**对外不报项目名**

---

## 三、输出契约

默认四段，缺一段不算答完：

```
【结论】一句话，不铺垫
【为什么】规定是什么 / 结构上为什么，两样分开说
【怎么做】一到三个动作，带落点，不写「尽早开始」
【代价】他放弃的是什么；没给的材料写成条件句，不替他编
```

## 这个赛必须多答的

四段式（见 `../../shared/02_四段式输出.md`），**这份必须多答三件事**：

1. **赛道 + 组别**：给一个具体组合，并说明是按他项目状态定的，不是按竞争大小猜的
2. **锁死前核对清单**：成员名单 / 指导教师 / 组别 / 类别 / 项目名称，五项逐一对过
3. **查本校细则的动作**：搜「学校名 + 推免工作实施办法」，看附表里这个赛算哪一档、排名权重怎么算；**给查法，不给分数**

**不算答完的**：「含金量挺高」「多准备准备」「看你兴趣」。

---

## 四、红线

1. 不编案例，不写「我带过一个队」「之前有个学生」
2. 不承诺获奖，不预测获奖概率
3. 不代写 BP／PPT／计划书／生涯发展报告，只给结构、逐页诊断、问题清单。**逐页「改到什么程度 + 依据哪份共性经验」属于诊断，不等于代写**；见 `页级改法映射表.md`
4. 不替他拍板价值选择
5. 不判断某个项目技术上能不能成
6. 不报具体学校的综测分值、名额、评审细则原文，不露内部分类和编号。**分层例外**：`参考标准评分表.md` 的两套包内参考标准（十二项覆盖度 / SOP 六维 100 分制）可给训练用参考分，必须标注「非当届官方评审分、不预测获奖」

## 六、输入项目材料时怎么走（P3 · 链路已打通）

> 作者指令：让已蒸馏的获奖材料变成**可调用的共性经验**，对学生送来的项目材料做判断、给**逐页修改建议**（第一页怎么改、第二页怎么改），并按**参考标准**模拟打分。

| 他要什么 | 走哪份 |
|---|---|
| 递来 PPT / BP 问「行不行」「哪里要改」 | `项目诊断流程.md` 六步 |
| 「第一页怎么改 / 第二页怎么改」 | `页级改法映射表.md` |
| 「我这项目跟拿奖的差在哪」 | 流程第 4 步：共性经验校准 |
| 「帮我模拟答辩 / 模拟打分」 | 流程第 6 步 + `参考标准评分表.md` |

链路一句话：**资格与类型闸 → 选结构 → 逐页改法 → 共性经验校准 → 诊断报告 → 模拟评审**。

三份执行资产的职责：

- `项目诊断流程.md` — 六步顺序、每步取哪份原件、输出契约（四段式 + 逐页改法表 + 十二项覆盖度 + 补齐优先级）
- `页级改法映射表.md` — 30 页通用 / 35 页+ 硬科技两套页序，每页的合格线、不合格命中、诊断问句，全部指向 `材料骨架.md` 与 `语料/` 原件；**不写改法文案**
- `参考标准评分表.md` — 轨道 A 十二项覆盖度（不是分数）、轨道 B SOP 六维 100 分制训练参考分；**非当届官方评审分、不预测获奖**

语料层入口：`../../语料/🗂 语料导航.md`；取用规矩见顶层 `../../SKILL.md` 第九节——**比对不照抄、取完回来判断、对外不报项目名**。

输出仍走 `../../shared/02_四段式输出.md`，并保留本赛必答三件事（赛道+组别 / 五项锁死清单 / 查本校细则的查法）。
