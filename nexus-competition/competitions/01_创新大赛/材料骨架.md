# 中国国际大学生创新大赛 · 材料骨架

> 这一块放**结构**：路演 PPT 排什么、BP 排什么、每一块要让评委相信什么、什么样的算不合格、怎么问学生让他自己排出来。
> 这一块给的是判断，不说成评审文件写的；凡引规定，一律注明「以当届通知为准」。
> **不带任何具体项目名、学校、页码引用、分值**——要举例只写「某类项目的国金作品」。

---

## 一、先定一个判断：排页之前，先有一句主张

**排页不是排版，是把一句主张拆成 30 个证据。**

学生上来就问「PPT 怎么做」，正确顺序是反的：

```
第一步：一句话说清「我在解决谁的什么问题，凭什么是我」
第二步：这句话拆成 4-6 个必须被相信的点
第三步：每个点给 3-8 页证据
第四步：才轮到页数和美化
```

**判定标准**：他说不出一句话主张，或者一句话里有三个「和」——题还没定，别做 PPT，回去定题。

**引导问句**：
- 你这个项目，如果只能说一句话，是哪一句？
- 这句话里的「谁」，能说出一个具体的人或一类具体单位吗？
- 「凭什么是我」，你的答案是一份检测报告、一份合同，还是一个想法？

## 二、路演 PPT：两套可参照的结构

### A. 通用结构（约 30 页，适合概念期、早期项目、创意组）

三幕式：**我是谁 → 我怎么解决 → 我值多少分**

| 页码 | 板块 | 这一块要建立什么 | 合格线 |
|---|---|---|---|
| 1 | 封面 | 0.5 秒记住你 | 一句话定位，不堆形容词 |
| 2-3 | 项目缘起／故事 | 信任感 | 有一个真实的起点，不是「国家政策要求」 |
| 4-8 | 背景（政策／行业／市场） | 赛道对 | 政策文件 + 市场规模 + 增速，数字带出处 |
| 9-12 | 痛点 | 问题真实且痛 | 三个痛点，每个都能接上后面一项技术 |
| 13-18 | 解决方案 | 我能解决 | 原理 → 产品 → 效果，三段递进 |
| 19-21 | 竞品分析 | 我比他们好 | 维度对比表，不是散文 |
| 22-23 | 商业模式 | 能持续 | 收入从谁那里来，画出来 |
| 24-25 | 团队 | 这群人行 | 能力与项目匹配，不是罗列奖项 |
| 26-27 | 规划 | 想清楚了 | 3-5 年路线，带节点 |
| 28-29 | 社会价值／教育维度 | 值得给高分 | 数字 + 具体受益方 |
| 30 | 结尾 | 记住我 | 回到第 2-3 页那个起点，闭环 |

### B. 硬科技／B2B／创业组结构（35 页以上）

顺序有一处关键不同：**公司资质先行**，先证明「我们是一家真实存在的企业」，再讲技术。

```
封面 → 公司与资质 → 市场+政策+需求（三板斧） → 痛点（三个，配数据）
→ 实践历程（时间线+现场照片） → 技术与方案（流程图→创新点→数据对比）
→ 技术壁垒（专利/认证/软著） → 竞品（多维碾压表） → 商业模式（产业链+变现方式）
→ 客户案例（三个，对应三种模式） → 市场推广 → 财务（历史+预测）
→ 团队（负责人/成员/顾问/导师，可占 3-4 页） → 教育维度 → 社会价值
→ 结尾 → 证明材料（财务、专利、合同、执照）
```

### 按项目类型选结构

| 项目类型 | 推荐页数 | 结构重心 |
|---|---|---|
| 概念期／早期 | 25-30 | 故事先行，逻辑紧凑 |
| 创业组／已注册公司 | 35+ | 公司先行，案例密集 |
| 社会价值／红旅 | 30-35 | 故事+政策+社会价值占比大 |
| 硬科技／B2B | 35+ | 数据密集，技术拆解，竞品对比 |
| 文化创意／消费 | 25-30 | 故事+设计+用户反馈 |

**页数不是评分项，是结构的自然结果。** 别为了凑 35 页注水，也别为了「简洁」把证据删掉。

## 三、逐块诊断：什么样的算不合格

**这一节是诊断表，不是模板。** 用法：学生把现有材料拿来，逐块对比「不合格的样子」，命中的就是要改的。

| 板块 | 不合格的样子 | 一句诊断问句 |
|---|---|---|
| 项目缘起 | 从「国家高度重视」开头，看不到人 | 这个故事里，第一个具体的人是谁？ |
| 背景 | 只有市场规模，没有政策和增速 | 这个数哪来的？去年的还是前年的？ |
| 痛点 | 痛点和技术对不上；用「体验不好」这种谁都能说的话 | 你说的问题，靠你哪项技术解决？逐个对上 |
| 解决方案 | 只讲原理，不讲做出来什么样 | 有实物、有样机、有测试画面吗？ |
| 竞品 | 只列名字，不比维度；或者只跟自己比 | 是拿你的强项比人家的弱项吗？ |
| 商业模式 | 只写「卖产品」，收入来源说不清 | 第一笔钱谁付？为什么付？ |
| 团队 | 罗列奖项和头衔，看不出分工 | 这四个位置各是谁：拍板、技术、材料、上台 |
| 规划 | 五年后「市场占有率 10%」这种无依据数字 | 第一年做到什么算成功？ |
| 社会价值 | 空喊「助力乡村振兴」，没有受益人数 | 受益的是谁，多少，谁在统计 |
| 教育维度 | 只提学校支持，不提学生成长 | 这个项目让团队里的学生长出了什么能力 |

**共同规律**：不合格的材料几乎都是同一个病——**说的是「我们很努力」，不是「问题被解决了」**。

## 四、BP：两套口径，按用途分叉

库里两套说法（八页表 / 九章）不是矛盾，是**给不同场合用的**。分不清就会给错。

| 你要的是 | 用哪套 | 多少 | 场合 |
|---|---|---|---|
| 路演前的一页纸／评审速览 | **八页表** | 8 屏 | 投递、初筛、答辩前给评委过一眼 |
| 正式提交的商业计划书 | **九章体系** | 80-100 页 | 书面评审、需要严密论证链 |

### 八页表（路演速览）

```
1 一句话主张 + 一句话定位        ← 30 秒决定他是否继续看
2 问题：谁、多痛、现在怎么凑合
3 方案：原理一句话 + 产品图
4 证据：检测/合同/用户数据（三选二）
5 壁垒：专利、工艺、资质
6 市场：规模 + 切入路径
7 商业模式：谁付钱、付多少
8 团队 + 这半年要做什么
```

### 九章体系（书面 BP）

```
执行摘要（2-3 页）      ← 唯一所有人都会认真看的部分
项目背景（8-12）         ← 证明赛道对
市场分析（10-15）        ← 证明市场对
产品与技术（10-15）      ← 证明方案对
商业模式（5-8）          ← 证明能赚钱
营销策略（5-8）          ← 证明能卖
团队（5-8）              ← 证明人能行
财务预测（8-12）         ← 证明想清楚了
风险与对策（5-8）        ← 证明有后手
附录（10-20）
```

**BP 三条铁律**：
1. **先搭目录再写内容**——目录没逻辑，写到一半想重来
2. **每章自成一体**——评委会跳着看，第 3 章和第 6 章要能单独读懂
3. **删掉所有形容词**——「显著提升／大幅增长／广泛好评」一律换成数字

**PPT 与 BP 的根本差别**：PPT 靠节奏带着评委走，BP 靠严密扛住评委挑。同一套内容，PPT 是表演稿，BP 是判决书。

## 五、七类项目的结构差体

同一套骨架，开头和论证方式按类型换。**这是最容易做错的一处：拿硬科技的骨架套社会价值项目，评委会觉得你答错了题。**

| 类型 | 开头怎么起 | 核心论证靠什么 | 信任来源 | 结尾落在哪 |
|---|---|---|---|---|
| 硬科技／装备制造 | 问题冲击（战略 + 数据） | 技术 → 专利 → 参数对比 | 检测报告、央企合同、专家评价 | 国产替代、产业意义 |
| 新材料／能源 | 行业瓶颈 | 配方／性能／成本三线对比 | 性能检测、认证 | 应用规模、降本空间 |
| 红旅／乡村振兴 | 一个地方、一群人 | 发现 → 行动 → 方案 → 成果 | 调研记录、农户／政府认可 | 持续机制，不是一次性帮扶 |
| 新医科／医疗 | 临床需求 | 技术路线 → 证据链 → 医院合作 | 动物／临床数据、伦理审批 | 可及性与普惠 |
| 平台／AI／服务 | 流程痛点 | 流程 → 平台 → 数据 → 客户 | 真实合同、毛利结构 | 网络效应、规模化 |
| 文化创意／消费 | 文化母题 | 产品矩阵 → 场景 → IP | 实物、线下场景、用户反馈 | 文化传播与商业闭环 |
| 海洋／深海等受封锁领域 | 封锁事实 | 国产化 → 海试 → 央企合作 | 海试数据、国际对标 | 自主可控 |

**引导问句**：你这个项目属于哪一类？先说类型，再说结构——说错类型，后面每一页都会歪。

## 六、十二项共性自检（国金作品的共同底子）

不是评分表，是**投出去之前的自查清单**。少于八项，材料基本不成立。逐项「有／不足／缺」的覆盖度记录格式，见 `参考标准评分表.md` 轨道 A。

1. 国家战略背景（政策文件、规划、卡脖子问题）
2. 市场规模与增速（带出处）
3. 三个痛点（技术／成本／效果，各对应一项方案）
4. 核心技术（专利、算法、材料、工艺，至少一样硬的）
5. 竞品对比（表格化、量化）
6. 第三方验证（检测报告、鉴定、应用证明）
7. 真实客户或合同（不是「已有多家意向客户」）
8. 商业模式（收入结构，不止一种更好）
9. 团队背书（能力与项目匹配）
10. 教育维度（学生成长、专创融合）
11. 社会价值（就业、环保、安全、国产替代等，带数字）
12. 战略规划（时间轴 + 可检验的里程碑）

**用法**：让学生逐项打勾，缺的那几项就是他这周要补的动作。第 6、7 项缺，通常是硬伤，不是靠改文案能救的。

## 七、逻辑链自检：上一页最后一句能不能接上下一页第一句

```
封面 → 你看到了一个巨大的问题
缘起 → 我正在经历什么
背景 → 这痛苦来自政策/行业/市场的真实变化
展开 → 你以为是个例？看数据，整个行业都这样
痛点 → 具体来说，这群人正被这三个问题折磨
方案 → 我能解决，这是原理、这是产品、这是效果
竞品 → 你觉得别人也能做？来，我告诉你为什么只有我能
模式 → 而且我已经想好怎么持续
团队 → 这群人就是能把这件事做成的人
规划 → 我们有清晰路线图
价值 → 做成之后，不止我们受益
结尾 → 回到开头那个问题：我们已经改变了它
```

**自检办法**：把每一页的标题单独抄下来，连成一段话读。读不通，就是这一页插错了位置。

## 不覆盖什么

这份给结构、给判断、给查法；下面几类**刻意不写**——写死就是错的：

| 不覆盖 | 为什么不写 |
|---|---|
| 评审细则原文与分值权重 | 逐届逐校都会调，写死即错。一律查当届通知与本院当年文件 |
| 具体项目、团队、获奖材料的真实案例 | 案例能指认到具体的人，不引用。只给判断，把适用与不适用条件写得更死 |
| 具体某校的认定与赋分、名额 | 各校各年不同，永远让学生查本校原件 |
| 「哪种写法得分更高」这类偏好结论 | 没有能核到原件的依据就不下结论 |
| 官方评审细则原文与分值权重（本模块仍不覆盖） | 见 `参考标准评分表.md`：可用包内可核的参考标准给**训练用参考分**，但不得说成官方得分或获奖预测 |
