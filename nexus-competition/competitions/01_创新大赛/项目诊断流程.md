# 中国国际大学生创新大赛 · 项目诊断流程

> 作者指令（P3）：把已蒸馏的获奖材料接成可调用链路——从共性经验里给建议、对送来的项目材料做判断和**逐页修改建议**、按**参考标准**模拟打分。
> 本文件只写「怎么走、取哪份原件、交出什么」。所有改法、共性经验、评分权重都从包内原件取，**不在这里另写一套内容**。

---

## 一、什么时候走这条链路

| 他说 | 走哪一步起 |
|---|---|
| 发来一份 PPT / BP / 项目介绍，问「我这项目行不行」「哪里要改」 | 第 1 步 |
| 「第一页怎么改」「第二页怎么写」 | 第 1 步 → 直接进第 3 步 |
| 「我这项目跟拿奖的差在哪」 | 第 1 步 → 重点第 4 步 |
| 「帮我模拟答辩 / 模拟打分」 | 第 1 步 → 第 6 步 |
| 只问该报哪个赛道、报名前要锁什么 | **不走本链路**，回 `建议.md` + `行动指南.md` |

## 二、六步（不得停在第一步）

### 第 1 步 · 资格与类型闸

先问清四件事，缺了就只问那一句，不追问第二句：

1. **赛道 + 组别**（高教主赛道 / 红旅 / 职教 / 产业；创意组 / 初创组 / 成长组）
2. **项目来源**：这题以前报过国赛没、是不是往届获奖项目改的
3. **有没有注册公司**：决定创意组还是初创/成长组
4. **项目类型**：概念期 / 硬科技 B2B / 文化创意 / 新医科 / 红旅社会价值 / 平台 AI 服务

依据：`知识库.md` 硬规则、`行动指南.md` 阶段一、`建议.md` 判断 2 与判断 4。
**这一步不定，后面页序会选错**（25–30 页 vs 35 页+ 是两套结构）。

### 第 2 步 · 选结构

按第 1 步的项目类型，在 `材料骨架.md` 第二节「按项目类型选结构」表里定一套：

- 通用 30 页（概念期 / 早期 / 创意组）→ 三幕式「我是谁 → 我怎么解决 → 我值多少分」
- 硬科技 / B2B / 创业组 35 页+ → **公司资质先行**，顺序见 `材料骨架.md` 第 55–62 行
- 社会价值 / 红旅 30–35 页 → 故事 + 政策 + 社会价值占比大

**页数不是评分项，是结构的自然结果**（`材料骨架.md:74`）。不为凑页注水，也不为简洁删证据。

### 第 3 步 · 逐页对标与改法

用 `页级改法映射表.md` 一页一页过。每条改法必须给全五样：

```
页码 / 现状（他材料里这一页写了什么）
→ 命中哪条「不合格的样子」
→ 改到什么程度（引用原件的合格线）
→ 依据哪份共性经验 / 板块维度文件
→ 优先级（硬伤 / 结构 / 表述）
```

依据原件：`材料骨架.md` 第三节逐块诊断表（9 类不合格 + 诊断问句）、第七节逻辑链自检、`../../语料/10_PPT维度/02_核心板块设计/` 下 12 份板块文件、`../../语料/20_BP维度/` 章节体系。

**逐页改完必须做一次逻辑链自检**：把每页标题连成一段话读，读不通就是这一页插错了位置（`材料骨架.md:201`）。

### 第 4 步 · 共性经验校准

按项目类型取，**一次取一份主规律 + 一份同类卡片**，不连甩：

| 要什么 | 取哪 |
|---|---|
| 国金项目的共同底子 | `材料骨架.md` 第六节「十二项共性自检」 |
| 从国金项目拆出来的可复用认知 | `../../语料/40_对标矩阵/国金项目共性规律.md`（页数、叙事顺序、五大硬核标配、案例三有、技术三段式、团队企业化、教育与社会价值） |
| 跨项目统计规律 | `../../语料/规律提炼/30国金项目跨项目规律总结.md` 12 个共性要素；同类还有 `51`、`75`、`21省市冠军` 三份 |
| 按项目类型的专项要点 | `../../语料/规律提炼/` 下 `硬科技` / `新医科医疗` / `文化创意非遗` / `平台AI服务型` / `红旅赛道` 五份，取对应那一份 |
| 同类项目写到什么颗粒度 | `../../语料/00_项目卡片/` 下三份索引定位 → 读 1 张同类卡片 |

**三条规矩（顶层 `../../SKILL.md` 第九节 + `../../语料/🗂 语料导航.md`）**：比对不照抄；取完必须回来判断，结论仍在赛事模块出；**对外不报项目名**，只说做法，不说「某某项目就是这么干的」。

### 第 5 步 · 出《项目诊断报告》

按 `../../shared/02_四段式输出.md`，四段之外**必须多附三张表**：

1. **逐页改法表**（第 3 步产物）
2. **十二项覆盖度**（`参考标准评分表.md` 轨道 A）
3. **补齐优先级**：分「这周能补的文案」「要去找第三方的证据」「补不了的硬伤」三档

`材料骨架.md:180` 明写：第 6 项第三方验证、第 7 项真实客户/合同缺了通常是硬伤，**不是靠改文案能救的**——诊断报告必须直说，不许用「建议进一步完善」糊过去。

### 第 6 步 · 模拟评审（可选，用户要才走）

输入项目基本信息（SOP「模拟前准备」七项）→ 按 `../../语料/60_模拟评审/模拟评审总览.md` 进 AI 评委模式 → 从 `../../语料/60_模拟评审/专家问题库.md` 8 维度挑题 → 按 `参考标准评分表.md` 轨道 B 给参考分 → 用 `../../语料/60_模拟评审/评委提问清单.md` 出提交前自查。

## 三、输出契约

```
【结论】一句话：这份材料现在卡在哪一档（硬伤 / 结构 / 表述）
【为什么】规定是什么 / 结构上为什么 / 命中国金共性里的哪一条，三样分开说
【怎么做】逐页改法表 + 这周能补的动作，带落点
【代价】缺第 6、7 项意味着什么；没给的材料写成条件句，不替他编
--- 附：逐页改法表 / 十二项覆盖度 / 补齐优先级 / 参考分（可选）
```

**不算答完**：「整体不错」「多打磨打磨」「参考一下国金项目」。每条建议要落到**具体页码 + 具体改到什么程度**。

---

## 四、红线（沿用，未放宽）

1. 不代写 BP / PPT / 计划书正文；**逐页「改到什么程度 + 依据」属于诊断，不等于代写**。
2. 不编案例、不编数字、不编第三方评价、不写「我带过一个队」。
3. 不承诺获奖、不预测获奖概率。
4. 不报具体学校的综测分值、推免名额、评审细则原文；不把当届赛程当永久事实。
5. **参考分只按包内可核到原件的参考标准给，明确标注「训练用参考分，非当届官方评审分、不预测获奖」**，见 `参考标准评分表.md`。
6. 不把判断说成文件写的：共性经验对外只说「这是我的判断 / 这是从获奖材料里提炼的做法」。
7. 引用具体项目或数据必须能核到原件，核不到就不写；对外不报项目名。
