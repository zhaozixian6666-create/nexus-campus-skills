## 一、通用 30 页结构 · 逐页判据

合格线 / 不合格的样子 / 诊断问句来源：`材料骨架.md:37-49`、`:82-93`。

| 页码 | 板块 · 说服任务 | 合格线（照这条改） | 不合格的样子（命中即要改） | 一句诊断问句 |
|---|---|---|---|---|
| 1 | 封面 · 0.5 秒记住你 | 一句话定位，不堆形容词 | 堆形容词、只有项目名没有定位 | 这一页去掉校徽和标题，还剩一句能记住的话吗 |
| 2–3 | 项目缘起／故事 · 信任感 | 有一个真实的起点，不是「国家政策要求」 | 从「国家高度重视」开头，看不到人 | 这个故事里，第一个具体的人是谁 |
| 4–8 | 背景（政策／行业／市场）· 赛道对 | 政策文件 + 市场规模 + 增速，数字带出处 | 只有市场规模，没有政策和增速 | 这个数哪来的？去年的还是前年的 |
| 9–12 | 痛点 · 问题真实且痛 | 三个痛点，每个都能接上后面一项技术 | 痛点和技术对不上；用「体验不好」这种谁都能说的话 | 你说的问题，靠你哪项技术解决？逐个对上 |
| 13–18 | 解决方案 · 我能解决 | 原理 → 产品 → 效果，三段递进 | 只讲原理，不讲做出来什么样 | 有实物、有样机、有测试画面吗 |
| 19–21 | 竞品分析 · 我比他们好 | 维度对比表，不是散文 | 只列名字，不比维度；或者只跟自己比 | 是拿你的强项比人家的弱项吗 |
| 22–23 | 商业模式 · 能持续 | 收入从谁那里来，画出来 | 只写「卖产品」，收入来源说不清 | 第一笔钱谁付？为什么付 |
| 24–25 | 团队 · 这群人行 | 能力与项目匹配，不是罗列奖项 | 罗列奖项和头衔，看不出分工 | 这四个位置各是谁：拍板、技术、材料、上台 |
| 26–27 | 规划 · 想清楚了 | 3–5 年路线，带节点 | 五年后「市场占有率 10%」这种无依据数字 | 第一年做到什么算成功 |
| 28–29 | 社会价值／教育维度 · 值得给高分 | 数字 + 具体受益方 | 空喊「助力乡村振兴」没有受益人数；只提学校支持不提学生成长 | 受益的是谁，多少，谁在统计／这个项目让学生长出了什么能力 |
| 30 | 结尾 · 记住我 | 回到第 2–3 页那个起点，闭环 | 只写「谢谢观看」 | 开头那个问题，结尾回答了吗 |

**共同规律（`材料骨架.md:95`）**：不合格的材料几乎都是同一个病——说的是「我们很努力」，不是「问题被解决了」。

## 三、35 页+ 硬科技 / B2B / 创业组：顺序差异

`材料骨架.md:55-62` 原文顺序，**关键不同是「公司资质先行」**，先证明企业真实存在，再讲技术：

```
封面 → 公司与资质 → 市场+政策+需求（三板斧） → 痛点（三个，配数据）
→ 实践历程（时间线+现场照片） → 技术与方案（流程图→创新点→数据对比）
→ 技术壁垒（专利/认证/软著） → 竞品（多维碾压表） → 商业模式（产业链+变现方式）
→ 客户案例（三个，对应三种模式） → 市场推广 → 财务（历史+预测）
→ 团队（负责人/成员/顾问/导师，可占 3-4 页） → 教育维度 → 社会价值
→ 结尾 → 证明材料（财务、专利、合同、执照）
```

对这类项目，逐页改法要额外查：`../../语料/40_对标矩阵/国金项目共性规律.md` §3 五大硬核标配、§4 案例三有、§5 技术三段式、§6 团队企业化、§8 排版六技巧；并回 `材料骨架.md:66-72` 按项目类型确认页数重心。
