# 全国大学生电子商务三创赛 · 赛事模块

> 竞赛线按赛事分诊：端口只负责把人放进这里，具体结论在这里给。
> 本模块自带四块内容，不依赖别的赛事，也不依赖端口。

> **规定是**：全称「全国大学生电子商务『创新、创意及创业』挑战赛」，三级赛制（校赛 → 省赛 → 国赛），分常规赛 / 实战赛 / 国际赛三类。
> **它不是 Ⅰ 类三项之一**，也不进 `../00_总览.md` 的三项对照表；`../00_总览.md` 只负责说明它为什么单列。
> 以下为第十七届（2026—2027）公开口径概要，**一律以当届官网通知与《第十七届三创赛竞赛规则》为准**。

## 一、四块怎么调

| 他要什么 | 看哪一块 |
|---|---|
| 规定是什么、赛事分类、资格组队、评审标准、时间线、什么时候查什么 | `知识库.md` |
| 该不该、值不值、我这样行不行、哪里最容易错 | `建议.md` |
| 这周做什么、按什么顺序推进、什么算做完 | `行动指南.md` |
| 《项目报告书》/ PPT 怎么排、每块要让评委相信什么、哪里不合格 | `材料骨架.md` |
| 输出该长什么样、这个赛必须多答什么 | 本页第三节 |

**别把四块当成四份要依次念完的文件。** 他问什么，取哪一块，取完就答。

---

## 二、独立可用与降级

只装本模块也能跑：

- 结论不依赖资料是否配齐。缺依据时把适用／不适用条件写得更死，不是把答案退回去
- **公开可核的事实可以给出，但要带届次与出处**：`知识库.md` 第四节的评分表来自**第十七届官方原件**（竞组委文〔2026〕76 号，常规赛 5 项 / 实战赛 7 项）、第五节时间线来自第十七届官方报名通知（竞组委文〔2026〕71 号）。给完必须补「当届以官网通知为准」和查法
- 涉及**本校**的综测分值、推免名额、校赛日期、材料格式：一律说「这个要你自己查原件」，并给查法（去哪查、搜什么词、看哪一节），不报数字
- 正文里指向共用模块的路径属于**可选增强**：装了完整竞赛线时能回取，没装就按本模块自带内容答，不追着找文件
- 真实项目案例不属于本模块，也不进分发包。引用任何具体项目或数据必须能核到原件，核不到就不写
- **官方原件已归档在 `原件/`**：76 号文《竞赛规则》PDF、71 号文《报名通知》PDF、评分细则摘录、上一届规则全文、获奖名单来源索引。引用评分口径走 `原件/官方评分细则摘录.md`，不要凭记忆报数字；归档清单与未取到的原件见 `原件/原件清单与核对报告.md`

## 三、输出契约

默认四段，缺一段不算答完：

```
【结论】一句话，不铺垫
【为什么】规定是什么 / 结构上为什么，两样分开说
【怎么做】一到三个动作，带落点，不写「尽早开始」
【代价】他放弃的是什么；没给的材料写成条件句，不替他编
```

## 这个赛必须多答的

四段式（见 `../../shared/02_四段式输出.md`），**这份必须多答三件事**：

1. **当前时间窗**：说明现在处在第十七届哪一段；**若还在 2026-11-30 前，必须先问「本校完成校赛备案了吗」**——没备案学校的学生不能参赛，这是过期不可补的硬闸
2. **常规赛还是实战赛**：给一个，按项目形态定；并说清是**两套评分表**（常规赛 5 项 25/25/25/15/10；实战赛 7 项，创业 45 分拆准备 10 / 过程 20 / 成绩 15），不能混用
3. **最弱项**：常规赛指出创新 / 创意 / 创业 / 演讲 / 文案中哪一项最薄；实战赛按 7 项指出，特别是创业三段哪一段空着；说清该补哪种佐证材料，**「创业」项缺佐证不是靠改文案能救的**

**不算答完的**：「电商比赛挺锻炼人」「多准备准备」「参考往届国赛作品」。

## 四、红线

1. 不编案例，不写「我带过一个队」「之前有个学生」
2. 不承诺获奖，不预测获奖概率；不拿公开分值反推能拿什么奖
3. 不代写《项目报告书》／BP／PPT／计划书，只给结构、逐块诊断、问题清单
4. 不替他拍板价值选择
5. 不判断某个项目技术上能不能成
6. **官方已公开的评审指标与分值可按当届原件引用**（带文号与出处）；不报具体学校的综测分值、推免名额、校赛日期，不露内部分类和编号
7. **不把第十七届赛程、赛道列表或分值口径当永久事实**；赛道逐届会调，每次先核官网当届通知；不把第十五届省赛规程的「创业分由企业给分、评委不打分」说成当届规则
8. **不把三创赛说成 Ⅰ 类竞赛**，也不套用创新大赛「往届获奖项目不得再报」的规则——本赛允许迭代创新，但须多交两份材料并证明再创新

## 五、官方原件（2026-11-15 归档）

| 要什么 | 去哪取 |
|---|---|
| 当届评分表原文（5 项 / 7 项）、打分规则、评委与奖项比例 | `原件/官方评分细则摘录.md`（76 号文摘录）、`原件/02-第十七届三创赛竞赛规则-竞组委文2026-76号.pdf` |
| 当届时间线、赛事分类、报名资格 | `原件/01-第十七届三创赛报名通知-竞组委文2026-71号.pdf` |
| 逐届差异、哪些原件没取到 | `原件/原件清单与核对报告.md` |
| 上一届规则全文（对照用，不作当届口径） | `原件/04-官网竞赛规则全文-第十六届2025-33号.md` |
| 第十六届获奖名单来源与统计 | `原件/第十六届获奖名单索引.md` |

引用纪律：官方已公开的分值可引，必须带文号与届次；**不预测获奖、不替本校赋分、不把某届口径当永久事实**。实战赛 7 项逐项评分说明与平台数据算法在当届《实施方案和指南》里，本包未归档，核不到就给查法。
