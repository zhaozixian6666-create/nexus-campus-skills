# 全国大学生电子商务三创赛 · 材料骨架

> 这一块放**结构**：《项目报告书》排什么、演讲 PPT 排什么、每一块要让评委相信什么、什么样的算不合格、怎么问学生让他自己排出来。
> 结构从 `知识库.md` 第四节的**评分说明反向映射**（常规赛 5 项 / 实战赛 7 项），不是另造一套模板；凡引规定，一律注明「以当届官网通知为准」。
> **不带任何具体项目名、学校、页码引用、也不新增分值**——分值只在 `知识库.md` 第四节与 `原件/官方评分细则摘录.md`。

---

## 一、先定一个判断：五维不是五个章节，是五个要回答的问题

学生上来就问「报告书怎么写」，正确顺序是反的：

```
第一步：一句话说清「我在解决谁的什么电商问题，凭什么是我」
第二步：把这句话拆成创新 / 创意 / 创业 / 演讲 / 文案五个问题
第三步：每个问题配一条能核验的证据，配不上的就是这周要补的动作
```

**评委不是在读报告，是在给评分表的格子找证据**（`知识库.md` 第四节：常规赛 5 项、实战赛 7 项）。格子空着，文字再漂亮也填不上分。

---

## 二、《项目报告书》：五维反推的板块

| 评分项 | 这一块要让评委相信 | 对应材料 | 不合格的样子 |
|---|---|---|---|
| 创新 | 新产品 / 新技术 / 新模式 / 新服务**至少有一个明确的创新点** | 创新点清单 + 与现有做法的对比 | 通篇「基于 AI 赋能」，说不出到底新在哪一个点 |
| 创意 | 商务策划和可行性分析是**创新性的** | 业务模式 / 营销模式 / 技术模式 / 财务支持的设计；经济、管理、技术、市场四方面可行性 | 只有一份市场介绍，没有「我打算怎么跑」的设计 |
| 创业 | **真的做过**，不是打算做 | 创业准备、注册公司或与公司合作、电商营销记录、经营效果，均须佐证；实战赛另有平台数据 | 三年财务预测精确到小数点后两位，但没有一笔真实交易 |
| 演讲 | 团队分工合理、表达清楚、**有问必答且回答合理** | 分工表、答辩分工、追问预案 | 只练了 8 分钟讲稿，没练过被追问 |
| 文案 | 报告书与 PPT 逻辑结构合理、内容完整严谨、图表清晰、**附录充分** | 完整目录、图表、附录（佐证材料） | 正文很满、附录为空，佐证散在聊天记录里 |

**两块最容易塌**：

- **创业项缺佐证是硬伤**，不是改文案能救的（与 `../01_创新大赛/项目诊断流程.md` 第 5 步对第 6/7 项的判读同理）。
- **实战赛的创业项 45 分按 76 号文拆成创业准备 10 / 创业过程 20 / 创业成绩 15 三段**，逐项打分；合作企业于校赛前 7 天、省级赛/国赛前 10 天提供实战业绩数据。逐项评分说明见当届《实战赛实施方案和指南》原件（本包未归档）。文案写得再好也填不上没有真实过程的那几格。

## 三、演讲 PPT：按答辩时间倒推

公开规程的小组赛答辩为 15 分钟（演讲 8 分钟 + 提问回答 7 分钟），终极赛演讲 8 分钟；**具体时长以当届赛项规程为准**。按 8 分钟倒推：

| 段 | 要建立的信任 | 对应评分项 |
|---|---|---|
| 开场一句话定位 | 我在解决谁的什么问题 | 创新 |
| 创新点 + 与现有做法对比 | 这事新在哪，不是一个换皮方案 | 创新 |
| 商务策划与可行性 | 我打算怎么跑，跑得通 | 创意 |
| 已做过的事 + 佐证 / 实战数据 | 不是 PPT 概念 | **创业** |
| 团队与分工 | 这群人做得成 | 演讲 |
| 回到开头那个问题 | 闭环 | 文案 |

**每页要有一句结论**。评委只记结论，不记细节；把每页标题连成一段话读，读不通就是页序插错了位置（同 `../01_创新大赛/材料骨架.md` 第七节逻辑链自检法）。

## 四、逐块诊断：什么样的算不合格

> 用法：学生把现有材料拿来，逐块对比「不合格的样子」，命中的就是要改的。**改法只指向上面表格的「对应材料」与 `知识库.md` 的评分说明，不代写正文。**

| 板块 | 一句诊断问句 |
|---|---|
| 创新点 | 去掉所有形容词，还剩下哪个具体的新东西 |
| 商务策划 | 第一笔钱谁付、为什么付、走哪条渠道，三句说得清吗 |
| 可行性 | 经济 / 管理 / 技术 / 市场四项，哪项你没写、为什么 |
| 创业佐证 | 这一页的每个数字，能拿出哪份原件 |
| 实战数据 | 有效销售额 / 订单数 / 用户数从哪天起算、平台在哪 |
| 团队分工 | 这五个位置各是谁：拍板、技术、运营、数据、上台 |
| 附录 | 佐证材料是不是都收进附录了，还是散在群里 |
| 迭代创新 | 与上次参赛作品的差异说明写了吗，再创新在哪一页 |

**共同规律**：不合格的材料几乎都在说「我们想做什么」，不是「我们已经做了什么、谁证明了」。

## 五、提交前自检

- [ ] 作品名与官网报名信息完全一致，团队名 ≤16 字符、作品名 ≤30 字符
- [ ] 报告书、PPT、佐证附录三样齐
- [ ] 五维逐项打勾，每项至少一条能核验的证据
- [ ] 「创业」项佐证齐全（实战赛另核平台数据起算日）
- [ ] 迭代创新项目已附「最近一次参赛作品」+「差异比较说明」
- [ ] 专利／软著／营业执照的署名或授权与团队成员对得上
- [ ] 地图使用合规；无与项目事实不符的证据、数据
- [ ] 答辩时长按**当届**规程核过，追问预案练过一轮
- [ ] 本校校赛的材料格式与提交截止时间已查（各校自定）

## 不覆盖什么

| 不覆盖 | 为什么不写 |
|---|---|
| 当届《竞赛规则》原文与分值权重 | 官方已公开部分见 `原件/官方评分细则摘录.md`（76 号文，带文号）；逐届逐赛道会调的部分仍写死即错，实战赛 7 项逐项说明须取当届《实施方案和指南》原件 |
| 具体项目、团队、获奖材料的真实案例 | 案例能指认到具体的人，不引用；对外只说做法，不报项目名 |
| 具体某校的认定与赋分、名额 | 各校各年不同，永远让学生查本校原件 |
| 「哪种写法得分更高」这类偏好结论 | 没有能核到原件的依据就不下结论 |
| 观点型改法与逐页文案 | 属代写，红线；结构和对标规则见 `../01_创新大赛/页级改法映射表.md`（那是创新大赛口径，本项目类型不同，不可直接套页序） |
