# 硬科技项目国金设计要点

> **从"锰"寐以"球"和"涂创未来"两个国金项目提炼的硬科技项目共性规律。**

---

## 一、硬科技项目 vs 其他项目的本质差异

| 维度 | 硬科技项目（材料/设备/芯片） | 消费/社会项目 |
|------|---------------------------|-------------|
| 开头 | 问题冲击型（国家战略+数据） | 人物故事型 |
| 核心论证 | 性能数据+检测报告 | 用户反馈+增长数据 |
| 信任来源 | 院士/专家背书、第三方检测 | 用户证言、媒体报道 |
| 壁垒 | 专利、论文、工艺秘密 | 品牌、渠道、网络效应 |
| 结尾 | 市场占有率、国产替代 | 社会影响力、用户规模 |

---

## 二、硬科技项目 PPT 标准结构（35页）

```
P1   封面：项目名 + 定位 + 学校/公司 + 负责人
P2   项目亮点页：一页四宫格，快速建立四大优势
P3-4 项目缘起/团队历程：时间线叙事
P5-7 行业背景：市场规模 + 市场份额 + 应用场景
P8-9 痛点分析：3个痛点，每个对应后续技术
P10-13 解决方案：核心技术1 + 核心技术2 + 产品展示
P14-16 性能测试：第三方检测 + 认证证书 + 数据对比
P17-18 商业模式/生产模式：产业链 + 四阶段生产
P19-20 竞品分析：国际对标表格
P21-22 团队主创：负责人学术背景
P23-25 团队/顾问：硕博团队 + 院士/专家顾问
P26-27 专家评价：推荐意见/盖章证明
P28  教育维度：奖项+专利+升学
P29  社会价值：国产替代/国家安全/产业意义
P30-33 战略规划：市场占有率目标 + 融资计划
```

## 三、一页四宫格项目亮点页（国金标配）

"涂创未来"P2页展示了硬科技项目最有效的开场方式：

```
┌─────────────┬─────────────┐
│ 国家战略    │ 核心技术    │
│ 与市场需求  │ 创新点      │
├─────────────┼─────────────┤
│ 科研平台    │ 商业模式    │
│ 支持        │ 与运营      │
└─────────────┴─────────────┘
```

每个格子 1-2 句话，配 1 个关键数字。整页不要多于 80 字。

> **作用**：让评委在前 30 秒知道这个项目"为什么值得高分"。

---

## 四、项目缘起时间线叙事

硬科技项目不要讲个人情怀，要用"国家战略 → 院士引导 → 团队研发 → 产品验证"的时间线：

| 时间 | 事件 | 关键人物/数据 |
|------|------|--------------|
| 2021.X | 发现国家战略需求/卡脖子问题 | 如 C919 发动机受制于人 |
| 2022.X | 院士/专家提出研发方向 | 何季麟院士建议研发热防护涂层 |
| 2023.X | 团队开展科研，取得突破 | 制备出高熵陶瓷粉体 |
| 2024.X | 产品验证，进入市场 | 通过小试验证，签署合作备忘录 |
| 2025.X | 公司化运营，规模化 | 成立公司，获得融资意向 |

> **关键**：每个节点都有具体人物、具体时间、具体成果。

---

## 五、行业背景三件套

硬科技项目行业背景页必须包含：

1. **市场规模增长图**：2023年多少 → 2027年多少，CAGR
2. **市场份额饼图/柱状图**：国外占多少、中国占多少、我们在哪里
3. **应用场景图**：产品在哪些部件/环节使用

> 数据来源：第三方报告、官网数据、政策文件。必须标注。

---

## 六、竞品分析国际对标表

"涂创未来"P14页展示了国际对标的标准做法：

| 指标 | 国际竞品 A | 国际竞品 B | 我们 | 提升幅度 |
|------|-----------|-----------|------|---------|
| 服役温度 | 1250°C | 1200°C | 1400°C | +12% |
| 结合强度 | 31 MPa | 28 MPa | 35 MPa | +75% |
| 热导率 | 0.96 | 1.13 | 0.78 | 隔热能力+50% |
| 热膨胀系数 | 11.6 | 8.4 | 13.0 | 热稳定性+54.7% |

> **要点**：只比你最强的 3-4 个维度，每个维度都有数字和百分比。

---

## 七、团队与背书页

硬科技项目团队页必须分三层：

1. **负责人页**：博士/硕士背景 + 论文 + 专利 + 国家级项目经历
2. **硕博团队页**：技术研发、工艺工程、商业运营三类角色
3. **专家顾问页**：院士 + 杰青/教授 + 产业专家
4. **专家评价页**：4 位专家推荐意见，附盖章/签名

> **误区**：不要只秀学生会、社团经历。要秀 SCI、专利、国家级项目。

---

## 八、教育维度与社会价值

### 教育维度（国创赛特色）
用三个数字：
- 国家级奖项 X 项
- 发明专利 X 项
- 本科生保送 X 人 / 升学率 X%

### 社会价值（硬科技项目）
突出三个关键词：
- **国产替代**：打破国外垄断
- **国家安全**：服务航空/军工/战略产业
- **产业升级**：带动上下游发展

> 最好配具体数字：如"预计 2028 年中国市场占有率达到 45%"

---

## 九、战略规划页

硬科技项目战略规划要有清晰的市场占有率目标：

```
2024：成立公司，产品上市
2025：系列化产品，研发总部
2026：自有生产基地，市场占有率 20%
2027：省级重点实验室，一体化生产线
2028：产业园区，市场占有率 45%
2029：行业领军者，市场占有率 65%
```

> 每个时间节点都有具体的、可验证的目标。

---

## 十、硬科技项目国金清单

提交前对照：

- [ ] 封面有具体定位，不是空泛口号
- [ ] P2 有一页四宫格亮点页
- [ ] 项目缘起用时间线，有院士/专家参与
- [ ] 行业背景有三件套：规模、份额、场景
- [ ] 痛点和解决方案一一对应
- [ ] 每个核心技术都有对比数据
- [ ] 有第三方检测报告/认证证书
- [ ] 商业模式有产业链图和四阶段生产计划
- [ ] 有国际竞品对标表
- [ ] 团队负责人有 SCI/专利/国家级项目
- [ ] 有院士/专家顾问和专家评价
- [ ] 教育维度有奖项/专利/升学数据
- [ ] 社会价值有国产替代/国家安全叙事
- [ ] 战略规划有市场占有率目标
- [ ] 结尾回到封面/国家战略，形成闭环
