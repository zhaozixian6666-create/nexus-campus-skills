# PPT维度总览

> **30-35页PPT是评委对你的第一印象。它不是好看就行——每一页都有自己的"说服任务"。**

---

## PPT三大工作模块

```
PPT制作 = 逻辑梳理（40%） + 板块设计（40%） + 视觉制作（20%）
```

| 模块 | 解决什么问题 | 入口 |
|------|-------------|------|
| **01_全局逻辑** | 这30-35页按什么顺序讲？故事线怎么走？ | [[01_全局逻辑/30-35页标准结构]] |
| **02_核心板块设计** | 每一页/每个板块怎么写？ | [[创赛板块索引]] |
| **03_制作规范** | 配色/字体/排版/数据图怎么做？ | 视觉设计原则（未建） |

---

## 标准30页结构速览

| 页码 | 板块 | 说服任务 |
|------|------|---------|
| 1 | 封面 | 0.5秒记住项目名+一句话定位 |
| 2-3 | 项目故事 | 制造情感共鸣，让评委"想听下去" |
| 4-5 | 项目缘起 | 回答"为什么你要做这件事" |
| 6-8 | 行业+市场+政策背景 | 证明赛道足够大、政策足够支持 |
| 9-12 | 痛点分析 | 证明问题真实存在、且足够痛 |
| 13-18 | 解决方案 | 证明你的方案能解决、且比别人好 |
| 19-21 | 竞品分析 | 证明你不是在自说自话 |
| 22-23 | 商业模式 | 证明这个事能持续、能赚钱 |
| 24-25 | 团队介绍 | 证明这群人能把事做成 |
| 26-27 | 财务与规划 | 证明你有清晰的路线图 |
| 28-29 | 社会价值/愿景 | 给评委一个"给你高分"的理由 |
| 30 | 结尾/封底 | 留下记忆点 |

---

## ⚠️ 三大致命错误

1. **每页塞太多信息**——评委 30 秒翻完，信息过载 = 什么都没记住
2. **板块跳跃**——从痛点突然跳到团队，逻辑链断了，评委困惑
3. **没有"一句总结"**——每页都应该有一句话结论，评委只记结论不记细节
