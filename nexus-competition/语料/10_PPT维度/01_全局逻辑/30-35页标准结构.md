# 30-35页标准结构

> **国奖PPT不是30页铁板一块。硬科技、社会价值、文化创意类项目往往35页+。这里给出两套可参照的结构。**

---

## 通用结构（30页左右）

```
第一幕（P1-5）  ：我是谁、我看到了什么问题
第二幕（P6-23） ：这问题有多严重、我怎么做、为什么我行
第三幕（P24-30）：我能走多远、你该给我高分
```

| 页码 | 板块 | 核心任务 | 黄金法则 |
|------|------|---------|---------|
| 1 | 封面 | 0.5秒记住你 | 一句话说清定位 |
| 2-3 | 项目故事/缘起 | 建立信任感 | 问题先行或情怀先行 |
| 4-5 | 背景（政策/行业/市场） | 证明赛道对 | 数据+政策双支撑 |
| 6-8 | 背景展开 | 同上 | 同上 |
| 9-12 | 痛点分析 | 问题真实且痛 | 图片+数据 |
| 13-18 | 解决方案 | 我能解决 | 原理→产品→效果 |
| 19-21 | 竞品分析 | 我比他们都好 | 全维度对比表 |
| 22-23 | 商业模式 | 能持续赚钱 | 清晰画出产业链和收入来源 |
| 24-25 | 团队介绍 | 这群人行 | 突出匹配度 |
| 26-27 | 财务规划/发展规划 | 想清楚了 | 3-5年路线图 |
| 28-29 | 社会价值 | 值得给高分 | 数字+情怀 |
| 30 | 结尾 | 记住我 | 回到问题，形成闭环 |

---

## 硬科技/B2B/创业组结构（35页+）⭐

从 **“锰”寐以“球”**（2024国金，高职赛道创业组）拆解：

| 页码 | 板块 | 说明 |
|------|------|------|
| 1 | 封面 | 项目名+赛道+公司+负责人 |
| 2 | 公司/团队简介 | 创业组项目先立企业资质 |
| 3-5 | 市场+政策+需求 | 三板斧快速建立赛道认知 |
| 6 | 痛点分析 | 三个痛点，配图+数据 |
| 7 | 实践历程 | 企业发展时间线+真实照片 |
| 8-11 | 技术与解决方案 | 流程图→三个创新点→数据对比 |
| 12 | 技术壁垒 | 专利、认证、软著墙 |
| 13 | 竞品分析 | 8维度碾压表 |
| 14-15 | 商业模式 | 产业链图+三种变现模式 |
| 16-18 | 案例示范 | 三个客户案例，对应三种模式 |
| 19 | 市场推广 | 获客渠道 |
| 20-22 | 财务数据 | 历史报表+未来预测 |
| 23-26 | 团队介绍 | 负责人+成员+顾问+导师（4页） |
| 27-28 | 教育维度 | 学校支持、专创融合 |
| 29-30 | 社会价值 | 就业+生态效益 |
| 31 | 结尾 | 愿景升华 |
| 32-35 | 证明材料 | 财务、专利、客户、营业执照 |

### 硬科技项目的叙事特点

1. **公司/资质先行**：创业组项目先证明“我们是一家真实企业”
2. **痛点用数据说话**：不讲故事，讲行业损失
3. **解决方案用三段式**：工艺流程图 → 创新点拆解 → 对比数据
4. **案例必须三有**：有合同、有现场、有数据
5. **团队企业化**：成员分技术研发/商务管理/设施工程三类，配行业顾问和法律顾问
6. **教育维度和社会价值**：国创赛特有加分项，独立成页

## 选择结构的判断标准

| 你的项目类型 | 推荐页数 | 结构特点 |
|-------------|---------|---------|
| 概念期/早期项目 | 25-30页 | 故事先行、逻辑紧凑 |
| 创业组/已有公司 | 35页+ | 公司先行、案例密集、团队企业化 |
| 社会价值/红旅 | 30-35页 | 故事+政策+社会价值占较大比重 |
| 硬科技/B2B | 35页+ | 数据密集、技术拆解、竞品对比 |
| 文化创意/消费 | 25-30页 | 故事+设计+用户反馈 |

---

## 逻辑链自检清单

每两页之间必须有逻辑衔接。判断方式：上一页的最后一句和下一页的第一句能不能接上。

```
P1 封面 → 你看到了一个巨大的问题
P2-3 → 我（或这个行业）正在经历什么
P4-5 → 这痛苦来自政策/行业/市场的真实变化
P6-8 → 你以为这是个例？看数据，整个行业都这样
P9-12 → 具体来说，这群人正被这3个问题折磨
P13-18 → 我能解决它，这是原理、这是产品、这是效果
P19-21 → 你可能觉得别人也能做？来，我告诉你为什么只有我能
P22-23 → 而且我已经想好怎么持续做下去
P24-25 → 这群人就是能把这件事做成的人
P26-27 → 我们有清晰的路线图
P28-29 → 做成之后，不止我们受益
P30 → 回到开头那个问题——我们已经改变了它
```
