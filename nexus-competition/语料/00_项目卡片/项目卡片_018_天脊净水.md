# 项目卡片_018：天脊净水—守护藏地"亚洲水塔"的生态轻骑兵

---

## 📋 基本信息

| 维度 | 内容 |
|------|------|
| 赛道 | 青年红色筑梦之旅赛道·创意组 |
| 学校 | 南京林业大学 + 西藏大学 |
| 一句话定位 | 守护藏地"亚洲水塔"的生态轻骑兵，解决西藏农村生活污水处理难题 |

---

## 🎯 核心要素

### 项目起源
- 2020年7月：雅鲁藏布江水科考途中发现水污染问题
- 2022年3月：西藏农村生活污水调研
- 2022年11月：与西藏大学联合组队
- 2023年7月：完成中试设备研发
- 2024-2025年：第一/二/三代设备落地，成立公司，与龙头企业签署订单

### 项目历程
| 时间 | 里程碑 |
|------|--------|
| 2020.7 | 发现雅鲁藏布江水污染问题 |
| 2022.3 | 西藏农村生活污水调研 |
| 2022.11 | 与西藏大学联合组队 |
| 2023.7 | 完成中试设备研发 |
| 2024.5 | 第一代设备落地 |
| 2024.8 | 第二代设备落地 |
| 2025.5 | 第三代设备落地、政府部门肯定 |
| 2025.6 | 成立公司实现运营 |
| 2025.7 | 与龙头企业签署订单 |

### 平台支撑
- 林业工程学科
- 高分子科学全球第1位
- 林木生物质低碳高效利用国家工程研究中心
- 中国科学院青藏高原雅鲁藏布江生态项目
- 国家青藏高原水生态项目
