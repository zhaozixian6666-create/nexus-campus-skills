# 项目卡片模板

> **每拿一个国奖项目，就填一张。多张卡片叠在一起，规律自己长出来。**

---

```markdown
# 项目卡片_{编号}：{项目名称}

日期：YYYY-MM-DD | 来源：{PPT文件 / BP文件 / 视频文件}

---

## 📋 基本信息

| 维度 | 内容 |
|------|------|
| 比赛 | 互联网+ / 挑战杯 / 创青春 / 三创赛 / 其他 |
| 年份 + 奖项 | 2024 国赛金奖 |
| 赛道 | 高教主赛道 / 红旅 / 职教 / 产业命题 |
| 学校 | XX大学 |
| 团队规模 | X人 |
| 一句话定位 | （用一句话说清做什么、为什么、怎么不一样） |

---

## 🎯 核心要素拆解

### 解决的问题
（用 3 句话以内说清用户真正的痛点）

### 解决方案
（核心产品/服务是什么，和竞品有什么本质差异）

### 目标用户
（具体画像：谁、在哪、什么场景、付费意愿）

### 商业模式
（怎么赚钱/怎么持续）

### 核心壁垒
（技术？资源？模式？先发优势？）

---
```
