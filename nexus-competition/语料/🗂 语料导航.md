# 🗂 语料导航

> 一批获奖材料被拆成同一套维度之后的结果。**用来对照，不用来抄。**

---

## 一、这一层装什么

| 目录 | 装什么 | 什么场景取 |
|---|---|---|
| `00_项目卡片/` | 单个项目拆成一张标准卡：解决的什么问题、方案、商业模式、团队、财务、PPT 结构 | 「我这个项目和拿奖的差在哪」 |
| `10_PPT维度/` | 30–35 页怎么排、每页放什么、逻辑线怎么走 | 「PPT 结构对不对」 |
| `20_BP维度/` | 80–100 页的章节体系、每章写什么 | 「BP 缺哪一章」 |
| `30_视频维度/` | 1–3 分钟脚本、拍摄、后期 | 「路演视频怎么拍」 |
| `40_对标矩阵/` | 多个项目摆在一起比，看共性与差异 | 「我这类的项目普遍怎么打」 |
| `60_模拟评审/` | 评委真问过的问题库、模拟答辩流程、提交前自查 | 「答辩会被问什么」 |
| `规律提炼/` | 跨项目总结出来的设计要点，按赛道和项目类型分 | 「哪些做法反复出现」 |

**三层递进**：

```
单个项目 → 项目卡片（原子化）
              ↓ 多个项目横向比
          对标矩阵 + 跨项目规律（方法论）
              ↓ 拿来对照自己的项目
          诊断与改法（回赛事模块出结论）
```

## 二、怎么取

| 他问的是 | 取什么 |
|---|---|
| 「我这项目跟拿奖的差在哪」 | `00_项目卡片/` 里同类的卡片，看每一项写到什么颗粒度 |
| 「PPT 结构对不对」 | `10_PPT维度/`，比页数结构与板块顺序 |
| 「BP 缺哪一章」 | `20_BP维度/`，比章节体系 |
| 「答辩会被问什么」 | `60_模拟评审/`，按类过一遍，不背答案 |
| 「我这类的项目普遍怎么打」 | `规律提炼/` 里对应赛道那一份 |
| 「路演视频怎么拍」 | `30_视频维度/` |
| 递来项目 PPT / BP 问「哪里要改」「第一页怎么改」 | `../competitions/01_创新大赛/项目诊断流程.md` + `../competitions/01_创新大赛/页级改法映射表.md` | 逐页给改到什么程度 |
| 「帮我模拟打分」 | `../competitions/01_创新大赛/参考标准评分表.md` + `60_模拟评审/` | 按参考标准给训练用参考分 |

**找项目**：先看 `00_项目卡片/` 下三份索引（按国金、省市冠军、红旅与农业等分组），定位到卡片再读。

## 三、三条规矩

1. **比对，不照抄。** 取一张卡片是为了知道「这一项该写到多细」，不是把别人写的内容搬过来。
2. **取完必须回来判断。** 语料只提供对照物，结论仍然在赛事模块里出，别变成「别人这样我也这样」。
3. **对外只说做法，不报项目名。** 给建议时讲「某类项目在团队页会放三类人」，不讲「某某项目就是这么干的」。

## 四、和赛事模块的关系

这七块目录**不给结论**，只给对照物。

判断在哪出：`competitions/` 下对应赛事的模块——先问是什么竞赛，再走行动指南、建议、知识库、材料骨架。语料是在那之后用来校准颗粒度的。

**创新大赛已把这条链子接实**：`../competitions/01_创新大赛/项目诊断流程.md` 第 4 步会按项目类型回取本层的 `40_对标矩阵/国金项目共性规律.md`、`规律提炼/` 对应专项、`00_项目卡片/` 同类卡片；第 3 步逐页改法回取 `10_PPT维度/02_核心板块设计/`；第 6 步模拟评审回取 `60_模拟评审/`。**取用仍守上面三条规矩。**

## 五、自己往下加

新拆一个项目，照 `00_项目卡片/项目卡片模板` 填一张，放进 `00_项目卡片/`；同类项目到五份以上，再填 `40_对标矩阵/` 提炼共性。

卡片里只写项目本身的公开信息（项目名、赛道、组别、方案与数据），**不写个人姓名与联系方式**。
