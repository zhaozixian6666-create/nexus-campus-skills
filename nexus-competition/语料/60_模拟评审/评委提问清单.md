# 评委提问清单 · 提交前自查

> **比赛前，把这份清单的每一项都准备好，答辩时就能从容应对。**

---

## 一、项目基本信息类

- [ ] 项目一句话定位是什么？
- [ ] 项目解决了什么具体问题？
- [ ] 目标用户是谁？用户画像清晰吗？
- [ ] 项目的核心产品/服务是什么？
- [ ] 项目目前处于什么阶段？

---

## 二、技术与创新类

- [ ] 核心技术是什么？一句话说清
- [ ] 技术创新点在哪里？
- [ ] 有没有专利？专利归属清晰吗？
- [ ] 与现有技术/产品相比，优势是什么？
- [ ] 技术成熟度如何？是否经过验证？
- [ ] 是否有第三方检测报告？
- [ ] 技术壁垒在哪里？别人能不能复制？
- [ ] 技术来源是哪里？是否完全自主创新？
- [ ] 核心参数是什么？数据可信吗？
- [ ] 技术是否可迁移到其他领域？

---

## 三、商业模式类

- [ ] 怎么赚钱？收入来源有哪些？
- [ ] 客单价是多少？
- [ ] 目标客户是谁？
- [ ] 获客渠道是什么？
- [ ] 成本结构是什么？
- [ ] 毛利率/净利率是多少？
- [ ] 是否已经有真实收入？
- [ ] 是否已经有付费客户？
- [ ] 商业模式是否可持续？
- [ ] 是否依赖单一客户或单一渠道？

---

## 四、市场与竞品类

- [ ] 市场总规模是多少？
- [ ] 目标市场占比是多少？
- [ ] 市场增速如何？
- [ ] 主要竞争对手是谁？
- [ ] 竞争对手的市场份额是多少？
- [ ] 与竞争对手相比，差异化优势是什么？
- [ ] 为什么客户选择你而不是竞争对手？
- [ ] 是否做过市场调研？
- [ ] 调研数据是否可靠？
- [ ] 市场准入壁垒是什么？

---

## 五、团队与运营类

- [ ] 团队核心成员有哪些？
- [ ] 每个成员的分工是什么？
- [ ] 团队负责人有什么背景？
- [ ] 团队是否有相关经验？
- [ ] 股权结构是什么？
- [ ] 是否有指导老师/顾问？
- [ ] 顾问具体贡献什么？
- [ ] 团队是否全职投入？
- [ ] 团队短板是什么？如何弥补？
- [ ] 团队成员毕业后是否继续项目？

---

## 六、财务数据类

- [ ] 是否有财务报表？
- [ ] 收入来源是否清晰？
- [ ] 成本构成是否清晰？
- [ ] 是否盈利？
- [ ] 何时能盈利？
- [ ] 是否有融资？融资金额和用途？
- [ ] 估值依据是什么？
- [ ] 现金流是否健康？
- [ ] 盈亏平衡点是多少？
- [ ] 财务预测依据是什么？

---

## 七、产品落地类

- [ ] 产品是否做出来？
- [ ] 是否有原型/MVP？
- [ ] 是否有实际案例？
- [ ] 案例是否真实？
- [ ] 是否有客户反馈？
- [ ] 产品是否量产？
- [ ] 供应链是否稳定？
- [ ] 生产周期多长？
- [ ] 良品率多少？
- [ ] 售后服务如何？

---

## 八、社会价值与教育类

- [ ] 项目的社会意义是什么？
- [ ] 受益人群是谁？
- [ ] 是否带动就业？
- [ ] 是否有生态效益？
- [ ] 项目如何育人？
- [ ] 学生获得了哪些成长？
- [ ] 是否有课程/实践平台？
- [ ] 是否产学研结合？
- [ ] 项目是否可复制推广？
- [ ] 公益性和商业性如何平衡？

---

## 九、风险与合规类

- [ ] 是否注册公司？
- [ ] 法律主体是什么？
- [ ] 是否取得必要资质？
- [ ] 知识产权是否清晰？
- [ ] 是否有政策风险？
- [ ] 是否有法律风险？
- [ ] 是否有数据安全风险？
- [ ] 是否有食品安全/环保风险？
- [ ] 是否有应急预案？
- [ ] 是否做过风险评估？

---

## 十、现场表现类

- [ ] 路演时间是否控制在5分钟内？
- [ ] 每页PPT是否有一句话结论？
- [ ] 数据是否标注来源？
- [ ] 佐证材料是否准备齐全？
- [ ] 是否准备纸质版材料？
- [ ] 是否预演过答辩？
- [ ] 是否准备可能被追问的回答？
- [ ] 是否熟悉项目的每一个数字？
- [ ] 是否有团队成员能回答技术细节？
- [ ] 是否保持自信、真诚的态度？

---

> 如果以上清单有 5 项以上没准备好，说明你的答辩准备还不够。
