# 04 · 共用判断集（赛事无关的五个判断）

> 这五条不管打哪个赛都一样。每条五字段：**判断 / 判定标准 / 归属 / 反例 / 材料不足怎么办**。
> 全部是**判断**，对外只说「这是我的判断」，不说成规定。

---

## 判断 1 · 队怎么组：先定位置，再找人

- **判断**：队长的质量决定上限，队友的质量决定下限。**先定位置再找人**；反过来（先凑人，再想谁干什么）是队伍散掉的头号原因
- **判定标准**：四个位置都有明确的人，且**每个位置都有人**：

| 位 | 干什么 |
|---|---|
| 拍板的 | 出分歧能定，不是投票 |
| 出技术的 | 核心方案是他想出来的，不是他搜出来的 |
| 写材料的 | 能把技术翻译成人话 |
| 上台讲的 | 答辩不怯场，能接住追问 |

  一人可以占两个位，但**不能四个位都是一个人**（抗不了变故），也**不能四个位都空着**（谁都在等别人先动）
- **反例**：① 全是技术大牛没人会讲——材料写得像论文；② 全是大佬没人干活；③ 跨年级组队且高年级只挂名——评委会问「这个项目谁做的」
- **材料不足**：不知道项目类型 → 分技术型／商业型问一句。技术型必须先有技术位，商业型可以先有场景位

## 判断 2 · 没有核心技术怎么办：换赛道或换位置，不是硬上

- **判断**：没有核心技术不是不能上，是**必须换赛道或换位置**。硬科技赛道没技术硬上，是必输的局
- **判定标准**：能说出「我在队里贡献什么别人替代不了的」。答得出来就上，答不出来就是挂名——挂名的分通常被排名权重摊薄，且简历上说不清
- **三条合法路径**：
  1. **换赛道**：走应用／商业／红旅／公益／文创，评委看场景和数据，不是参数
  2. **换位置**：占商业位（市场、模式、财务）／材料位（BP、PPT、视频）／答辩位
  3. **换队伍**：去找有技术的人，你带场景或资源进去——**「我能拿到什么场景」本身就是稀缺资源**
- **反例**：① 硬科技赛道讲「我们用了 AI」但没自研成分，一问就穿；② 挂名第五人还想靠这个保研——先查本校排名权重
- **材料不足**：问一句「你会什么、认识谁」，从答案里找位置。两样都没有，直接建议先去实验室或先补一项技能，别现在打

## 判断 3 · 材料怎么做才过：每页都能回答「所以呢」

- **判断**：评委在材料里只找三件事——**问题真不真、方案能不能落地、数据撑不撑得住**。技术多先进是第四位的事
- **判定标准**：每一页都能回答「所以呢」。答不出的页，是给自己看的，不是给评委看的
- **标准结构（页数按赛事要求调）**：

| 页 | 要回答 | 最常见的错 |
|---|---|---|
| 1 封面 | 一句话说清做什么 | 只有项目名，看不出做什么 |
| 2 痛点 | 谁在什么场景下痛、痛到什么程度 | 张口「市场规模千亿」，没有一个人物 |
| 3 方案 | 怎么解决、跟现有做法差在哪 | 讲技术原理，不讲用户得到什么 |
| 4 壁垒 | 别人为什么做不出来／追不上 | 「我们团队很努力」不算壁垒 |
| 5 数据 | 验证到哪一步（用户、订单、测试、专利） | 全是预测，没有一条实测 |
| 6 团队 | 为什么是你们做这件事 | 只列学历奖项，不说跟项目的关系 |
| 7 财务／规划 | 钱怎么花、下一阶段验证什么 | 三年预测编得很细，第一阶段没有 |
| 8 社会价值 | 除了赚钱还有什么意义 | 红旅／公益类缺这页直接扣分 |

- **反例**：① 第一页就是技术架构图——评委还没被说服「这事值得做」；② 数据全是「预计」「有望」——等于没有数据；③ 团队页写满荣誉——评委只想知道谁真正做过这件事
- **材料不足**：没看到材料 → **让他发一页**（最好是痛点页或数据页），一页就能看出整份的水平。不给材料就只给结构，不评价

## 判断 4 · 答辩会被问什么：八成在问「你凭什么」

- **判断**：评委问的问题里，八成是「你凭什么」，两成是「你怎么做」。多数人把八成时间花在准备后两成
- **判定标准**：每个问题能在 30 秒内答完，且**不躲**。躲的表现：反问、讲背景、说「这个我们后续会考虑」
- **高频清单（按被问概率排）**：

| 问的 | 实际在问 | 该怎么答 |
|---|---|---|
| 这个东西真的有人要吗 | 需求是不是你编的 | 给一个具体的人、一次具体的使用或付费 |
| 别人为什么做不了 | 壁垒在哪 | 给一个技术点／资源／时间窗口，别给「团队努力」 |
| 数据哪来的 | 是不是编的 | 说清样本量、时间、怎么测的，**测不出来就说测不出来** |
| 团队能不能撑住 | 会不会做完就散 | 谁全职、谁负责哪块、毕业了怎么办 |
| 钱怎么花 | 会不会乱花 | 按阶段给，别给一张三年表 |
| 跟别人有什么区别 | 有没有真调研过竞品 | 说清强在哪一项，**承认不如的地方** |
| 你这个技术我不太懂 | 能不能讲人话 | 一句比喻说清，别背术语 |

- **反例**：① 背稿——一追问就断；② 答非所问；③ 过度防御——一提缺点就急着解释，越解释越像有问题
- **材料不足**：不知道他的项目 → 只给问题清单，让他自己标「哪个我答不上来」，那几个就是他要改的材料

## 判断 5 · 没拿奖怎么算：奖只是五样产出里的一样

- **判断**：把奖当唯一产出，是这趟亏掉的真正原因。**至少五样产出：能力、作品、人、认知、奖。** 拿不到奖但拿到另外三样，这趟不算亏
- **判定标准**：赛后能说出「下次能直接复用什么」——一份能改的 BP、一个能带的队友、一条被评委点破的认知。说得出来就有沉淀，说不出来就是纯消耗
- **反例**：① 拿奖了但队散了、材料没留——这趟其实也亏，只是看不出来；② 没拿奖就否定自己——**评审是一次采样，不是能力评估**
- **材料不足**：不知道赛果 → 不用问。直接按「无论结果如何，这五样至少带走三样」给复盘清单

> 补一句边界：在校期间犯一个便宜错的代价最低。**现在做砸，损失的是一学期；三年后同样的错，损失的是三年。**

## 常见误判总表

| 学生以为 | 实际 |
|---|---|
| 含金量看名字大不大 | 看本校认不认、认多少分 |
| 拿个省奖也有用 | 省奖在不少学校接近零，国奖和国二之间可能差一倍 |
| 先报名边打边想做什么 | 赛道不对改不了，只能硬做 |
| 技术越硬越容易拿奖 | 评委常看不懂技术，看得懂的是「这东西谁在用」 |
| 队伍人越多越好 | 超过 5 人协调成本爆炸，且排名权重被摊薄 |
| 材料写得越全越好 | 评委看材料是筛不是读，第一页没打中就直接降档 |
| 答辩要显得什么都会 | 承认「这块还没验证」比硬答加分 |
| 没拿奖就是白打 | 白打的是「没留下任何可复用东西」的那种 |
